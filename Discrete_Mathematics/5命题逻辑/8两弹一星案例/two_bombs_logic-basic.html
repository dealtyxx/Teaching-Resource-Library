关键判断符号化

命题变元 / 必要条件 / 逆否命题

低门槛 · 建立直觉

🎯 把关键判断符号化为蕴含式，并辨析逆否命题。

关联词 → 公式
p → q只要 p，就 q（p 是 q 的充分条件）
q → p只有 p，才 q（p 是 q 的必要条件）
¬p → q除非 p，否则 q
¬q → ¬pp → q 的逆否命题，与原命题等价
q → p逆命题；否命题 ¬p → ¬q。二者都不与原命题等价
MP / MTp→q, p ⇒ q；p→q, ¬q ⇒ ¬p

符号化 · 逆否辨析
1情境背景 · 两弹一星关键时间节点

1955 年，中央作出发展原子能事业的战略决策；20 世纪 60 年代初，外部技术援助中断，我国科技工作者坚持自力更生、艰苦奋斗，在较短时间内突破了核弹、导弹和人造卫星等尖端技术。

  1. 1964-10-16我国第一颗原子弹爆炸成功。
  2. 1966-10-27导弹核武器试验（“两弹结合”）成功。
  3. 1967-06-17我国第一颗氢弹爆炸成功，距第一颗原子弹爆炸约 2 年 8 个月。
  4. 1970-04-24我国第一颗人造地球卫星“东方红一号”发射成功。
  5. 1999-09-18中共中央、国务院、中央军委表彰 23 位“两弹一星”功勋科学家（其中 7 位为追授）。

“两弹一星”最初指原子弹、导弹和人造卫星；后来“两弹”也泛指核弹（原子弹、氢弹）和导弹。

5价值引领 · 必要条件里的自立自强

把“只有坚持自力更生，才能保障国家安全”符号化为 S → P，自力更生处在必要条件的位置：它并不单独保证成功（逆命题 P → S 不能由此推出），但缺了它就无从谈起（逆否命题 ¬P → ¬S）。

外部技术援助中断之后，老一辈科学家正是靠自己的力量攻克了核弹、导弹和卫星的关键技术。今天说“关键核心技术要牢牢掌握在自己手中”，强调的也是这个必要条件——分清“必要”与“充分”，既不妄自菲薄，也不以为有了自主就万事大吉。

热爱祖国、无私奉献自力更生、艰苦奋斗大力协同、勇于登攀

“两弹一星”精神：热爱祖国、无私奉献，自力更生、艰苦奋斗，大力协同、勇于登攀。
