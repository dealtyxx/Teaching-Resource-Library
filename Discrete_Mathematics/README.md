# 离散数学课程资源库 · 课程思政

> 湖南信息学院 · 计算机科学与工程 — 将离散数学的严谨数理训练与家国情怀、科学精神、创新意识相融合的交互式教学资源库。

🔗 **在线访问**：<https://dealtyxx.github.io/Teaching-Resource-Library/Discrete_Mathematics/>

## 项目简介

以红金玻璃化交互页面串联 **11 章知识体系**，把计数、集合、关系、逻辑、图论与代数系统转化为可操作、可推理、可迁移的学习案例。每个知识单元按 **三阶层次** 组织：

| 层次 | 定位 | 适用场景 |
|------|------|----------|
| **基础层** | 建立概念直觉，完成对象抽取、符号化与第一步建模 | 课前预习、课堂导入 |
| **进阶层** | 围绕核心算法、推理链与可视化反馈展开互动演示 | 课堂讲解、动手探索 |
| **拓展层** | 迁移到工程系统、文化数字化、智能应用与综合案例 | 项目实践、思政延展 |

**规模**：11 章 · 122 个知识单元（其中 43 个为应用案例）· 366 个三阶案例页 · 6 大课程思政核心理念。

## 主要特性

- **三阶递进教学**：每节配 `basic / 进阶 / extend` 三个层次页面，难度与思政深度逐级递进。
- **交互可视化**：图论最短路、欧拉/哈密顿图、群与同构、纠错码等以 SVG/Canvas 实时演示。
- **课程思政融入**：两弹一星、北斗导航、湖湘织锦、非遗数字化等本土案例贯穿数理推理。
- **统一导航**：每个小节页左下角有「上一节 · 目录 · 下一节」导航坞（保持当前所在层），目录抽屉可筛选 11 章 122 个小节并直达任一层；主页每个小节旁有「基 / 进 / 拓」三个直达按钮。
- **学习足迹**：已访问的小节与层在目录、主页中高亮，仅保存在浏览器 localStorage（`dm_visited_v1`），不上传任何数据。
- **主页搜索与筛选**：输入即搜（可按 `/` 聚焦），支持按知识领域筛选与「仅看案例」，无结果时给出提示，不再弹窗。
- **数学公式渲染**：MathJax 按需懒加载，无公式页面零开销；纯文本上下标自动归一化。
- **AI 学习助手**：内置悬浮坞式助手（BYO-key，密钥仅存浏览器 localStorage，直连大模型，不经任何第三方服务器）。
- **响应式自适配**：内容感知的整页缩放，兼顾不同分辨率首屏观感；移动端独立响应式。
- **社交分享就绪**：全站 Open Graph / Twitter Card / canonical 元数据 + 品牌分享封面，每页标题、描述按「编号 · 层次：层名」自动生成。

## 统一约定

全站的编号、名称与案例标记只在一个地方定义：`../tools/dm/catalog.py`。

- **小节编号**：`章.节`（第 1 章为 `1.1.1` 三级编号）。同一小节含多个分部时编号相同、分部名不同（如 `8.6 生成树 · 搜索生成树 / 最小生成树`）。
- **案例命名**：所有应用案例小节统一以「案例」结尾，并在面包屑、目录、主页上带「案例」徽标，同时启用「能力雷达」。案例页的 `SECTION_META.title` 统一为「〈领域〉应用 · 〈主题〉」。
- **页面标题**：`编号 小节名 · 层次：层名 | 离散数学课程资源库`，如 `7.1 图的基本概念 · 进阶层：关联与相邻 | 离散数学课程资源库`。
- **共享资源**：所有页面统一引用 `shared/discrete-ui.css`、`mathjax-auto.js`、`ai-tutor.js`、`site-shell.js`，并带同一个版本号 `?v=`。

## 目录结构

```
Discrete_Mathematics/
├─ index.html                 # 课程资源库主页（章节导航 / 搜索 / 思政理念；目录区块由脚本生成）
├─ 1计数基础与数论基础/ … 11环、域、格和布尔代数/   # 11 章，按 小节/ 组织三阶页面
└─ shared/                    # 全站共享资源
   ├─ discrete-ui.css         # 统一视觉与组件样式
   ├─ site-shell.js           # 统一外壳：面包屑、返回主页浮标、导航坞、目录抽屉、学习足迹
   ├─ catalog.js              # 课程目录数据（由 tools/dm/apply_catalog.py 生成，勿手改）
   ├─ ai-tutor.js             # 学习助手（BYO-key）
   ├─ mathjax-auto.js         # MathJax 按需加载 + 整页自适配缩放
   ├─ auto-superscript.js     # 纯文本上/下标自动渲染
   ├─ favicon.svg             # 站点图标（图节点 motif）
   └─ og-cover.png            # 社交分享封面（1200×630）
tools/dm/                     # 维护脚本（仅开发时使用，站点运行不依赖）
├─ catalog.py                 # 统一课程目录：编号、名称、案例标记、三阶页面路径
├─ apply_catalog.py           # 批量规范页面元数据、生成 catalog.js 与主页目录
├─ build_home.py              # 主页目录区块与脚本的生成器
└─ extract_meta.js            # 读取各页 SECTION_META（供 apply_catalog.py 调用）
```

## 维护指南

新增或改名小节后，在 `tools/dm/catalog.py` 中登记（编号、名称、是否案例、主页面路径，层页面沿用 `-basic / -extend` 命名），然后在仓库根目录运行：

```bash
python3 tools/dm/apply_catalog.py           # 统一各页 <title>/OG/canonical、SECTION_META、共享资源引用，并重新生成主页目录
python3 tools/dm/apply_catalog.py --check   # 仅检查是否已规范（有差异时退出码为 1，可放进 CI）
```

脚本可重复运行（幂等）。修改 `shared/` 下的 css/js 后，把 `apply_catalog.py` 里的 `VERSION` 递增再运行一次，即可让浏览器拉取新版本。部署域名变化时修改 `catalog.py` 中的 `BASE_URL`。需要 Python 3 与 Node.js（仅开发时）。

## 技术栈

纯静态站点：HTML5 + 原生 CSS/JavaScript，站点运行无构建步骤、无重型依赖。公式渲染用 MathJax 3（CDN 按需加载），字体用 Google Fonts，访问统计用不蒜子。可直接部署到 GitHub Pages 或任意静态服务器。
