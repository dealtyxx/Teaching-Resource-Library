二元关系 R 就是 A×B 的一个子集：从「一切可能的有序对」中，挑出真实存在的联系。
同一个 R 有三种等价的工程形态：0-1 矩阵（邻接矩阵）、二部图的边集、两列的数据表（关系数据库中的一张表）。
定义域 dom R = 出现在第一分量的元素；值域 ran R = 出现在第二分量的元素。
|R| = 0|A×B| = 16 密度 = 0%关系总数 = 2^16 dom R = ∅ ran R = ∅
