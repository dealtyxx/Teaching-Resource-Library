Rⁿ / 恰好 n 步可达 / 布尔幂

R¹

初始阶段

R¹ 代表直接的影响力。思想的火种刚刚点燃，开始照亮周围。

R¹ = R，Rⁿ⁺¹ = Rⁿ∘R，规定 R⁰ = IA。(x, y) ∈ Rⁿ ⇔ 关系图中有从 x 到 y 恰好 n 步的通路；MRⁿ 是 MR 的 n 次布尔幂。
A 有限时幂序列最终循环；R ∪ R² ∪ … ∪ Rⁿ 表示 n 步以内可达。
本页是 3.4 二元关系的运算的专项练习页，系统学习请进入上方三阶卡：基础层「集合运算与逆运算」、进阶层「复合运算与关系矩阵」、拓展层「关系的幂与可达」。
