R⁻¹ / 有序对反向 / 矩阵转置

当前：关系 R（向前发展）

关系 R 指向未来，象征着前人的奉献与时代的进步。

R
R⁻¹ = {(y, x) | (x, y) ∈ R}。关系图中每条边掉头；矩阵上 MR⁻¹ = MRT（转置）。
性质：(R⁻¹)⁻¹ = R；dom R⁻¹ = ran R；R 对称 ⇔ R = R⁻¹。
本页是 3.4 二元关系的运算的专项练习页，系统学习请进入上方三阶卡：基础层「集合运算与逆运算」、进阶层「复合运算与关系矩阵」、拓展层「关系的幂与可达」。

逆关系：换个方向看联系

R = {(1921, 1949), (1949, 1978), (1978, 2025)} 表示「先 → 后」的传承；R⁻¹ 把每个有序对反向，得到「后 → 先」的溯源。
