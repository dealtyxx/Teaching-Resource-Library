① R⁰ = IA，Rⁿ⁺¹ = Rⁿ∘R；Rm∘Rn = Rm+n，(Rm)n = Rmn。
② (x, y) ∈ Rⁿ ⇔ 关系图中有从 x 到 y、恰好 n 步的通路；R ∪ R² ∪ … ∪ Rⁿ 表示 n 步以内可达。
③ 周期性：A 有限时，A 上的关系只有有限个，幂序列必然出现 Rs = Rt（s < t），此后以 p = t − s 为周期循环。
④ 传递闭包预备：|A| = n 时，t(R) = R ∪ R² ∪ … ∪ Rⁿ（3.6 节详学）。
