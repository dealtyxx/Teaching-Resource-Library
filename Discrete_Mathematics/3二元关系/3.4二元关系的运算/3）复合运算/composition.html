复合运算专项练习

S∘R / 目标 → 举措 → 成果 / 布尔积

准备就绪

点击节点建立连接，或点击"实现愿景"查看复合关系的生成过程。

本页采用左复合（与函数复合 g∘f 同序）记法：S∘R = {(a, c) | ∃b：aRb 且 bSc}，即先 R 后 S，MS∘R = MR ⊙ MS。若所用教材采用右复合记法，同一关系写作 R∘S。
点击结点可高亮经过它的路径；点击矩阵格子可修改 R、S。
本页是 3.4 二元关系的运算的专项练习页，系统学习请进入上方三阶卡：基础层「集合运算与逆运算」、进阶层「复合运算与关系矩阵」、拓展层「关系的幂与可达」。

复合：从蓝图到现实

R：战略目标 → 具体举措；S：具体举措 → 现实成果。复合把目标与成果直接联系起来。

三层路径：A → B → C

A: 战略目标 → B: 具体举措 → C: 现实成果

矩阵推演（布尔积）

MS∘R = MR ⊙ MS（先 R 后 S）

MR：部署（A→B）
⊙
MS：落实（B→C）
=
MS∘R：实现（A→C）
