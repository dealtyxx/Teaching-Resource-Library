⚖️法治意识 Robots协议User-Agent

场景导入

爬虫拿到 URL 就冲？慢——先看门口的告示牌。几乎每个网站的根目录都放着一份 robots.txt（例如 https://example.com/robots.txt），用几行朴素文本宣告：哪些路径欢迎抓取、哪些谢绝来访、对哪个爬虫另有约法。它没有密码、没有防火墙，技术上拦不住任何人——但在法庭上，它是被反复引用的「行业规矩」。这一课，我们让代码替你读懂它、遵守它。

动手实验

裁判当熟了，就让标准库替你值班。urllib.robotparser 是 Python 自带的 robots 裁判，无需安装任何第三方包。真实环境里它自己上网读协议：

# 真实环境：裁判自己去读站点的 robots.txt
from urllib.robotparser import RobotFileParser

rp = RobotFileParser()
rp.set_url("https://www.example.com/robots.txt")
rp.read()                                  # 发起真实请求读取协议
print(rp.can_fetch("study-bot", "https://www.example.com/news/1.html"))

思政会客厅

⚖️法治意识· 从君子协定到裁判文书

  • Robots 协议 1994 年由工程师社区自发提出，是互联网最早的「君子协定」之一；我国司法实践普遍将其认定为内容行业公认的商业道德。
  • 违反 robots 不必然违法，但「无视告示牌 + 替代性使用他人内容」的组合，多次被法院依《反不正当竞争法》认定为不正当竞争。
  • 合规的正确姿势是写进代码：请求发出之前先 can_fetch，禁止就不抓——让程序替你守住底线，比事后解释可靠得多。
📁今日头条诉趣头条不正当竞争案2018不正当竞争

趣头条未经许可，大量抓取「今日头条」App 内的资讯内容与用户评论充实自家产品，被诉至法院。法院认为，此类无视协议约束的「搬运式」抓取实质性替代了原告产品，违背诚实信用原则和公认的商业道德。给爬虫工程师的启示很直接：抓取在技术上可行，从来不是免责理由；是否正当、是否守约，才是。

⚖️ 结果：法院认定构成不正当竞争，判决赔偿 500 万元。
