场景导入

图书馆要把馆藏目录导给一个新系统，对方甩来一个 XML 文件。你打开一看：每本书裹在一对 <book> 标签里，书号写成了标签上的「属性」，书名、作者、价格则是里面一个个「子节点」。跟 JSON 的大括号不同，XML 靠成对的尖括号标签自我描述，天生适合表达有层次的文档。今天就用 Python 标准库里的 xml.etree.ElementTree，把这棵「文档树」遍历一遍，抽出一张干净的目录，并顺手算个平均定价。

动手实验

解析 XML 记住两个动作就够了：取标签上的属性用 .get()，取子节点里的文本用 .find(标签).text。findall("book") 帮我们把每一本书遍历出来。注意价格取出来是字符串，要 float() 转成数字才能求和：

思政会客厅

💡创新思维· 标准是地基，不是枷锁

  • 正因为有 ISBN（国际标准书号，标准编号 ISO 2108）给每本书一个全球唯一身份，图书才能在不同书店、图书馆、电商系统间自由流转、互不打架。
  • XML 由 W3C 制定、图书馆界的 Dublin Core（都柏林核心）元数据标准约定字段——统一的「接口」让各方专注在其上创新，而不必反复为「怎么描述一本书」吵架。
  • 读懂标准、善用标准，把力气省下来投到真正的新点子上，这本身就是工程师的创新姿势：先站稳规范，再自由生长。

📐书同文，车同轨——数字时代版

从 ISBN 到 XML，从 Dublin Core 到机读目录 MARC，标准化把「各说各话」变成「彼此互通」。它是秩序，也是效率：没有统一规范，再好的数据也只是一座座信息孤岛。
