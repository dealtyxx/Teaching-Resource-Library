动手实验

真实环境里，礼貌三件套的标准写法如下（本机运行）：

# 真实环境的礼貌三件套（先 pip install requests）
import time
import requests

urls = ["https://jwc.example.edu/notice/2026-001.html"]   # 待抓清单

session = requests.Session()                  # Session 复用 TCP 连接，本身就在给对方减负
session.headers.update({
    "User-Agent": "campus-bot/1.0 (contact: you@campus.edu)",   # 亮明身份，可被联系
})

for url in urls:
    resp = session.get(url, timeout=(3.05, 10))   # (连接超时, 读取超时)：不死等
    print(resp.status_code, url)
    time.sleep(3)                                 # 固定间隔——深夜也不例外

思政会客厅

🧭职业伦理· 三件装备，三种教养

  • User-Agent 亮明身份是「敢署名」：匿名与伪装的心态本身就是风险信号；写上联系方式，站长有疑问能直接找到你。
  • 请求间隔是「不插队」：服务器算力是共享资源，你多占一分，正常用户就慢一分；robots 里的 Crawl-delay 优先于你自己的默认值。
  • 超时控制是「不纠缠」：拿不到响应就体面退出并记录，而不是挂着连接耗双方的资源，更不是立刻疯狂重发。

🤝社会责任· 你的对面是无数普通人

  • 教务网背后是全校的选课与成绩查询，公交接口背后是站台上等车的乘客——压垮服务器，伤害的从来不只是「网站」。
  • 单个爬虫全速跑似乎无伤大雅，规模化之后效果与拒绝服务攻击无异。工程师必须为代码的外部性负责。
  • 真正的高手先找官方渠道：开放 API、数据集下载、管理员授权——很多采集问题的最优解，根本不是「爬」。

⚖️《网络安全法》第二十七条

任何个人和组织不得从事非法侵入他人网络、干扰他人网络正常功能、窃取网络数据等危害网络安全的活动。高频轰炸把对方服务拖慢甚至拖垮，就可能落入「干扰他人网络正常功能」的范畴——限速不只是礼貌，更是法律底线。
