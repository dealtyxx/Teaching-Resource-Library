场景导入

你所在的团队接了个「智慧城市」项目：几千个温度、水位、空气传感器铺在城市各处，读数每分钟涌进来。这些数据是新基建的「神经末梢」——调度供暖、预警内涝、监测污染全靠它。可传感器会坏、会漂移、甚至会被伪造，所以采集系统不能只顾着「收」，还得一边收、一边判断「这个读数可信吗」。这一节，我们亲手搭一个最小的监控循环。

思政会客厅

🤝社会责任· 城市生命线，容不得糊弄

  • 新基建数据直接连着供暖、排涝、防灾——一个被忽略的异常读数，可能就是一次没能预警的事故。采集质量在这里等同于公共安全。
  • 「宁可误报，不可漏报」：关键场景下告警逻辑要偏保守，把判断权交给人，而不是让系统悄悄咽下异常。
  • 系统要可审计：每一次告警、每一条被丢弃的坏点都留痕，出了问题才追得到源头。

🛡️数据主权· 关键基础设施数据要自主可控

  • 城市运行数据属于重要数据，《数据安全法》第21条要求按重要程度分类分级、重点保护。
  • 关键信息基础设施在境内运营中收集、产生的重要数据，应当境内存储（《网络安全法》第37条）——不能一股脑托管到不受控的境外平台。
  • 从传感器、网关到数据库，核心链路尽量自主可控，才谈得上把城市的「数据命脉」握在自己手里。

🛡️重要数据，分级而治

《数据安全法》第21条确立数据分类分级保护制度：关系国计民生的重要数据要重点保护、境内存储、自主可控。智慧城市采集的每一条读数，既是服务市民的资源，也是必须守好的国家数据资产。
