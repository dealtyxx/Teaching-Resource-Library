点阵汉字显示（"中国"）

综合挑战 硬件趣味 ★★★★★ 约 180 分钟

学习目标：综合数组知识理解底层显示原理

二维数组位映射图形化输出

场景导入：屏幕上的”中”字从哪里来

火车站的 LED 大屏、电梯楼层显示器、单片机上的 OLED——它们显示汉字的原理惊人一致：点阵字模。

一个 16×16 的汉字 = 256 个”亮/灭” = 256 个比特 = 32 字节。C 语言的存法极其紧凑：

const uint16_t font[16];   /* 16行,每行1个uint16管16盏灯 */

第 r 行第 c 列亮不亮？一个表达式解决：

int on = (font[r] >> (15 - c)) & 1;

右移把目标位挪到最低位，& 1 把它”抠”出来——这叫位映射。本项目是模块四的收官：二维结构（16 行）、一维数组（font[16]）、嵌套循环（逐行逐列扫描）、位运算初体验，全部会师。

#include <stdio.h>
#include <stdint.h>

/* "中" 的 16×16 字模:每行1个uint16,1位=1灯 */
const uint16_t font[16] = {
    0x0180, 0x0180, 0x0180, 0x7FFE,
    0x6186, 0x6186, 0x6186, 0x6186,
    0x7FFE, 0x0180, 0x0180, 0x0180,
    0x0180, 0x0180, 0x0180, 0x0180,
};

int main(void) {
    for (int r = 0; r < 16; r++) {          /* 逐行扫描 */
        for (int c = 0; c < 16; c++) {      /* 逐位取出 */
            int on = (font[r] >> (15 - c)) & 1;
            printf(on ? "██" : "  ");
        }
        printf("\n");
    }
    return 0;
}

💡 一个汉字 = 16 行 × 16 位 = 256 个比特 = 32 字节。你手机屏上的每一个字， 本质都是这样一张"亮灭表"（现代字体是矢量的，但渲染到像素时同样归为位图）。 关键表达式 (font[r] >> (15-c)) & 1：右移把目标位挪到最低位， 按位与 1 把它"抠"出来——这是第 13 章位运算的先导。真实产品用的 HZK16 字库， 存着 8000+ 个这样的字模，等你到文件章节亲手读它。

VibeCoding 三段迭代提示

  1. 手写基础版：用给定的”中”字模数组，双层循环在控制台打出汉字（█ 与空格）。先手算一行：0x7FFE 有几位是 1？
  2. AI 优化进阶版：让 AI 实现”横向滚动显示”——每帧整体左移一列（提示：每行 (row << 1) | (row >> 15) 循环移位）。审查移出的位是丢弃还是绕回？两种效果分别是什么？
  3. 信创加固定稿版：把字模声明为 const（放 Flash 不占 RAM——嵌入式黄金习惯）；支持反显、放大 2 倍（每个比特画 2×2）；思考 8000 个汉字的 HZK16 字库占多少空间（8000×32=250KB），如何按 GB2312 区位码索引（第 12 章文件操作的伏笔）。

素养与思政

上世纪 70 年代，计算机处理不了汉字，有人断言”计算机是汉字的掘墓人”。王选院士团队用字形压缩+高速还原技术实现汉字激光照排，让”告别铅与火、迎来光与电”成为现实；GB2312 国标字库把 6763 个汉字编成整齐的区位矩阵。 你今天点亮的”中国”二字，走的正是这条路的第一步：把方块字翻译成比特，再让比特替文明发光。汉字信息化四十年，是”用自己的技术守护自己的文字”最生动的注脚。
