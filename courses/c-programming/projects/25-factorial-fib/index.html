基础必做 数学基础 ★★★ 约 60 分钟

学习目标：掌握函数的基本定义与调用

函数定义调用返回值

场景导入：给一段代码起个名字

前四个模块里，所有逻辑都挤在 main 里。计算 5! 要写一个循环，计算 8! 再抄一遍？ 函数让你给一段逻辑起名字、定接口，然后随处调用：

long long fact(int n) { ... }   /* 定义:返回类型 名字(参数表) */
long long f = fact(5);          /* 调用:传入5,接回120 */

调用的本质是控制流的跳转：程序跳进函数体执行，遇到 return 带着结果跳回调用点。参数是入口，返回值是出口——函数就是一台”值的加工机”。

💡 函数的三要素在代码里一一对应：定义（第 4 行的名字/参数/返回类型）、调用（main 里的 fact(n)——程序跳过去执行）、返回（return 把结果带回调用点）。把 n 拉到 13 以上， 看 int 版本怎么"安静地算错"——返回值的类型设计也是函数设计的一部分。

fact.c
#include <stdio.h>

/* 函数定义:名字、参数、返回值类型 */
long long fact(int n) {
    long long result = 1;
    for (int i = 2; i <= n; i++) {
        result *= i;
    }
    return result;      /* 把结果"带回"调用处 */
}

int main(void) {
    int n = 10;
    long long f = fact(n);   /* 调用:跳过去,算完跳回来 */
    printf("%d! = %lld\n", n, f);
    return 0;
}
运行结果
10! = 3628800

素养与思政

斐波那契数列的每一项都是前两项之和——没有凭空出现的数字，正如没有凭空出现的成果。从”两弹一星”到北斗组网，每一代工程师都在前人的 F(n−1) 和 F(n−2) 之上写出自己的 F(n)。 函数思维也是如此：把可靠的逻辑封装好、命好名，后人调用即可，不必重新发明。科学的积累性，就藏在”调用”这个动作里。
