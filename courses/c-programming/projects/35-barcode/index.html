条形码识别（指针扫描）

进阶选做 工业应用 ★★★★★ 约 130 分钟

学习目标：工业场景指针高效处理能力

指针移动模式匹配字符串解析

场景导入：扫码枪里的指针芭蕾

产线上每件物料都贴着条形码。扫码枪把黑白条纹转成一串 0/1，接下来就是纯指针功夫：

[起始符 11011][0][4位数字][0][4位数字][0]…[结束符 11011]

解析这种格式化字节流的工业范式是”游标指针”：

  • const char *p 是唯一的”读到哪儿了”——所有进度只看它；
  • 模式匹配开路：strncmp(p, "11011", 5) 验起始符（项目 23 的匹配思想，这次由你手动驱动）；
  • 按格式步进：读 4 位算一个数字，p += 5 跳过数据+分隔符；
  • 哨兵终止：遇到结束符停下——绝不越界狂奔。

这套”校验-步进-终止”的三拍子，同样是解析 NMEA 报文、Modbus 帧、图片文件头的通用内功。

barcode_scan.c
#include <stdio.h>
#include <string.h>

/* 返回解出的位数,-1=码制错误 */
int scan_barcode(const char *bits, char *out) {
    const char *p = bits;             /* 扫描指针 */
    if (strncmp(p, "11011", 5) != 0)
        return -1;                    /* 校验起始符 */
    p += 6;                           /* 跳过起始符+分隔 */
    int n = 0;
    while (strncmp(p, "11011", 5) != 0) {
        int val = 0;                  /* 读4位二进制 */
        for (int k = 0; k < 4; k++) {
            val = val * 2 + (*p - '0');
            p++;                      /* 指针前进1位 */
        }
        out[n++] = '0' + val;
        p++;                          /* 跳过分隔符 */
    }
    out[n] = '\0';
    return n;
}

💡 这就是指针解析的工业范式：p 是"读到哪儿了"的唯一事实—— 校验起始符（strncmp 模式匹配）→ 按格式步进（`p += 5`）→ 遇结束符停下。 项目 23 的 strstr 是"帮你找位置"，这里你亲手控制每一步位移。 想想异常防护：如果条码被撕掉一角、结束符丢了，while 会发生什么？（p 一路狂奔越界——真实扫码枪必须带长度上限。）

VibeCoding 三段迭代提示

  1. 手写基础版：实现 scan_barcode，解出 5 位物料号。先在纸上标出 p 在每个阶段应停的位置。
  2. AI 优化进阶版：让 AI 增加”奇偶校验位”（每个数字后跟 1 位，使 5 位中 1 的个数为偶）。审查它读校验位后 p 的步进量改对了没——格式变了，所有偏移都要联动。
  3. 信创加固定稿版：加”最大扫描长度”护栏（残码防越界——p 与 end 哨兵比较，项目 32 的安全遍历落地）；错误码区分：-1 起始符错 / -2 数字段非法 / -3 超长未见结束符。

素养与思政

《产品质量法》与国家”一物一码”追溯体系，让一支疫苗、一包奶粉都能扫码溯源——从原料批次到运输温控，链条上的每个环节都被编码进那几毫米宽的条纹。 你写的解析器每天在产线上跑百万次，p 的每一步都不允许含糊：错解一位，追溯链就断一环。工业软件的可靠性，具体到微观，就是一支指针在字节流上走得分毫不差。
