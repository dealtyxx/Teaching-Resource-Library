我的第一张名片打印

基础必做 生活趣味 ★ 约 30 分钟

学习目标：理解程序基本结构，学会输出信息

printf输出转义字符基本格式

场景导入：你的第一次”人机对话”

在第 2 章你已经运行过 Hello, World。现在，让程序替你做一件真实的小事：打印一张属于你自己的名片。 这件事的全部秘密只有一个——printf 语句会按照你书写的顺序，一条接一条地执行。这就是 C 语言三大结构中最朴素的一种：顺序结构。

互动实验：定制你的 C 语言名片

printf · 转义字符
边框风格

💡 注意生成代码里的 \n：它是转义字符，代表换行。 每条 printf 按从上到下的顺序依次执行，输出才能拼成一张完整名片。

card.c（随输入实时生成）
#include <stdio.h>

int main(void) {
    printf("******************************\n");
    printf("*  姓名：王小明\n");
    printf("*  班级：软件工程 2025 级 1 班\n");
    printf("*  座右铭：代码报国，自主可控\n");
    printf("******************************\n");
    return 0;
}
运行结果
******************************
*  姓名：王小明
*  班级：软件工程 2025 级 1 班
*  座右铭：代码报国，自主可控
******************************

VibeCoding 三段迭代提示

  1. 手写基础版：不要复制上面的代码，在你的 IDE 里逐字敲出名片程序（错一个分号都编译不过——这正是训练）。
  2. AI 优化进阶版：把你的代码交给 AI，要求”对齐边框宽度、姓名居中”。逐行审查它给的方案：它用了什么格式说明符？%-10s 是什么意思？
  3. 信创加固定稿版：思考——若名片内容来自外部输入（如 scanf），超长姓名会发生什么？给出你的防护思路（第 3 章将正式解决它）。

素养与思政

一张名片虽小，却完成了你与机器的第一次严肃合作：你定义意图，机器忠实执行。 北斗系统数百万行的星载代码，也是从某位工程师的第一行 printf 调试信息开始的。自主可控不是口号——它始于你能说清楚自己写下的每一行代码为什么存在。
