两个数交换（指针版）

基础必做 基础概念 ★★★★ 约 70 分钟

学习目标：建立指针与地址的核心概念

指针定义解引用地址传递

场景导入：项目 27 埋的雷，今天拆

模块五说过：值传递给函数的是副本，函数改不了外面的变量。那 swap(a, b) 怎么办？ 答案是 C 语言的灵魂——指针：不传值，传地址。

三个新符号，一句话各记一条：

  • int *p; —— 定义指针变量：p 里存的不是数，是一个地址（第 1 章”内存是编号的抽屉”，p 存的就是抽屉编号）；
  • &a —— 取地址：a 住在哪个抽屉；
  • *p —— 解引用：顺着 p 里的编号找到那个抽屉，读它或写它。

swap(&a, &b) 把两个抽屉编号交给函数——函数虽然在自己的栈帧里，却能顺着编号隔空改写 main 的内存。

💡 三个新符号一次看懂：int *pa 定义指针（存地址的变量）；&a 取 a 的地址；*pa 解引用—— 顺着地址找到那格内存进行读写。项目 27 的"值传递改不了外面"之谜，答案在此揭晓：传值给副本，传址达真身。

swap_ptr.c（正解）
#include <stdio.h>

/* 指针版:传地址,隔空修改 */
void swap(int *pa, int *pb) {
    int tmp = *pa;  /* *pa:顺着地址取值 */
    *pa = *pb;      /* 写回 main 的 a */
    *pb = tmp;      /* 写回 main 的 b */
}

int main(void) {
    int a = 30, b = 116;
    swap(&a, &b);   /* &:取地址 */
    printf("a=%d b=%d\n", a, b);
    return 0;   /* 真的换过来了! */
}

素养与思政

指针给了你直达物理内存的权力——也把”写错一个地址就毁掉系统”的风险交到你手上。第 1 章说过：嵌入式裸机没有安全网，野指针一次乱写，北斗终端就可能变砖。 能力与责任从来成对出现。 C 语言不设护栏，是因为它信任工程师的专业；配得上这份信任的方式，就是每次解引用前先问一句：这个地址，真的有效吗？
