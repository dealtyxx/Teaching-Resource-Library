光伏电压倍率换算器

进阶选做 信创场景 ★★ 约 60 分钟

学习目标：新能源电控基础数据处理能力

浮点运算单位换算公式推导

场景导入：MCU 怎么”看见”几十伏的电压？

光伏板输出几十伏电压，但国产 MCU 的 ADC（模数转换器）只能测 0~3.3V。 硬件工程师用分压电阻把电压按固定倍率缩小；软件工程师（你）的任务，是把 ADC 读到的数字按同样的倍率还原回去：

  1. 还原采样端电压：v_adc = adc_raw / 4095.0 × V_REF —— 12 位 ADC 的 4095 对应满量程；
  2. 乘倍率得真实电压：v_real = v_adc × DIV_RATIO。

两步公式，一条流水线——又是顺序结构。但这一次，算错的代价是烧毁真实设备。

两步公式推导（顺序结构）

  1. ① v_adc = 2867 / 4095 × 3.3 = 2.3104 V
  2. ② v_real = 2.3104 × 21 = 48.52 V
0 V光伏输出电压100 V

✅ 当前电压 48.52 V，处于安全范围（<60 V）。

pv_voltage.c
#include <stdio.h>

#define ADC_MAX   4095.0f     /* 12位ADC满量程 */
#define V_REF     3.3f      /* 参考电压(V) */
#define DIV_RATIO 21.0f     /* 分压倍率 */

int main(void) {
    int adc_raw = 2867;                    /* ADC采样原始值 */
    float v_adc  = adc_raw / ADC_MAX * V_REF;   /* ① 还原采样端电压 */
    float v_real = v_adc * DIV_RATIO;           /* ② 乘倍率得真实电压 */
    printf("采样端电压 = %.4f V\n", v_adc);
    printf("光伏真实电压 = %.2f V\n", v_real);
    return 0;
}
运行结果
采样端电压 = 2.3104 V
光伏真实电压 = 48.52 V

VibeCoding 三段迭代提示

  1. 手写基础版：固定 ADC 值与倍率，完成两步换算并输出。
  2. AI 优化进阶版：让 AI 支持”电流采样”（020mA 对应 03.3V）。审查它的公式：斜率和偏移算对了吗？（对照第 3 章 3.6.2 的 4-20mA 传感器换算。）
  3. 信创加固定稿版：加入 ADC 越界检查（>4095 为非法）、isfinite 防 NaN、断线检测（v_real 接近 0 判为断线）。想想哪些检查必须放在换算之前——顺序，依然是关键。

素养与思政

到 2060 年碳中和，中国要新增数十亿千瓦的光伏装机。每一块光伏板背后，都有一颗国产 MCU 在毫秒级地采样、换算、决策。 “双碳”不只是宏大叙事——它落在你手里，就是 4095.0f 那个不能省略的 .0f，就是倍率宏定义旁那行注释。新能源的安全底座，是一行行算得准的代码。
