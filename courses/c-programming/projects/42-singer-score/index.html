💡 看艾力江的分：有位评委给了离谱的 6.2（其余全是 9.3+）。去高去低把这个异常值自动剔除， 他的最终分依然公允——试着把 6.2 改成 9.9，看排名如何变化。 这套算法 = 项目 14 的擂台法 + 项目 15 的异常剔除 + 项目 38 的结构体排序，模块七到此合龙。

singer_score.c
#include <stdio.h>
#define JUDGES 5
#define N 4

typedef struct {
    char  name[16];
    float scores[JUDGES];   /* 结构体里装数组 */
    float final;            /* 去高去低平均分 */
} Singer;

/* 核心算法:去掉最高最低取平均 */
float trimmed_mean(const float s[], int n) {
    float max = s[0], min = s[0], sum = 0;
    for (int i = 0; i < n; i++) {   /* 打擂+累加 */
        if (s[i] > max) max = s[i];
        if (s[i] < min) min = s[i];
        sum += s[i];
    }
    return (sum - max - min) / (n - 2);
}

int main(void) {
    Singer list[N] = { /* ...录入评分... */ };
    for (int i = 0; i < N; i++)
        list[i].final =
            trimmed_mean(list[i].scores, JUDGES);
    /* 按final降序冒泡(项目38) → 颁奖 */
    return 0;
}

素养与思政

“去掉一个最高分，去掉一个最低分”家喻户晓，它的学名是截尾均值（trimmed mean）——统计学对抗异常值的经典手段。体操、跳水的国际裁判规则用它，评标采购用它，你的代码今天也用它。 程序正义的意思是：公平不依赖每个评委都完美，而由规则结构性地保障。 把规则写成代码，代码就成了公平的执行者——这是”用技术守护公正”最朴素的样本，也是你从语法学习者变成规则构建者的时刻。
