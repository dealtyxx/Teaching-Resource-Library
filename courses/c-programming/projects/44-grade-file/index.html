学习目标：掌握结构化数据的文件存储

文件读写格式化IO数据持久化

场景导入：存进去，还要读得回来

项目 43 只是往文件”扔”文本；真实系统要的是往返闭环：结构体数组 → 文件（序列化），文件 → 结构体数组（反序列化）。文本格式的对仗工整：

  • 写：fprintf(fp, "%d %s %.1f\n", ...) —— 每条记录一行、字段空格隔开；
  • 读：fscanf(fp, "%d %15s %f", ...) —— 按同样格式逐行解析；
  • 灵魂细节：fscanf 的返回值 = 成功读到的字段数。while (fscanf(...) == 3) 意思是”三个字段都齐才收这条”——文件尾（EOF）或坏行自动退出循环。

写和读的格式必须像锁和钥匙一样咬合——多一个空格、错一个 %，读回来就是乱码。

素养与思政

你的高考成绩、学籍记录，会在教育系统的档案里保存几十年——当年写入它们的程序早已退役，数据却必须继续可读。这就是”数据的生命周期远长于程序”：格式要文档化、编码要标准化、校验要内建。 国家档案局的电子档案标准要求”来源可靠、程序规范、要素合规”。你今天设计的一行 %d %s %.1f，就是最小的”档案格式规范”——认真对待它，是对未来读档人的负责。
