多重循环数据统计阈值告警

场景导入：一座大棚的一天 = 96 次巡检

寿光的一座智能大棚里，4 个温湿度传感器每小时上报一次数据。一天下来是 24×4 = 96 组读数。 监控固件要完成三件事，而它们恰好是本模块所有武器的集结：

  1. 双重循环遍历”小时 × 传感器”网格（项目 12 的嵌套循环，从画图案升级为扫数据）；
  2. 阈值告警：温度过高/过低、湿度过低即计数并输出（模块二的复合条件在循环里工作）；
  3. 全天统计：最高/最低/平均（项目 14 的计数器、累加器、擂台法整套复用）。

greenhouse.c
#include <stdio.h>
#define HOURS 24
#define SENSORS 4

int main(void) {
    float t[HOURS][SENSORS], h[HOURS][SENSORS]; /* 采样数据 */
    float t_hi = 30, t_lo = 12, h_lo = 50;   /* 告警阈值 */
    int alarms = 0;
    float t_max = -99, t_min = 99, t_sum = 0;
    /* ...从传感器总线读入 t/h 数组(第6章数组详解)... */
    for (int hr = 0; hr < HOURS; hr++) {       /* 外层:24小时 */
        for (int s = 0; s < SENSORS; s++) {    /* 内层:4传感器 */
            float ct = t[hr][s], ch = h[hr][s];
            if (ct > t_hi || ct < t_lo || ch < h_lo) {
                alarms++;                       /* 告警计数 */
                printf("[告警]%02d时 S%d:%.1f°C %.0f%%\n",
                       hr, s + 1, ct, ch);
            }
            if (ct > t_max) t_max = ct;         /* 全天统计 */
            if (ct < t_min) t_min = ct;
            t_sum += ct;
        }
    }
    printf("全天:max=%.1f min=%.1f avg=%.1f 告警%d次\n",
           t_max, t_min, t_sum/(HOURS*SENSORS), alarms);
    return 0;
}

💡 双重循环共执行 24×4=96 次内层体——外层每走 1 小时，内层就把 4 个传感器全巡一遍。 把高温阈值拉到 24°C，看看正午时段红成什么样：阈值定得太严，告警就会淹没真问题， 这是所有监控系统的第一课。

VibeCoding 三段迭代提示

  1. 手写基础版：用二维思路（先当作 24 次×4 次两层循环）实现告警计数与全天统计。先在纸上算清楚：内层体总共执行几次？
  2. AI 优化进阶版：让 AI 增加”连续 2 小时同一传感器告警 → 升级为严重告警”。审查它的连续性判断：跨小时的状态要不要在外层循环里维护？内层清零还是外层清零？
  3. 信创加固定稿版：所有阈值宏定义并写注释说明农艺依据（如番茄适温 15~30°C）；传感器坏值（-999）先过滤再统计（项目 15 的 continue 回归）；思考若采样从每小时 1 次改为每分钟 1 次，int 告警计数器和 float 累加器还够用吗（项目 5 的溢出问题回归）。

素养与思政

山东寿光的蔬菜大棚从”看天吃饭”到”数据种菜”用了三十年：如今一部手机管理几十个棚，温湿度曲线代替了老农的直觉。这背后是数百万台国产传感器与嵌入式控制器 24 小时不停的循环。 乡村振兴的科技底座，就是你今天写的这个双重循环——它不休息、不遗漏、不抱怨，替农民守着每一度温差。把论文写在祖国大地上，也可以是把循环跑在祖国的大棚里。

随堂小测

24 小时 × 4 传感器的双重循环中，内层循环体总共执行多少次？

要统计『每小时的平均温度』（而非全天平均），sum 和 count 应该在哪里清零？
