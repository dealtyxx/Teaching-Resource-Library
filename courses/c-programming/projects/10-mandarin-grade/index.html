普通话等级鉴定系统

进阶选做 考试应用 ★★★ 约 90 分钟

学习目标：理解嵌套分支的程序设计

多分支嵌套判断

场景导入：先验资格，再定等级

普通话水平测试分三级六等：一级甲等（≥97）、一级乙等（≥92）、二级甲等（≥87）、二级乙等（≥80）、三级甲等（≥70）、三级乙等（≥60）。

看起来是一条 else if 长链？没错——但工程上还差一层：如果输入的分数是 -5 或 120 呢？ 直接进等级链会得出荒谬的”未达三级乙等”或”一级甲等”。正确的骨架是嵌套分支：

外层 if：分数在 0~100 内吗？
 ├─ 否 → 报错，拒绝鉴定
 └─ 是 → 内层 else-if 链：从高到低逐级比对

外层管”资格”，内层管”业务”——这是所有输入处理程序的通用模式。

互动实验：一个分数的两层旅程

嵌套判断 · 边界防护

外层 if：分数在 0~100 之间吗？有效 ✓ → 进入内层

内层 else-if 链（仅当外层通过才会执行）

≥97 一级甲等≥92 一级乙等≥87 二级甲等≥80 二级乙等≥70 三级甲等≥60 三级乙等

二级甲等（教师资格要求）

main.c
1#include <stdio.h>
2 
3int main(void) {
4    float score = 88.5f;
5    if (score < 0 || score > 100) {          /* 外层:先验有效性 */
6        printf("输入无效:分数超出0~100\n");
7    } else {                                  /* 内层:再定等级 */
8        if      (score >= 97) printf("一级甲等\n");
9        else if (score >= 92) printf("一级乙等\n");
10        else if (score >= 87) printf("二级甲等\n");
11        else if (score >= 80) printf("二级乙等\n");
12        else if (score >= 70) printf("三级甲等\n");
13        else if (score >= 60) printf("三级乙等\n");
14        else                  printf("未达三级乙等\n");
15    }
16    return 0;
17}
运行结果
二级甲等

💡 输入 96.9 和 97 只差 0.1 分，却隔着一个等级——边界值是分支程序测试的重点。 再输入 -1：外层防护先把非法数据拦住，内层根本不会执行。「先验合法性，再做业务」， 这个嵌套结构就是所有输入处理程序的骨架。
