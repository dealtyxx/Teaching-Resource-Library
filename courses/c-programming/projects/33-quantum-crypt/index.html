量子通讯信息加密

学习目标：指针在通信安全中的应用

指针操作字符串加密内存操作

场景导入：一支指针，走完加密全程

2016 年”墨子号”量子科学实验卫星升空，实现千公里级量子密钥分发（QKD）：光子的量子态一被窃听即坍缩，窃听必然留痕。它分发的密钥怎么用？最经典的搭配是异或加密：

*p = *p ^ key[i % klen];   /* 逐字节异或 */

异或的自反性（A^K^K == A）意味着：同一个函数、同一把密钥，第一次调用是加密，对密文再调一次就是解密。 指针在这里是天然的工作载体：p 从缓冲区头走到尾，逐字节原地改写（in-place）——不开新数组、不留明文副本，这在安全代码里本身就是一种美德。

素养与思政

“墨子号”首席科学家潘建伟说：量子通信要”在别人卡脖子之前，先把路走通”。从墨子号到”京沪干线”，中国在量子保密通信领域实现了从跟跑到领跑。 但再强的量子密钥，落到地面也要经过你这样一段 C 代码——密钥分发靠物理，密钥使用靠工程。指针走过的每一个字节、用后销毁的每一段密钥内存，都是这条安全链路上不可替代的一环。国之重器与手中代码，从来是同一条战线。
