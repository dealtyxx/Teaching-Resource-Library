身体BMI指数计算器

基础必做 生活健康 ★★ 约 50 分钟

学习目标：掌握单分支与双分支结构

if-else关系运算条件判断

场景导入：程序开始”做选择”

模块一里，程序像一列直行的火车——每条语句必然执行。但现实世界充满选择：BMI 超标要提醒锻炼，正常则鼓励保持。 让程序拥有”选择能力”的，就是分支结构：if 判断条件，成立走一条路，不成立走另一条。

BMI（身体质量指数）= 体重(kg) ÷ 身高(m)²，中国成人标准：<18.5 偏瘦 / 18.524 正常 / 2428 超重 / ≥28 肥胖。 四个区间、四条路径——正是 if-else if 链的用武之地。

建立直觉：if-else if-else 链像一排安检门——从第一扇开始逐个尝试，进了任何一扇，后面的门就都不用看了。因此每个条件其实自带”前面都没通过”的隐含前提。

💡 观察右侧代码：不管 BMI 是多少，四个分支只有一个会执行（高亮行）。 else if 链从上到下逐个测试，命中即停——所以第二个条件写 bmi < 24 就够了， 不必写 bmi >= 18.5 && bmi < 24。想想为什么？

main.c
1#include <stdio.h>
2 
3int main(void) {
4    float height_m = 1.75f, weight_kg = 65.0f;
5    float bmi = weight_kg / (height_m * height_m);
6    printf("BMI = %.1f\n", bmi);
7    if (bmi < 18.5f) {
8        printf("偏瘦：注意营养均衡\n");
9    } else if (bmi < 24.0f) {
10        printf("正常：继续保持\n");
11    } else if (bmi < 28.0f) {
12        printf("超重：建议加强锻炼\n");

素养与思政

“健康中国 2030”把全民健康素养写进了国家战略。BMI 计算器虽小，却是”用数据认识自己”的第一步。 程序做判断的逻辑也提醒我们：标准要清晰，边界要明确，判断要有依据——这既是写分支的要求，也是科学看待健康数据的态度：BMI 只是初筛指标，超出范围应咨询专业医生，而不是焦虑。
