用户名校验函数

进阶选做 系统应用 ★★★★ 约 90 分钟

学习目标：掌握校验类函数的设计方法

字符串函数返回状态码

场景导入：注册页背后的那个函数

每个注册页都有一位隐形守门员：用户名 4~16 字符、字母数字下划线、不能数字开头…… 这类校验函数有一套标准设计范式：

  • 返回状态码：0 表示合法，负数区分具体错误——调用方拿着错误码给用户精准提示（项目 16 登录、第 3 章信创版都用过这套约定，如今由你亲手设计）；
  • 早退结构（early return）：一条条检查、一失败立刻 return，不合格的数据不配进入下一关；
  • 字符串工具箱：strlen 量长度，ctype.h 的 isdigit/isalnum 判字符类别——它们本身就是别人封装好的函数。

状态码约定（调用方据此提示用户）

0 → 合法 ✓
-1 → 空指针
-2 → 太短（不足4字符）
-3 → 太长（超过16字符）
-4 → 不能以数字开头
-5 → 含非法字符（仅限字母/数字/下划线）

💡 试试 张三——UTF-8 汉字的 3 个字节都不是字母数字下划线， 被第 5 关拦下（项目 23 的字节视角回归）。再体会早退模式（early return）： 一条条关卡顺序检查、一失败立刻 return，代码扁平没有嵌套金字塔——校验类函数的标准姿势。

main.c
1#include <string.h>
2#include <ctype.h>
3 
4/* 返回0=合法,负数=具体错误码 */
5int check_username(const char *name) {
6    if (name == NULL)  return -1;   /* 空指针 */
7    size_t len = strlen(name);
8    if (len < 4)       return -2;   /* 太短 */
9    if (len > 16)      return -3;   /* 太长 */
10    if (isdigit((unsigned char)name[0]))
11                       return -4;   /* 数字开头 */
12    for (size_t i = 0; i < len; i++) {
13        char c = name[i];
14        if (!isalnum((unsigned char)c) && c != '_')
15                       return -5;   /* 非法字符 */
16    }
17    return 0;                       /* 全部通过 */
18}

素养与思政

差的报错是”用户名无效”，好的报错是”用户名不能以数字开头”——同一个函数，五个错误码的差别，就是用户体验里的被尊重感。 《个人信息保护法》要求产品”以显著方式、清晰易懂的语言”告知用户规则。把规则写成清晰的状态码，把状态码翻译成明白的提示——技术上的严谨与表达上的诚恳，加起来才是对用户的尊重。
