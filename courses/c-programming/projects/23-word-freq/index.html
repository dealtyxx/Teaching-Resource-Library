场景导入：字符串是特殊的数组

二十大报告中，“人民”一词出现了 177 次。新闻里的这类词频统计，底层就是字符数组的遍历匹配。

C 语言里字符串就是”以 \0 结尾的字符数组”：

  • char text[] = "人民" 在 UTF-8 编码下是 7 个字节：6 字节汉字 + 1 字节 \0——一个汉字占 3 字节；
  • C 不认识”汉字”，只认识字节序列——找”人民”就是找 6 字节的模式串；
  • 标准库 strstr(p, kw) 从 p 开始找 kw 第一次出现的位置，找不到返回 NULL。

统计全文出现次数 = strstr + while 循环 + 匹配后指针前移，三者缺一不可。

UTF-8 字节视角："人民" = 6 字节
[0xE4, 0xBA, 0xBA, 0xE6, 0xB0, 0x91]
word_freq.c
#include <stdio.h>
#include <string.h>

int main(void) {
    /* UTF-8编码:1个汉字占3字节 */
    char text[] = "江山就是人民,人民就是江山...";
    char kw[]   = "人民";     /* 6 字节 */
    int count = 0;
    char *p = text;
    while ((p = strstr(p, kw)) != NULL) {
        count++;              /* 找到一次 */
        p += strlen(kw);      /* 跳过本次匹配,继续向后找 */
    }
    printf("\"人民\" 出现 %d 次\n", count);
    return 0;
}
运行结果
"人民" 出现 14 次

💡 C 的字符串没有"汉字"概念，只有字节序列：UTF-8 里一个汉字占 3 字节， "人民"就是 6 个字节的模式串。strstr 做的是逐字节滑动匹配—— 匹配成功后 p += strlen(kw) 这步至关重要：不前移指针， while 将永远停在第一处匹配，死循环（模块三的老朋友又来敲门）。

VibeCoding 三段迭代提示

  1. 手写基础版：不用 strstr，手写双层循环匹配：外层滑动起点 i，内层逐字节比对 text[i+k] == kw[k]。写完再对比库函数，体会”轮子”里的循环。
  2. AI 优化进阶版：让 AI 统计多个关键词（人民/发展/安全）并按次数排序输出（项目 19 的冒泡回归）。审查它的二维字符数组 char kws[3][16] 定义对不对。
  3. 信创加固定稿版：处理编码陷阱——同一个程序在 GBK 编码源文件下”人民”只占 4 字节！用 sizeof 打印验证，理解”字符串处理必须明确编码”；给输入文本长度设上限并校验。
