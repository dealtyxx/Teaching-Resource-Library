area.c
#include <stdio.h>

int main(void) {
    float width  = 7.5f;
    float height = 4.2f;
    float area = width * height;
    float peri = 2 * (width + height);
    printf("面积 = %.2f\n", area);
    printf("周长 = %.2f\n", peri);
    return 0;
}
运行结果
面积 = 31.50
周长 = 23.40

VibeCoding 三段迭代提示

  1. 手写基础版：用 scanf 让用户输入长和宽，计算面积与周长（注意 scanf("%f", &width) 里的 &——先照抄，第 9 章指针会揭晓它的秘密）。
  2. AI 优化进阶版：让 AI 补充”输入校验”：长宽为负数或 0 时怎么办？审查它的方案用了什么语句（很可能是 if——这正是模块二的预告）。
  3. 信创加固定稿版：把长宽上限设为宏常量 #define MAX_SIDE 1000，超限拒算。想想为什么工程代码不允许”魔数”。

素养与思政

港珠澳大桥的沉管对接误差不到 5 厘米，靠的不是运气，而是每一次计算都类型明确、精度可控。 你在实验中看到：把 7.5 存进 int，0.5 米就悄无声息地消失了。在工程世界里，“差不多”就是”差很多”——对数字的严谨，就是对生命的负责。
