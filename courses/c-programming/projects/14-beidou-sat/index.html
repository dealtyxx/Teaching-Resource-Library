北斗卫星遍历统计

基础必做 北斗场景 ★★★ 约 80 分钟

学习目标：学会循环遍历与统计方法

for循环计数器累加器

场景导入：接收机每秒都在”点名”

北斗接收机同时跟踪十几颗卫星，每颗都有信噪比（SNR）。每一秒，固件都要回答三个问题： 几颗可用？平均信号多强？最强的是哪颗？

这三问对应循环统计的三大件：

  • 计数器（counter）：count++ —— 数个数；
  • 累加器（accumulator）：sum += snr[i] —— 攒总和，最后除以个数得平均；
  • 擂台法（max/min）：if (snr[i] > max) max = snr[i] —— 逐个打擂，留下最强者。

它们都必须在循环外初始化（count=0, sum=0），在循环内逐步演化——初始化位置放错，是循环统计的第一大 bug。

sat_stat.c（随采样/阈值实时生成）
#include <stdio.h>

int main(void) {
    int snr[12] = {42,18,35,47,22,39,16,44,29,33,20,38};
    int th = 30;                  /* 可用信噪比阈值(dB-Hz) */
    int count = 0, sum = 0, max = 0; /* 计数器/累加器/擂台 */
    for (int i = 0; i < 12; i++) {
        if (snr[i] >= th) {
            count++;                 /* 计数器 +1 */
            sum += snr[i];           /* 累加器攒总和 */
        }
        if (snr[i] > max) max = snr[i]; /* 打擂台求最大 */
    }
    printf("可用卫星:%d颗\n", count);
    if (count > 0)
        printf("平均SNR:%.1f 最强:%d\n", (float)sum/count, max);
    return 0;
}

VibeCoding 三段迭代提示

  1. 手写基础版：给定 12 颗卫星 SNR 数组，统计可用数、平均值、最大值。先默写三大件的初始化位置。
  2. AI 优化进阶版：让 AI 增加”最弱可用卫星”（min 擂台）与”可用率百分比”。审查 min 的初始值——AI 若写 min=0 就永远打不了擂（所有 SNR 都>0），正确姿势是初始化为一个足够大的数或第一个元素。
  3. 信创加固定稿版：count=0 时除法防护（sum/count 除零！）；SNR 合法范围校验（0~60）；思考观测 1 小时=3600 帧×12 颗，int sum 会不会溢出？

素养与思政

从 2000 年北斗一号双星起步，到 2020 年 55 颗组网收官，北斗人用 20 年把”点名册”从 2 写到 55。每颗卫星发射前，测试团队要遍历数千项指标——一项不过，整星不放行。 你的 for 循环每秒点名 12 颗卫星，北斗地面运控系统每天点名全星座数万次。遍历，是工程世界最朴素的责任制：一个都不能漏。
