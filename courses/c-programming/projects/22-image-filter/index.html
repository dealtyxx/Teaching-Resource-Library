图像均值滤波（3×3）

进阶选做 图像处理 ★★★★ 约 120 分钟

学习目标：掌握二维数组的工程应用

二维数组邻域运算矩阵操作

场景导入：一张图，就是一个二维数组

灰度图像在内存里就是 unsigned char img[H][W]——每个元素是一个像素的亮度（0 黑 ~ 255 白）。 摄像头传感器的椒盐噪声（随机纯黑/纯白点）怎么去掉？最朴素的算法是均值滤波：

每个像素的新值 = 它自己 + 周围 8 个邻居，共 9 个值的平均。

孤立的噪点会被 8 个正常邻居”投票”拉回正常值。实现上是四层循环：外两层遍历图像的行和列，内两层遍历 3×3 邻域——img[r+dr][c+dc]，其中 dr、dc 各取 −1、0、1。

均值滤波后

把鼠标悬停在左图任意像素上，查看它的 3×3 邻域与求均值算式。
mean_filter.c
#include <stdio.h>
#define H 12
#define W 12

void mean_filter(unsigned char in[H][W],
                 unsigned char out[H][W]) {
    for (int r = 1; r < H - 1; r++) {       /* 跳过边缘 */
        for (int c = 1; c < W - 1; c++) {
            int sum = 0;
            for (int dr = -1; dr <= 1; dr++)     /* 3×3 邻域 */
                for (int dc = -1; dc <= 1; dc++)
                    sum += in[r + dr][c + dc];
            out[r][c] = sum / 9;             /* 9 个像素求均值 */
        }
    }
}

💡 四层循环嵌套：外两层走遍图像（行×列），内两层走遍邻域（3×3）。 总运算量 ≈ 10×10×9 = 900 次加法。换成 1080P 图像（1920×1080）就是 1866 万次——这就是为什么图像处理天生需要硬件加速（第 1 章边缘 AI 模组的 NPU 派上用场了）。 另外注意 out 和 in 必须是两个数组：原地滤波会让后算的像素用到已被改掉的邻居！

VibeCoding 三段迭代提示

  1. 手写基础版：对 12×12 数组实现均值滤波（边缘像素直接复制）。先想清楚：为什么行循环从 1 到 H−2，而不是 0 到 H−1？
  2. AI 优化进阶版：让 AI 改成中值滤波（9 个值取中位数而非平均——去椒盐噪声效果更好）。审查它取中位数用的什么方法？9 个元素冒泡取第 5 个（项目 19 回归）合理吗？
  3. 信创加固定稿版：sum 用 int 而非 unsigned char（9×255=2295 早爆了 255 上限——第 3 章溢出回归）；边界策略做成宏可选（跳过/复制/镜像）；估算 1920×1080 图像的运算量并思考分块处理。

素养与思政

风云气象卫星的云图、“天问”传回的火星地表、医院 CT 的断层影像——第一步处理几乎都是去噪滤波。图像质量差一分，台风路径预测就偏一分，病灶就可能漏检一分。 国产 GPU 与 AI 芯片正在把这些滤波算法做进硬件。“看得更清”是一种硬实力，而它的最底层，就是你今天写的这个四层循环——宏大叙事与基础代码之间，从来只隔着一层认真。
