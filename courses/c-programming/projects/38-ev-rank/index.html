新能源汽车排行榜

基础必做 信创场景 ★★★★★ 约 110 分钟

学习目标：异构数据批量管理能力

结构体数组排序批量管理

场景导入：六辆车，一张表

汽车之家式的排行榜：每辆车有名称、续航、月销、价格四个属性，共 6 辆——这就是结构体数组：

EvCar cars[6];        /* 6条记录,每条4个字段 */
cars[2].range = 710;  /* 下标定位记录,点号定位字段 */

排序时最妙的一幕：EvCar tmp = cars[j]; cars[j] = cars[j+1]; ...——结构体支持整体赋值，一条语句搬走整条记录（名称、续航、销量、价格绑定同行）。四个平行数组永远做不到这种”数据不散架”。

另一个升级：把”怎么比大小”抽成独立的比较函数——按续航、按销量、按价格，排序骨架（项目 19 的冒泡）一行不改，换个 cmp 就换了榜单。

💡 换排序键时，搬动的是整条记录：`arr[j] = arr[j+1]` 一条语句就把 32 字节的结构体整体赋值 （名字、续航、销量、价格一起走）——数组做不到的"异构数据打包搬家"，结构体天生就会。 排序算法还是项目 19 的冒泡，变的只是比较函数——算法与数据解耦，这是 qsort 的设计思想。

ev_rank.c（比较函数随排序键切换）
#include <stdio.h>
#include <string.h>
#define N 6

typedef struct {       /* typedef省去每次写struct */
    char  name[20];
    int   range;       /* 续航km */
    float sales;       /* 月销万辆 */
    float price;       /* 指导价万元 */
} EvCar;

/* 比较函数:当前按【续航】排序 */
int cmp(const EvCar *a, const EvCar *b) {
    return b->range - a->range;   /* 降序 */
}

void sort_cars(EvCar arr[], int n) {
    for (int i = 0; i < n - 1; i++)
        for (int j = 0; j < n - 1 - i; j++)
            if (cmp(&arr[j], &arr[j+1]) > 0) {
                EvCar tmp = arr[j];    /* 结构体 */
                arr[j] = arr[j+1];     /* 整体赋值 */
                arr[j+1] = tmp;        /* 一次搬家 */
            }
}

VibeCoding 三段迭代提示

  1. 手写基础版：定义 EvCar 结构体数组（6 辆国产车），按续航降序冒泡排序并打印榜单。
  2. AI 优化进阶版：让 AI 改用标准库 qsort（函数指针传 cmp——第 9 章预告）。审查它的 cmp 签名 int (*)(const void*, const void*) 里强制转换写对了没。
  3. 信创加固定稿版：增加”综合评分”字段（续航/价格/销量加权）并按它排序；权重做成宏；思考浮点比较函数返回 a-b 强转 int 的隐患（0.4-0.1=0.3 截断成 0——第 3 章截断陷阱在排序里的复活）。

素养与思政

2015 年中国新能源汽车年销 33 万辆，2024 年接近 1300 万辆、全球占比超六成——十年间，榜单上的名字从特斯拉一家独大变成比亚迪、蔚来、小鹏、理想群星闪耀。 你排序的每条结构体记录背后，是电池、电机、电控的整条国产供应链。榜单会变，支撑榜单的产业能力才是根本——写代码如此（排序算法不变，比较维度常新），产业竞争亦然。
