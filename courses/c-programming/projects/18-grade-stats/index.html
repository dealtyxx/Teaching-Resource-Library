一维数组遍历求和求平均

场景导入：40 个变量？不，一个数组

要统计 10 名同学的成绩，难道定义 s1, s2, ..., s10 十个变量？全校 4000 人呢？ 数组一次解决：int scores[10] 在内存中申请连续的 10×4=40 字节，用下标访问每一格：

  • scores[0] 是第一个元素——下标从 0 开始，最后一个是 scores[9]；
  • scores[i] 的地址 = 首地址 + i×4——下标本质是”偏移量”，这就是它从 0 数起的原因；
  • 数组 + 循环 = 批量处理：模块三的遍历统计三大件（计数、累加、擂台），从此有了真正的用武之地。

grades.c（随编辑实时生成）
#include <stdio.h>
#define N 10

int main(void) {
    int scores[N] = {78,92,65,88,54,95,71,83,60,87};
    int sum = 0, max = 0, min = 100, pass = 0;
    for (int i = 0; i < N; i++) {     /* 下标 0 ~ N-1 */
        sum += scores[i];
        if (scores[i] > max) max = scores[i];
        if (scores[i] < min) min = scores[i];
        if (scores[i] >= 60) pass++;
    }
    printf("平均%.1f 最高%d 最低%d\n",
           (float)sum / N, max, min);
    printf("及格率%d%%\n", pass * 100 / N);
    return 0;
}

💡 危险实验（脑内进行）：如果循环写成 i <= N， 会读到 scores[10]——数组后面的陌生内存。 C 不会阻止你，程序可能输出鬼数字，也可能崩溃。第 1 章 AI 代码的"缓冲区越界"，根源就在这一个等号。

  2. AI 优化进阶版：让 AI 增加”高于平均分的人数”统计。审查要点：这需要两次遍历（先算平均、再数人数），AI 有没有想当然地在一次循环里做完？
  3. 信创加固定稿版：输入校验（0~100 之外重新输入）；人数改用 #define N；思考若 N 从 10 改到 4000，代码要改几处？（答案应该是 1 处——这就是符号常量的意义。）

素养与思政

平均分抹平了差异，最低分却指向一个需要帮助的具体的人。教育部要求”精准资助”，就是拒绝只看平均数的懒惰——你的程序里那行找最低分的擂台代码，对应着现实中一双发现掉队者的眼睛。 统计的意义不是数字本身，而是数字背后的人。 写代码的人若心里有人，冷冰冰的数组也会有温度。
