# 算法互动课堂 v2 · 玩中学

基于李春葆《算法设计与分析》（第3版）PPT 打造的**高吸引力交互式教学系统**。

## 打开方式

双击打开：

```
interactive-course/index.html
```

推荐 Chrome / Edge。无需安装、无需服务器。

## v2 升级亮点

| 维度 | 内容 |
|------|------|
| **视觉** | 星空背景、渐变标题、玻璃拟态、发光按钮、动效卡片 |
| **游戏化** | XP 升级、星星收集、五彩纸屑、Toast 反馈 |
| **交互** | 速度档、单步/自动、拖拽几何、赛道竞速、翻转卡片 |
| **趣味文案** | 助教提示、挑战条、通关话术 |

## 12 章互动一览

1. **绪论** — 复杂度曲线 + 算法赛道 + 翻转特性卡  
2. **递归** — 阶乘栈呼吸 + 汉诺塔直播  
3. **穷举** — 百钱买百鸡 + 前缀和拖滑块  
4. **分治** — 快排 DJ 控台（可调速）  
5. **回溯** — N 皇后皇室试错秀  
6. **分支限界** — 迷宫 BFS 闯关  
7. **动态规划** — Fib 填表 + 背包格子冒险  
8. **贪心** — 活动安排时间轴  
9. **图算法** — Prim 生长动画  
10. **计算几何** — 叉积拖点 + 凸包  
11. **计算复杂性** — 可点击 P/NP 宇宙图  
12. **概率近似** — 蒙特卡罗狂投估 π  

## 进度说明

- XP / 星星存在浏览器 `localStorage`
- 门户页可点「重置 XP」清空进度
- 完成测验会掉星与 confetti

## 课堂使用建议

1. 全屏投影，从门户「启航」进入第 1 章  
2. 每章先 30 秒讲概念，再点演示按钮「表演」  
3. 留 2 分钟让学生做挑战测验抢 XP  
4. 下章导航在页面底部  

祝教学顺利，学生上头 🚀
