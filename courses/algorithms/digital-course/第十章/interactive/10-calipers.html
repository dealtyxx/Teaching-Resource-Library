学习目标

  1. 理解凸多边形直径就是点集的最远点对距离，且这对点一定都在凸包顶点上
  2. 掌握对踵点对（antipodal pair）概念：能被一对平行支撑线同时夹住的两个顶点，最远点对必是对踵点对
  3. 掌握旋转卡壳思想：两条平行支撑线绕凸包同向旋转，用叉积/面积判断哪条边先转到，双指针推进
  4. 能分析：求凸包 O(n log n) 之后，卡壳一趟两指针各绕行一圈为 O(h)，故求直径整体 O(n log n)
  5. 了解卡壳可解的一类问题：直径 / 最远点对、凸多边形宽度、最小外接矩形等

直径—
应用：最小宽度、最大距离、凸包支撑相关问题。先凸包 O(n log n)，再卡壳 O(h)。

一、直径与最远点对

diameter = farthest pair
定义

点集的直径（diameter）是最远两点之间的距离，即最远点对。关键事实：最远点对的两个端点一定都是凸包顶点——若某端点在凸包内部，把它沿背离对方的方向移到边界总能得到更远的一对，矛盾。因此只要在凸包顶点里找最远对即可，无需考虑内部点。

别用 O(n²) 硬枚举：直径不必对全部 n 个点两两求距离。先求凸包留下 h 个顶点，再在这 h 个顶点中用旋转卡壳找最远对，可把「找最远对」这一步降到 O(h)。

二、对踵点对

antipodal pairs · supporting lines
定义

用一对平行直线从两侧夹住凸多边形、两条线都与多边形相切（各至少碰到一个顶点/一条边），这样的支撑线所触及的两个顶点称为一组对踵点对（antipodal pair）。最远点对必定是某组对踵点对：因为最远两点处各作一条垂直于两点连线的支撑线，它们平行且夹住整个凸包。

卡壳的画面感：把两条平行支撑线想成一把游标卡尺（calipers）的两个卡爪，卡住凸包后一起旋转一周。旋转过程中卡爪接触的顶点不断变化，扫过的所有对踵点对里就包含了最远的那一对。

三、旋转卡壳的推进

rotating calipers
1
枚举凸包的每条边 hull[i]→hull[i+1]，把它看作下卡爪贴合的方向。
2
找该边的对踵顶点：即离这条边所在直线最远的顶点 hull[j]。「离边多远」用三角形面积度量——面积 = ½·底(边长)·高，底固定时面积随高单调，故用叉积 |Cross(hull[i], hull[i+1], hull[j])| 比较即可。
3
双指针推进：边按 i 前进时，最远顶点 j 也只会朝同一方向前移、绝不回退。于是 j 用一个 while 一直往前，直到再前进一格面积不再增大就停下。
4
更新答案：用当前对踵关系下的候选距离（hull[i]、hull[i+1] 分别到 hull[j]）刷新最大值。i 绕一圈、j 也累计绕一圈后，扫过全部对踵点对，得到直径。
用面积作推进判据：|Cross(hull[i], hull[i+1], hull[j+1])| > |Cross(hull[i], hull[i+1], hull[j])| ⟹ j 前进

四、复杂度分析

O(n log n) + O(h)
求凸包 O(n log n) + 卡壳 O(h) = O(n log n)　　（h ≤ n）
分析

卡壳阶段，外层 i 走一圈是 h 步，内层指针 j 单调前进、总位移也只有一圈 ≈ h 步（摊还），故卡壳本身是 O(h)。加上前置的凸包构造 O(n log n)，后者主导，求直径整体 O(n log n)。若凸包已给定，则纯卡壳是线性的 O(h)。

本页演示的写法：为了让动画逐对高亮、看得清楚，页面里求直径用的是枚举凸包顶点全部两两对的 O(h2) 简化版；真正的旋转卡壳是 O(h)——靠上面第 3 步的双指针单调推进省掉大量比较。两者结果一致，仅效率不同。

五、C++ 实现

旋转卡壳求直径
// 依赖基础模板：Point / Cross(a,b,c) / Length / operator- // hull：逆时针凸包顶点(已去共线)，h≥2 double area2(Point a, Point b, Point c) { // 两倍三角形面积 = |叉积| return fabs(Cross(a, b, c)); } double Diameter(const vector<Point>& hull) { int h = hull.size(); if (h == 1) return 0; // 退化：单点 if (h == 2) return Length(hull[1] - hull[0]); // 退化：两点 double ans = 0; int j = 1; for (int i = 0; i < h; i++) { Point a = hull[i], b = hull[(i + 1) % h]; // j 单调前进：下一个顶点离边 a→b 更远就继续走 while (area2(a, b, hull[(j + 1) % h]) > area2(a, b, hull[j])) j = (j + 1) % h; // hull[j] 是边 a→b 的对踵点，更新两个候选距离 ans = max(ans, max(Length(hull[j] - a), Length(hull[j] - b))); } return ans; // 直径 = 最远点对距离 }
推进判据为什么用面积而非距离：固定底边 a→b，顶点到该直线的距离 = 2·面积 / |ab|，底边长不变时面积与高同增同减。用叉积面积比较，既避开除法与开方、整数坐标下精确，又天然刻画了「谁离这条边更远」的单调性。
易错点
  • 以为求直径要对所有点两两枚举 O(n2)：其实端点必在凸包上，只需 O(h) 卡壳。
  • 忘记先求凸包而直接在原始点集上卡壳，内部点破坏支撑线的单调性。
  • 推进判据用到顶点的距离而非到边的距离（叉积面积），单调性不成立，j 会走错。
  • 双指针 j 允许回退：j 必须单调前进，写成可回退会破坏 O(h) 且可能死循环。
  • 凸包含共线点未去除，面积出现相等（并列最远），推进条件写成 >= 可能空转。
  • 只比较 hull[i] 与 hull[j]，漏比 hull[i+1] 与 hull[j]，错过部分对踵候选。
本节小结
  • 凸多边形直径 = 最远点对距离，两端点一定都是凸包顶点。
  • 最远点对必是对踵点对——能被一对平行支撑线同时夹住的两顶点。
  • 旋转卡壳：平行支撑线绕凸包旋转，用叉积面积判断对踵顶点，双指针单调推进 O(h)。
  • 先求凸包 O(n log n)、再卡壳 O(h)，求直径整体 O(n log n)。
  • 卡壳同样可解凸多边形宽度、最小外接矩形等支撑线相关问题。
1关于点集的最远点对（直径），下列说法正确的是？
A两个端点一定都是凸包顶点，且构成一组对踵点对
B端点可能在凸包内部
C必须枚举所有点对才能求出
D最远点对一定与最近点对共享一个端点
解析：选 A。若某端点在内部，沿背离对方的方向移到边界会得到更远的对，矛盾，故端点必在凸包上；最远两点各作垂直于连线的支撑线即平行夹住凸包，说明它们是对踵点对。B、C 因此都错；D 没有任何依据。
2真正的旋转卡壳求直径是 O(h) 而非 O(h2)，关键原因是？
A凸包顶点数 h 很小
B对踵顶点指针 j 只单调前进、总共只绕一圈，摊还后是线性的
C用叉积代替了开方
D提前排序了所有顶点
解析：选 B。外层枚举 h 条边，内层指针 j 随边推进从不回退，绕行一圈的总步数也是 O(h)，两者叠加仍 O(h)（摊还分析）。C 只是常数与精度优化，不改变数量级；A 是运气不是原因；D 与卡壳无关。本页演示的 O(h²) 版正是放弃了这个单调双指针、改为两两枚举。
3用旋转卡壳求 n 个点的直径，整体时间复杂度的瓶颈在于？
A卡壳阶段 O(h)
B前置的求凸包 O(n log n)
C计算叉积 O(1)
D输出结果 O(1)
解析：选 B。卡壳本身只要 O(h) ≤ O(n)，而先要把 n 个点求成凸包需 O(n log n)，后者更大，主导整体复杂度。因此求直径整体为 O(n log n)；若凸包已给定，则只剩线性的卡壳 O(h)。
