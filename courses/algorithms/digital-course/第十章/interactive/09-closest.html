学习目标

  1. 理解最近点对问题：n 个点中找出距离最小的一对，暴力法为 O(n2)
  2. 掌握分治框架：按 x 中位数把点分成左右两半，递归求各自最近距离，取 δ = min(δL, δR)
  3. 理解跨中线的最近点对只可能落在宽 2δ 的中线带状区域内，需单独合并检查
  4. 能说明带内按 y 排序后，每个点只需与后面常数个（至多 7 个）点比较——这是复杂度的关键
  5. 能推导递归式 T(n) = 2T(n/2) + O(n) = O(n log n)，并说明它优于暴力法的原因

一、问题与暴力法

closest pair · brute force
定义

最近点对问题：给定平面上 n 个点，找出其中距离最小的一对点。最直接的做法是枚举所有 C(n,2) 对点、取距离最小者，需要 O(n2) 次比较，n 大时不可接受。分治可把它降到 O(n log n)。

比较用距离平方：「谁更近」只需比较 距离的平方，因为 t ↦ t2 在非负区间单调递增。整数坐标下平方是精确整数，既避免每次 sqrt 的开销，又消除舍入误差；只在最后需要输出实际距离时才开方。

二、分治框架

divide & conquer
1
分（Divide）：把点按 x 坐标排序，取中位数 midX 作竖直中线，将点集分成左右两半 L、R，各约 n/2 个。
2
治（Conquer）：递归求左半最近距离 δL 与右半最近距离 δR，令 δ = min(δL, δR)。当点数 ≤ 3 时直接暴力，作为递归基准。
3
合（Combine）：真正的最近点对可能一个在左、一个在右（跨中线）。这种点对两点到中线的水平距离都 < δ，故只可能落在以中线为轴、宽 2δ 的带状区域内。只需在这条带里找是否存在比 δ 更近的点对。
跨界点对必在　|x − midX| < δ　的带状区域内

三、关键：带内为何只需常数次比较

the O(n) merge
第一步：把带内点按 y 坐标排序，逐个考察 让「y 相近」的点相邻 第二步：对点 p，任何能刷新 δ 的点 q 必满足 |yq − yp| < δ，故 q 落在 p 上方一个 2δ(宽) × δ(高) 的矩形内 超出这个矩形距离必 ≥ δ 第三步：把该矩形划成 8 个 (δ/2)×(δ/2) 的小格；每个小格整体落在中线某一侧，而同侧任意两点距离已 ≥ δ，故每格至多 1 个点 小格对角线 = δ/√2 < δ 第四步：矩形内至多 8 个点，于是 p 只需与其后至多 7 个点比较 常数上界 → 带内合并是 O(n)
这一步是分治能成立的灵魂：若带内两两都比，仍是 O(n2)；正是「按 y 排序后每点只与后面常数个点比较」把合并压到 O(n)，才换来整体 O(n log n)。代码里用 strip[j].y − strip[i].y < δ 作为内层循环的提前终止条件来实现这个剪枝。

四、复杂度推导

master theorem
T(n) = 2T(n/2) + O(n)　⟹　T(n) = O(n log n)
分析

分裂成两个规模减半的子问题得 2T(n/2)；带内合并（含按 y 归并 + 常数次比较）是 O(n)。由主定理（Master Theorem）a=2、b=2、f(n)=O(n)，属 logba = 1 的临界情形，故 T(n) = O(n log n)。

别把 log 因子做丢：要达到真正的 O(n log n)，带内点的 y 序应由子问题归并得到（合并阶段 O(n)）。若每层递归都对带内点重新 sort（如本页演示为清晰起见的写法），合并变成 O(n log n)，总复杂度退化为 O(n log2 n)——正确但不最优。预先按 y 排序并在递归中归并即可修复。

五、C++ 实现

分治求最近点对
// 依赖基础模板：Point / Length / operator- double dist(Point a, Point b) { return Length(b - a); } double brute(vector<Point>& p, int l, int r) { // 小规模暴力 double best = 1e18; for (int i = l; i < r; i++) for (int j = i + 1; j < r; j++) best = min(best, dist(p[i], p[j])); return best; } // px 已按 x 排序；返回最近距离 double closest(vector<Point> px) { int n = px.size(); if (n <= 3) return brute(px, 0, n); // 递归基准 int mid = n / 2; double midX = px[mid].x; vector<Point> L(px.begin(), px.begin() + mid); vector<Point> R(px.begin() + mid, px.end()); double d = min(closest(L), closest(R)); // 递归左右两半 vector<Point> strip; // 收集中线 ±d 带内的点 for (auto& q : px) if (fabs(q.x - midX) < d) strip.push_back(q); sort(strip.begin(), strip.end(), [](Point a, Point b) { return a.y < b.y; }); // 按 y 排序 for (int i = 0; i < (int)strip.size(); i++) for (int j = i + 1; j < (int)strip.size() && strip[j].y - strip[i].y < d; j++) d = min(d, dist(strip[i], strip[j])); // 只比常数个点 return d; }
易错点
  • 带内比较写成两两全比，漏掉 y 差 < δ 的提前终止，合并退化为 O(n2)。
  • 只取 min(左半, 右半) 就返回，漏掉跨中线的点对，答案偏大。
  • 带内点未按 y 排序，「每点只比常数个点」的几何前提不成立，剪枝失效。
  • 每层递归内重新 sort 带内点，复杂度悄悄升到 O(n log2 n)；应预排序 + 归并。
  • 比较距离时反复 sqrt，既慢又有误差；应比较距离平方，仅末尾开方。
  • 递归基准（n ≤ 3）或中位数 mid 取值写错，导致左右不均、漏点或死递归。
本节小结
  • 最近点对暴力法 O(n2)，分治可优化到 O(n log n)。
  • 按 x 中位数分成左右两半，递归求 δ = min(δL, δR)。
  • 跨中线的更近点对只可能落在宽 2δ 的中线带状区域内。
  • 带内按 y 排序后，每点只需与后续常数个（至多 7 个）点比较，合并是 O(n)。
  • 递归式 T(n) = 2T(n/2) + O(n) = O(n log n)；比较用距离平方免开方。
1合并阶段，带内点按 y 排序后，每个点为什么只需与后面常数个点比较？
A因为带内点总数是常数
B能刷新 δ 的点必在一个 2δ×δ 矩形内，该矩形按几何装箱至多容纳 8 个点
C因为 y 排序后相同 y 的点只有一个
D因为左右两半各自已经有序
解析：选 B。要打败 δ 的点 q 必满足 |Δy| < δ 且 |Δx| < δ，落在 2δ×δ 的矩形里；把矩形切成 8 个 (δ/2)² 小格，每格整体在中线一侧、同侧点距 ≥ δ，故每格至多 1 点 → 至多 8 点 → 每点只比后续 ≤ 7 个。A 错——带内点数可达 O(n)；限制的是「每点的比较次数」而非「带内点总数」。
2若算法只返回 min(左半最近距离, 右半最近距离) 而省略带内检查，会怎样？
A结果不变，带内检查是多余的
B会漏掉跨中线的点对，可能给出偏大的错误答案
C复杂度会更高
D会重复统计同一对点
解析：选 B。最近的两点完全可能一个在左半、一个在右半，仅比较左右子问题会错过它们，返回值偏大。带状区域检查正是为了在 O(n) 内补上这类跨界点对，缺它答案就不正确。
3递归式 T(n) = 2T(n/2) + O(n) 的解是？
AO(n)
BO(n2)
CO(n log n)
DO(log n)
解析：选 C。这与归并排序的递归式完全相同：每层合并 O(n)，共 log n 层，故 O(n log n)。前提是带内合并确实做到 O(n)——若每层重新排序带内点，合并变 O(n log n)，整体会退化为 O(n log2 n)。
