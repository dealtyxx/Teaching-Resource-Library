一、向量的坐标表示与线性运算

vector · coordinate representation
定义

在平面直角坐标系中，既有大小又有方向的量称为向量（vector），记作 a = (x, y)。若向量由点 A(x1, y1) 指向点 B(x2, y2)，则该有向线段对应的向量为 AB = B − A = (x2−x1, y2−y1)。

a + b = (x1+x2, y1+y2)　　a − b = (x1−x2, y1−y2)　　k·a = (kx1, ky1)
1
加法（平行四边形法则）：以 O 为公共起点作 p 与 q，则 p+q 是以它们为邻边的平行四边形的对角线。演示中的虚线框就是这个平行四边形。
2
减法（三角形法则）：p − q 是从 q 的终点指向 p 的终点的向量。记忆口诀「指向被减数」。在演示里它等于连接 Q → P 的那条箭头。
3
数乘：k > 0 时 k·a 与 a 同向、长度伸缩 k 倍；k < 0 时反向。k = 0 得零向量 (0, 0)。
点与向量共用一个结构体：代码里 Point 与 Vector 都是 (x, y)，但语义必须分清 —— 点 − 点 = 向量（有几何意义）、点 + 向量 = 点（平移）、向量 + 向量 = 向量；而点 + 点在几何上没有意义（只有取中点等加权平均才有意义）。

二、模长与单位向量

length · normalization
|a| = √(x2 + y2)　　　â = a / |a|　（|a| ≠ 0）
性质

模长即向量的长度，也就是两点间的欧几里得距离：dist(A, B) = |B − A| = √((x2−x1)2 + (y2−y1)2)。单位向量 â 保留方向、长度为 1，常用于「沿某方向前进 d 个单位」这类构造：P′ = P + d·â。

只比大小时不要开方：若只需比较 dist(A,B) 与 dist(C,D) 的大小，直接比较距离的平方即可。平方运算在整数坐标下是精确的，而 sqrt 会引入舍入误差且慢得多——这是计算几何最常用的提速兼提精技巧。

三、点积及其几何意义

dot product · projection
定义

点积（dot product，又称数量积、内积）定义为 a·b = x1x2 + y1y2。它的结果是一个标量（数），不是向量。

a · b = x1x2 + y1y2 = |a| |b| cos θ
第一步：设 a、b 夹角为 θ，由余弦定理 |a−b|2 = |a|2 + |b|2 − 2|a||b|cos θ 三角形三边关系 第二步：把左端按坐标展开 |a−b|2 = (x1−x2)2 + (y1−y2)2 代入模长公式 第三步：整理得 |a−b|2 = |a|2 + |b|2 − 2(x1x2 + y1y2) 完全平方展开后归并 第四步：两式对照，立得 x1x2 + y1y2 = |a||b|cos θ 坐标式与几何式等价 第五步：于是 cos θ = (a·b) / (|a||b|)，而 a 在 b 方向上的投影长度 = |a|cos θ = (a·b) / |b| 点积的几何意义
性质

符号判角：由于 |a|、|b| 恒非负，a·b 的符号完全由 cos θ 决定 ——
a·b > 0 ⇔ θ < 90°（锐角，方向大致相同）；
a·b = 0 ⇔ θ = 90°（垂直）；
a·b < 0 ⇔ θ > 90°（钝角，方向大致相反）。

性质

点积满足交换律 a·b = b·a、分配律 a·(b+c) = a·b + a·c、与数乘相容 (ka)·b = k(a·b)；且 a·a = |a|2，这正是「用点积算模长」的依据。

四、C++ 实现

Point / Vector 基础库
// ---------- 计算几何基础模板（本章反复使用）---------- const double EPS = 1e-8; // 容差：坐标量级约 1e3 时的经验取值 int sgn(double x) { // 三态符号函数，避免直接和 0 比较 if (fabs(x) < EPS) return 0; // |x| 足够小就当作 0 return x < 0 ? -1 : 1; } struct Point { // 点与向量共用同一结构 double x, y; Point(double x = 0, double y = 0) : x(x), y(y) {} }; typedef Point Vector; // 语义别名：Vector 表示自由向量 // 线性运算：点−点=向量，点+向量=点 Vector operator+(Vector a, Vector b) { return Vector(a.x + b.x, a.y + b.y); } Vector operator-(Point a, Point b) { return Vector(a.x - b.x, a.y - b.y); } Vector operator*(Vector a, double k) { return Vector(a.x * k, a.y * k); } Vector operator/(Vector a, double k) { return Vector(a.x / k, a.y / k); } // 点积、模长、距离 double Dot(Vector a, Vector b) { return a.x * b.x + a.y * b.y; } double Length2(Vector a) { return Dot(a, a); } // 模长平方：无开方，优先使用 double Length(Vector a) { return sqrt(Dot(a, a)); } double Dist(Point a, Point b) { return Length(b - a); } // 单位向量：调用前必须保证 a 不是零向量 Vector Normalize(Vector a) { double L = Length(a); if (sgn(L) == 0) return Vector(0, 0); // 防除零：零向量无方向 return a / L; } // 夹角（弧度，取值 [0, π]）；必须把 cosθ 夹到 [-1,1]，否则 acos 返回 NaN double Angle(Vector a, Vector b) { double c = Dot(a, b) / (Length(a) * Length(b)); if (c > 1.0) c = 1.0; if (c < -1.0) c = -1.0; return acos(c); } // 垂直判定：不能写 Dot(a,b) == 0 ！ bool Perpendicular(Vector a, Vector b) { return sgn(Dot(a, b)) == 0; }

五、复杂度分析

全部为 O(1)，但常数差别很大
运算时间浮点开销整数坐标下是否精确
加 / 减 / 数乘O(1)1 次加减精确
点积 DotO(1)2 乘 1 加精确（不溢出时）
模长平方 Length2O(1)2 乘 1 加精确
模长 LengthO(1)含 1 次 sqrt（约 10~20 倍乘法）否，有舍入
夹角 AngleO(1)含 sqrt + acos（最慢）否，误差最大
结论：能用 Dot / Length2 表达的判定，就绝不写 Length / Angle。整数坐标下 Dot 与 Length2 是零误差的，这也是后续叉积判定能做到「几乎不出错」的根本原因。

六、退化情形与浮点精度

本章的生死线
退化 / 陷阱后果正确处理
零向量 a = (0,0)Normalize 除零得 inf/nan；夹角无定义先 sgn(Length(a))==0 判空并单独返回
Dot/( |a||b| ) 因舍入超出 [−1,1]acos 返回 NaN，之后所有比较都为 false先 clamp 到 [−1, 1] 再 acos
写 Dot(a,b) == 0 判垂直几乎永远为 false，逻辑失效写 fabs(Dot(a,b)) < EPS
EPS 取得过大 / 过小过大：不同的点被当成同一点；过小：等价的量被判为不等按坐标量级选：坐标 ~1e3 用 1e-8；坐标 ~1e9 需用相对误差
坐标是大整数且用了 int 存点积x1x2 溢出，符号翻转用 long long 或 double，并估算量级
易错点
  • 把模长写成 x2+y2 而忘记开方——或者反过来，明明只比大小却多此一举开了方。
  • 用 == 直接比较两个浮点数（判重合、判垂直、判共线都不行）。
  • 把 a·b 当成向量：点积的结果是标量，不能再拿去做叉积。
  • 把「点 + 点」写进代码——除非是在求中点 (A+B)/2，否则几何上没有意义。
  • acos 之前不 clamp，遇到两向量几乎同向时得到 NaN。
  • 误以为 a·b = 0 就一定是垂直：若 a 或 b 是零向量，点积也是 0，但此时夹角根本没有定义。

七、承上启下

两个原语撑起一整章
点积与叉积是本章一切几何判定的基础。点积回答「夹角是锐还是钝」，叉积（下一节）回答「在左还是在右」。此后的方向判断、点到线段距离、跨立相交、点在多边形内、多边形面积、凸包扫描、旋转卡壳，全部都是由这两个 O(1) 的原语拼装出来的——把它们写对、写稳，本章就成功了一半。
向量vector 模长magnitude / length 单位向量unit vector 点积dot product 投影projection 容差epsilon / tolerance 退化情形degenerate case
本节小结
  • 向量用坐标 (x, y) 表示；点 − 点 = 向量是把几何问题代数化的第一步。
  • 加减遵循平行四边形 / 三角形法则，数乘只改变长度与朝向，运算全部逐分量进行。
  • 模长 |a| = √(x2+y2)；只作大小比较时用模长平方，既快又精确。
  • 点积 a·b = x1x2+y1y2 = |a||b|cos θ，几何意义是投影；符号直接给出锐角 / 直角 / 钝角。
  • 所有基本运算都是 O(1)，但 sqrt 与 acos 既慢又有误差，能不用就不用。
  • 浮点比较一律走 sgn(x) 容差函数；acos 之前一定要 clamp；零向量必须单独判。
1已知 a = (3, 4)，b = (−4, 3)，则 a·b 与两向量的夹角分别是？
Aa·b = 0，夹角为 90°
Ba·b = 25，夹角为 0°
Ca·b = 24，夹角为锐角
Da·b = −24，夹角为钝角
解析：a·b = 3×(−4) + 4×3 = −12 + 12 = 0，故两向量垂直，选 A。B 的 25 其实是 |a|·|b| = 5×5，是模长的乘积而非点积，把公式 a·b = |a||b|cos θ 里的 cos θ 漏掉了；C、D 是把两项符号搞错（写成 3×4 + 4×3 或 3×(−4) − 4×3）的结果。注意：这里点积为 0 能推出垂直，是因为 a、b 都不是零向量。
2要判断向量 a 与 b 是否垂直，下列 C++ 写法中唯一正确的是？
Aif (Dot(a, b) == 0)
Bif (Dot(a, b) < EPS)
Cif (fabs(Dot(a, b)) < EPS)
Dif (Angle(a, b) == acos(0))
解析：选 C。A 用 == 比较浮点，由于舍入误差实际算出的可能是 3.55e-15 而非严格的 0，条件几乎永远不成立。B 是最有迷惑性的错误：Dot < EPS 只卡住了上界，任何很大的负点积（比如 −1000，明显是钝角）都会被误判为垂直，必须取绝对值。D 同样是浮点相等比较，而且经过 sqrt 与 acos 两次放大，误差比 A 还大。
3在一个整数坐标点集中反复比较「哪两点更近」，最佳做法是？
A用 Length 求出距离后比较，代码最直观
B比较距离的平方 Length2，避免 sqrt
C比较 Angle，角度小的点更近
D先 Normalize 再比较单位向量
解析：选 B。因为 t ↦ t2 在非负区间上单调递增，比较 d 与比较 d2 结论完全一致；而整数坐标下 d2 是精确整数，既零误差又省掉每次约 10~20 倍乘法开销的 sqrt。A 结论正确但慢且引入舍入误差；C 完全跑偏——夹角与距离无关，两个夹角很小的点可能相距很远；D 归一化后长度信息被抹掉了，根本无从比较远近。
