第3章 穷举法 · 算法演示加深

系统枚举候选解并检验。前缀和、并查集、Kadane、位运算幂集、皇后与 TSP 全排列均可交互。

本章学习目标

  1. 能够陈述穷举法（brute force）的定义与"确定解空间 → 系统列举 → 逐一检验"三步框架，并判断一个问题是否适合用穷举法求解。
  2. 能够写出三类列举方式的代码骨架：多重循环、递归回溯、位运算掩码，并说明各自的适用规模。
  3. 能够推导本章各算法的时间复杂度：幂集 O(n·2n)、全排列 Θ(n!)、n 皇后 O(n!)、前缀和预处理 O(n) + 查询 O(1)、并查集近似 O(α(n))。
  4. 能够应用前缀和与并查集这两种"降复杂度"工具，并解释穷举法为何只适合小规模问题、后续章节用什么手段突破。

知识地图

Knowledge Map · 九节之间的依赖关系
A
方法论主干（§01 → §02）：先建立穷举法的三步框架与通用伪代码模板，再落到三种具体列举手段（多重循环 / 递归回溯 / 位运算掩码）。这两节是全章的"语法基础"。
B
加速工具（§03 前缀和、§04 并查集）：穷举本身无法避免枚举量，但可以把"每次检验"的代价压下来。前缀和把区间求和从 O(n) 降到 O(1)；并查集把连通性判断降到近似 O(α(n))。它们是穿插在穷举循环内部的常数级工具。
C
子集型解空间（§05 最大子段和、§06 幂集）：解空间是 2n 规模。§06 讲"枚举全部子集"这一模式本身，§05 则展示同一问题从 O(n3) → O(n2) → O(n log n) → O(n) 的优化脉络。
D
排列型解空间（§07 全排列、§08 n 皇后、§09 分配与 TSP）：解空间是 n! 规模。§07 给出生成排列的两套算法；§08 用"列的排列"巧妙压缩解空间；§09 把排列穷举用到两个经典 NP 难问题上，作为全章落脚点。
