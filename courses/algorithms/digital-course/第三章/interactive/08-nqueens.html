学习目标

  2. 能够推导对角线冲突的判定条件：两皇后同对角线 ⇔ |行差| = |列差| ⇔ |q[k] − q[i]| = |k − i|。
  3. 能够写出 n 皇后的 C++ 穷举/回溯代码，并说明冲突检查放在哪一层。
  4. 能够对比逐格暴力、列排列穷举与回溯剪支三种做法的解空间规模。

易错点
  • 解向量含义：q[i] 记第 i 行皇后所在列。逐行放一个天然避免了“同行冲突”。
  • 同列判定：q[i]==q[k] 即同列。
  • 同对角线判定：|q[i]−q[k]| == |i−k| 一式同时覆盖主、副对角线，别只判一条。
  • 用排列穷举时：排列已保证列互不相同（同列自动排除），只需再判对角线。
  • 解数记错：8 皇后共 92 个解，不是 8。
  • 下标越界：q[i] 取值范围 0..n−1，检查冲突只需与已放置的前 i 行比较。
本节小结
  • 用解向量 q[0..n−1]，q[i] 为第 i 行皇后的列号，逐行放置。
  • 两皇后 (i,q[i])、(k,q[k]) 冲突 ⟺ 同列 q[i]==q[k] 或同对角线 |q[i]−q[k]|==|i−k|。
  • 穷举全排列判对角线为 O(n!·n)；回溯边扩展边剪枝远快于纯穷举。
  • 解的规模随 n 增长不单调：4→2、5→10、6→4、7→40、8→92。
  • 空间 O(n)（仅一个解向量）。
