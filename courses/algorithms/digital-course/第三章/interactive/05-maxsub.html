一、问题定义

Maximum Subarray Problem
定义

最大连续子段和问题（maximum subarray problem）：给定整数序列 a[0..n−1]（可含负数），求一个连续子段 a[i..j]（0 ≤ i ≤ j ≤ n−1），使 ∑t=ij a[t] 最大，输出该最大值（有时还需输出 i、j）。

两个必须先厘清的约定：
① "连续"：子段必须是原序列中相邻的一段，与"子序列"（可跳着取）截然不同。本问题若允许不连续，答案就退化成"所有正数之和"，毫无难度。
② 空子段是否合法：若允许取空子段（和为 0），则全负数组的答案是 0；若要求至少取一个元素，则全负数组的答案是最大的那个负数。李春葆教材与多数 OJ 采用后者，本页所有代码也采用后者。这是本题最容易被忽略的边界。
贯穿全节的样例：a = [−2, 1, −3, 4, −1, 2, 1, −5, 4]（即上方演示的默认数据）。答案是子段 a[3..6] = [4, −1, 2, 1]，和为 6。可在演示中点击"▶ Kadane"逐步观察。

二、解法一：O(n3) 朴素三重循环

Brute Force

最直接的穷举：枚举起点 i、终点 j，再用第三重循环把 a[i..j] 累加一遍。这是"三步框架"的原样套用——解空间是全部 C(n,2)+n = n(n+1)/2 个子段。

// 解法一：O(n³) —— 枚举 i、j 后重新累加 int maxSub1(int a[], int n) { int best = a[0]; for (int i = 0; i < n; i++) for (int j = i; j < n; j++) { int s = 0; for (int k = i; k <= j; k++) s += a[k]; // ← 第三重循环，纯属浪费 if (s > best) best = s; } return best; }
第一步 子段个数为 ∑i=0n−1(n−i) = n(n+1)/2 = Θ(n2) 外两重循环 第二步 每个子段的累加平均耗时 Θ(n) 内层第三重循环 第三步 总时间 T(n) = Θ(n2) · Θ(n) = Θ(n3) 精确为 n(n+1)(n+2)/6

三、解法二：O(n2) 边枚举边累加

Incremental Sum
优化的关键观察：当 j 从 i 递增到 n−1 时，a[i..j] 的和只需在 a[i..j−1] 的和上再加一个 a[j]，完全不必重算。第三重循环因此被彻底消除。这等价于对每个固定的 i 就地维护一个前缀和（呼应 §03 的思想）。
// 解法二：O(n²) —— 消去第三重循环 int maxSub2(int a[], int n) { int best = a[0]; for (int i = 0; i < n; i++) { int s = 0; for (int j = i; j < n; j++) { s += a[j]; // 增量累加，O(1) 得到 a[i..j] 之和 if (s > best) best = s; } } return best; // 时间 Θ(n²)，空间 O(1) }
另一种等价写法：先建前缀和数组 S，则 a[i..j] 之和 = S[j+1] − S[i]，同样把内层降到 O(1)，总时间也是 O(n2)，但额外用了 O(n) 空间。上方演示中的"暴力对比"按钮采用的正是本节的增量累加写法，其步数计数即 n(n+1)/2。

四、解法三：O(n log n) 分治法

Divide and Conquer · 与第 4 章呼应
定理

把序列 a[lo..hi] 从中点 mid = (lo+hi)/2 一分为二，则最大子段必属于且仅属于下列三种互斥情况之一：
① 完全落在左半 a[lo..mid] 之内；
② 完全落在右半 a[mid+1..hi] 之内；
③ 跨越中点，即同时包含 a[mid] 与 a[mid+1]。
故答案 = max(情况①, 情况②, 情况③)。

为什么这三种情况恰好穷尽：任取一个子段 a[i..j]。若 j ≤ mid，属①；若 i ≥ mid+1，属②；否则必有 i ≤ mid < mid+1 ≤ j，即该子段同时越过 mid 与 mid+1，属③。三种情况不重不漏——这正是分治法正确性的全部依据，也是穷举思想在分治框架下的体现。
情况③为何能在 O(n) 内求出：跨中点的子段必然形如 a[i..mid] + a[mid+1..j]。这两段可以独立取最优：从 mid 向左逐个累加，记录能达到的最大值 leftMax；从 mid+1 向右逐个累加，记录最大值 rightMax；答案即 leftMax + rightMax。两次线性扫描共 O(n)。注意这两段都必须非空（各至少含一个元素），因此初值应设为负无穷而非 0。
// 解法三：O(n log n) 分治法 const int NEG = -1000000000; // 求跨越中点的最大子段和：必须同时含 a[mid] 与 a[mid+1] int crossMax(int a[], int lo, int mid, int hi) { int s = 0, leftMax = NEG; for (int i = mid; i >= lo; i--) { // 从中点向左扩张 s += a[i]; if (s > leftMax) leftMax = s; } s = 0; int rightMax = NEG; for (int j = mid + 1; j <= hi; j++) { // 从中点向右扩张 s += a[j]; if (s > rightMax) rightMax = s; } return leftMax + rightMax; // 两段独立取最优，直接相加 } int maxSub3(int a[], int lo, int hi) { if (lo == hi) return a[lo]; // 递归出口：只剩一个元素 int mid = lo + (hi - lo) / 2; int L = maxSub3(a, lo, mid); // ① 左半最大子段 int R = maxSub3(a, mid + 1, hi); // ② 右半最大子段 int C = crossMax(a, lo, mid, hi); // ③ 跨中点最大子段 int ans = L > R ? L : R; // 三者取最大 return ans > C ? ans : C; } // 调用：maxSub3(a, 0, n-1);
第一步 分解：把规模 n 的问题拆成两个规模 n/2 的子问题 对应 2T(n/2) 第二步 合并：crossMax 两次线性扫描 对应 O(n) 第三步 得递推式 T(n) = 2T(n/2) + Θ(n)，T(1) = Θ(1) 与归并排序完全同型 第四步 由主定理，a = 2、b = 2、f(n) = Θ(nlog22) 属情形 2 故 T(n) = Θ(n log n)
手工演算（跨中点部分）：对 a = [−2, 1, −3, 4, −1, 2, 1, −5, 4]，取 lo=0、hi=8、mid=4。
向左从 a[4]=−1 累加：−1, 3(+4), 0(−3), 1(+1), −1(−2) ⇒ leftMax = 3（对应 a[3..4]）。
向右从 a[5]=2 累加：2, 3(+1), −2(−5), 2(+4) ⇒ rightMax = 3（对应 a[5..6]）。
故 crossMax = 3 + 3 = 6，恰为全局答案（子段 a[3..6]）。
空间复杂度：分治法本身只用 O(1) 辅助变量，但递归栈深度为 O(log n)，故空间为 O(log n)——这是它相比 Kadane 的唯一劣势。分治法的价值在于它是通用的思想训练（第 4 章）：当问题不具备最优子结构、无法用 Kadane 时，分治往往仍然可行。

五、解法四：O(n) Kadane 算法

Kadane's Algorithm · 动态规划思想
状态定义

设 dp[i] = 以 a[i] 为结尾的最大子段和（注意：是"必须以 a[i] 结尾"，不是"前 i 个元素中的最大子段和"）。这一定义是全部推导的起点，定义错了后面全错。

dp[i] = max( a[i],   dp[i−1] + a[i] )，  dp[0] = a[0]
第一步 以 a[i] 结尾的子段只有两种可能 要么它自己单独成段，要么它接在以 a[i−1] 结尾的某个子段之后 第二步 若接在后面，则前面那段应取最优，即 dp[i−1] 最优子结构：局部最优可拼成全局最优 第三步 故 dp[i] = max(a[i], dp[i−1] + a[i])；等价写法 dp[i] = a[i] + max(0, dp[i−1]) 即"前面那段若为负就丢掉" 第四步 最终答案 = max0≤i<n dp[i] 最大子段总得以某个元素结尾，遍历全部结尾即可
// 解法四：O(n) Kadane —— 完整 dp 数组版（便于理解） int maxSub4(int a[], int n) { int dp[100005]; dp[0] = a[0]; int best = dp[0]; for (int i = 1; i < n; i++) { dp[i] = (dp[i - 1] + a[i] > a[i]) ? dp[i - 1] + a[i] : a[i]; if (dp[i] > best) best = dp[i]; } return best; // 时间 O(n)，空间 O(n) } // 滚动变量版：dp[i] 只依赖 dp[i-1]，故一个变量足矣 —— 空间降到 O(1) int kadane(int a[], int n) { int dp = a[0], best = a[0]; for (int i = 1; i < n; i++) { dp = (dp > 0) ? dp + a[i] : a[i]; // 前缀为负则丢弃，从 a[i] 重新开始 if (dp > best) best = dp; } return best; // 时间 O(n)，空间 O(1) } // 需要同时输出区间端点 [bl, br] 的版本 int kadanePos(int a[], int n, int &bl, int &br) { int dp = a[0], best = a[0], L = 0; bl = br = 0; for (int i = 1; i < n; i++) { if (dp > 0) dp += a[i]; else { dp = a[i]; L = i; } // 重新开始时更新左端点 if (dp > best) { best = dp; bl = L; br = i; } } return best; }

六、四种解法复杂度对照

Comparison
解法核心思想时间空间n=105 可否能否输出端点
① 朴素三重循环穷举全部子段并重新累加Θ(n3)O(1)否（约 1015）可
② 增量累加 / 前缀和消去内层重复求和Θ(n2)O(1) / O(n)否（约 1010）可
③ 分治法左半 / 右半 / 跨中点三者取最大Θ(n log n)O(log n) 栈可（约 1.7×106）可（需额外记录）
④ Kadanedp[i] = max(a[i], dp[i−1]+a[i])Θ(n)O(1)可（105）可
优化脉络（本节的真正主线）：Θ(n3) → Θ(n2) → Θ(n log n) → Θ(n)。
第一步优化靠消除重复计算（增量累加）；第二步靠分治（把 n2 对起止点的枚举压成 log n 层合并）；第三步靠动态规划（发现最优子结构，把"枚举起点"这一维彻底消掉）。这条脉络几乎是全书方法论的缩影：同一问题，随着对结构认识的加深，复杂度层层下降。而 Θ(n) 已是本问题的下界——任何算法至少要读一遍全部输入。
易错点
  • best 初始化为 0：当数组全为负数时会错误地输出 0。若题目要求子段非空，应初始化为 a[0] 或负无穷，绝不能用 0。这是本题最高频的 WA 原因。
  • dp 状态定义成"前 i 个元素中的最大子段和"：这样定义无法写出递推——因为不知道最优子段是否延伸到 i。必须定义成"以 a[i] 结尾"，最后再对所有 dp[i] 取最大。
  • 忘记最后对 dp[] 取最大值：直接返回 dp[n−1] 是错的，它只是"以最后一个元素结尾"的最大值。样例中 dp[8]=5 ≠ 6。
  • 分治的 crossMax 把 leftMax/rightMax 初值设为 0：这会允许"左段为空"或"右段为空"，与情况③"必须跨越中点"矛盾，在全负数组上给出错误答案。初值必须是负无穷。
  • 分治只算左右两半而忘了跨中点：这是分治法的头号错误，会漏掉所有横跨中线的解，样例中恰好就会漏掉正确答案 6。
  • mid 写成 (lo+hi)/2 且 lo、hi 很大：可能整型溢出，应写 lo + (hi - lo) / 2。
  • Kadane 写成 dp = max(dp + a[i], 0)：这是"允许空子段"的变体，与"子段非空"的题设不符，全负数组会返回 0。
  • 把本题与"最大子序列和"混淆：后者不要求连续，答案就是所有正数之和（或最大元素），是完全不同的问题。
本节小结
  • 问题：求连续子段的最大和；先确认"是否允许空子段"，这决定了全负数组的答案是 0 还是最大负数。
  • O(n3)：枚举 i、j 后再累加，第三重循环纯属重复劳动。
  • O(n2)：固定 i、j 递增时增量累加（或用前缀和），消去第三重循环。
  • O(n log n) 分治：最大子段必属"完全在左半 / 完全在右半 / 跨越中点"三者之一，三者取最大；跨中点部分由两次线性扫描 O(n) 求出（两段均须非空）。递推式 T(n) = 2T(n/2) + O(n) ⇒ Θ(n log n)。
  • O(n) Kadane：定义 dp[i] 为以 a[i] 结尾的最大子段和，递推 dp[i] = max(a[i], dp[i−1] + a[i])，答案取 max dp[i]；用滚动变量可把空间压到 O(1)。
  • 优化脉络 Θ(n3) → Θ(n2) → Θ(n log n) → Θ(n) 分别对应"消除重复计算 → 分治 → 动态规划"，是全书方法论的缩影。
1用分治法求最大子段和时，若遗漏了"跨越中点"这一情况，对样例 a = [−2, 1, −3, 4, −1, 2, 1, −5, 4]（mid = 4）会得到什么结果？
A仍得 6，因为最优解恰好落在右半
B得 4，小于正确答案 6
C得 0，因为左右两半的和都是负数
D结果不确定，取决于递归的分解方式
解析：B 正确。左半 a[0..4] = [−2,1,−3,4,−1] 的最大子段是 [4]，和为 4；右半 a[5..8] = [2,1,−5,4] 的最大子段是 [2,1]，和为 3；两者取最大得 4。而正确答案 6 对应的子段 a[3..6] 恰好横跨中点 mid=4 与 mid+1=5，正是被漏掉的那一类。A 的错误在于没验算就假定最优解在某一半。C 混淆了"子段和"与"整半之和"——即使某一半的总和为负，其内部仍可能存在正的子段。D 错误：分治的分解点虽可变，但三种情况穷尽是定理，漏掉一种必然可能出错，与分解方式无关。
2Kadane 算法中 dp[i] 的正确含义是？
Aa[0..i] 这一前缀中的最大子段和
B所有以 a[i] 结尾的子段中的最大和
C所有以 a[i] 开头的子段中的最大和
Da[0..i] 的前缀和，即 a[0]+…+a[i]
解析：B 正确。正因为强制"以 a[i] 结尾"，才能与 dp[i−1] 建立联系：以 a[i] 结尾的段要么单独是 a[i]，要么是"以 a[i−1] 结尾的最优段"再接上 a[i]。A 是最具迷惑性的错误——它虽然也是一个合法的状态定义，但无法写出递推式：仅知道前缀内的最大值，无从判断能否把 a[i] 接上去。若采用 A，答案确实等于 dp[n−1]（这也是很多人记混的根源），但递推无法成立。C 的定义需要从右往左递推，是 B 的镜像版本，与本节公式不符。D 是 §03 的前缀和，与最大子段无关（样例中 dp[6]=6 而前缀和为 2）。
3数组 a = [−5, −2, −8, −1, −7]（全为负数），要求子段至少含一个元素。若代码把 best 初始化为 0，输出是多少？正确答案又是多少？
A输出 0，正确答案也是 0
B输出 0，正确答案是 −1
C输出 −1，正确答案是 −23
D输出 −23，正确答案是 −1
解析：B 正确。best 初始化为 0 后，由于所有 dp[i] 都是负数，条件 dp > best 永不成立，best 始终保持 0，程序输出 0——但题目要求子段非空，0 对应的是空子段，是非法解。正确答案应是最大的那个元素 −1（子段 [−1]）。A 是"允许空子段"约定下的答案，与题设不符。C、D 中的 −23 是全部元素之和，只有在"必须取整个数组"时才有意义，不是本题的解。修复方法：把 best 初始化为 a[0] 或 INT_MIN。
