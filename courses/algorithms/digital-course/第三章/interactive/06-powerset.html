一、幂集的定义

Power Set · 集合论基础
定义

设 S 是一个集合。S 的幂集（power set）记作 2S 或 P(S)，定义为由 S 的全部子集所构成的集合：

2S = { A  |  A ⊆ S }
请注意三点措辞：
① 幂集的元素本身是集合——2S 是一个"集合的集合"。因此 {1} ∈ 2S 与 {1} ⊆ S 是两个不同层次的断言，都成立但含义不同。
② 幂集一定包含空集 ∅ 和 S 自身，因为 ∅ ⊆ S 且 S ⊆ S 恒成立。漏掉这两个是最常见的错误。
③ 记号 2S 中的"2"并非巧合：它来自下面的基数公式，也来自"每个元素有 2 种命运（属于/不属于）"这一直观。
例：S = {a, b, c}，则
2S = { ∅, {a}, {b}, {c}, {a,b}, {a,c}, {b,c}, {a,b,c} }，共 8 个元素。
再如 S = ∅ 时，2∅ = { ∅ }，只有 1 个元素（注意不是空集本身——2∅ 是含一个元素的集合，|2∅| = 1 = 20 ✓）。

二、基数性质与证明

Cardinality
定理

若 |S| = n（S 为有限集），则 |2S| = 2n。

|2S| = 2|S|
证法一（乘法原理） 为 S 的每个元素独立决定"属于 A"或"不属于 A" 共 n 个元素，每个 2 种选择 不同的决策组合给出不同的子集，且任一子集都由某组决策产生 决策与子集一一对应（双射） 故子集总数 = 2 × 2 × … × 2（n 个 2）= 2n 乘法原理 证法二（二项式） 大小恰为 k 的子集有 C(n,k) 个，故总数 = ∑k=0n C(n,k) 按子集大小分类计数 由二项式定理 (1+1)n = ∑k=0n C(n,k)·1k·1n−k = 2n 两种证法结果一致
性质

与 0/1 向量的双射：把子集 A ⊆ S 映射为特征向量 x = (x0, …, xn−1)，其中 xi = 1 ⇔ ai ∈ A。该映射是双射，而 0/1 向量又与整数 [0, 2n) 一一对应。正是这条"子集 ⇔ 0/1 向量 ⇔ 整数"的三重对应，使得位掩码枚举成为可能，也是状态压缩动态规划（第 7 章）的理论基础。

性质

幂集的格结构：(2S, ⊆) 构成一个布尔格（Boolean lattice），最小元是 ∅，最大元是 S，交与并分别是格的下确界与上确界。在位掩码表示下，∩ 对应按位与 &，∪ 对应按位或 |，补集对应按位取反后与全集掩码相与。这使得集合运算可以用单条 CPU 指令完成——这正是位运算法常数极小的根本原因。

三、算法实现与复杂度

Implementation
// ===== 求幂集：位掩码法（对应上方演示）===== // 依据：子集 ⟺ 0/1 向量 ⟺ 整数 mask ∈ [0, 2^n) void powerSet(char a[], int n) { int total = 1 << n; // total = 2^n，即 |2^S| for (int mask = 0; mask < total; mask++) { // 外层：2^n 个子集 printf("{"); for (int i = 0; i < n; i++) // 内层：检查 n 个二进制位 if ((mask >> i) & 1) printf("%c ", a[i]); printf("}\n"); // mask = 0 时输出 {}，即空集 } } // 时间 O(n·2^n)，额外空间 O(1)
// ===== 求幂集：递归法（"选 / 不选"判定树）===== char path[32]; int top = 0; void dfs(char a[], int n, int i) { if (i == n) { output(path, top); return; } path[top++] = a[i]; dfs(a, n, i + 1); top--; // 选 a[i] dfs(a, n, i + 1); // 不选 a[i] } // 时间 O(n·2^n)，空间 O(n)（递归栈 + path）
// ===== 求幂集：增量构造法（数学归纳法的直接实现）===== // 依据：2^{S ∪ {x}} = 2^S ∪ { A ∪ {x} : A ∈ 2^S } // 即：加入一个新元素，幂集规模恰好翻倍 void buildIncremental(char a[], int n, vector<vector<char>> &res) { res.clear(); res.push_back({}); // 起点：2^∅ = { ∅ } for (int i = 0; i < n; i++) { int sz = res.size(); // 先记下当前规模，否则会边遍历边扩容 for (int k = 0; k < sz; k++) { vector<char> t = res[k]; t.push_back(a[i]); // 每个旧子集派生一个含 a[i] 的新子集 res.push_back(t); } } // 规模变化：1 → 2 → 4 → … → 2^n }
第一步 外层循环执行 2n 次 每个 mask 对应一个子集，共 |2S| = 2n 个 第二步 内层循环固定执行 n 次 需逐位检查 n 个二进制位 第三步 T(n) = Θ(n · 2n) 这也是输出全部子集所需时间的下界——所有子集的元素总数恰为 n·2n−1 第四步 该复杂度无法改进 输出规模本身就是 Θ(n·2n)，属输出敏感（output-sensitive）的紧界
T(n) = O(n · 2n)，  空间 O(1)（位掩码法，不含输出）
为什么是 n·2n 而不是 2n：常见误答是 O(2n)——那只是"子集的个数"。但要真正输出或处理每个子集，平均还需 O(n) 的工作量（检查 n 个位或复制 n/2 个元素）。事实上，全部子集的元素总数为 ∑k k·C(n,k) = n·2n−1，与 n·2n 同阶。只有当每个子集用 O(1) 时间处理（例如仅用 mask 本身做状压 DP 的下标）时，总时间才是 O(2n)。

与后续章节的联系：幂集是"子集型解空间"的标准形态。0/1 背包、集合覆盖、最大团、旅行商的状压 DP，其解空间都是某个集合的幂集。因此本节的 2n 不只是一个数字，它是一整类 NP 难问题的规模标尺：把 mask 直接当作 DP 数组下标，就得到第 7 章的状态压缩动态规划。
易错点
  • 漏掉空集或全集：幂集必含 ∅ 与 S 本身。位掩码法中 mask 必须从 0 取到 2n−1（含两端），任何"从 1 开始"或"到 2n−2 结束"的写法都是错的。
  • 把 |2S| 算成 2n 或 n2：是 2 的 n 次方，不是 2 乘 n。n = 10 时是 1024 而不是 20 或 100。
  • 混淆 ∈ 与 ⊆：{a} ∈ 2S 正确（幂集的元素是集合）；{a} ⊆ 2S 则要求 a 本身是 S 的子集，通常不成立。而 ∅ 特殊：∅ ∈ 2S 与 ∅ ⊆ 2S 同时成立。
  • 认为 2∅ = ∅：错。2∅ = { ∅ }，含 1 个元素，|2∅| = 20 = 1，而 |∅| = 0。
  • 把复杂度写成 O(2n)：忽略了处理每个子集的 O(n) 代价。除非每个子集只需 O(1) 处理，否则应写 O(n·2n)。
  • 增量构造法中边遍历边 push_back：若循环条件直接写 k < res.size()，res 在循环内不断增长会导致死循环。必须先用 sz 记下本轮开始时的规模。
  • n ≥ 31 时用 int 存 mask：1 << 31 溢出，须用 1LL << n；不过 n > 25 时本就该换算法了。
本节小结
  • 幂集 2S = { A | A ⊆ S }，是"由 S 的全部子集构成的集合"；它的元素本身是集合，且必含 ∅ 与 S。
  • 核心性质 |2S| = 2|S|，可由乘法原理（每元素两种命运）或二项式定理 ∑C(n,k) = 2n 两种途径证明。
  • "子集 ⇔ 0/1 向量 ⇔ 整数 mask"的三重双射，是位掩码枚举与状态压缩 DP 的共同理论基础。
  • 求幂集的时间复杂度为 O(n·2n)（位掩码法额外空间 O(1)），且该界不可改进，因为输出规模本身即 Θ(n·2n)。
  • 三种实现（位掩码 / 递归 / 增量构造）时间同阶，差别在空间、生成顺序与能否剪支。
  • 本节侧重幂集这一对象的定义与性质；§02 侧重列举技巧的选择与比较——两者互补，不是重复。
1设 S = {1, 2, 3, 4}，下列关于 2S 的说法正确的是？
A|2S| = 8，因为 4 个元素每个有两种状态，2×4 = 8
B|2S| = 16，且 ∅ ∈ 2S、S ∈ 2S 均成立
C|2S| = 15，因为空集不算作子集
D|2S| = 16，但 2S 的元素都是数，不是集合
解析：B 正确：|2S| = 24 = 16，且幂集必含空集与全集。A 把乘法原理算成了加法——是 2×2×2×2 = 24，不是 2×4。C 是"真子集/非空子集"的个数（2n−1 = 15），但空集是子集，题问的是全部子集。D 的基数对了，但概念错了：幂集的元素是 S 的子集（如 {1,3}），是集合而非数。
2用位掩码法枚举并打印 n 个元素的全部子集，时间复杂度是？
AO(2n)
BO(n · 2n)
CO(n2)
DO(n!)
解析：B 正确：外层 2n 个 mask，内层固定 n 次位检查，故 O(n·2n)。A 是最具迷惑性的错误——2n 只是子集的个数，遗漏了处理每个子集所需的 O(n)。只有当每个子集用 O(1) 处理（如仅把 mask 用作 DP 下标而不展开元素）时才是 O(2n)。C 严重低估：n = 20 时 n2 = 400，而实际约 2×107。D 混淆了子集型（2n）与排列型（n!）解空间，n ≥ 4 时 n! > 2n。
3下列代码试图枚举 a[0..n−1] 的全部子集，其中存在错误的是？
A: for(int m=0; m<(1<<n); m++)   B: for(int m=0; m<=(1<<n)-1; m++)   C: for(int m=1; m<(1<<n); m++)
A只有 A 错
B只有 B 错
C只有 C 错，它漏掉了空集
D三者都正确，只是风格不同
解析：C 错，且 C 正确。A 与 B 是完全等价的写法：m < 2n 与 m ≤ 2n−1 在整数上同义，都恰好遍历 0..2n−1 共 2n 个值。C 从 m = 1 起，跳过了 m = 0 所对应的空集，只枚举了 2n−1 个非空子集。若题目要求"全部子集"则 C 是错的；若恰好要求"全部非空子集"，C 反而正确——这提醒我们：先读清题目对空集的要求，再决定循环起点。选 D 的人往往没有意识到 m = 0 承载着空集这一合法解。
