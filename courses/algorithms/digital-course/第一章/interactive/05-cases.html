关于"随机输入"按钮：它每次只生成一个随机数组并跑一遍，得到的是某一次抽样的结果，多点几次会发现数字每次都不一样。这不等于平均情况复杂度——平均情况是对全部可能输入按概率加权求出的期望值 E[T(n)]，是一个确定的数学量，不能通过跑一次得到。详见下文第三部分。

一、三种情况的定义

Best / Worst / Average Case

同一个算法对不同的输入，执行的基本操作次数可能相差很大。设 Dn 为规模为 n 的全部合法输入构成的集合，T(I) 为算法在输入 I 上的基本操作次数。

定义

最好情况（Best Case）：B(n) = minI ∈ Dn T(I)，即在所有规模为 n 的输入中，算法执行次数最少的那一个。

定义

最坏情况（Worst Case）：W(n) = maxI ∈ Dn T(I)，即在所有规模为 n 的输入中，算法执行次数最多的那一个。它给出了运行时间的上界保证。

定义

平均情况（Average Case）：A(n) = E[T(I)] = ∑I ∈ Dn P(I)·T(I)，其中 P(I) 为输入 I 出现的概率，∑P(I) = 1。它是对所有输入按概率加权的数学期望。

A(n) = ∑I ∈ Dn P(I) · T(I)　　（通常假定各输入等概率，即 P(I) = 1/|Dn|）
B(n) ≤ A(n) ≤ W(n)

二、插入排序的 C++ 实现与推导

Insertion Sort
// 直接插入排序：把 a[i] 插入到左侧已排好序的 a[0..i-1] 中 // 基本操作：关键字比较 a[j] > key void insertSort(int a[], int n) { for (int i = 1; i < n; i++) { // 外层：n-1 趟 int key = a[i]; // 待插入元素（哨兵） int j = i - 1; while (j >= 0 && a[j] > key) { // 比较：基本操作 a[j + 1] = a[j]; // 移动 j--; } a[j + 1] = key; // 落位 } }

最好情况（输入已升序，如 1 2 3 … 8）：每趟 while 的条件 a[j] > key 第一次判断即为假，立刻退出。

每趟比较 1 次，移动 0 次 a[i-1] ≤ a[i] 立即成立 B(n) = ∑i=1n−1 1 = n − 1 外层共 n-1 趟 ⇒ B(n) = Θ(n) 线性阶

最坏情况（输入已降序，如 8 7 6 … 1）：每趟 key 都比左侧有序区的所有元素小，必须一直比较到 j < 0 为止。

第 i 趟（i = 1, 2, …, n−1）左侧有序区含 i 个元素 key 小于其中每一个 ⇒ 该趟比较 i 次、移动 i 次 一直退到数组左端 W(n) = ∑i=1n−1 i 对所有趟求和 　　　= 1 + 2 + 3 + … + (n−1) 展开 　　　= [(n−1) + 1] · (n−1) / 2 等差数列：(首项+末项)×项数/2 　　　= n(n−1)/2 = n2/2 − n/2 ⇒ W(n) = Θ(n2) 保留最高阶，舍去常数 1/2
W(n) = ∑i=1n−1 i = n(n−1)/2 = O(n2)

验算：演示中 n = 8，公式给 8×7/2 = 28。点击"最坏（逆序）"按钮，比较计数最终恰为 28，移动计数也是 28，与推导完全一致。而点击"最好（已序）"，比较为 7 = n−1，移动为 0。

三、平均情况的正确算法

期望，而不是"跑一次随机数据"

求 A(n) 必须建立概率模型。对插入排序，标准假设是：输入为 n 个互不相同元素的随机排列，n! 种排列等概率出现。

第 i 趟：key = a[i] 要插入到有序区 a[0..i−1] 中 它可能落在 i+1 个位置之一，且各位置等概率 随机排列假设 落在第 k 个位置需比较约 k 次（k = 1, 2, …, i），退到最左端需比较 i 次 该趟期望比较次数 ≈ (1 + 2 + … + i)/(i+1) + … ≈ (i+1)/2 平均落在中间 A(n) = ∑i=1n−1 (i+1)/2 ≈ (1/2)·∑i=1n−1 i 对所有趟求期望之和 　　　≈ n(n−1)/4 = n2/4 − n/4 ⇒ A(n) = Θ(n2) 与最坏情况同阶，只差常数因子 1/2
务必区分：页面上的"随机输入（单次抽样）"按钮做的是 T(I随机)——单个样本的观测值，每次都不同；而 A(n) = E[T(I)] 是遍历全部 n! 种输入按概率加权的期望，是一个确定的数。若要用实验估计 A(n)，正确做法是跑大量随机样本再取算术平均（蒙特卡洛方法），且只是估计而非精确值。
为什么平均情况分析常被回避？① 必须先给出输入的概率分布，而现实中的分布往往未知；② 期望的推导数学难度远高于最坏情况。因此工程上通常以最坏情况作为性能承诺——它不依赖任何分布假设，且给出的是"绝不会更差"的硬保证。

结论：插入排序的最好与最坏相差一个数量级（n 与 n2），说明它对基本有序的数据非常友好——这也是 std::sort 在子区间较短时切换为插入排序、以及 Timsort 大量利用已有序段的原因。

性质

插入排序的空间复杂度为 S(n) = O(1)（只用 key、i、j 三个变量），且是稳定排序——相等元素的相对次序不变，因为 while 条件用的是严格大于 a[j] > key 而非 >=。

易错点
  • 以为"跑一次随机数据"就得到了平均情况。A(n) 是期望 ∑P(I)·T(I)，需要概率模型；单次随机试验只是一个样本点。
  • 把"最好/最坏/平均"与"O/Ω/Θ"混为一谈。前者说的是选哪个输入，后者说的是函数的界。可以说"最好情况是 Θ(n)"，也可以说"最坏情况是 O(n2)"——两个维度互相独立。
  • 认为平均情况一定介于最好与最坏的正中间。只保证 B(n) ≤ A(n) ≤ W(n)。插入排序的 A(n) ≈ n2/4 与 W(n) ≈ n2/2 同阶，并不"居中"于 n 与 n2 之间；快速排序则相反，平均 Θ(n log n) 与最坏 Θ(n2) 不同阶。
  • 推导时把求和上下限写错。外层 for (i = 1; i < n; i++) 共 n−1 趟，故求和是 ∑i=1n−1，结果 n(n−1)/2；若误写成 ∑i=1n 会得到 n(n+1)/2。虽同为 O(n2)，但精确值错了。
  • 忽略移动次数。比较与移动是两种不同的基本操作，最好情况下插入排序比较 n−1 次但移动 0 次，二者不能混同。
  • 误以为最坏情况一定罕见。逆序数组在实际中相当常见（例如把降序榜单当升序处理），最坏情况并非"理论假想"。
本节小结
  • 三种情况定义：B(n) = min T(I)、W(n) = max T(I)、A(n) = ∑P(I)·T(I)（期望），恒有 B(n) ≤ A(n) ≤ W(n)。
  • 插入排序：最好 Θ(n)（已序，比较 n−1 次、移动 0 次）；最坏 Θ(n2)（逆序，比较与移动均为 n(n−1)/2）；平均 Θ(n2)（约 n(n−1)/4）。
  • 最坏情况推导核心一步：∑i=1n−1 i = n(n−1)/2。
  • 平均情况是对全部输入按概率加权的期望，不能用一次随机运行代替；实验估计需大量样本取均值。
  • 工程上以最坏情况作性能承诺：不依赖分布假设，给出硬上界。
  • 插入排序空间 O(1)、稳定，对基本有序数据表现优异，故被用作高级排序算法的小规模子过程。
1关于算法的平均情况时间复杂度 A(n)，下列理解正确的是？
A随机生成一组输入运行一次所测得的操作次数
B最好情况与最坏情况的算术平均，即 (B(n)+W(n))/2
C在给定输入概率分布下，操作次数的数学期望 ∑P(I)·T(I)
D去掉最好和最坏两个极端后，其余所有输入的平均
解析：正确答案 C。
A 是单次抽样的观测值，每次运行结果都不同，而 A(n) 是确定的数学量——本页"随机输入（单次抽样）"按钮做的正是 A 所描述的事，因此它不能用来读出平均复杂度。
B 是最流行的误解：以插入排序为例，B(n) ≈ n、W(n) ≈ n2/2，(B+W)/2 ≈ n2/4 恰好数值接近，但这是巧合；对快速排序，B、W 分别是 n log n 与 n2，其平均却是 n log n，绝非二者的算术平均。
D 是无依据的杜撰，期望必须包含所有输入。
2用直接插入排序对 n 个元素的逆序数组排序，关键字比较次数为？
An − 1
Bn(n+1)/2
Cn(n−1)/2
Dn2
解析：正确答案 C。外层 for (i = 1; i < n; i++) 共执行 n−1 趟；第 i 趟左侧有序区有 i 个元素且 key 比它们都小，需比较 i 次。故总数 ∑i=1n−1 i = n(n−1)/2。n = 8 时为 28，与演示计数一致。
A 是最好情况（已升序）的答案。
B 是把求和上限误写为 n 的结果（∑i=1n i = n(n+1)/2），是最常见的计算错误。
D 只是同阶的粗略值，不是精确次数。
3下列说法中错误的是？
A插入排序最好情况下比较 n−1 次，但移动 0 次
B插入排序的平均情况与最坏情况同为 Θ(n2)
C因为最坏情况用 O 表示、最好情况用 Ω 表示，所以 O 就是最坏、Ω 就是最好
D插入排序是稳定排序，且空间复杂度为 O(1)
解析：错误的是 C，故选 C。这是本章最顽固的概念混淆：最好/最坏/平均 描述的是"在哪一类输入上分析"，而 O/Ω/Θ 描述的是"函数的界是什么"。二者是正交的两个维度——完全可以说"最好情况的时间是 Θ(n)"，也可以说"最坏情况的时间是 Ω(n2)"。
A 正确：已序时 while 条件首次即假，不进入循环体，故无移动。
B 正确：平均约 n(n−1)/4，与最坏 n(n−1)/2 只差常数因子。
D 正确：条件用严格 > 保证了稳定性。
