复杂度曲线、渐进界、插入排序最好/最坏、vector 扩容、栈队列模拟。

本章学习目标

  1. 能够复述算法的定义，并判断一段描述是否满足有穷性、确定性、可行性、有输入、有输出五大特性。
  2. 能够写出算法设计的六个基本步骤，并对一个具体问题（如求最大公约数）完整走一遍流程。
  3. 能够推导给定 C++ 代码段的时间复杂度 T(n)，并用 O、Ω、Θ 三种渐进符号规范表示。
  4. 能够区分最好、最坏、平均三种情况，并以插入排序为例给出三者的复杂度及其推导。
  5. 能够选用合适的 STL 容器（vector / list / deque / set / map / unordered_map）并说明其操作复杂度依据。

知识地图

Knowledge Map · 各节依赖关系

本章分两条主线：§01–§05 是理论主线（什么是算法 → 怎么设计 → 怎么度量 → 怎么表示 → 怎么分情况讨论）；§06–§08 是工具主线（用 STL 把算法写出来）。理论主线中每一节都是下一节的前置，建议顺序学习；工具主线可在理论主线之后集中学习。

1
§01 算法定义：给出"算法"的概念边界。产出——判定"是不是算法"的五条标准。后继→ §02（有了定义才能谈设计）。
2
§02 设计步骤：从问题到可运行程序的六步流程。依赖← §01。后继→ §03（第六步"复杂度与测试"正是 §03 的内容）。
3
§03 时间与空间复杂度：把"快不快"量化为函数 T(n) 与 S(n)。依赖← §02。后继→ §04（T(n) 太精细，需要渐进符号抽象）。
4
§04 渐进符号 O/Ω/Θ：给出 T(n) 的上界、下界与紧确界的严格定义。依赖← §03。后继→ §05（不同输入下 T(n) 不同，需分情况）。
5
§05 最好/最坏/平均：同一算法在不同输入上的复杂度差异。依赖← §03、§04（要用 O 与 Θ 表述结论）。本章理论主线终点。
6
§06 STL 体系：容器 / 迭代器 / 算法 / 适配器 / 函数对象五大部件总览。依赖← §03（选容器的依据就是复杂度）。后继→ §07、§08。
7
§07 序列容器：vector / list / deque 的底层结构与摊还分析。依赖← §06、§03。
8
§08 容器适配器与关联容器：stack / queue / priority_queue 与 set / map。依赖← §07（适配器要以序列容器为底层）。
依赖链一览：§01 ⇒ §02 ⇒ §03 ⇒ §04 ⇒ §05；§03 ⇒ §06 ⇒ §07 ⇒ §08。其中 §03 与 §04 是全书基础，后续第 2～10 章的所有算法分析都建立在它们之上。
