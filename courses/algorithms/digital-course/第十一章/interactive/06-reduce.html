多项式时间归约 A ≤ₚ B

把 A 的实例多项式变成 B 的实例，且 yes↔yes。用于在问题之间传递难度。

学习目标

  1. 能写出多项式时间（多对一/映射）归约 A ≤p B 的正式定义：多项式时间可计算函数 f 使 x∈A ⟺ f(x)∈B。
  2. 能说清归约方向的意义：A ≤p B 意味着「B 至少与 A 一样难」——B 易则 A 易，A 难则 B 难。
  3. 能陈述并证明归约的传递性：A ≤p B 且 B ≤p C ⇒ A ≤p C。
  4. 能用归约完成两类任务：借易问题证 B∈P，借难问题证 B 难。
  5. 能识别并避免方向搞反这一最常见错误。

归约方向：从已知难问题归约到目标问题，说明目标「至少一样难」。

一、多项式时间归约的定义

Polynomial-time (mapping) reduction

归约是把「解 A」这件事转化为「解 B」：先用一个多项式时间的翻译器 f 把 A 的实例改写成 B 的实例，再交给解 B 的算法。翻译必须保真——yes 变 yes、no 变 no。

定义 1 · 多项式时间映射归约

判定问题 A 多项式时间归约到判定问题 B，记 A ≤p B，当且仅当存在一个多项式时间可计算的函数 f，使得对每一个实例 x 都有：
x ∈ A ⟺ f(x) ∈ B。
这里两个条件缺一不可：f 必须能在 poly(|x|) 时间算出；映射必须双向保真（充要，不能只保 yes→yes）。

A ≤p B ⟺ ∃ 多项式时间 f：x ∈ A ⟺ f(x) ∈ B

读作「A 归约到 B」或「A 不比 B 难」。注意箭头方向：被归约的 A 在左，目标 B 在右。

二、方向的意义：难度沿箭头传给右边

Which way is which

A ≤p B 一句话记法：「用 B 就能解 A」，所以 B 至少和 A 一样难。

定理 2 · 难度传递

设 A ≤p B。① 若 B ∈ P，则 A ∈ P（易向左传）；② 逆否地，若 A ∉ P，则 B ∉ P（难向右传）。

已知 A ≤p B：f 多项式时间，x∈A ⟺ f(x)∈B 归约定义 设 B∈P，有多项式算法 B_solve 判定 B 前提 解 A 的算法：输入 x → 算 f(x) → 返回 B_solve(f(x)) 先翻译再求解 用时 = poly(|x|) + poly(|f(x)|) 仍是多项式（f(x) 长度受多项式界） 多项式复合 且答案正确：x∈A ⟺ f(x)∈B ⟺ B_solve 接受 ⇒ A∈P 证毕 ① 取逆否：A∉P ⇒ B∉P，即「A 难则 B 难」 ②
方向一定别搞反：要证明目标问题 B 很难，须把一个已知很难的 A 归约到 B（写 A ≤p B）。反过来写 B ≤p A 只能说明「B 不比 A 难」，对证明 B 难毫无帮助。

三、传递性：难度可以接力

Transitivity
定理 3 · ≤p 具有传递性

若 A ≤p B 且 B ≤p C，则 A ≤p C。

A ≤p B 由 f 见证；B ≤p C 由 g 见证，f、g 均多项式时间 前提 令 h(x) = g(f(x))，即先 f 后 g 复合翻译 x∈A ⟺ f(x)∈B ⟺ g(f(x))∈C，即 x∈A ⟺ h(x)∈C 等价链 h 是多项式时间可计算（多项式复合仍多项式，且 |f(x)| 受多项式界） 封闭性 故 h 见证 A ≤p C 证毕

传递性是构造 NPC 家族的基石：一旦 SAT 被证 NPC，只要 SAT ≤p B 就得 B 是 NP-Hard——因为「任意 NP 问题 ≤p SAT ≤p B」。

易错点
  • 方向搞反（头号错误）。证 B 难要写「已知难的 A ≤p B」；写成「B ≤p 已知难问题」只说明 B 不更难，证不出 B 难。
  • 忘记 f 必须多项式时间可计算。若翻译本身就要指数时间，难度传递的推导（多项式复合）立刻失效。
  • 只保证 yes→yes。映射归约要求充要：x∈A ⟺ f(x)∈B，no 实例也必须映到 no，否则会把无解错判成有解。
  • 以为 A ≤p B 就有 B ≤p A。归约一般不对称；两向都成立才说 A、B 多项式等价。
  • 混淆 多项式（映射）归约 ≤p 与更宽松的图灵归约（可多次调用 B 作子程序）。本章 NPC 理论用的是映射归约。
  • 误以为归约让两个问题「变成同一个问题」。归约只传递难度，A 与 B 仍是不同问题。
本节小结
  • A ≤p B：存在多项式时间 f 使 x∈A ⟺ f(x)∈B；f 多项式可计算 + 双向保真，缺一不可。
  • 一句话理解方向：「用 B 能解 A」⇒ B 至少和 A 一样难。B 易则 A 易，A 难则 B 难。
  • 证目标 B 难：把已知难的 A 归约到 B（A ≤p B），切勿写反。
  • 传递性：A ≤p B 且 B ≤p C ⇒ A ≤p C，靠翻译函数复合 h=g∘f 得证。
  • 传递性 + 一个「万能」NPC（SAT）= 整个 NPC 家族的构造机制。
1已知团问题 Clique 是 NPC。要证明新问题 X 是 NP-Hard，应当构造哪个归约？
AClique ≤p X（把已知难的 Clique 归约到 X）
BX ≤p Clique（把 X 归约到 Clique）
C随便哪个方向都行，归约是对称的
D先证 X ∈ P，再归约
解析：选 A。要说明「X 至少和 Clique 一样难」，须把已知难的 Clique 归约到 X。B 只说明 X 不比 Clique 难，证不出 X 难；C 错在归约一般不对称；D 与「证难」南辕北辙。
2已知 A ≤p B。下列推断哪一个一定成立？
A若 A ∈ P，则 B ∈ P
B若 B ∈ P，则 A ∈ P
C必有 B ≤p A
DA 和 B 是同一个问题
解析：选 B。A ≤p B 表示 B 至少和 A 一样难，故 B 易（∈P）时 A 也易。A 项方向反了；C 归约不对称；D 归约不等于相等。
3关于映射归约中的翻译函数 f，哪项要求是必须的？
Af 只需保证 x∈A 时 f(x)∈B 即可
Bf 多项式时间可计算，且 x∈A ⟺ f(x)∈B（双向保真）
Cf 可以是任意可计算函数，时间不限
Df 必须是双射（一一对应）
解析：选 B。映射归约要求 f 多项式时间可计算且充要保真。A 漏掉 no→no，会把无解错判成有解；C 放弃多项式时间会破坏难度传递；D 并不要求 f 是双射，允许多对一。
