一、P 类：确定性多项式时间可判定

Class P

本章所有复杂度类都建立在判定问题（答案只有 yes / no）之上。把一个判定问题看成它所有 yes 实例组成的语言 L，「解问题」就等于「判定一个串是否属于 L」。

定义 1 · P 类

判定问题（语言）L 属于 P，当且仅当存在一个确定性算法（确定性图灵机）A 与常数 k，使得对任意输入 x，A 都在 O(|x|k) 时间内停机，并且 A 接受 x ⟺ x ∈ L。直观地说，P 就是「能在多项式时间内算出答案」的判定问题全体，即上一章所说的「易解」。

P = { L : 存在确定性算法在 O(nk) 时间判定 L }

排序的判定版、「最短路是否 ≤ K」、图是否连通、2-SAT、素数判定（AKS 算法）都在 P 中。

二、NP 类：多项式时间「可验证」

Class NP · verifiability

NP 的精髓不是「快速求解」，而是「快速核对」：若有人塞给你一份「答案的证据」，你能在多项式时间内核实它对不对。

定义 2 · NP 类（验证器定义）

语言 L 属于 NP，当且仅当存在一个多项式时间验证器 V(x, y) 与多项式 p，使得：对任意 x，x ∈ L ⟺ 存在证书（certificate）y，满足 |y| ≤ p(|x|) 且 V(x, y) 接受。其中 y 是「yes 答案的短证据」（如一组满足赋值、一条哈密顿回路、一个 k-团的顶点集），V 只负责核对而不负责寻找。

x ∈ L ⟺ ∃ y，|y| ≤ p(|x|)，V(x, y) = 接受
性质 2.1 · 等价的非确定定义

NP 还可等价定义为「存在非确定图灵机（NTM）在多项式时间内判定 L」。NTM 每一步可「猜」一个分支，只要存在一条接受计算路径就接受——这条被猜中的路径恰好对应验证器中的证书 y。因此 NP = Nondeterministic Polynomial（非确定多项式），字母 N 绝不是「Non-（非）」。

SAT、3-SAT、团、顶点覆盖、哈密顿回路、子集和都在 NP 中：它们的 yes 实例都有一段能被多项式时间核对的短证据。

三、P ⊆ NP：可解一定可验证

P ⊆ NP
定理 3 · P ⊆ NP

每个 P 中的问题都在 NP 中。

设 L ∈ P，存在多项式时间算法 A 判定 L P 的定义 构造验证器 V(x, y)：忽略证书 y，直接运行 A(x)，A 接受则接受 用空证书 V 是多项式时间的，且 x∈L ⟺ A(x) 接受 ⟺ 存在 y 使 V(x,y) 接受 等价 故 L ∈ NP，于是 P ⊆ NP 证毕

反过来 NP ⊆ P 是否成立，正是 P = NP 问题——至今无人能证明或否证。

四、co-NP 与 P vs NP 的图景

co-NP · the big picture
定义 4 · co-NP 类

L ∈ co-NP，当且仅当它的补问题 L̄ ∈ NP。等价地：co-NP 是「no 实例有多项式长证书」的问题类。例如「重言式 TAUTOLOGY（公式恒真）」「UNSAT（公式不可满足）」在 co-NP 中——一个反例赋值就是「它不是重言式 / 它其实可满足」的短证据。

P ⊆ NP ∩ co-NP · NP ?= co-NP（未解）
性质 4.1 · 当前已知与未知

① P ⊆ NP 且 P ⊆ co-NP（P 对取补封闭，把接受/拒绝对调即可）。
② P = NP 是否成立——七大千禧年难题之一，学界普遍猜测 P ≠ NP 但无证明。
③ 在 P ≠ NP 的主流假想下：P 是 NP 的真子集，NPC = NP ∩ NP-Hard 位于 NP 的「最难一档」，与 P 不相交；NP-Hard 还可伸到 NP 之外（甚至含不可判定问题）。这正是上方宇宙图所画的图景。

易错点
  • 把 NP 读成「Non-Polynomial（非多项式）」。它是 Nondeterministic Polynomial，指「非确定图灵机多项式时间」或等价的「多项式时间可验证」。
  • 以为 NP 里的问题「不能多项式求解」。恰恰相反，P ⊆ NP，所有易解问题都在 NP 里；NP 只要求「可验证」，并不排斥「可求解」。
  • 混淆验证与求解。NP 保证「给了证书能快速核对」，不保证「能快速找到证书」——「找」的难度才是 P 与 NP 之争的核心。
  • 默认 NP = co-NP。二者是否相等尚未知；一般相信 NP ≠ co-NP，且这与 P ≠ NP 并不等价。
  • 对优化问题直接套 P / NP。这些类只对判定问题定义，须先把「最优值是多少」改写成「是否存在解 ≥ K / ≤ K」的判定版。
  • 认为 P vs NP「显然」或「已解决」。它是公开难题，无论 P=NP 还是 P≠NP 至今都无证明。
本节小结
  • P：存在确定性算法在多项式时间判定的问题类，即「易解」。
  • NP：存在多项式长证书 y 与多项式时间验证器 V，使 x∈L ⟺ ∃y, V(x,y) 接受；等价于非确定图灵机多项式时间。
  • P ⊆ NP：可解一定可验证（用空证书即可），反向 NP⊆P 就是 P=NP 问题。
  • co-NP：补问题在 NP，即 no 实例有短证书；P ⊆ NP ∩ co-NP，NP 与 co-NP 是否相等未知。
  • 在 P≠NP 的假想下，NPC = NP ∩ NP-Hard 是 NP 的最难一档，与 P 不相交。
1关于 NP 类，下列说法正确的是？
ANP 指「非多项式时间」，即不能在多项式时间内解决的问题
BNP 指 yes 实例存在多项式长证书、可多项式时间验证；N 意为「非确定」
CNP 与 P 不相交，任何 NP 问题都无法用多项式算法求解
DNP 问题都是无解的，因此才叫「难」
解析：选 B。NP = Nondeterministic Polynomial，核心是「可验证」。A 把 N 误读为 Non-；C 错在 P ⊆ NP，P 中问题都在 NP 且能多项式求解；D 错在 NP 问题都可解（如枚举证书），只是未必有多项式算法。
2为什么 P ⊆ NP 成立？
AP 中问题能多项式求解，可让验证器忽略证书直接求解，故也多项式可验证
B因为 P 和 NP 其实是同一个类，这已被证明
C因为每个 NP 问题都能归约到某个 P 问题
D因为 NP 的定义要求所有问题都先属于 P
解析：选 A。可解一定可验证：对 L∈P，用空证书、让验证器直接跑求解算法即可，故 L∈NP。B 描述的是尚未证明的 P=NP；C、D 均非事实。
3「判定一个 CNF 公式是否不可满足（UNSAT）」最直接属于哪个类？
AP，因为可以枚举所有赋值
Bco-NP，因为它的补问题 SAT 在 NP 中
C它不属于任何复杂度类
DNP，因为存在使公式为真的赋值作为证书
解析：选 B。UNSAT 的补问题正是 SAT∈NP，故 UNSAT∈co-NP：它的 no 实例（即「其实可满足」）有短证据——一个满足赋值。A 的枚举是指数时间，不能说明它在 P；D 描述的是 SAT（yes 有证书），不是 UNSAT。
