图灵机 · 纸带动画

无限纸带 + 读写头 + 有限状态。算法 ≈ 对任意输入都停机的确定性图灵机（DTM）。

学习目标

  1. 能够默写图灵机的七元组定义 M = (Q, Σ, Γ, δ, q0, qaccept, qreject)，并说明每个分量的含义。
  2. 能够读懂并填写转移函数 δ 的表格，据此手工模拟一台图灵机的运行（以「二进制加一」为例）。
  3. 能够写出格局（configuration）的表示法，用它描述计算过程。
  4. 能够说清非确定性图灵机（NTM）与 DTM 的唯一区别：δ 返回的是集合；并解释「存在一条接受路径即接受」的语义。
  5. 能够论证 NTM ⟺「猜测 + 验证」的等价性，从而理解第 4 节 NP 的两种定义为何一致。
  6. 能够用步数与纸带格数分别定义时间复杂度与空间复杂度，写出 P = ∪k TIME(nk)。

一、图灵机的正式定义（七元组）

Deterministic Turing Machine

「算法」这个词在 1936 年之前并没有数学定义。图灵机的意义就在于：它把「机械地一步步算」这件事形式化成了七个集合与一个函数，此后才谈得上「证明某问题没有算法」。

定义 3.1 · 确定性图灵机（DTM）

一台单带确定性图灵机是一个七元组

M = (Q, Σ, Γ, δ, q0, qaccept, qreject)
分量名称含义
Q状态集有限个状态的集合，代表「控制器此刻记住了什么」
Σ输入字母表有限符号集，不含空白符 ⊔（如 Σ = {0, 1}）
Γ纸带字母表有限符号集，满足 Σ ⊆ Γ 且 ⊔ ∈ Γ；可含运算中用的辅助符号（如 X、#）
δ转移函数δ : Q × Γ → Q × Γ × {L, R}
读到什么 ⇒ 写什么、变到哪个状态、读写头左移还是右移
q0初始状态q0 ∈ Q，计算从这里开始，读写头位于输入最左端
qaccept接受状态一旦进入立即停机并输出 yes
qreject拒绝状态一旦进入立即停机并输出 no；要求 qaccept ≠ qreject
定义 3.2 · 格局与计算

把「纸带内容 + 状态 + 读写头位置」这三样东西打包，称为一个格局（configuration），写作 u q v：纸带上从左到右依次是串 uv（其余为 ⊔），当前状态为 q，读写头正指着 v 的第一个符号。若 δ(q, a) = (q′, b, R)，则格局 u q a w 一步转移到 u b q′ w，记作 ⊢。一次计算就是从初始格局 q0x 出发的格局序列；含 qaccept 的格局称接受格局。

定义 3.3 · 判定语言

M 接受串 x，若从 q0x 出发的计算最终进入 qaccept。M 接受的语言 L(M) = { x | M 接受 x }。若 M 对一切输入都停机（不会无限运行），则称 M 判定（decide）语言 L(M)。「算法」= 对所有输入都停机的图灵机——这就是丘奇–图灵论题（Church–Turing thesis）所主张的：任何直观意义上「可机械计算」的东西，都能被图灵机计算。

图灵机Turing machine 转移函数transition function 格局configuration 空白符blank ⊔ 丘奇–图灵论题Church–Turing thesis 停机halt

二、读懂 δ 表：上面动画的「二进制加一」机

A worked δ table

上方演示的那台机器，正式写出来就是下面这张表。纸带上写着二进制数 1011，读写头从最低位（最右端）开始，逐位处理进位，得到 1100。

M+1 = ( {q0, qcarry, qaccept},　Σ = {0, 1},　Γ = {0, 1, ⊔},　δ 如下表,　q0,　qaccept,　qreject )
当前状态 q读到符号 aδ(q, a) = (新状态, 写入, 移动)直观含义
q01(qcarry, 0, L)1 + 1 = 10：本位写 0，产生进位，左移
q00(qaccept, 1, S)0 + 1 = 1：本位写 1，无进位，完成
qcarry1(qcarry, 0, L)1 + 进位：写 0，进位继续向左传
qcarry0(qaccept, 1, S)0 + 进位：写 1，进位被吸收，完成
qcarry⊔(qaccept, 1, S)最高位还要进位：在左侧补一个 1（如 111 → 1000）

注：演示里为了画面整洁，把纸带预填成 0 而非 ⊔，因此第 5 行在动画中表现为「读到 0 就写 1 停机」。标准图灵机用 ⊔ 表示空白格。表里的 S 表示原地不动（stay）；只允许 L/R 的教科书版本可用「先 R 再 L」两步等价实现，不影响复杂度的多项式量级。

q0 指着最低位：1 0 1 1　格局 101 q0 1 初始 δ(q0,1) = (qcarry,0,L)：1 0 1 0 写 0，进位 δ(qcarry,1) = (qcarry,0,L)：1 0 0 0 写 0，进位继续 δ(qcarry,0) = (qaccept,1,S)：1 1 0 0 写 1，停机 结果 1011 + 1 = 1100，用了 3 步，访问了 3 个纸带格 时间 / 空间
// 把 δ 表写成代码，就是上方动画的核心循环（等价于一台 DTM） while (true) { char a = tape[head]; // 读 if (q == Q0 && a == '1') { tape[head] = '0'; q = CARRY; head--; } else if (q == CARRY && a == '1') { tape[head] = '0'; q = CARRY; head--; } else { tape[head] = '1'; q = ACCEPT; break; } // 读到 0 或 ⊔ } // 每轮循环 = 一步转移；循环次数 = 时间；head 走过的格子数 = 空间

三、非确定性图灵机 NTM：把「唯一后继」换成「一堆后继」

Nondeterministic Turing Machine

NTM 与 DTM 的区别只有一处：转移函数的值域。别的（纸带、读写头、状态、格局）一模一样。

定义 3.4 · 非确定性图灵机（NTM）

NTM 的七元组与 DTM 完全相同，唯独转移函数改为返回一个集合：

DTM：δ : Q × Γ → Q × Γ × {L, R}
NTM：δ : Q × Γ → P( Q × Γ × {L, R} )

P(·) 表示幂集。也就是说，处在同一个格局、读到同一个符号时，NTM 可以有 0 个、1 个或多个合法的下一步。于是计算不再是一条链，而是一棵计算树（computation tree）：根是初始格局，每个结点的孩子是它所有可能的后继。

定义 3.5 · NTM 的接受语义（存在量词）

NTM 接受 x，当且仅当计算树中至少存在一条从根到 qaccept 的路径。注意这是存在而非「全部」：哪怕 999 条路径都跌进 qreject，只要有 1 条路通向接受，整台机器就判 yes。反之，只有当所有路径都拒绝时才判 no。直观上可以理解为：NTM 在分叉处「并行猜测所有分支」，或者说「每次都恰好猜对」。

// 计算树示意：判定「4 个数中是否存在子集和 = t」，每层猜一个数选或不选 q0 : 初始格局 / \ 选 a1 不选 a1 / \ / \ 选 a2 不选 a2 选 a2 不选 a2 / \ / \ / \ / \ ... ... ... ... ... ... ... ... | | | | | | | | reject accept reject reject ... reject reject reject ^ +--- 只要存在这样一条接受路径，NTM 就接受该输入 // 树高 = 4（猜 4 次） ⇒ NTM 的运行时间 = 最短接受路径长度 = O(n) // 树的结点总数 = 2^4 ⇒ DTM 逐条遍历需要 O(2^n) 时间（这就是 P 与 NP 的落差所在）
定理 3.1 · NTM ⟺ 「猜测 + 验证」

一台多项式时间 NTM 的运行，总可以拆成两个阶段：① 猜测阶段——用非确定性分叉在纸带上写下一个长度为 poly(n) 的串 c（因为多项式步内最多写下多项式个符号）；② 验证阶段——之后完全确定性地检查 (x, c) 是否合法。反过来，给定一个多项式时间验证器 V(x, c)，也能造一台 NTM：先非确定性地逐位猜出 c，再确定性地运行 V。两个方向都是多项式时间的，故二者等价。

NTM 接受 x 定义 3.5 ⟺ 计算树中存在一条接受路径 展开 ⟺ 存在一串「分叉选择」c（每个分叉记一次选了第几个后继） 路径 ≡ 选择序列 ⟺ 存在 |c| = poly(n) 的串 c，使确定性地沿 c 走会到达 qaccept poly 步内 |c| 必为 poly ⟺ 存在证书 c 使验证器 V(x, c) = yes 「沿 c 走一遍」就是验证器 ⇒ 第 4 节 NP 的两个定义（NTM 版 / 证书版）是同一件事 结论
NTM 是数学工具，不是机器：现实中造不出 NTM，它也不是并行计算机、更不是量子计算机。它的价值在于把「运气好的时候能多快解出来」这件事写成了严格定义。用 DTM 逐条模拟 NTM 的所有分支（广度优先遍历计算树）是可行的，但时间会从 t 步涨到 bt 量级（b 为最大分叉数）——目前没有人知道能否把这个指数降为多项式，那正是 P vs NP。

四、复杂度怎样度量：步数与格数

Time & space measures
定义 3.6 · 时间复杂度

设 DTM M 对一切输入都停机。M 的时间复杂度是函数 t(n)：所有长度为 n 的输入中，M 停机前所执行的转移步数的最大值（最坏情况）。对 NTM，t(n) 定义为计算树中最短接受路径的长度（若拒绝，则取树的最大深度）。

定义 3.7 · 空间复杂度

M 的空间复杂度是函数 s(n)：所有长度为 n 的输入中，M 在整个计算过程里访问过的不同纸带格数的最大值。

TIME(f(n)) = { L | 存在 O(f(n)) 时间的 DTM 判定 L }　　SPACE(f(n)) = { L | 存在 O(f(n)) 空间的 DTM 判定 L }
P = ⋃k ≥ 1 TIME(nk)　　NP = ⋃k ≥ 1 NTIME(nk)
度量在图灵机上在演示动画中对应类
时间转移步数动画播放了几帧转移P、NP、EXP
空间访问过的纸带格数读写头走过几个方格L、PSPACE
性质 3.1 · 时间与空间的基本关系

一步转移最多让读写头移动一格、访问一个新格子，所以 s(n) ≤ t(n) + O(1)：空间永远不会超过时间。反之不然——用 O(n) 空间可以跑很久。由此可得基本包含链：P ⊆ NP ⊆ PSPACE ⊆ EXP。

为什么可以放心用「步数」当复杂度？因为各种合理模型（单带 / 多带图灵机、RAM、真实 CPU）之间可多项式时间互相模拟：例如 k 带机的 t 步可被单带机在 O(t2) 步内模拟。平方是多项式，因此「是不是多项式时间」这件事在模型之间不变——这正是第 1 节所说的健壮性。
易错点
  • 把 NTM 当成「并行计算机」或「量子计算机」。NTM 是纯数学构造，物理上不可实现；量子计算机遵循的是完全不同的（BQP）模型，并没有被证明能解 NPC 问题。
  • 误以为 NTM 的接受条件是「所有路径都接受」。恰恰相反：存在一条接受路径即接受（∃ 而非 ∀）；「所有路径都接受」对应的是 co-NP 那一侧的语义。
  • 把 NTM 的运行时间算成「计算树的结点数」。它是最短接受路径的长度（树高量级），不是结点总数——正因如此 NTM 才「看上去」比 DTM 快指数倍。
  • 忘记 Σ ⊆ Γ 且 ⊔ ∈ Γ、以及 qaccept ≠ qreject 这些定义中的约束条件。
  • 混淆「接受语言 L(M)」与「判定语言 L」。接受只要求 yes 实例会停在 qaccept；判定额外要求对 no 实例也必须停机（不能死循环）。前者对应可枚举（RE），后者才对应「有算法」。
  • 用「运行时间」度量却忘了取最坏情况。所有复杂性类都按长度为 n 的输入中的最大值定义。
本节小结
  • 图灵机 = 七元组 M = (Q, Σ, Γ, δ, q0, qaccept, qreject)；核心是转移函数 δ : Q × Γ → Q × Γ × {L, R}。
  • 格局 u q v 把纸带、状态、头位置打包；一次计算就是一串格局的转移序列。
  • 「算法」的严格定义 = 对一切输入都停机的 DTM（丘奇–图灵论题）。
  • NTM 与 DTM 唯一的区别是 δ 返回集合（幂集）；接受语义是存在一条接受路径，可理解为「并行猜测所有分支」。
  • NTM 多项式时间 ⟺ 多项式长证书 + 多项式时间验证器；这保证了 NP 的两种定义一致。
  • 时间 = 转移步数，空间 = 访问过的纸带格数，均取最坏情况；P = ⋃k TIME(nk)，且 s(n) ≤ t(n)。
1确定性图灵机（DTM）与非确定性图灵机（NTM）在定义上的唯一区别是什么？
ANTM 有无限多条纸带，DTM 只有一条
BNTM 的转移函数返回集合：δ : Q × Γ → P(Q × Γ × {L,R})，同一格局可有多个后继；其余分量完全相同
CNTM 的读写头可以任意跳到纸带的任何位置，DTM 只能左右各移一格
DNTM 每一步都随机决定走哪条分支，因此可能算错
解析：选 B。NTM 的七元组与 DTM 一字不差，只是 δ 的值域从单个三元组变成了三元组的幂集。A 说的是多带图灵机（与单带多项式等价）；C 说的是随机存取模型；D 错在 NTM 不是随机机器——它的接受条件是确定性的逻辑判断「∃ 一条接受路径」，与概率毫无关系（那是概率图灵机 / BPP）。
2一台 NTM 在某输入上的计算树共有 2n 个结点，其中恰有 1 条长度为 n 的路径到达 qaccept，其余全部到达 qreject。该 NTM 的运行时间与判定结果是？
A时间 O(2n)，判定为 reject（因为绝大多数路径都拒绝）
B时间 O(n)，判定为 accept（存在一条接受路径即接受，时间按最短接受路径计）
C时间 O(2n)，判定为 accept（必须把整棵树遍历完才敢下结论）
D无法判定，因为接受路径与拒绝路径互相矛盾
解析：选 B。NTM 的接受语义是存在量词：一条接受路径就够了，多数决不作数（排除 A）。运行时间定义为最短接受路径的长度，即树高 n，而非结点总数（排除 C——那是 DTM 模拟 NTM 的代价）。D 混淆了「多条路径给出不同结果」与「矛盾」：NTM 的定义本就允许这种情况。
3关于图灵机的时间与空间复杂度，下列说法正确的是？
A空间可能远大于时间，因为纸带是无限长的
Bs(n) ≤ t(n) + O(1)，因为每步最多访问一个新纸带格；由此可得 P ⊆ PSPACE
C时间与空间总是相等，一步转移正好用掉一格
D时间取平均情况，空间取最坏情况
解析：选 B。纸带虽然无限长，但访问过的格子数受步数限制：t 步最多让读写头移动 t 次，故 s(n) ≤ t(n) + O(1)（排除 A）。反向不成立——原地打转可以在 O(1) 空间里耗掉指数时间，所以 C 也错。D 错在两者都取最坏情况。
