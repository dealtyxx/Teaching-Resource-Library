NP 完全：定义与证明

NPC = NP ∩ NP-Hard。第一个 NPC 问题：SAT（Cook-Levin 定理）。

学习目标

  1. 能写出 NP-Hard 的定义：所有 NP 问题都可多项式归约到它（本身未必在 NP 中）。
  2. 能写出 NPC（NP 完全）的定义：既在 NP 中，又是 NP-Hard。
  3. 能陈述 Cook-Levin 定理：SAT 是第一个被证明的 NPC 问题，及其证明思路。
  4. 能复述证 L∈NPC 的两步模板：先证 L∈NP，再把某个已知 NPC 问题归约到 L。
  5. 能说明关键推论：只要某个 NPC 问题 ∈ P，就有 P = NP。
L ∈ NPC ⟺ L ∈ NP 且 L 是 NP-Hard
按「下一步」展开标准证明清单。

一、NP-Hard 与 NP 完全

NP-Hard & NP-Complete

「NP 完全」把两件事捏在一起：它自己在 NP 里（不太难，答案可验证），同时又是 NP 里最难的一档（所有 NP 问题都能归约到它）。

定义 1 · NP-Hard（NP 难）

语言 L 是 NP-Hard，当且仅当每一个 L′ ∈ NP 都满足 L′ ≤p L。即 L「至少和 NP 中所有问题一样难」。注意：NP-Hard 并不要求 L 本身属于 NP——L 可以更难，甚至不可判定（例如停机问题就是 NP-Hard 却不在 NP 中）。

定义 2 · NP 完全（NPC）

语言 L 是 NP 完全（NP-Complete），当且仅当同时满足：① L ∈ NP，且 ② L 是 NP-Hard。NPC 恰好是 NP 与 NP-Hard 的交集，代表 NP 内部「最难」的问题——它们彼此多项式等价，一荣俱荣、一损俱损。

L ∈ NPC ⟺ L ∈ NP 且 ∀ L′∈NP，L′ ≤p L

二、Cook-Levin 定理：第一个 NPC

Cook–Levin Theorem

证 NPC 的模板要「借」一个已知的 NPC 当起点。但第一个 NPC 无从借起——它必须从定义硬证：让任意 NP 问题都归约到它。Cook 与 Levin 完成了这件事。

定理 3 · Cook-Levin（1971 Cook / 1973 Levin 独立）

SAT ∈ NPC。即布尔可满足性问题是第一个被证明的 NP 完全问题。证明思路：任取 L∈NP，它由某台非确定图灵机在多项式时间内判定；把「该机在输入 x 上存在一条长度多项式的接受计算」这件事，用一个规模多项式的 CNF 公式 φx 完整编码（变量描述每一步纸带格与状态，子句约束初始/转移/接受合法），使得 φx 可满足 ⟺ 机器接受 x ⟺ x∈L。这就构造出 L ≤p SAT，对一切 L∈NP 成立，故 SAT 是 NP-Hard；又 SAT∈NP，于是 SAT∈NPC。

归约方向别记反：Cook-Levin 证的是「所有 NP 问题 ≤p SAT」（大家归约到 SAT），而不是「SAT 归约到别人」。有了这块基石，之后只需 SAT ≤p 3-SAT ≤p 团 ≤p … 借传递性繁衍出整个 NPC 家族。

三、证 L∈NPC 的标准两步模板

The proof template

右侧演示的清单，正是课本证明 NPC 的固定套路。核心是「借传递性」：不再从头证「所有 NP 归约到 L」，而是找一个已知 NPC 的 A 归约到 L。

① 证 L ∈ NP：给出证书格式 + 多项式时间验证算法 缺这步只证到 NP-Hard ② 选一个已知 NPC 问题 A（如 3-SAT、团、顶点覆盖、哈密顿） 起点 ③ 构造多项式时间 f，把 A 的任意实例变成 L 的实例 A ≤p L ④ 证等价：x∈A ⟺ f(x)∈L 双向保真 A∈NPC ⇒ A 是 NP-Hard，且 A ≤p L ⇒（传递性）L 也 NP-Hard 难度接力 L∈NP 且 L 是 NP-Hard ⇒ L ∈ NPC 证毕
定理 4 · NPC 与 P=NP 的杠杆

若任意一个 NPC 问题 L 属于 P，则 P = NP。因为对每个 L′∈NP 有 L′ ≤p L 且 L∈P，由难度传递 L′∈P，故 NP⊆P，又 P⊆NP，得 P=NP。反之，若相信 P≠NP，则所有 NPC 问题都没有多项式算法。

易错点
  • 混淆 NP-Hard 与 NPC。NP-Hard 只要求「所有 NP 归约到它」，不必在 NP 中（可更难、甚至不可判定）；NPC 额外要求 ∈ NP。停机问题是 NP-Hard 但不是 NPC。
  • 证 NPC 时漏掉「L∈NP」这一步，只证了难。只证难得到的是 NP-Hard，不是 NP 完全。
  • 归约方向反了：证 L 难要把已知 NPC 的 A 归约到 L（A ≤p L），不是 L ≤p A。
  • 误记 Cook-Levin 的方向。它是「所有 NP 问题归约到 SAT」，从而 SAT 最难；不是「SAT 归约到某问题」。
  • 以为 NPC 问题「无解 / 算不出」。它们完全可解（如枚举证书），只是没有已知的多项式算法；难解 ≠ 不可计算。
  • 忘了杠杆推论：任一 NPC ∈ P 就推出 P=NP。这也是「找到某 NPC 的多项式算法」如此重大的原因。
本节小结
  • NP-Hard：所有 NP 问题都 ≤p 它；本身未必在 NP 中。
  • NPC = NP ∩ NP-Hard：既 ∈NP，又是 NP-Hard，是 NP 中最难的一档。
  • Cook-Levin：SAT 是第一个 NPC，靠「把任意 NP 机器的接受计算编码成多项式规模 CNF」硬证。
  • 证 L∈NPC 两步：① L∈NP；② 已知 NPC 的 A ≤p L（借传递性得 L 是 NP-Hard）。
  • 任一 NPC ∈ P ⇒ P = NP；相信 P≠NP 即相信 NPC 无多项式算法。
1NP-Hard 与 NP 完全（NPC）的区别是什么？
A二者完全相同，只是叫法不同
BNPC 要求问题额外属于 NP；NP-Hard 不要求，可能更难甚至不可判定
CNP-Hard 一定属于 NP，NPC 不一定
DNP-Hard 更容易，NPC 更难
解析：选 B。NPC = NP ∩ NP-Hard，比 NP-Hard 多了「∈NP」这一约束。停机问题是 NP-Hard 却不在 NP 中，故不是 NPC。C 恰好说反了。
2Cook-Levin 定理的核心内容是？
A证明了 P = NP
BSAT 是第一个 NPC 问题：任意 NP 问题都可多项式归约到 SAT
CSAT 可以在多项式时间内求解
DSAT 可以归约到任意 NP 问题
解析：选 B。Cook-Levin 把「任意 NP 机器的多项式接受计算」编码为多项式规模 CNF，得到「所有 NP ≤p SAT」，故 SAT 是第一个 NPC。A、C 都是未知/不成立的强命题；D 把方向记反了。

A只有那一个问题变简单，其他 NP 问题不受影响
BP = NP：所有 NP 问题都随之有多项式算法
C说明该问题原本就不是 NPC
D停机问题也随之可判定
