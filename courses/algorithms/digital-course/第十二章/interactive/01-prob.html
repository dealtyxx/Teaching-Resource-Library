学习目标

  2. 能够对任一给定算法，判断它属于四类中的哪一类，判据是"运行时间是否确定"与"输出是否一定正确"两条。

概率算法的正式定义

先把四类的边界划清楚
定义 · 概率算法

概率算法（probabilistic algorithm，又称随机化算法 randomized algorithm）：在执行过程中至少调用一次随机数发生器的算法。对同一个输入实例，不同次运行可能走过不同的执行路径，因而其运行时间、输出结果或二者之一是随机变量。
关键：随机性来自算法内部的掷硬币，而不是来自输入——因此下面所有结论对任意输入实例都成立，不需要"输入服从某分布"这类假设。

定义 ① · 数值概率算法

数值概率算法（numerical probabilistic algorithm）：用随机采样求某个数值量的近似解。它得到的解几乎不可能精确，但解的精度随采样量（或允许的运行时间）的增加而提高。
典型用途：数值积分、求 π、大规模矩阵/网络参数估计等本身就只要求"够准"的问题。典型例子：§02 的投点法求 π——采样 N 个点，误差量级为 O(1/√N)。

定义 ② · 蒙特卡罗算法

蒙特卡罗算法（Monte Carlo algorithm）：运行时间确定（对规模 n 的输入总在同一个时间界内结束），总是给出一个答案，但这个答案可能是错的。
设算法对任意实例给出正确解的概率至少为 p（1/2 < p < 1），称之为 p-正确（p-correct）；2p − 1 称为该算法的优势（advantage）。由于每次运行使用独立的随机位，独立重复运行并综合结果可使错误概率随重复次数指数下降——这是蒙特卡罗算法可用的根本原因。典型例子：§03 的主元素判定。

定义 ③ · 拉斯维加斯算法

拉斯维加斯算法（Las Vegas algorithm）：绝不返回错误答案——它要么给出正确解，要么报告"本次失败、未能求解"；但它是否成功以及花多长时间是随机的，运行时间是随机变量。
因此评价拉斯维加斯算法的正确指标是期望运行时间 E[T]，而不是最坏运行时间（最坏时间往往是无穷大）。失败时只需重启再来一次，正确性永远不受损。典型例子：§04 的随机化 n 皇后。

定义 ④ · 舍伍德算法

舍伍德算法（Sherwood algorithm）：总能得到正确解（既不出错，也不报告失败）。它的作用是通过随机化消除算法对特定输入的敏感性——当某个确定性算法"平均很快、但对某些特定输入极慢"时，在算法内部引入随机选择，使得每个输入实例的期望代价都等于原算法在所有输入上的平均代价，从而把最坏情形的高代价"摊平"为期望代价。
换句话说：舍伍德不降低平均复杂度，它降低的是"运气不好时被卡住"的风险；代价的期望值与输入无关，只与算法内部的随机源有关。典型例子：§05 的随机化快速选择——固定取首元素作 pivot 时有序输入退化为 O(n2)，随机 pivot 后对任何输入期望都是 O(n)。

一句话记忆：数值概率——算不准（近似解）；蒙特卡罗——可能错（时间稳）；拉斯维加斯——可能白跑（结果稳）；舍伍德——一定对、期望稳（只是把最坏摊平）。

最容易混的一对：拉斯维加斯 vs 舍伍德。二者结果都正确、时间都随机，差别在于——拉斯维加斯可能失败（这一次什么都没算出来，要重来）；舍伍德绝不失败，每次运行都必然产出正确解，只是这次快一点、那次慢一点。此外舍伍德的出发点是"已有一个对某些输入很慢的确定性算法，我来把它的最坏情形消掉"，而拉斯维加斯往往是从零设计的。

四类算法的代码骨架

C++ · 对比同一份"外壳"的差异
// ① 数值概率：采样 N 次求近似值，N 越大越准（误差 ~ O(1/√N)） double numerical(int N) { double sum = 0; for (int i = 0; i < N; ++i) sum += sampleOnce(); // 时间确定 = O(N) return sum / N; // 返回的是近似解，几乎不可能精确 } // ② 蒙特卡罗：时间确定；单次可能错，独立重复 k 次把错误率压到 2^(-k) bool monteCarlo(int a[], int n, int k) { for (int t = 0; t < k; ++t) // 恰好 k 轮，绝不多也绝不少 if (oneTrial(a, n)) return true; // 返回 true 一定对（偏真型） return false; // 返回 false 可能错，概率 <= 2^(-k) } // ③ 拉斯维加斯：结果绝不错；失败就重启，运行时间是随机变量 bool lasVegas(int res[], int n) { while (true) { // 循环次数不确定 —— 只能谈期望时间 if (tryOnce(res, n)) return true; // 成功：res 一定是合法解 // 失败：本轮完全作废，不产生任何错误输出，直接重来 } } // ④ 舍伍德：一定正确、绝不失败；随机化只用来打散"最坏输入" int sherwoodSelect(int a[], int l, int r, int k) { if (l == r) return a[l]; int p = l + rand() % (r - l + 1); // 唯一的随机点：pivot 随机 swap(a[l], a[p]); int m = partition(a, l, r); if (k == m) return a[m]; // 每次调用必然返回正确的第 k 小 return k < m ? sherwoodSelect(a, l, m - 1, k) : sherwoodSelect(a, m + 1, r, k); }
看骨架抓差异：② 的循环次数是常数 k（时间确定），③ 的循环次数是不确定的 while(true)（时间随机），④ 没有重试循环——它一遍就走完，随机性只影响递归深度与划分平衡度。

易错点
  • 把"概率算法"一律理解成"结果不可靠"。只有数值概率与蒙特卡罗的结果可能不精确/不正确；拉斯维加斯与舍伍德的结果永远正确。
  • 把拉斯维加斯的"失败"当成"输出了错误答案"。失败是诚实报告"我没算出来"，绝不会伪造一个错解，这正是它与蒙特卡罗的分水岭。
  • 认为舍伍德能降低平均复杂度。不能。随机化快速选择的期望仍是 O(n)，与"随机输入下确定性算法的平均"同阶；舍伍德改变的是代价在输入上的分布，不是均值。
  • 误以为蒙特卡罗重复 k 次就"一定对了"。错误率是 ≤ 2−k，只能任意接近 0，永远到不了 0。
  • 把"随机化"与"假设输入随机"混为一谈。随机来自算法掷的硬币；即使输入是对手精心构造的最坏数据，期望界依然成立。
  • 用最坏运行时间去评价拉斯维加斯算法。它的最坏时间通常无界，正确指标是期望运行时间。
本节小结
  • 概率算法 = 执行中调用随机数发生器的算法，其时间和/或结果是随机变量；随机性来自算法内部而非输入假设。
  • 用「时间是否确定」×「结果是否一定正确」两条判据即可定位四类：数值概率（时间定、只给近似解）、蒙特卡罗（时间定、可能错）、拉斯维加斯（时间随机、结果对或失败）、舍伍德（时间随机但期望有界、结果一定对且不失败）。
  • 蒙特卡罗的核心度量是错误概率（p-正确、优势 2p−1，重复 k 次 ≤ 2−k）；拉斯维加斯与舍伍德的核心度量是期望运行时间；数值概率的核心度量是误差量级 O(1/√N)。
  • 舍伍德的独特价值：把"对某些输入很慢"变成"对任何输入都以高概率不慢"，期望代价与输入分布无关。
1某算法对任意规模为 n 的输入都恰好运行 c·n 步，并总是输出一个答案，但这个答案有不超过 1/3 的概率是错的。它属于哪一类概率算法？
A数值概率算法
B蒙特卡罗算法
C拉斯维加斯算法
D舍伍德算法
解析：抓两条判据——"恰好 c·n 步"说明时间确定；"答案有概率是错的"说明结果不保证正确。两条合起来正是蒙特卡罗的定义（这里 p = 2/3 > 1/2，是 2/3-正确的，优势为 2×2/3 − 1 = 1/3）。A 错——数值概率求的是数值量的近似，谈的是精度而非"对/错"；此题输出的是一个离散答案且有明确的错误概率。C 错——拉斯维加斯绝不输出错误答案，它只会说"失败"。D 错——舍伍德结果一定正确，且时间是随机变量而非固定的 c·n。
2下列关于四类概率算法的说法，正确的是？
A蒙特卡罗算法的结果一定正确，只是时间不确定
B拉斯维加斯算法可能返回一个错误的解，因此要重复运行来降低错误率
C舍伍德算法总能得到正确解，随机化的作用是消除算法对特定输入的敏感性
D数值概率算法只要采样足够多，就能得到完全精确的解
解析：A 把蒙特卡罗和拉斯维加斯说反了——蒙特卡罗是"时间确定、结果可能错"，这是本章最高频的送分/送命点。B 错在"返回错误的解"：拉斯维加斯永不返回错解，重复运行是因为它可能失败（无输出），重复降低的是"失败概率"而非"错误率"。D 错——数值概率算法的解是近似解，采样越多误差越小（O(1/√N)），但永远达不到精确；而且要多算一位精度就得多花约 100 倍采样点。C 正是舍伍德的定义：正确性不受影响，随机化只把"对某些输入极慢"摊平成"对任何输入期望都不慢"。
3把确定性快速排序的"取首元素为 pivot"改成"随机取一个元素为 pivot"，得到的算法属于哪一类？其平均时间复杂度相比原算法有何变化？
A蒙特卡罗算法；平均复杂度从 O(n2) 降为 O(n log n)
B舍伍德算法；平均复杂度仍是 O(n log n)，但不再存在使其退化的特定最坏输入
C拉斯维加斯算法；因为它可能排序失败需要重排
D数值概率算法；因为它给出的是近似有序的序列
解析：随机 pivot 的快速排序结果永远完全正确、也永不失败，只是划分是否平衡带随机性——这正是舍伍德。B 的后半句是关键：确定性快排的平均复杂度本来就是 O(n log n)（在"输入随机"的假设下），随机化并没有把均值改好；它改的是"最坏情形出现的条件"——原本已排序的输入必然触发 O(n2)，随机化后任何固定输入触发 O(n2) 的概率都低到可忽略。A 的"平均从 O(n2) 降到 O(n log n)"混淆了最坏与平均。C 错——排序不会"失败"。D 错——输出是完全有序的，不是近似解。
