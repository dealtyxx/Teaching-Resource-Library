学习目标

  1. 能够推导投点法的概率原理：随机点落入内切圆的概率 = 圆面积 / 正方形面积 = π/4。

  4. 能够写出投点法的 C++ 实现，并分析其时间与空间复杂度。

概率原理：为什么是 π/4

几何概型 · 面积比即概率
问题与模型

取边长为 1 的正方形 S = [0,1] × [0,1]，其中四分之一圆 C = { (x,y) ∈ S : x2 + y2 ≤ 1 }。在 S 中均匀独立地随机投掷 N 个点，记落入 C 的点数为 Nin。
（页面演示用的是"正方形 + 内切圆"，两者完全等价：内切圆恰好由四个这样的四分之一圆拼成，面积比相同。）

① 几何概型：点均匀落在 S 上，落入子区域 A 的概率 = |A| / |S| 面积比即概率 ② 正方形面积 |S| = 12 = 1；四分之一圆面积 |C| = (1/4)·π·12 = π/4 ③ 故单点落入圆内的概率 p = |C| / |S| = π/4 ≈ 0.7854 这就是"π/4"的来历 ④ 令 Xi = 1（第 i 点落入圆内）或 0（落在圆外），则 Xi ~ Bernoulli(p)，E[Xi] = p ⑤ Nin = Σ Xi ~ B(N, p)，由期望的线性性 E[Nin] = N·p = N·π/4 ⑥ 取估计量 π̂ = 4·Nin/N，则 E[π̂] = 4·E[Nin]/N = 4·(N·π/4)/N = π 无偏估计 ∴ 用频率 Nin/N 逼近概率 π/4，再乘 4 即得 π 的估计 ∎
P(点落入圆内) = 圆面积 / 正方形面积 = π/4　⟹　π ≈ 4 · Nin / N
为什么必须"均匀且独立"？均匀保证"面积比 = 概率"这一步成立；独立保证 Nin 服从二项分布，从而下面的方差计算可用。若随机数发生器有周期短、低维相关等缺陷，采样点会在平面上形成规则条纹，估计值将系统性偏离 π——这在实践中是真实存在的陷阱。

误差分析：O(1/√N) 的铁律

数值概率算法最关键、也最"劝退"的性质
① Nin ~ B(N, p)，二项分布方差 Var[Nin] = N·p·(1 − p) ② π̂ = 4·Nin/N，由 Var[aX] = a2Var[X] 得    Var[π̂] = (4/N)2 · N·p(1−p) = 16·p(1−p) / N 方差与 N 成反比 ③ 标准差（即典型误差量级）σ(π̂) = 4·√(p(1−p)) / √N 开方后变成 1/√N ④ 代入 p = π/4 ≈ 0.7854：√(p(1−p)) = √(0.7854 × 0.2146) ≈ 0.4105    σ(π̂) ≈ 4 × 0.4105 / √N ≈ 1.64 / √N ∴ 误差 = Θ(1/√N)，与被估计的量、与维数都无关，是蒙特卡罗方法的普适规律 ∎
关键推论 · 100 倍定律

要把误差缩小到原来的 1/10（即多得到一位十进制有效数字），由 1/√N 可知需要 √N 增大 10 倍，即 N 增大 100 倍。
这就是数值概率算法的根本局限：它能极快地给出 2～3 位有效数字，但要拿到 8 位有效数字则需要约 1016 个采样点——实际不可行。因此蒙特卡罗方法不适合追求高精度，它的用武之地是高维、不规则、解析方法失效的场合（此时传统数值方法的复杂度随维数指数爆炸，而蒙特卡罗的 O(1/√N) 与维数无关）。

C++ 实现

投点求 π 与蒙特卡罗积分
// 投点法（Monte Carlo）估计 π // 思路：在单位正方形内均匀撒 N 个点，统计落入 1/4 圆内的个数 cnt // P(落入) = (π/4)/1 = π/4 ==> π ≈ 4 * cnt / N // 时间 O(N)，空间 O(1)；误差量级 Θ(1/√N) double estimatePi(long long N) { srand((unsigned)time(0)); long long cnt = 0; for (long long i = 0; i < N; ++i) { double x = (double)rand() / RAND_MAX; // x ~ U[0,1] double y = (double)rand() / RAND_MAX; // y ~ U[0,1] if (x * x + y * y <= 1.0) ++cnt; // 落入 1/4 圆 } return 4.0 * cnt / N; // 无偏估计：E[结果] = π } // 推广：蒙特卡罗积分，估计 ∫[a,b] f(x) dx // 原理：∫f = (b-a) * E[f(U)]，U ~ 均匀分布[a,b]；用样本均值代替期望 double integrate(double (*f)(double), double a, double b, long long N) { double sum = 0; for (long long i = 0; i < N; ++i) { double x = a + (b - a) * rand() / RAND_MAX; sum += f(x); } return (b - a) * sum / N; // 同样是 Θ(1/√N) 误差 }
T(N) = O(N)　　S(N) = O(1)　　误差 σ ≈ 1.64/√N　　欲减小误差 10 倍需 N × 100
工程注记：rand() 在多数实现中 RAND_MAX 仅 32767，低位随机性差，用于大规模采样会引入系统偏差；C++11 起应改用 std::mt19937 + std::uniform_real_distribution<double>。另外注意 x*x + y*y <= 1.0 中不要开平方——比较平方即可，省一次开方且避免精度损失。

易错点
  • 把误差写成 O(1/N)。正确是 O(1/√N)——方差与 N 成反比，标准差要再开一次方。写错这一条，"100 倍定律"就整个塌掉。
  • 误以为增大 N 一定使本次估计更准。误差是随机变量，单次运行完全可能"N 更大反而更偏"；1/√N 说的是标准差（典型量级），不是逐次单调的保证。
  • 忘记乘 4。Nin/N 收敛到的是 π/4 ≈ 0.785，不是 π。
  • 判定圆内时写成 sqrt(x*x+y*y) <= 1。虽不算错，但多一次开方、且引入浮点误差；直接比较平方更好。
  • 用低质量随机数发生器（如未播种的 rand()、或周期极短的 LCG）。采样点若在平面上呈规则格纹，"均匀"假设失效，估计值会稳定偏离真值，且增大 N 也救不回来。
  • 误以为蒙特卡罗方法总比数值积分好。一维光滑函数上，辛普森法等确定性方法误差可达 O(h4)，远胜 O(1/√N)；蒙特卡罗的优势只在高维（误差不随维数恶化）与不规则区域。
本节小结
  • 投点法的概率原理：均匀随机点落入内切圆的概率 = 圆面积 / 正方形面积 = π/4，故 π ≈ 4·Nin/N，且该估计是无偏的。
  • 误差分析：Nin ~ B(N, π/4)，Var[π̂] = 16p(1−p)/N，标准差 σ ≈ 1.64/√N——误差量级为 Θ(1/√N)。
  • 100 倍定律：精度每提高一位十进制数，采样量需增加约 100 倍。这是数值概率算法的根本局限，也是它不适合高精度计算的原因。
  • 算法时间 O(N)、空间 O(1)；同样的思路可直接推广为蒙特卡罗积分，其优势在于误差率 O(1/√N) 与维数无关。
  • 随机数质量是隐形前提：非均匀或有相关性的随机源会造成系统偏差，增大 N 也无法消除。
1用投点法估计 π 时，若希望误差缩小为原来的 1/10，采样点数 N 大约需要变为原来的多少倍？
A10 倍
B100 倍
C√10 ≈ 3.16 倍
D1000 倍
解析：误差量级为 σ ≈ 1.64/√N。要让 σ 变为 1/10，需 √N 变为 10 倍，故 N 变为 102 = 100 倍。A 是把误差误当成 O(1/N) 的典型错误；C 恰好把关系倒过来用了（以为 N 增大 √10 倍就够）；D 对应误差缩小到 1/√1000 ≈ 1/31.6，过头了。记住这条"100 倍定律"：想多要一位有效数字，就得多花 100 倍算力——这正是蒙特卡罗方法无法用于高精度计算的原因。
2在边长为 1 的正方形内均匀随机投一点，它落入其内切圆的概率是多少？
Aπ ≈ 3.1416
Bπ/4 ≈ 0.7854
Cπ/2 ≈ 1.5708
D1/4 = 0.25
解析：内切圆半径 r = 1/2，圆面积 = π·(1/2)2 = π/4；正方形面积 = 1。由几何概型，概率 = 面积比 = π/4 ≈ 0.7854。A、C 大于 1，概率不可能超过 1——这是一眼可以排除的；A 实际上是"概率乘 4"之后的估计值，正说明为什么代码里最后要写 4.0 * cnt / N。D 是把"四分之一圆"的形状误当成了面积比。
3关于投点法（数值概率算法）的性质，下列说法错误的是？
A它的运行时间是确定的，由采样点数 N 决定，为 O(N)
B4·Nin/N 是 π 的无偏估计，即其数学期望恰好等于 π
C只要 N 取得足够大，就能得到 π 的精确值
D误差量级为 Θ(1/√N)，且该量级与问题维数无关
解析：C 错——这正是数值概率算法的定义要点：它给出的是近似解，精度随采样量提高但永远不会精确。而且 4·Nin/N 是有理数，π 是无理数，二者不可能相等，从这个角度也能立刻否定 C。A 对——时间确定是数值概率与蒙特卡罗共有的特征。B 对——见推导 ⑥：E[4Nin/N] = 4·(Nπ/4)/N = π。D 对——这既是它的局限（一维时打不过辛普森法），也是它的优势（高维时不随维数指数恶化，这才是蒙特卡罗方法在实际科学计算中的真正价值）。
