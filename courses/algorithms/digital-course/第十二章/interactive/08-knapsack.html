背包问题的近似

对价值缩放后做 DP，用精度换时间，得到 (1−ε) 近似。贪心按价值密度也可给常数近似。

学习目标

  1. 能够指出纯价值密度贪心对 0/1 背包没有常数近似比，并给出反例。
  2. 能够说明"密度贪心 vs 最大单件取较大者"如何得到 1/2-近似。
  3. 能够复述 FPTAS 的值域缩放思想：v'i = ⌊vi/K⌋，K = εP/n。
  4. 能够证明缩放 DP 输出 ≥ (1−ε)·OPT，时间 O(n³/ε)。
  5. 能够区分分数背包（密度贪心最优）与 0/1 背包（密度贪心不最优）。

价值密度贪心及其局限

直觉很好，但对 0/1 背包会失手
定义 · 0/1 背包（最大化）

给定容量 W 与 n 件物品，第 i 件重 wi、值 vi，每件只能整取或不取（0/1）。在总重不超过 W 的前提下最大化总价值。该问题 NP-难，但存在 FPTAS。

纯价值密度贪心对 0/1 背包没有任何常数近似比。反例：容量 W，物品 1（w=1, v=2, 密度 2）、物品 2（w=W, v=W, 密度 1）。贪心先取密度高的物品 1（占 1，剩 W−1 装不下物品 2），得 ALG=2；而 OPT 取物品 2 得 W。比值 2/W → 0，可任意坏。
修正为 1/2-近似：同时算两个候选，取较大者 ① G = 价值密度贪心（按 vi/wi 降序装，装得下就装）所得价值 ② H = 单件价值最大且能装下的物品价值 = max{ vi : wi ≤ W } ③ 输出 ALG = max(G, H)，可证 ALG ≥ OPT/2 大件被 H 兜底，碎件由 G 兜底 ∴ 修正贪心是 2-近似（最大化：ALG ≥ OPT/ρ，ρ=2）
注意区分：对分数背包（物品可切分），价值密度贪心是最优算法；正是"0/1 不可切分"让贪心失去了最优性，只能退到近似。

FPTAS：值域缩放 + 按价值 DP

用精度换时间，得 (1−ε) 近似
思路：0/1 背包有按价值的 DP —— dp[v] = 达到总价值 v 所需的最小重量，时间 O(n·Σvi) 是伪多项式（价值可指数大）。把价值缩小刻度后状态数骤降，只损失可控误差。
记 P = maxi vi（单件最大价值），取缩放粒度 K = εP/n 缩放价值 v'i = ⌊vi/K⌋，对 v'i 跑按价值 DP，得集合 S' 每件的取整夹逼：vi − K ≤ K·v'i ≤ vi 因 ⌊x⌋ ≥ x−1 设 O 为真正最优集；因 S' 对缩放价值最优，ΣS' v'i ≥ ΣO v'i val(S') = ΣS' vi ≥ ΣS' K·v'i ≥ ΣO K·v'i ≥ ΣO(vi − K) = OPT − |O|·K 因 |O| ≤ n，故 val(S') ≥ OPT − nK = OPT − εP 又 OPT ≥ P（最优解至少能装下价值最大的可行单件），故 εP ≤ ε·OPT ∴ val(S') ≥ OPT − ε·OPT = (1 − ε)·OPT，是 (1−ε)-近似 ∎ 时间 = O(n·Σv'i) = O(n · nP/K) = O(n³/ε)，对 n 与 1/ε 都多项式 → FPTAS
v'i = ⌊vi/K⌋，K = εP/n　⟹　val ≥ (1 − ε)·OPT，时间 O(n³/ε)

FPTAS 的代码骨架

C++ · 缩放价值后按价值 DP
// 0/1 背包 FPTAS：值域缩放 + 按价值 DP，得 (1-ε) 近似，时间 O(n^3/ε) double knapsackFPTAS(vector<int>& w, vector<int>& v, int W, double eps) { int n = v.size(), P = *max_element(v.begin(), v.end()); double K = eps * P / n; // 缩放粒度 vector<int> vs(n); int Vsum = 0; for (int i = 0; i < n; ++i) { vs[i] = (int)(v[i] / K); Vsum += vs[i]; } // v'_i = floor(v_i/K) const long long INF = 1e18; vector<long long> dp(Vsum + 1, INF); dp[0] = 0; // dp[val]=达到缩放价值 val 的最小重量 for (int i = 0; i < n; ++i) for (int val = Vsum; val >= vs[i]; --val) dp[val] = min(dp[val], dp[val - vs[i]] + w[i]); int best = 0; for (int val = 0; val <= Vsum; ++val) if (dp[val] <= W) best = val; return best * K; // 还原近似价值，≥ (1-ε)·OPT }

易错点
  • 以为价值密度贪心对 0/1 背包有常数近似比。没有，可任意坏（反例 w={1,W}, v={2,W}）。必须改成 max(密度贪心, 最大可装单件) 才得 1/2-近似。
  • 把分数背包与 0/1 背包混为一谈。密度贪心对分数背包最优、对 0/1 背包不最优——差别就在能否切分。
  • 缩放缩错对象。FPTAS 缩的是价值不是重量：容量约束必须精确（重量不能超 W），只能对价值做近似。
  • (1−ε) 方向记反。最大化问题 ALG ≥ (1−ε)·OPT，等价于 ρ = 1/(1−ε) ≥ 1；ε 越小越准、时间越大。
  • 把伪多项式当多项式。按价值 DP 的 O(n·Σv) 里 Σv 可随输入位数指数增长，不是多项式；缩放后 O(n³/ε) 才是关于输入规模与 1/ε 的多项式，这正是"完全"的含义。
  • 以为所有 NP-难问题都有 FPTAS。背包是弱 NP-难（伪多项式可解）才有 FPTAS；强 NP-难问题（如一般 TSP）在 P≠NP 下无 FPTAS。
本节小结
  • 纯价值密度贪心对 0/1 背包无常数近似比；改成"贪心 vs 最大可装单件取较大者"可得 1/2-近似（ρ=2）。
  • 0/1 背包有按价值的伪多项式 DP：dp[v] = 达到价值 v 的最小重量，时间 O(n·Σv)。
  • FPTAS 值域缩放：v'i=⌊vi/K⌋、K=εP/n，缩放后 DP 时间 O(n³/ε)，输出 ≥ (1−ε)·OPT。
  • 证明关键：取整每件损失 ≤ K，n 件共损失 ≤ nK = εP ≤ εOPT（用 OPT ≥ P）。
  • 背包有 FPTAS 源于它是弱 NP-难；强 NP-难问题一般无 FPTAS。
1对 0/1 背包只用"按价值密度降序装"的纯贪心，它的近似比是？
A2-近似
B3/2-近似
C没有任何常数近似比（可任意坏）
D最优（比值恒为 1）
解析：纯密度贪心对 0/1 背包可任意坏：w={1,W}, v={2,W} 时 ALG=2、OPT=W，比值 2/W→0，故 C。要得到常数近似必须补上"最大可装单件"再取较大者，那样才是 1/2-近似（ρ=2，选项 A 描述的是这个修正版而非纯贪心）。D 是分数背包的结论，不是 0/1。
2背包 FPTAS 用 v'i=⌊vi/K⌋、K=εP/n 缩放价值。它缩放的是什么、总时间是多少？
A缩放重量；时间 O(nW)
B缩放价值；时间 O(n³/ε)
C缩放价值；时间 O(n·2ⁿ)
D缩放容量；时间 O(n log n)
解析：FPTAS 缩放的是价值（重量/容量必须精确，否则可能超载），按价值 DP 状态数从 O(Σv) 降到 O(nP/K)=O(n²/ε)，总时间 O(n·n²/ε)=O(n³/ε)，对 n 与 1/ε 都多项式，故 B。A、D 缩错对象；C 是枚举法的指数时间，不是 FPTAS。
3FPTAS 保证 val(S') ≥ (1−ε)·OPT，证明里"n 件累计损失 ≤ εP ≤ εOPT"用到了哪个关键事实？
AΣvi ≤ P
BOPT ≥ P（最优解至少装得下价值最大的可行单件）
COPT ≤ P
DW ≥ n
解析：每件取整损失 ≤ K，n 件累计 ≤ nK = n·(εP/n) = εP。要把 εP 换成 εOPT，需要 OPT ≥ P：价值最大的那件（能装下）本身就是一个可行解，故最优不低于 P，即 B。C 方向反了；A、D 与推导无关。
