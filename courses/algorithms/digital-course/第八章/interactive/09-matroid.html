拟阵的定义

matroid · 贪心可证的抽象框架
定义

拟阵是一个二元组 M = (E, ℐ)，其中 E 是有限基础集，ℐ 是 E 的若干子集构成的独立集族，满足两条公理：

公理 ① 遗传性

若 A ∈ ℐ 且 B ⊆ A，则 B ∈ ℐ。
——独立集的任意子集仍独立。

公理 ② 交换性质

若 A, B ∈ ℐ 且 |A| < |B|，则存在 x ∈ B ∖ A 使 A ∪ {x} ∈ ℐ。
——较小的独立集总能从较大的独立集中借入一个元素而保持独立。

秩与基：秩（rank）＝极大独立集的大小，基（base）＝极大独立集本身。交换性质保证所有基等势，从而局部最优不会把你引入死胡同——这正是贪心能全局最优的结构性根源。

加权拟阵贪心定理

Rado–Edmonds · 贪心正确性的理论基础
定理

给每个元素 e 赋非负权 w(e)。将元素按权降序排列，依次尝试加入，只要加入后仍是独立集就保留，否则丢弃。该贪心得到的独立集是权和最大的基。反之，若某个下降贪心对一切权函数都最优，则该结构必是拟阵。

证明思路（交换论证 + 交换性质） 设贪心解 G = {g1, …, gk}（按加入序，即权降序），O 为任意最优基 由拟阵性质可证所有基等势 ⇒ |O| = |G| = k 秩相同 设 gi 是 G 与 O 第一处不同的元素，前缀 A = {g1, …, gi−1} ⊆ O 对独立集 A ∪ {gi} 与更大的 O 反复用交换性质，可在 O 中换入 gi、换出某元素 o 因贪心按权降序考察，gi 是 A 之后能加入的权最大元素 ⇒ w(gi) ≥ w(o) 故 O' = O − {o} + {gi} 仍是基且 w(O') ≥ w(O)，公共前缀增长 不劣性 对分歧点归纳 ⇒ 可把 O 改造成 G 而权不减 ⇒ G 最优 ∎

实例：图拟阵与 Kruskal

独立集 = 无环边集（森林）· 对应上方演示
图拟阵

基础集 E = 图的边集；一个边子集"独立" ⟺ 它不含环（构成森林）。验证两公理：森林的子集仍是森林（遗传性 ✓）；若森林 A 边数少于森林 B，则 B 中必有一条边连接 A 的两棵不同的树，加入 A 不成环（交换性质 ✓）。

Kruskal = 图拟阵上的加权贪心：求最小生成树时按权升序加边（等价于对相反权求最大基），"加入不成环"就是"保持独立"，"成环"就是"破坏独立"。
边集 (u,v,w)：(0,1,1) (1,2,2) (0,2,3) (2,3,4) (1,3,5)，按权升序考察（求 MST）： (0,1) w=1：不成环 ⇒ 加入，总权 = 1 独立 (1,2) w=2：不成环 ⇒ 加入，总权 = 1+2 = 3 (0,2) w=3：0 与 2 已连通 ⇒ 跳过（成环，破坏独立） (2,3) w=4：不成环 ⇒ 加入，总权 = 3+4 = 7 (1,3) w=5：已连通 ⇒ 跳过（成环） MST：{(0,1),(1,2),(2,3)}，权 = 1+2+4 = 7（3 条边 = 4 结点 − 1，正好一棵生成树）

C++ 实现与复杂度

并查集判独立性
// 加权拟阵贪心 · 以图拟阵（Kruskal 求 MST）为例 // 独立集 = 无环边集（森林）；用并查集判"加入是否成环" struct Edge { int u, v, w; }; int find(vector<int> &fa, int x){ return fa[x] == x ? x : fa[x] = find(fa, fa[x]); } int kruskal(vector<Edge> &es, int n) { sort(es.begin(), es.end(), [](const Edge &a, const Edge &b){ return a.w < b.w; // MST 按权升序；求最大权基则改降序 }); vector<int> fa(n); for (int i = 0; i < n; ++i) fa[i] = i; int tot = 0, cnt = 0; for (Edge &e : es) { int ru = find(fa, e.u), rv = find(fa, e.v); if (ru != rv) { // 不成环 ⇒ 仍是独立集 fa[ru] = rv; tot += e.w; ++cnt; } // 成环 ⇒ 破坏独立，跳过 } return cnt == n - 1 ? tot : -1; // 不连通返回 -1 }
T(m) = O(m log m) （排序） + O(m · α(n)) （并查集） ≈ O(m log m)
易错点
  • 以为"任何贪心题都是拟阵"。拟阵只覆盖一大类可证问题；活动安排、哈夫曼等不套拟阵框架也各有证明。
  • 混淆遗传性与交换性质。遗传性管"子集封闭"，交换性质管"小集可扩充"，缺一不构成拟阵。
  • 求最大权基与最小权基搞反排序方向。最大权基按权降序，MST（最小）按权升序或取相反权。
  • 把"独立"误当成"元素互不相同"。独立性由 ℐ 定义（如无环），不是简单的不重复。
  • Kruskal 忘判连通性。加入的边数应为 n−1；不足说明图不连通，没有生成树。
  • 并查集不做路径压缩/按秩合并。退化成链会使单次 find 变 O(n)，总复杂度劣化。
本节小结
  • 拟阵 M = (E, ℐ) 由遗传性与交换性质两公理定义，交换性质保证所有基等势。
  • 加权拟阵贪心定理：按权排序 + 保持独立，即得最大权基；这是一大类贪心正确性的统一来源。
  • 图拟阵以无环边集为独立集，Kruskal 就是其上的加权贪心："成环 = 破坏独立"。
  • 示例边集 Kruskal 得 MST 权 = 7（边 (0,1)、(1,2)、(2,3)），跳过成环的 (0,2)、(1,3)。
  • 用并查集判独立性，复杂度约 O(m log m)，排序主导。
1下列哪一条是拟阵的交换性质？
A独立集的任意子集仍是独立集
B若 A、B 独立且 |A| < |B|，则存在 x∈B∖A 使 A∪{x} 独立
C任意两个独立集的并仍独立
D所有元素的权互不相同
解析：A 是遗传性；C 一般不成立（两个森林之并可能成环）；D 与拟阵定义无关。交换性质是 B：较小独立集总能从较大者借入一个元素保持独立，它保证了所有极大独立集（基）等势。
2加权拟阵贪心（求最大权基）的正确做法是？
A按权升序，能加就加
B按权降序依次尝试，加入后仍独立则保留，否则丢弃
C随机加入元素直到不能再加
D先枚举出所有基再取权最大的
解析：求最大权基应按权降序贪心并保持独立性（选 B），由 Rado–Edmonds 定理保证最优。升序（A）对应最小权基/MST。D 枚举所有基是指数级，没必要。

A6
B7

D15
解析：按权升序：加 (0,1)=1、(1,2)=2；(0,2)=3 时 0、2 已连通成环跳过；加 (2,3)=4；(1,3)=5 成环跳过。MST = 1+2+4 = 7，3 条边连通 4 个结点，选 B。15 是所有边权之和，不是 MST。
