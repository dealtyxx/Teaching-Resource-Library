Huffman—
初始权: 5,9,12,13,16,45

问题与贪心策略

哈夫曼编码 · 最优前缀码
定义

给定 n 个字符及其出现频率（权）w1, …, wn。用二叉树为每个字符分配 01 编码：字符全在叶子上，从根到叶的路径即其编码——这样任何编码都不是另一编码的前缀（前缀码，可无歧义解码）。设叶子 i 的深度为 di，定义带权路径长度（WPL）＝编码后的总位数：

WPL = Σi=1n wi · di　　（目标：最小化）
贪心准则

把 n 个权看作 n 棵单结点树放入小根堆；每次取出权最小的两棵合并为一棵新树，新树根的权 = 两子树权之和，放回堆中；重复 n−1 次直到只剩一棵，即哈夫曼树。

直觉：权大的字符应离根近（编码短），权小的离根远（编码长）。让当前最小的两个权沉到最底层配成兄弟，正是把"长编码"分配给"最不常用"的字符。

正确性 · 交换论证

贪心选择性质 + 最优子结构
引理（贪心选择性质）

设 x、y 是频率最小的两个字符。则存在一棵最优前缀码树，其中 x 与 y 是最深层的兄弟（同一父结点）。

证明（交换论证） 取任意最优树 T。设 a、b 是 T 中处于最深层的一对兄弟叶子 最深处必有一对兄弟 不失一般性设 w(x) ≤ w(y)、w(a) ≤ w(b)；因 x、y 是全局最小 ⇒ w(x) ≤ w(a)、w(y) ≤ w(b) 把 x 与 a 交换位置得 T'。WPL 改变量：   ΔWPL = ( w(x)·da + w(a)·dx ) − ( w(x)·dx + w(a)·da ) = ( w(a) − w(x) )( dx − da )   因 w(a) ≥ w(x) 且 da ≥ dx（a 在最深层）⇒ ( w(a)−w(x) ) ≥ 0、( dx−da ) ≤ 0 ⇒ ΔWPL ≤ 0 交换不使 WPL 变大 同理再把 y 与 b 交换，WPL 仍不增 ⇒ 得到一棵不劣于 T、且 x、y 为最深兄弟的最优树 ∎
最优子结构

把 x、y 合并成一个权为 w(x)+w(y) 的新字符 z，得到规模 n−1 的子问题。可证：子问题最优树换回 x、y 后，WPL 恰好增加 w(x)+w(y)（z 变父结点，x、y 各深一层）。故子问题最优 ⇒ 原问题最优，对 n 归纳即得哈夫曼树最优。

合并权 = WPL 增量：每次合并让两棵子树各下沉一层，总位数正好增加"新结点的权"。因此 WPL = 所有合并所产生的新权之和——这给了一条独立的验算路径。

C++ 实现与复杂度

小根堆 + WPL 计算
// 哈夫曼树：每次取两棵权最小的树合并 struct Node { int w; Node *l, *r; }; struct Cmp { bool operator()(Node *a, Node *b){ return a->w > b->w; } }; // 小根堆 Node* buildHuffman(vector<int> &freq) { priority_queue<Node*, vector<Node*>, Cmp> pq; for (int f : freq) pq.push(new Node{f, nullptr, nullptr}); while (pq.size() > 1) { Node *a = pq.top(); pq.pop(); // 最小 Node *b = pq.top(); pq.pop(); // 次小 pq.push(new Node{a->w + b->w, a, b}); // 合并，新权 = 两子权之和 } return pq.top(); // 根结点 } // 带权路径长度 WPL = Σ 叶权 × 叶深 long long wpl(Node *r, int depth = 0) { if (!r) return 0; if (!r->l && !r->r) return (long long)r->w * depth; // 叶子 return wpl(r->l, depth + 1) + wpl(r->r, depth + 1); }
T(n) = O(n log n) （n−1 次堆操作，每次 O(log n)）　　S(n) = O(n)
易错点
  • 合并后忘记把新树放回堆。新权必须重新参与后续"取最小两棵"的比较，否则建出的不是哈夫曼树。
  • 新结点权算错。新权 = 两子树根权之和，不是叶子个数、也不是深度。
  • WPL 用错公式。WPL = Σ 叶权×叶深；等价地 = 所有合并新权之和，两者应相等，可互检。
  • 把内部结点也当字符编码。只有叶子对应字符，内部结点仅是路径分叉。
  • 误以为编码表唯一。左右 0/1 可互换、等权结点合并次序可不同，编码可能不同，但最优 WPL 唯一。
  • 用反复排序找最小而非堆。每轮重排是 O(n² log n)，用小根堆才能做到 O(n log n)。
本节小结
  • 哈夫曼编码 = 每次从小根堆取权最小的两棵树合并，新权为二者之和，共 n−1 次。
  • 正确性由交换论证保证：两个最小权字符可放到最优树的最深兄弟位，交换 ΔWPL ≤ 0。
  • 权 [5,9,12,13,16,45] 建树后 WPL = 224；叶权×叶深与合并新权之和两法互检一致。
  • 相比定长码 300 位，哈夫曼 224 位，体现最优前缀码对高频字符用短码的思想。
  • 复杂度 O(n log n)（堆），空间 O(n)；编码表不唯一但最优 WPL 唯一。
1权值为 {5,9,12,13,16,45} 的哈夫曼树，其带权路径长度 WPL 为？
A200
B224
C240
D300
解析：合并顺序 5+9=14、12+13=25、14+16=30、25+30=55、45+55=100，WPL = 14+25+30+55+100 = 224；也可按叶权×叶深核对：45·1+12·3+13·3+16·3+5·4+9·4 = 224，选 B。300 是定长 3 位码的位数，不是哈夫曼结果。
2构造哈夫曼树时，每一步的贪心操作是？
A取权最大的两棵树合并
B取权最小的两棵树合并，新树权为二者之和
C取权最小和权最大的两棵树合并
D按字符出现顺序两两合并
解析：哈夫曼贪心每次取权最小的两棵合并（选 B），使小权字符沉到最深、获得较长编码，大权字符靠近根、编码更短，从而最小化 WPL。取最大或按顺序合并都得不到最优前缀码。
3哈夫曼编码是"前缀码"，其含义与好处是？
A所有编码都以相同前缀开头，便于压缩
B任一编码都不是另一编码的前缀，故解码无歧义、无需分隔符
C每个编码长度相同，便于对齐
D编码越短的字符出现频率越低
解析：字符都在叶子上，没有哪个叶子在另一叶子到根的路径上，因此任一编码都不是另一编码的前缀（选 B），解码时沿树走到叶即可切分，无需额外分隔符。C 是定长码，与哈夫曼相反；D 说反了——频率越高编码越短。
