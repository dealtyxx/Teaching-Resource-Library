一、TSP 与难解性

Travelling Salesman Problem
定义

旅行商问题（TSP）：给定 n 座城市及两两距离，求一条经过每座城恰好一次再回到起点的最短哈密顿回路。判定型 TSP 是 NP 完全（NPC）问题，优化型 TSP 是 NP 难（NP-hard）问题——目前没有已知的多项式时间精确算法。

度量 TSP（Metric TSP）

若距离满足三角不等式 d(i,k) ≤ d(i,j)+d(j,k)（如平面欧氏距离），称为度量 TSP。它仍是 NP 难的，但存在常数比近似算法；一般（非度量）TSP 则连常数比近似都不存在（除非 P=NP）。本页演示的平面点集属于度量 TSP。

二、精确算法的代价

穷举 vs 动态规划
不同回路数 = (n−1)!/2  |  Held–Karp DP：时间 O(n2·2n)，空间 O(n·2n)
穷举：固定起点得 (n−1)! 条有向回路，对称距离再 ÷2，逐条求值 ⇒ Θ(n!) Held–Karp（状压 DP）：设 dp[S][j] = 从起点出发、恰好访问集合 S、当前停在 j 的最短路径 状态数 2n·n，每次转移枚举下一个城 O(n) ⇒ 时间 O(n2·2n) 它把 Θ(n!) 降到 O(2nn2)：n=20 时 n! ≈2.4×1018，而 2nn2 ≈4×108，仍指数但已可算
方法类型时间解的质量适用规模
穷举全排列精确Θ(n!)最优n≤10~12
Held–Karp DP精确O(n22n)最优n≤~20
最近邻 NN启发式O(n2)无常数保证（度量下最坏 Θ(log n) 倍）很大
MST 双倍树近似O(n2)度量下 ≤ 2 倍最优很大
Christofides近似O(n3)度量下 ≤ 1.5 倍最优大

三、最近邻与分治启发式

本页演示的思路
最近邻（Nearest Neighbor）

从起点出发，每一步都贪心地走向当前最近的未访问城市，直至走遍所有城市再回到起点。时间 O(n2)，实现简单，但可能因贪心「近视」而在最后被迫拉出很长的返程边，故不保证最优。

本页分治示意：① 按 x 坐标中位数把点集划分为左右两半（分解） ② 对左右子集各自构造子回路（求解） ③ 找「桥边」把两条子回路拼接成一条大回路（合并） 诚实提醒：合并两条最优子回路未必得到全局最优——最优大回路可能反复穿越分界线，这正是分治对 TSP «不奏效为精确解» 的根本原因，只能作启发式
为什么分治救不了 TSP：分治高效的前提是「子问题独立、合并廉价」。TSP 的最优回路会在左右点集之间来回穿插，子问题并不独立，且「如何最优地合并子回路」本身又是一个难题。因此 TSP 只能用分治做近似，精确解仍需 DP 或分支限界（第 6 章）。

四、C++ 实现

最近邻（与演示一致）+ Held–Karp 精确
// ===== 最近邻启发式：O(n²)，与页面动画的 nnTour 一致 ===== double dist(Point a, Point b) { return hypot(a.x - b.x, a.y - b.y); } vector<int> nnTour(const vector<Point>& P) { int n = P.size(); vector<bool> used(n, false); vector<int> order = {0}; // 从城 0 出发 used[0] = true; int cur = 0; for (int step = 1; step < n; ++step) { int best = -1; double bd = 1e18; for (int i = 0; i < n; ++i) // 找最近的未访问城 if (!used[i]) { double d = dist(P[cur], P[i]); if (d < bd) { bd = d; best = i; } } used[best] = true; order.push_back(best); cur = best; } return order; // 回路：order[0]→…→order[n-1]→order[0] } // ===== Held-Karp 精确解：O(n²·2ⁿ)，只适合小 n ===== long long heldKarp(int n, const vector<vector<int>>& D) { int FULL = 1 << n; const long long INF = 1e15; vector<vector<long long>> dp(FULL, vector<long long>(n, INF)); dp[1][0] = 0; // 只访问 {0}，停在 0 for (int S = 1; S < FULL; ++S) if (S & 1) for (int j = 0; j < n; ++j) if ((S >> j & 1) && dp[S][j] < INF) for (int k = 0; k < n; ++k) if (!(S >> k & 1)) dp[S | 1 << k][k] = min(dp[S | 1 << k][k], dp[S][j] + D[j][k]); long long best = INF; for (int j = 1; j < n; ++j) best = min(best, dp[FULL - 1][j] + D[j][0]); return best; // 访问全部城后回到起点 0 }

五、易错点

Common Pitfalls
易错点
  • 以为分治能精确解 TSP：划分-合并只是启发式，最优回路会跨越分界线，子问题不独立，得不到全局最优。
  • 把最近邻当成最优算法：NN 是贪心启发式，一般无常数近似保证，度量情形下最坏也能差到 Θ(log n) 倍。
  • Christofides / 2-近似忘记前提：这些保证只对满足三角不等式的度量 TSP 成立；一般 TSP 无常数比近似。
  • 混淆 NPC 与 NP 难：判定型 TSP 是 NPC，优化型 TSP 是 NP 难；NPC 特指 NP 内的判定问题。
  • Held–Karp 复杂度记成 O(2n)：应是 O(n22n)（状态 n·2n，每次转移 O(n)），空间 O(n·2n)。
  • 回路漏算返程边：无论 NN 还是穷举，最后都要加「末城 → 起点」这条边，否则算的是路径不是回路。
本节小结
  • TSP 是 NP 难问题（判定型为 NPC），无已知多项式精确算法。
  • 精确解：穷举 Θ(n!)、Held–Karp 状压 DP O(n22n)；后者把阶乘降为指数，可解到 n≈20。
  • 最近邻是 O(n2) 贪心启发式，简单但不保证最优；本页分治「划分-子回路-合并」同为启发式。
  • 分治救不了 TSP 精确解：最优回路跨越分界线，子问题不独立、合并本身也难。
  • 度量 TSP（满足三角不等式）有常数比近似：MST 双倍树 2-近似、Christofides 1.5-近似。

2把点集按中位数划分、分别求子回路再合并，这种分治方法对 TSP 而言？
A一定能得到最优回路
B只是启发式，不保证最优——最优回路可能跨越分界线，子问题并不独立
C把复杂度降到多项式且保证最优
D与最近邻完全等价
解析：选 B。分治要求子问题独立、合并廉价，但 TSP 最优回路会在左右点集间来回穿插，子问题不独立，且最优合并本身又是难题，故只能近似。C 若成立即 P=NP；D 错，NN 与「划分-合并」是两种不同启发式。
3Christofides 算法对满足三角不等式的度量 TSP 能给出的近似比是？
A1（即最优）
B不超过 1.5 倍最优
C不超过 2 倍最优
D对任意（含非度量）TSP 都有常数比
解析：选 B。Christofides 保证解 ≤ 1.5 倍最优，优于 MST 双倍树的 2 倍（C）。A 错，它是近似而非精确；D 错，常数比近似仅对满足三角不等式的度量 TSP 成立，一般 TSP 除非 P=NP 否则无常数比近似。
