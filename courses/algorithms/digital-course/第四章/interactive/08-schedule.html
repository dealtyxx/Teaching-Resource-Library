循环日程安排

n=2ᵏ 支队伍，n−1 天每队恰赛一场。分治：先填左上，右上 = 左上 + n/2，再对称填下半。

学习目标

  1. 能够陈述循环赛日程表问题：n=2k 支队伍在 n−1 天内，每队每天恰赛一场，每两队恰赛一次。
  2. 能够解释分治填表法：递归排好左上 n/2 块后，用「右上=左上+n/2、下半对称」三条规则一次性拼出全表。
  3. 能够写出递归填表的 C++ 代码，并说清三条复制规则对应的象限。
  4. 能够推导复杂度 T(n)=T(n/2)+Θ(n2)=Θ(n2)，即与表格单元数同阶。
  5. 能够手工验证 n=2、n=4 的日程表满足全部约束。
表[i][j] = 第 i 队在第 j 天的对手（1-based 队号）。

一、问题定义

Round-Robin Tournament
定义

循环赛日程表问题：设有 n=2k 支队伍参加循环赛，要求安排一张比赛日程表，满足三条约束：① 每支队伍与其他 n−1 支队伍各赛一场；② 每支队伍每天恰赛一场；③ 整个赛程共 n−1 天。

表格约定

用 n×n 表 T 存放：第 0 列 T[i][0]=i+1 记队号；第 j 列（1≤j≤n−1）记队 i 在第 j 天的对手编号。因每队 n−1 天各赛一场，恰好把其余 n−1 支队伍填满，故表格右侧 n−1 列正是完整赛程。

二、分治填表策略

左上递归 + 三条复制规则
分解：把 n×n 表按中线分成 4 个 (n/2)×(n/2) 象限，令 h=n/2 求解：先递归填好左上象限——它本身就是「前 h 支队伍、前 h−1 天」的合法子日程 合并（三条规则）： 　右上 T[i][j+h] = T[i][j] + h 前 h 队在后 h 天改打「后 h 队」，对手号整体 +h 　左下 T[i+h][j] = T[i][j+h] 后 h 队前 h 天的对手 = 右上块（对称） 　右下 T[i+h][j+h] = T[i][j] 后 h 队后 h 天互打，复用左上块 出口：n=1 时无需比赛，直接返回
n=4 的完整结果（第 0 列为队号，第 1~3 列为第 1~3 天的对手）：
队1： 1 | 2 3 4   队2： 2 | 1 4 3
队3： 3 | 4 1 2   队4： 4 | 3 2 1
逐天核对：第1天 (1↔2)(3↔4)；第2天 (1↔3)(2↔4)；第3天 (1↔4)(2↔3)——6 对全部出现且每天每队只赛一场。✓

三、复杂度分析

递推式
T(n) = T(n/2) + Θ(n2)
只有左上一个象限递归 ⇒ 系数 a=1（不是 4） 三条复制规则各遍历 (n/2)2 个单元 ⇒ 合并代价 Θ(n2)，即 f(n)=Θ(n2)，d=2 主定理：a=1, b=2, d=2，log21=0 < 2 ⇒ 情形③ ⇒ T(n)=Θ(n2) 校验：全表需填 n(n−1) 个对手单元，每个 O(1) ⇒ Θ(n2)，与结论一致且最优
易混：本题只递归一个子块（a=1），不同于棋盘覆盖的 4 个子块（a=4）。两者合并代价也不同：棋盘是 O(1)、日程是 O(n2)，因此一个得 Θ(n2)（情形①）、一个也得 Θ(n2)（情形③），殊途同归但推导路径不同。

四、C++ 实现

与上方填表动画一致
// T[i][0] = i+1 为队号；T[i][j] = 队 i 第 j 天的对手 const int MAXN = 64; int T[MAXN][MAXN]; // 填满 n×n 日程表（假设左上 n/2 块尚未填，由递归负责） void fill(int n) { if (n == 1) return; // 出口：单队无需比赛 int h = n / 2; fill(h); // 先递归排好左上 h×h for (int i = 0; i < h; ++i) for (int j = 0; j < h; ++j) { T[i][j + h] = T[i][j] + h; // 右上 = 左上 + h T[i + h][j] = T[i][j + h]; // 左下 = 右上 T[i + h][j + h] = T[i][j]; // 右下 = 左上 } } void schedule(int n) { for (int i = 0; i < n; ++i) T[i][0] = i + 1; // 初始化队号列 fill(n); }
为什么右上要「+h」：左上块记录的是「前 h 支队伍之间」的对阵，其对手号都在 1..h。前 h 队在后半程（后 h 天）要改打「后 h 支队伍」，把左上块每个对手号统一加 h，正好映射到 h+1..2h 的队号，既不重复也不遗漏。

五、易错点

Common Pitfalls
易错点
  • 误以为要递归 4 个象限：日程表只需递归左上一块，其余三块由复制规则 O(1) 得到，故 a=1 而非 4。
  • 右上块忘记「+h」：直接抄左上会让前 h 队在后半程又跟前 h 队重赛，违反「每两队只赛一次」。
  • 下半两块规则记反：左下=右上、右下=左上；写反会使某天出现两队互不对应（i 说打 j，j 却没打 i）。
  • 复杂度写成 Θ(n) 或漏算合并：合并三块共 Θ(n2) 单元，主定理情形③得 Θ(n2)。
  • 把队数取成非 2 的幂：此分治构造要求 n=2k；n 为奇数或非 2 幂时需另设「轮空」处理，不能直接对半分。
  • 混淆第 0 列与比赛日：第 0 列是队号标签，真正的赛程是第 1..n−1 列，别把队号当成第 0 天的对手统计。
本节小结
  • 循环赛日程表：n=2k 队、n−1 天，每队每天一场、两两各赛一次。
  • 分治只递归左上象限，再用「右上=左上+h、左下=右上、右下=左上」三条规则拼出全表。
  • 「+h」的本质是把前半队伍的对手整体映射到后半队伍，保证不重复对阵。
  • 递推式 T(n)=T(n/2)+Θ(n2)，主定理情形③ ⇒ Θ(n2)，与单元总数同阶且最优。
  • n=4 结果可逐天核对 6 对全出现，验证构造正确。

1n=2k 支队伍的循环赛，共需安排多少天，每天进行多少场比赛？
An 天，每天 n 场
Bn−1 天，每天 n/2 场
Cn−1 天，每天 n 场
Dn(n−1)/2 天，每天 1 场
解析：选 B。每队要和其余 n−1 队各赛一次、每天只赛一场，故需 n−1 天；n 支队伍两两配对，每天同时进行 n/2 场。总场数 = (n−1)·(n/2)=n(n−1)/2，恰为 C(n,2)，与 D 的总场数一致，但 D 把「总场数」误当成「天数」。

解析：选 C。递推式 T(n)=T(n/2)+Θ(n2)：a=1,b=2,d=2，log21=0<2 属情形③，T=Θ(n2)。也可直接看：表中要填 n(n−1) 个对手单元，每个 O(1)，共 Θ(n2)。
3设 h=n/2，已填好左上象限 T[i][j]（0≤i,j<h）。右上象限的正确填法是？
AT[i][j+h] = T[i][j]（直接复制左上）
BT[i][j+h] = T[i][j] + h
CT[i][j+h] = T[i][j] × 2
DT[i][j+h] = h − T[i][j]
解析：选 B。右上象限表示前 h 支队伍在后半程改打「后 h 支队伍」，把左上块的对手号统一加 h，即映射到队号 h+1..2h，保证既是后半队伍又不重复。A 会让前 h 队与前 h 队重赛；C、D 得到的号可能越界或对不上对手。
