残缺棋盘 L 型骨牌覆盖

2ⁿ×2ⁿ 棋盘缺一格：中心放 L 骨牌制造 4 个「缺一」子棋盘，递归覆盖。骨牌数 = (4ⁿ−1)/3。

学习目标

  1. 能够描述棋盘覆盖问题：2k×2k 残缺棋盘用 L 型三格骨牌不重叠地覆盖所有正常方格。
  2. 能够推导所需骨牌数恰为 (4k−1)/3，并说明它一定是整数。
  3. 能够解释分治思路：四等分棋盘，用一块 L 骨牌覆盖中心三格，把每个子棋盘都变成「缺一格」。
  4. 能够写出 chessBoard 递归函数的 C++ 代码，正确处理四个象限。
  5. 能够推导时间复杂度 T(n)=4T(n/2)+Θ(1)=Θ(n2)，并说明它是最优的。

一、问题定义

Chessboard Covering
定义

棋盘覆盖问题：在一个 2k×2k 的棋盘中，恰有一个方格是特殊方格（残缺格）。要求用 L 型三格骨牌（tromino）不重叠、不越界地覆盖棋盘上除特殊方格外的所有方格。L 型骨牌有 4 种旋转方向，每块盖住 3 个格子。

骨牌数（先算清账）

棋盘共 4k 个格，除去 1 个特殊格，剩 4k−1 个格待覆盖；每块 L 骨牌盖 3 格，故骨牌数 = (4k−1)/3。因 4≡1 (mod 3)，有 4k≡1，故 4k−1 必被 3 整除，骨牌数一定是整数。k=1,2,3,4 分别为 1, 5, 21, 85。

二、分治策略

四等分 + 中心一块骨牌
分解：用水平、竖直两条中线把 2k×2k 棋盘均分为 4 个 2k−1×2k−1 的子棋盘 关键构造：特殊格必落在某一个子棋盘内；另外 3 个子棋盘暂时是「完整」的，无法递归 制造子问题：在棋盘正中央放一块 L 骨牌，恰好盖住「无特殊格的 3 个子棋盘」各自靠中心的那一格 这样：4 个子棋盘各有且只有一个「缺格」（真特殊格或被中心骨牌占的格），全部化为同一形式的子问题 求解：对 4 个子棋盘递归覆盖；合并：无需操作（子棋盘互不重叠） 出口：子棋盘缩到 1×1 时，该唯一格就是缺格，直接返回
正确性（归纳法）：对 k 归纳。k=0 时棋盘只有 1 格且为特殊格，0 块骨牌即完成。设规模 2k−1 的「缺一格棋盘」都可覆盖；对规模 2k，放中心骨牌后 4 个子棋盘均为「缺一格的 2k−1 棋盘」，由归纳假设均可覆盖，故规模 2k 也可覆盖。

三、复杂度分析

递推式与最优性
T(n) = 4 T(n/2) + Θ(1),  n = 2k
每层：4 个规模减半的子问题 + 放 1 块中心骨牌 Θ(1) 主定理：a=4, b=2, d=0，logba = log24 = 2 > d = 0 ⇒ 情形① T(n) = Θ(nlog24) = Θ(n2) n=2ᵏ 时即 Θ(4ᵏ) 按 k 展开亦得：T(k)=4T(k−1)+c = Θ(4k)
最优性：算法放置的骨牌数正是 (4k−1)/3=Θ(4k)=Θ(n2)，每块 O(1) 时间。任何算法都至少要「写」这么多格，故 Θ(n2) 已达下界，无法更快。

四、C++ 实现

经典 chessBoard 递归
// board 为全局二维数组；tile 为骨牌编号计数器 // (tr,tc): 子棋盘左上角坐标；(dr,dc): 特殊方格坐标；size: 子棋盘边长 int tile = 0; int board[N][N]; void chessBoard(int tr, int tc, int dr, int dc, int size) { if (size == 1) return; // 出口：1×1 即缺格本身 int t = ++tile; // 本层这块 L 骨牌的编号 int s = size / 2; // 子棋盘边长 // —— 左上子棋盘 —— if (dr < tr + s && dc < tc + s) // 特殊格在左上 chessBoard(tr, tc, dr, dc, s); else { // 否则用 t 覆盖左上的右下角格 board[tr + s - 1][tc + s - 1] = t; chessBoard(tr, tc, tr + s - 1, tc + s - 1, s); } // —— 右上子棋盘 —— if (dr < tr + s && dc >= tc + s) chessBoard(tr, tc + s, dr, dc, s); else { board[tr + s - 1][tc + s] = t; chessBoard(tr, tc + s, tr + s - 1, tc + s, s); } // —— 左下子棋盘 —— if (dr >= tr + s && dc < tc + s) chessBoard(tr + s, tc, dr, dc, s); else { board[tr + s][tc + s - 1] = t; chessBoard(tr + s, tc, tr + s, tc + s - 1, s); } // —— 右下子棋盘 —— if (dr >= tr + s && dc >= tc + s) chessBoard(tr + s, tc + s, dr, dc, s); else { board[tr + s][tc + s] = t; chessBoard(tr + s, tc + s, tr + s, tc + s, s); } }
四个分支的对称性：每个象限只有两种情况——含特殊格（直接递归），或不含（先用本层骨牌 t 盖住它靠棋盘中心的那个角，把该角当作新的「缺格」再递归）。四块拼起来的三个中心角正好构成一块 L 骨牌。

五、易错点

Common Pitfalls
易错点
  • 骨牌数公式记成 4k/3 或 (4k+1)/3：应是 (4k−1)/3——先减去 1 个特殊格再除以 3。
  • tile 编号在四个分支各自 ++：本层只放一块 L 骨牌，四个「补角」共用同一个 t，必须在递归前只自增一次。
  • 补角位置搞错：无特殊格的象限要补的是它靠棋盘正中心的那个角，不是任意角，否则拼不成 L 且中心留洞。
  • 象限判定边界写错：用 dr < tr+s / dc < tc+s 判定，混用 ≤/< 会把中线上的格分错象限。
  • 把复杂度当成 O(4klog) 或误套减一型：本题是标准 T(n)=4T(n/2)+O(1)=Θ(n2)，别多加 log。
  • 递归出口漏写 size==1：会在 1×1 时继续四分导致越界。
本节小结
  • 棋盘覆盖：2k×2k 缺一格，用 L 型三格骨牌全覆盖，共需 (4k−1)/3 块。
  • 分治三步：四等分棋盘 → 中心放一块 L 骨牌把 3 个完整象限各变出一个缺格 → 4 个子棋盘递归。
  • 正确性由对 k 的数学归纳保证；每个象限「含特殊格则直接递归，否则先补中心角再递归」。
  • 递推式 T(n)=4T(n/2)+Θ(1)，主定理情形① ⇒ Θ(n2)=Θ(4k)，且已达下界最优。
  • 代码要点：本层骨牌编号只自增一次、四象限共用；补角补在靠中心的角。

1一个 8×8（即 k=3）的残缺棋盘，用 L 型三格骨牌覆盖需要多少块？
A16
B21
C22
D63
解析：选 B。棋盘 43=64 格，去掉 1 个特殊格剩 63 格，每块盖 3 格 ⇒ 63/3=21。D=63 是待覆盖格数不是骨牌数；A、C 为凑数干扰。
2棋盘覆盖分治算法对 n×n（n=2k）棋盘的时间复杂度是？
AΘ(n log n)
BΘ(4k log n)
CΘ(n2)
DΘ(n3)
解析：选 C。递推式 T(n)=4T(n/2)+Θ(1)，a=4,b=2,d=0，log24=2>0 属情形①，T=Θ(nlog24)=Θ(n2)=Θ(4k)。B 多加了不该有的 log 因子（每层工作是 O(1)，不是 O(n)）。
3分治覆盖中，在棋盘正中央放置那一块 L 骨牌的作用是？
A标记特殊方格的位置
B让原本完整的 3 个子棋盘各产生一个「缺格」，从而都能递归求解
C把 4 个子棋盘合并成一个大问题
D减少骨牌总数
解析：选 B。特殊格只落在 1 个子棋盘里，另外 3 个是完整棋盘、不符合「缺一格」的子问题形式。中心骨牌盖住这 3 个子棋盘各自的中心角，等于给它们各造一个「缺格」，使 4 个子棋盘统一为可递归的同型子问题。C 说反了（是分解不是合并）；D 无关；A 特殊格是输入给定的，无需标记。
