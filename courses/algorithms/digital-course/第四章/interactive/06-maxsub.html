最大连续子段和 · 分治

左半 / 右半 / 跨中线 三者取 max。跨中 = 左向最大后缀 + 右向最大前缀。T=Θ(n log n)。

学习目标

  1. 能够说明最优子段的三种互斥位置（完全在左、完全在右、跨越中点），并论证这三种情况不重不漏。
  2. 能够写出 maxCrossing 的 C++ 代码：从中点向左求最大后缀和、向右求最大前缀和，两者相加。
  3. 能够推导 T(n)=2T(n/2)+Θ(n) ⇒ Θ(n log n)，并解释跨中处理为什么是 Θ(n) 而非 Θ(n2)。
  4. 能够对比蛮力 O(n3)、前缀和 O(n2)、分治 O(n log n)、Kadane 线性扫描 O(n) 四种解法。
  5. 能够处理全负数组等边界情形，区分"允许空子段"与"要求非空子段"两种约定。

答案—
区间—
观察跨中线合并如何产生全局最优。
易错点
  • 三种情况不可漏：最大子段和只可能①全在左半、②全在右半、③跨越中点，三者取最大。
  • 跨中点段必须含中点两侧：= “从中点向左的最大后缀和” + “从中点右侧向右的最大前缀和”。
  • 跨中点用线性扫描：从中点分别向两侧累加求最值，O(n)，不是再次分治。
  • 递推式：T(n)=2T(n/2)+O(n)=O(n log n)，与归并排序同量级。
  • 全负数 / 空段约定：若不允许空段，答案为最大的单个元素（负数）；允许空段则为 0，先明确定义。
  • 只比左右忘了跨段：会漏掉横跨中线的最优解，这是最常见错误。
本节小结
  • 分治把区间从中点一分为二，最大子段和取“左半 / 右半 / 跨中点”三者最大。
  • 跨中点段 = 左侧最大后缀和 + 右侧最大前缀和，线性求出。
  • 递推 T(n)=2T(n/2)+O(n)，解得 O(n log n)。
  • 另有 Kadane 动态规划解法可达 O(n)，分治胜在展示“合并”思想。
  • 注意空段 / 全负数的定义约定，避免边界答案出错。
