# 算法设计与分析 · 交互可视化课程

基于李春葆《算法设计与分析》第 3 版的**离线 HTML 交互教学系统**。
十二章、113 节可视化演示，每一次比较、每一步剪支、每一格状态转移都可以逐帧回放。

纯前端，无需安装、无需联网、无 CDN 依赖。整个文件夹可直接拷贝分发。

---

## 快速开始

用浏览器打开 **[index.html](./index.html)** 即可。建议 Chrome / Edge。

- 课程门户会记录学习进度，点「继续上次学习」直接回到上次看到的地方
- 任何页面按 <kbd>Ctrl</kbd>+<kbd>K</kbd> 搜索全站 113 节，直接跳转
- 课堂投影：<kbd>F</kbd> 全屏，<kbd>Space</kbd> 播放，<kbd>←</kbd> <kbd>→</kbd> 翻节

## 目录结构

```
digital-course/
├── index.html              课程门户（学习进度 · 全站搜索）
├── README.md               本说明
├── assets/
│   ├── theme.css           统一设计系统（亮/暗双模式）
│   ├── theme.js            外壳：主题 · 命令面板 · 进度 · 快捷键
│   └── sitemap.js          全站结构索引（自动生成）
├── 第一章/
│   ├── interactive/        章节总览页 + 各节演示页
│   └── 图N_*.svg           配套矢量插图
├── …
└── 第十二章/
```

以 `_` 开头的 Python 文件是开发辅助脚本（`_build_shell.py` 接入设计系统、
`_build_release.py` 打包发布版），不影响页面运行，发布版本中已剔除。

各章 `interactive/` 下的 `_build_pages.py` 是早期的页面生成脚本，**已废弃**——
页面内容此后经过大量人工修订，重新运行会覆盖这些修订。请直接编辑 HTML。

## 常见问题

**打开后样式丢失 / 排版错乱**
请保持目录结构完整，`assets/` 文件夹必须与 `index.html` 同级。单独拷贝某个 HTML 文件出来是不行的。

**深色模式下画布看不清**
演示画布在两种主题下都保持浅色底、高对比配色，这是有意为之，以保证投影效果。

**能打印或导出 PDF 吗**
可以。浏览器打印时会自动隐藏导航、工具条与动画背景，只保留教学内容。

**在手机上能看吗**
可以，布局会自适应。但 Canvas 演示在大屏上体验更好，建议课堂使用笔记本或投影。
