本章学习目标

  1. 能够选择合适的图存储结构：说明邻接矩阵 O(n2) 与邻接表 O(n+e) 的空间差异，并根据稠密图/稀疏图给出选型理由。

  3. 能够辨析三种单源最短路算法的适用边界：Dijkstra 要求非负权、Bellman-Ford/SPFA 可处理负权并检测负环、Floyd 求全源最短路。
  4. 能够构造一个使 Dijkstra 出错的负权反例，并解释"已定型顶点不再更新"这一贪心前提为何失效。
  5. 能够复述最大流最小割定理，写出割的容量定义与增广路定义，并说明 Ford-Fulkerson → Edmonds-Karp → Dinic 的改进动机。
  6. 能够建模二分图最大匹配为最大流问题，并说明匈牙利算法中"增广路取反"为何能使匹配数恰好加一。
  7. 能够默写本章各算法在不同实现下的时间与空间复杂度，并据此为给定规模的图选择算法。

一、前置知识：图的存储方式

Graph Representation · 全章公共基础

本章所有算法的复杂度都写成 n（顶点数 |V|）与 e（边数 |E|）的函数，而同一个算法在不同存储结构下复杂度不同。因此在进入 Prim 之前，必须先把图怎么"装进内存"讲清楚。

定义

设图 G = (V, E)，记 n = |V|、e = |E|。邻接矩阵（adjacency matrix）用一个 n×n 的二维数组 A 表示图：A[i][j] 存边 (i, j) 的权值，无边时存 ∞（无权图存 0/1）。邻接表（adjacency list）为每个顶点 i 挂一条链，链上依次存放 i 的所有出边的终点与权值。

操作 / 指标邻接矩阵邻接表说明
空间Θ(n2)Θ(n + e)与实际边数无关 vs 与边数成正比
判断边 (u,v) 是否存在O(1)O(deg(u))矩阵可随机访问
遍历 u 的全部邻接点O(n)O(deg(u))矩阵必须扫完整行
遍历全图所有边O(n2)O(n + e)BFS/DFS 的代价差别即源于此
增删一条边O(1)O(1) 头插 / O(deg) 删除—
适用图型稠密图 e ≈ Θ(n2)稀疏图 e = O(n)见下方判据
稠密（dense）：e 接近 n(n−1)/2  →  邻接矩阵   |   稀疏（sparse）：e = O(n) 或 e ≪ n2  →  邻接表
// ===== 存储方式一：邻接矩阵（适合稠密图，n 不大，如 n <= 1000） ===== const int N = 1005, INF = 0x3f3f3f3f; int A[N][N]; // A[i][j] = 权值，无边为 INF，A[i][i] = 0 void initMatrix(int n) { for (int i = 0; i < n; i++) for (int j = 0; j < n; j++) A[i][j] = (i == j ? 0 : INF); } // 无向图加边：对称赋值；有向图只赋一次 void addEdgeM(int u, int v, int w) { A[u][v] = w; A[v][u] = w; } // ===== 存储方式二：邻接表 · vector 版（适合稀疏图，最常用） ===== struct Edge { int to, w; }; vector<Edge> g[N]; // g[u] 存 u 的所有出边 void addEdgeL(int u, int v, int w) { g[u].push_back({v, w}); g[v].push_back({u, w}); // 有向图删去此行 } // 遍历 u 的邻边：只花 O(deg(u))，而不是 O(n) // for (auto [v, w] : g[u]) { ... } // ===== 存储方式三：链式前向星（数组模拟邻接表，网络流必备） ===== // 成对存边：第 i 条边的反向边下标恰为 i^1，这是残留网络的关键技巧 int head[N], nxt[2*N], to[2*N], wt[2*N], cnt = 0; void initStar(int n) { memset(head, -1, sizeof(head)); cnt = 0; } void addEdgeS(int u, int v, int w) { to[cnt] = v; wt[cnt] = w; nxt[cnt] = head[u]; head[u] = cnt++; } // for (int i = head[u]; i != -1; i = nxt[i]) { int v = to[i], w = wt[i]; ... }
选型判据：若 e < n2/32 左右，邻接表在空间上明显占优；若图接近完全图，或算法本身就要 O(n2)（如 Floyd、朴素 Prim、朴素 Dijkstra），则直接用矩阵反而更简洁更快（无指针跳转，缓存友好）。Floyd 只能用邻接矩阵，因为它的状态就是矩阵本身。
易错点
  • 邻接矩阵初始化时把无边写成 0：最短路中 0 会被误认为"距离为 0 的边"。应写 INF，且 A[i][i] = 0。
  • 用 INF = INT_MAX 做初值：松弛时 dist[u] + w 会整型溢出变成负数。惯例取 0x3f3f3f3f（约 109），两个相加仍不溢出，且可用 memset 按字节 0x3f 填充。
  • 无向图开边数组只开 e 个：无向图每条边要存两份，链式前向星须开 2e。
  • 把复杂度里的 e 当成常数：稠密图中 e 可达 n2，O(e log n) 未必优于 O(n2)。

二、知识地图

Knowledge Map · 三条主线
1
最小生成树（MST）· 第 1∼2 节：Prim 从点扩张、Kruskal 从边挑选。二者共用同一条正确性依据——割性质。选型看疏密：稠密图用朴素 Prim O(n2)，稀疏图用 Kruskal O(e log e) 或堆优化 Prim O((n+e) log n)。
2
最短路 · 第 3∼5 节：Dijkstra（单源、非负权、贪心）→ Bellman-Ford / SPFA（单源、可负权、可判负环）→ Floyd（全源、动态规划、O(n3)）。三者的分界线是边权能否为负与要不要全源。
3
网络流 · 第 6∼10 节：先立概念（容量、流、残留网络、割、增广路），再看方法的三级演进——Ford-Fulkerson（伪多项式 O(e·|f*|)）→ Edmonds-Karp（BFS 选最短增广路，O(n e2)，与容量数值无关）→ Dinic（分层图 + 多路增广，O(n2e)）。最后用最大流解二分图匹配，与匈牙利算法互为镜像。

本章导读小结
  • 本章三条主线：最小生成树、最短路、网络流；分别对应贪心、动态规划/贪心、增广思想。
  • 复杂度一律用 n = |V| 与 e = |E| 表述；同一算法在邻接矩阵与邻接表下复杂度不同，作答时必须说明所用存储结构。
  • 邻接矩阵 Θ(n2) 空间、O(1) 查边，适合稠密图；邻接表 Θ(n+e) 空间、O(deg) 遍历，适合稀疏图。
  • INF 取 0x3f3f3f3f 而非 INT_MAX，避免松弛时溢出——这是本章代码题最常见的隐性失分点。
