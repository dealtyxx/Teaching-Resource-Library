Dijkstra · 非负权单源最短路

每次确定 dist 最小的未定点，再松弛出边。结点上的数字是当前 dist。

学习目标

  1. 能够手工模拟 Dijkstra：逐轮写出被选定的顶点、dist 数组的变化，并给出最终最短距离与路径。
  2. 能够论证 Dijkstra 的正确性，并明确指出论证在哪一步用到了"边权非负"这个前提。
  3. 能够构造一个使 Dijkstra 给出错误答案的负权反例，并说明为什么"随手加一条负边"往往构造不出反例。
  4. 能够默写朴素与堆优化两版代码，并分别推导 O(n2)、O((n+e) log n)、O(n log n + e) 三种复杂度。
  5. 能够选择：给定图的疏密与是否含负权，判断该用 Dijkstra 还是 Bellman-Ford。

一、定义与算法框架

Single-Source Shortest Path
定义

给定带权有向（或无向）图 G = (V, E, W) 与源点 s，单源最短路径问题（single-source shortest path, SSSP）要求对每个顶点 v 求出 s 到 v 的最短路径长度 dist[v]（不可达时为 ∞）。松弛（relaxation）操作指：若 dist[u] + w(u,v) < dist[v]，则令 dist[v] = dist[u] + w(u,v)。

Dijkstra 算法

把顶点分为两类：已定型集合 S（dist 值已确定为最终最短距离）与未定型集合 V−S。初始 dist[s] = 0、其余为 ∞，S = ∅。重复 n 次：从 V−S 中取出 dist 值最小的顶点 u 加入 S（此刻宣布 dist[u] 已确定），然后用 u 松弛它的所有出边。前提：所有边权 w ≥ 0。

正确性定理

若图中所有边权非负，则每当 Dijkstra 把顶点 u（当前 V−S 中 dist 最小者）加入 S 时，dist[u] 已等于 s 到 u 的真实最短距离。

反证 设 u 是第一个被错误定型的顶点，即 dist[u] > δ(s, u)（δ 表真实最短距离） "第一个"保证 S 中已有顶点全部正确 第一步 取一条 s→u 的真实最短路径 P，沿 P 走，令 y 是 P 上第一个不在 S 中的顶点，x 为 P 上 y 的前驱（x ∈ S） u ∉ S 且 u 在 P 上，故这样的 y 必存在 第二步 x 已正确定型，dist[x] = δ(s, x)；x 入 S 时松弛过边 (x, y)，故 dist[y] = δ(s, y) 最短路径的前缀也是最短路径（最优子结构） 第三步 y 在 P 上位于 u 之前（或等于 u），且 P 上 y→u 段的长度 ≥ 0 ★ 此处唯一用到"边权非负" 第四步 于是 δ(s, y) ≤ δ(s, u)，即 dist[y] ≤ δ(s, u) < dist[u] 最后一个不等号来自反证假设 第五步 但算法此刻选的是 V−S 中 dist 最小者 u，应有 dist[u] ≤ dist[y]，矛盾 故不存在被错误定型的顶点 结论 非负权下 Dijkstra 正确；第三步一旦允许负权即崩塌 y→u 段若含负边，其长度可小于 0，δ(s,y) 就可能大于 δ(s,u)

二、为什么不能有负权：一个完整反例

Counterexample · 本节最重要的内容
核心结论：Dijkstra 的贪心前提是"已加入 S 的顶点，其 dist 不会再变小"。这一前提成立，是因为任何后续路径都只会在已有距离上再加非负值。一旦出现负权边，"绕远路反而更短"成为可能，被过早定型的顶点再也没有机会被更新，错误就此固化并沿着最短路径树向下传播。

反例图（有向图，4 个顶点）

边s → as → bb → aa → t
权 w25−41
初始 dist = [s:0, a:∞, b:∞, t:∞]，S = ∅ 源点 s 第 1 轮 选 s（dist=0）入 S。松弛 s→a 得 dist[a]=2；松弛 s→b 得 dist[b]=5 dist = [0, 2, 5, ∞] 第 2 轮 V−S 中最小者是 a（dist=2），定型 dist[a] = 2。松弛 a→t 得 dist[t] = 3 dist = [0, 2, 5, 3] 第 3 轮 最小者是 t（dist=3），定型 dist[t] = 3。t 无出边 错误已经扩散到 t 第 4 轮 选 b（dist=5）入 S。松弛 b→a：5 + (−4) = 1 < 2 ★ 但 a 已在 S 中，被跳过，dist[a] 保持 2 算法输出 dist[a] = 2，dist[t] = 3 算法终止 真实答案 s→b→a = 5 − 4 = 1；s→b→a→t = 1 + 1 = 2 Dijkstra 在 a 与 t 上同时出错
Dijkstra 输出 dist[a] = 2、dist[t] = 3   ≠   真实 δ(s,a) = 1、δ(s,t) = 2
错在哪一步：对照第一节的正确性证明，第 2 轮定型 a 时，真实最短路径 P = s→b→a 上第一个不在 S 中的顶点是 y = b，此时 dist[b] = 5。证明的第四步要求 δ(s, b) ≤ δ(s, a)，即 5 ≤ 1——不成立。原因正是 P 上从 b 到 a 那一段的长度是 −4 < 0，违反了第三步"该段长度 ≥ 0"的假设。

为什么反例必须这样构造

很多同学会随手画一个含负边的图，却发现 Dijkstra 居然算对了。例如这个常见的"伪反例"：s→a 权 1，s→b 权 4，a→b 权 −3。

第 1 轮 选 s，松弛得 dist[a] = 1、dist[b] = 4 dist = [0, 1, 4] 第 2 轮 选 a（dist=1）定型，松弛 a→b：1 + (−3) = −2 < 4 b 尚未定型，更新成功，dist[b] = −2 第 3 轮 选 b（dist=−2）定型 输出 dist[b] = −2 真实答案 s→a→b = 1 − 3 = −2 ✓ Dijkstra 竟然算对了
关键：负边本身并不足以致错，负边必须指向一个已被定型的顶点才会出错。在"伪反例"中，负边 a→b 的终点 b 在松弛时还是未定型的，所以更新照常生效。要造出真正的反例，必须让负边的终点先被定型——因此负边的终点应当是一个 dist 很小、会被早早选中的顶点，而负边的起点应当 dist 较大、很晚才被选中。上面 4 顶点反例中，a 的初始 dist 是 2（早选），b 是 5（晚选），负边正是 b→a，这才成功。
补充：不要试图用"全体加常数"来消除负权。把每条边的权都加上一个大常数 C 会破坏最短路——因为不同路径边数不同，边多的路径被多加了 C，原本最短的多边路径可能变得不再最短。含负权时正确做法是改用 Bellman-Ford / SPFA（下一节），或在无负环时用 Johnson 重赋权（用势函数 h(v) 令 w′(u,v) = w(u,v) + h(u) − h(v) ≥ 0，这样加的量沿路径可伸缩抵消）。

三、规范 C++ 代码

两种实现
// ========== 实现一：邻接矩阵朴素 Dijkstra —— O(n^2)，适合稠密图 ========== const int N = 1005, INF = 0x3f3f3f3f; int A[N][N]; // 邻接矩阵，无边为 INF int dist_[N], pre[N]; // dist_：最短距离；pre：前驱，用于还原路径 bool vis[N]; // 是否已定型（是否已加入集合 S） void dijkstra(int n, int s) { for (int i = 0; i < n; i++) { dist_[i] = INF; vis[i] = false; pre[i] = -1; } dist_[s] = 0; for (int cnt = 0; cnt < n; cnt++) { int u = -1, mn = INF; for (int i = 0; i < n; i++) // ① 选未定型中 dist 最小者：O(n) if (!vis[i] && dist_[i] < mn) { mn = dist_[i]; u = i; } if (u == -1) break; // 剩余顶点均不可达 vis[u] = true; // ② 定型：dist_[u] 从此不再改变 for (int v = 0; v < n; v++) // ③ 用 u 松弛所有出边：O(n) if (!vis[v] && A[u][v] != INF && dist_[u] + A[u][v] < dist_[v]) { dist_[v] = dist_[u] + A[u][v]; pre[v] = u; } } } // 还原 s 到 v 的路径（递归输出） void printPath(int v) { if (pre[v] != -1) { printPath(pre[v]); printf("->"); } printf("%d", v); } // ========== 实现二：邻接表 + 优先队列 —— O((n+e) log n)，适合稀疏图 ========== typedef pair<int, int> pii; // (当前距离, 顶点) vector<pii> g[N]; // g[u] = {(v, w), ...} int dis[N]; void dijkstraHeap(int n, int s) { memset(dis, 0x3f, sizeof(int) * n); // 0x3f3f3f3f，相加不溢出 priority_queue<pii, vector<pii>, greater<pii>> pq; // 小根堆 dis[s] = 0; pq.push({0, s}); while (!pq.empty()) { auto [d, u] = pq.top(); pq.pop(); if (d > dis[u]) continue; // 惰性删除：过期元素直接丢弃 for (auto [v, w] : g[u]) if (dis[u] + w < dis[v]) { // 松弛成功才入堆 dis[v] = dis[u] + w; pq.push({dis[v], v}); } } }
惰性删除（lazy deletion）：C++ 的 priority_queue 不支持 decrease-key，所以每次松弛成功就压入一个新元素，旧元素留在堆里。取出时用 if (d > dis[u]) continue; 判掉过期项。堆内元素上界 O(e)，因此仍是 O((n+e) log n)。漏掉这一句会让每个顶点被重复扩展，复杂度上升且在稠密图上明显变慢。

初始 dist = [0, ∞, ∞, ∞, ∞, ∞]，S = ∅ 源点 0 第 1 轮 选 0（0）。松弛 0→1 得 6；0→5 得 5 dist = [0, 6, ∞, ∞, ∞, 5] 第 2 轮 选 5（5）。松弛 5→1：5+3=8 > 6 不更新；5→2：5+4=9 ✓；5→4：5+2=7 ✓ dist = [0, 6, 9, ∞, 7, 5] 第 3 轮 选 1（6）。松弛 1→2：6+5=11 > 9 不更新 dist 不变 第 4 轮 选 4（7）。松弛 4→2：7+3=10 > 9 不更新；4→3：7+5=12 ✓ dist = [0, 6, 9, 12, 7, 5] 第 5 轮 选 2（9）。松弛 2→3：9+4=13 > 12 不更新 dist 不变 第 6 轮 选 3（12）。全部定型，结束 定型顺序：0, 5, 1, 4, 2, 3，dist 值严格非降
dist = [0, 6, 9, 12, 7, 5]；例如 0→3 的最短路径为 0 → 5 → 4 → 3，长度 5 + 2 + 5 = 12
一条重要观察：顶点被定型的 dist 值序列 0, 5, 6, 7, 9, 12 是单调非降的。这正是非负权的直接推论，也是"已定型顶点不会再变小"的直观表现。如果你手算时发现某轮定型的 dist 比上一轮小，那要么算错了，要么图里有负权边。
易错点
  • 对含负权边的图使用 Dijkstra。这是本节头号错误：程序不会报错、不会死循环，只会静悄悄给出错误答案。判断标准只看边权，与图是否有环、是否有向都无关。
  • 误以为"没有负环就能用 Dijkstra"：负环只是 Bellman-Ford 的判定对象；只要有一条负边，Dijkstra 就可能出错，哪怕图是无环的 DAG。
  • 试图给所有边权统一加常数 C 来消除负权：不同路径边数不同，加的总量不同，会改变最短路的相对大小。
  • 堆优化中漏写 if (d > dis[u]) continue;，或误写成 if (vis[u]) continue; 却忘了给 vis 赋值。
  • INF 用 INT_MAX：dist[u] + w 溢出成负数，会把不可达点当成"距离极短"而错误定型。用 0x3f3f3f3f。
  • 把 Dijkstra 的松弛式写成 Prim 的 w < dis[v]：那求的是最小生成树而不是最短路（见第 1 节）。
  • 只求一个终点就以为可以少算：Dijkstra 必须按 dist 升序定型，可以在目标点被定型时提前 break，但不能跳过中间顶点。
本节小结
  • Dijkstra 求非负权图的单源最短路：每轮取未定型顶点中 dist 最小者定型，再用它松弛出边，共 n 轮。
  • 正确性证明的关键一步是"最短路径上 y 到 u 的一段长度 ≥ 0"，这正是非负权前提的落点；负权使该步失效。
  • 负权反例（s→a=2、s→b=5、b→a=−4、a→t=1）：Dijkstra 输出 dist[a]=2、dist[t]=3，真值为 1 和 2。致错要害是负边指向已定型顶点；若负边终点尚未定型（如 s→a=1、s→b=4、a→b=−3），Dijkstra 反而恰好算对，故反例必须精心构造。
  • 复杂度：数组 Θ(n2)（稠密图）、二叉堆 O((n+e) log n)（稀疏图）、斐波那契堆 O(n log n + e)（理论最优）。
  • 顶点定型的 dist 值单调非降，可作为手算自检的判据。含负权时改用 Bellman-Ford / SPFA。

解析：B 正确。Dijkstra 第 2 轮选中 a（dist=2）并定型，随即松弛 a→t 得 dist[t]=3 并在第 3 轮定型；直到第 4 轮才轮到 b，此时松弛 b→a 得 5−4=1 < 2，但 a 已定型被跳过，错误无法回滚。真实路径 s→b→a→t = 5−4+1 = 2。A 的迷惑性最强——"无负环"是 Bellman-Ford 的适用条件，不是 Dijkstra 的；Dijkstra 要求的是每条边非负，本图虽无环但含负边，照样出错。C 把两个数字弄反了。D 错：Dijkstra 主循环固定执行 n 次，不含负环也不会死循环，它的失败方式是安静地给出错误结果，这比崩溃更危险。

CBellman-Ford，O(ne) = 6×1010，通用性最好

解析：A 正确。稠密图中 e ≈ n2/2，堆优化的 (n+e) log n ≈ 1.2×107×12.3 ≈ 1.5×108，反而大于 n2 = 2.5×107，且堆操作常数远大于数组扫描。B 的算式正确但结论错——"堆优化一定更快"只在稀疏图成立。C 虽然能算出正确答案，但边权非负时用 O(ne) 换通用性完全没必要，且 6×1010 已超时。D 更离谱：n3 = 1.25×1011，且题目只要单源，求全源是巨大浪费。
3下列关于 Dijkstra 的说法中，正确的是？
A把所有边权同时加上一个足够大的正数 C，即可用 Dijkstra 处理负权图
B顶点被定型的先后顺序，就是它们按到源点距离由近到远的顺序，因此中途可以随意跳过不感兴趣的顶点
C顶点被定型时的 dist 值序列单调非降；若只需求 s 到某个特定点 t 的距离，可在 t 被定型的那一刻立即终止
D无向图中若存在一条负权边，只要它不构成负环，Dijkstra 仍可正确求解
解析：C 正确：非负权保证定型值单调非降，t 定型时其 dist 已是最终值，后续轮次只会处理更远的顶点，故可安全 break（这也是 A* 等启发式搜索的基础）。A 错，这是最经典的错误直觉：不同路径边数不同，一条 3 条边的路径会被加 3C，一条 1 条边的路径只加 C，路径间的大小关系被扭曲；正确的重赋权方法是 Johnson 算法的势函数 w′(u,v)=w(u,v)+h(u)−h(v)，它沿路径求和时中间项相消，才不改变最短路。B 前半句对、后半句错——"跳过"中间顶点意味着不用它松弛出边，而 t 的最短路可能正好经过被跳过的顶点，结果会偏大。D 错，无向图中一条负边 (u,v) 本身就等价于 u→v 与 v→u 两条负边，来回走一趟即构成权为 2w < 0 的负环，最短路根本不存在，Dijkstra 与 Bellman-Ford 都无法给出有意义的答案。
