一、流网络与流的定义

Flow Network
流网络

一个流网络是有向图 G = (V, E)，每条边 (u, v) 有非负容量 c(u, v) ≥ 0（无边则 c = 0），并指定一个源点 s 与一个汇点 t。目标是从 s 尽可能多地把"流"送到 t。

流（flow）

一个流 f 给每条边赋一个实数 f(u, v)，需同时满足两条约束：
① 容量约束：对每条边 0 ≤ f(u, v) ≤ c(u, v)——流量不超过容量、不为负；
② 流量守恒：对每个中间点 v ≠ s, t，流入量 = 流出量，即 ∑u f(u, v) = ∑w f(v, w)。
流的值 |f| 定义为源点净流出量 |f| = ∑v f(s, v) − ∑v f(v, s)，它也等于汇点的净流入量。

容量约束 0 ≤ f(u,v) ≤ c(u,v)   ·   守恒 ∑ 入 = ∑ 出 (v≠s,t)   ·   |f| = 源点净流出
直观：把边想成水管、容量是管径、流量是实际水流。除了水源 s 和水槽 t，任何接头处流进多少必须流出多少（不能凭空积水或造水）。整个系统能送到 t 的总水量就是 |f|，我们要让它最大。

二、残量网络与增广路

Residual Network
残量网络

给定当前流 f，残量网络 Gf 描述"还能怎么调整"。每条原边 (u, v) 产生两份残量：
① 正向残量 cf(u, v) = c(u, v) − f(u, v)——顺着还能再推多少；
② 反向残量 cf(v, u) = f(u, v)——逆着可以撤回多少已推的流。
只保留 cf > 0 的边构成 Gf。Gf 中一条 s→t 的路径称为增广路，沿它可把流增加"路径上最小残量"那么多。

反向边为什么重要：反向残量给了算法"反悔"的能力。某条边上先前推了 5 单位流，反向残量就是 5——后续如果发现这 5 单位走别的路更划算，可以通过走反向边把它"抽回来"重新分配。没有反向边，贪心一旦走错就无法纠正，最大流可能求不对（详见下一节 Ford-Fulkerson）。
// 残量网络的标准存法：成对存边，i 与 i^1 互为正反向 struct Edge { int to, cap; }; // cap = 当前残量 c_f vector<Edge> e; // 所有边（含反向边） vector<int> g[N]; // g[u]：从 u 出发各边在 e 中的下标 void addEdge(int u, int v, int c) { g[u].push_back(e.size()); e.push_back({v, c}); // 正向：残量 = c g[v].push_back(e.size()); e.push_back({u, 0}); // 反向：残量 = 0 } // 沿边 i 推流 d：正向减、反向加。e[i^1] 即 e[i] 的反向边（异或取偶/奇） void push(int i, int d) { e[i].cap -= d; e[i ^ 1].cap += d; }

三、割与最大流最小割定理

Max-Flow Min-Cut
s-t 割

一个 s-t 割 (S, T) 把顶点集划成两部分，使 s ∈ S、t ∈ T（且 S ∪ T = V，S ∩ T = ∅）。割的容量 c(S, T) = ∑ 所有从 S 指向 T 的边 (u, v) 的 c(u, v)。注意：只累加 S→T 的正向边，T→S 的反向边不计入。

跨割净流 对任意流 f 与任意割 (S,T)，穿过割的净流 f(S,T) = (S→T 的流) − (T→S 的流) 守恒使中间点抵消 等于流值 由流量守恒可证 |f| = f(S,T) 对每个割都成立 从 s 出发的净流必等量穿过任一把 s、t 分开的割 弱对偶 f(S,T) ≤ (S→T 的流) ≤ (S→T 的容量) = c(S,T) 流不超容量，且减去非负的反向流 于是 |f| ≤ c(S,T)：任一流值 ≤ 任一割容量 最大流 ≤ 最小割
最大流最小割定理

在任意流网络中，最大流的值 = 最小割的容量。等价地，以下三个命题相互等价：
① f 是最大流；
② 残量网络 Gf 中不存在增广路（s 到不了 t）；
③ 存在某个割 (S, T) 使 |f| = c(S, T)。
其中 S = "在 Gf 中从 s 可达的点集"，这个 (S, T) 就是一个最小割。

为什么定理成立（要点）：①⇒② 若还有增广路就能增大流，矛盾；②⇒③ 取 S 为残量图中 s 可达点集，则所有 S→T 的原边都已满载（否则残量 > 0，T 中点应可达），故 |f| = c(S, T)；③⇒① 由弱对偶 |f| ≤ 任一割 ≤，已取等号故 f 必为最大流。这条链既是定理证明，也是所有增广路算法"无增广路即停止"的正确性依据。
易错点
  • 把守恒用到 s、t 上：流量守恒只对中间点成立；源点净流出、汇点净流入正是流值 |f|，本就不守恒。
  • 计算割容量时把 T→S 的反向边也加进去：割容量只累加 S→T 的正向边容量，反向边一律不计。
  • 忘记建反向边：没有反向残量，算法无法"反悔"，可能收敛到非最大流的错误值。
  • 误以为"最小割 = 边数最少的割"：最小割指容量之和最小，与边的条数无关。
  • 把"无增广路"理解成"图中已无 s-t 路径"：应是残量网络 Gf 中无 s-t 路径，原图里可能还有路径但都已满载。
  • 处理反平行边（同时有 u→v 和 v→u）时直接混用：需拆点或用成对存边，避免正反向残量互相污染。
本节小结
  • 流需同时满足容量约束 0≤f≤c 与中间点流量守恒；流值 |f| = 源点净流出 = 汇点净流入。
  • 残量网络 Gf：正向残量 c−f、反向残量 = f；Gf 中的 s→t 路径即增广路，反向边提供"反悔"能力。
  • s-t 割 容量只计 S→T 正向边；对任意流与任意割有弱对偶 |f| ≤ c(S, T)。
  • 最大流最小割定理：最大流值 = 最小割容量；"f 最大 ⇔ 无增广路 ⇔ |f| 等于某割容量"三者等价。
  • 该定理是一切增广路算法（FF / EK / Dinic）"无增广路即停止"的正确性基石，也是把匹配等问题转化为最大流的桥梁。
1在残量网络中，一条已推了流量 f = 3、容量 c = 5 的边 (u, v)，其正向与反向残量分别是多少？
A正向 cf(u,v) = 5−3 = 2，反向 cf(v,u) = 3
B正向 = 5，反向 = 0
C正向 = 3，反向 = 5
D正向 = 2，反向 = 0（残量网络没有反向边）
解析：A 正确。正向残量 = 还能再推的量 = c−f = 5−3 = 2；反向残量 = 已推、可撤回的量 = f = 3。D 的错误在于否认反向边——反向边正是残量网络的核心，它让算法能撤销之前的推流。C 把两者的公式弄反了。
2关于最大流最小割定理，下列说法正确的是？
A最大流的值总是严格小于最小割的容量
B最小割指割开的边数最少的那个割
C最大流值 = 最小割容量；当残量网络中不存在增广路时，当前流即为最大流
D只要原图中还存在一条 s 到 t 的路径，就一定还能继续增广
解析：C 正确，这是定理与三个等价命题的直接表述。A 错：是"相等"不是"严格小于"，弱对偶给出 ≤，定理进一步给出取等。B 错：最小割比的是容量之和最小，不是边的条数。D 错：判据是残量网络 Gf 中无 s-t 路径；原图里可能还有 s→t 的路径，但如果这些路径上的边都已满载（残量为 0），就不再是增广路，无法继续增广。
3割 (S, T) 的容量 c(S, T) 应如何计算？
A所有跨越割的边容量之和，S→T 与 T→S 都算
B只累加从 S 指向 T 的边的容量，T→S 的边不计
C跨割边的容量之和，再减去 T→S 边的容量
DS 中所有点的出边容量之和
解析：B 正确。割容量的定义只统计方向为 S→T 的正向边容量，T→S 的反向边不计入（它们在跨割净流里出现，但不在割容量里）。A、C 把反向边也算进容量，会算大。D 错：应只数跨越割的边，S 内部边不算。正是"割容量只计正向边"这一点，配合弱对偶推出 |f| ≤ c(S, T)。
