学习目标

  1. 能够定义八数码问题的状态、目标态与合法移动（空格与相邻块交换），说明分支因子 ≤ 4。
  2. 能够写出 A* 的评价函数 f=g+h，指出 g=已走步数、h=各非空块曼哈顿距离之和。
  3. 能够论证曼哈顿启发的可采纳性，并解释为何要排除空格、它为何优于"错位块数"。
  4. 能够用逆序数奇偶性判断八数码的可解性，说明为何"合法移动打乱"必然可解。
  5. 能够估计状态空间规模（9! 全体、9!/2 可达）与 A* 最坏的指数级时间/空间。

一、问题与状态空间

滑块 · 合法移动 · 目标态
定义 1 · 八数码问题

3×3 棋盘上放 1∼8 共 8 个数字块与 1 个空格。每步可把与空格相邻（上/下/左/右）的一个块滑入空格——等价于空格与该相邻块交换。目标是用最少步数把任意初始布局复原成目标态 1 2 3 / 4 5 6 / 7 8 □。空格在角上有 2 个移动方向、在边上 3 个、在中心 4 个，故分支因子 ≤ 4。

性质 · 状态空间规模

9 个格子的全排列共 9! = 362880 种布局，但它们分成两个互不连通的集合（合法移动无法跨越），因此从目标态可达的状态只有 9!/2 = 181440 个。求最短复原序列，就是在这张状态图上求从初态到目标态的最短路径。

二、A* 求最短复原序列

f = g + h · 曼哈顿启发
定义 2 · 启发函数（曼哈顿距离之和）

把每个非空块 v 从当前位置移到它在目标态中的位置，至少需要 |Δ行|+|Δ列| 步（曼哈顿距离）。令 h(s) = Σv≠空格 块 v 的曼哈顿距离。它可采纳：每走一步只能让某一个块的曼哈顿距离改变 ±1，所以把总距离降到 0 至少需要 h(s) 步，即 h(s) ≤ 真实最短步数，从不高估。

f(s) = g(s) + h(s) g = 从初态已走步数 h = Σ 非空块的曼哈顿距离
空格必须排除：计算 h 时只对 1∼8 求曼哈顿距离，不算空格。若把空格也计入，会重复计量、可能高估真实步数，破坏可采纳性从而丢失最优。演示代码里的 if(!s[i]) continue; 正是在跳过空格。
// ── 八数码 · A* 求最短复原（曼哈顿启发）─────────── int h(const State& s) { // 曼哈顿距离之和（不含空格） int d = 0; for (int i = 0; i < 9; i++) { int v = s[i]; if (v == 0) continue; // 跳过空格 int gi = v - 1; // 块 v 的目标下标 d += abs(i/3 - gi/3) + abs(i%3 - gi%3); } return d; } int astar(State start) { priority_queue<Node> open; // 活结点表：按 f=g+h 的小根堆 open.push({start, 0, h(start)}); seen[start] = 0; // 状态 → 已知最小 g（去重） while (!open.empty()) { Node u = open.top(); open.pop(); // 取 f 最小者作扩展结点（LC） if (u.state == goal) return u.g; // 目标出队 ⇒ 最优步数 for (State v : neigh(u.state)) { // 分支：空格与四邻交换 int ng = u.g + 1; if (seen.count(v) && seen[v] <= ng) continue; // 已有不劣路径则剪 seen[v] = ng; open.push({v, ng, ng + h(v)}); } } return -1; // 不可解 }
A* 就是本章的 LC 分支限界：open 表 = 优先队列（活结点表），每轮取 f 最小者作扩展结点，f=g+h 充当限界值；曼哈顿可采纳 ⇒ 目标首次出队即最短序列。seen 表做状态去重，避免同一布局被反复扩展导致爆炸。

三、可解性与复杂度

逆序数奇偶性 · 指数级
把布局按行优先展开成序列（去掉空格），统计逆序数：前面比后面大的数对个数 如 2 1 3 有 1 个逆序对 每次合法移动（3×3 奇数宽）都保持逆序数的奇偶性不变 左右滑不改序列；上下滑跨越 2 个数，逆序数变化为偶数 目标态 1..8 逆序数为 0（偶）⇒ 可解 ⇔ 初态逆序数为偶 奇偶性是移动不变量 恰好一半（9!/2=181440）布局逆序数为偶、可解，另一半不可解 奇偶两类各占一半 本页"打乱"从目标态出发做若干次合法移动 ⇒ 停在同一奇偶类，必然可解 这是随机合法走子的必然结果
为什么不能"随机填 1∼8,0"来打乱？随机排布有一半概率落到不可解的那一类，A* 会白搜整个可达分量后返回失败。用合法移动打乱可保证始终停在可解类内——这正是演示 shuffle 采用连续随机走子而非随机填充的原因。
A* 最坏需扩展指数级结点，优先队列同时存指数级活结点 状态空间虽有限但组合巨大 曼哈顿启发把实际扩展规模压到远小于 181440，通常瞬间求解 h 越紧，扩展越少 更难的 15 数码（4×4）状态达 16!/2，常改用 IDA* 以 O(深度) 空间迭代加深 规避 A* 的指数级内存
易错点
  • 算 h 时把空格也计入曼哈顿距离。必须只对 1∼8 求和；计入空格会高估、破坏可采纳性，可能返回非最优序列。
  • 用"错位块数"当唯一选择。错位块数也可采纳但更松；曼哈顿距离之和占优（总不小于错位数），扩展结点更少，是更好的启发。
  • 随机填数字来"打乱"。随机排列有一半不可解；应像演示那样从目标态连续合法移动打乱，保证落在可解类。
  • 用错误的可解性判据。3×3（奇数宽）的判据是逆序数为偶即可解；把偶数宽（如 15 数码要考虑空格所在行）的规则套用到 8 数码是常见错误。
  • 省掉状态去重（seen/closed）。八数码状态会大量重复，不去重会让同一布局被反复入队，时间与内存迅速爆炸。
  • 以为 A* 内存无忧。A* 活结点表最坏指数级；对更大的 15 数码常需 IDA* 等以时间换空间的变体。
本节小结
  • 八数码：状态=3×3 布局，移动=空格与相邻块交换（分支因子 ≤ 4），求到目标态的最短滑动序列。
  • A*：f=g+h，g=已走步数，h=各非空块曼哈顿距离之和（须排除空格）；曼哈顿可采纳 ⇒ 目标首次出队即最优。
  • 曼哈顿占优于错位块数（更紧、扩展更少）；A* 即本章 LC 分支限界，需 seen 表去重。
  • 可解性由逆序数奇偶性决定：3×3 逆序数为偶即可解；合法移动保持奇偶性，故合法走子打乱必可解。
  • 状态空间 9!=362880（可达 9!/2=181440）；A* 最坏指数级空间，更大规模用 IDA*。
1八数码 A* 的启发函数 h 取"曼哈顿距离之和"。下列关于它的说法正确的是？
A应对 9 个格子（含空格）都求曼哈顿距离并求和
B只对 1~8 这 8 个块求和、排除空格，这样才可采纳（不高估）
C它一定高估真实步数，所以 A* 用它得不到最优解
D它与"错位块数"完全等价，随便用哪个都一样
解析：选 B。曼哈顿启发只统计 1∼8 各块到目标位的曼哈顿距离，排除空格；因为每走一步只改变某一块的曼哈顿距离 ±1，故 h ≤ 真实步数，可采纳、不高估，A* 得最优（C 错）。A 把空格计入会高估、破坏可采纳性。D 错在两者不等价：曼哈顿占优于错位块数（总不小于它），是更紧、更高效的启发。
2本页"打乱"按钮从目标态出发做若干次随机合法移动。为什么不直接把 1~8 和空格随机排布？
A随机排布计算太慢
B随机排布有一半概率不可解；合法移动保持逆序数奇偶性，保证始终可解
C随机排布会破坏棋盘的 3×3 结构
D两种方式没有区别，只是习惯写法
解析：选 B。八数码只有逆序数为偶的一半布局（9!/2 个）可复原到目标态。合法移动是逆序数奇偶性的不变量，从可解的目标态出发连续走子，永远停在可解类内；而随机排布有约 50% 概率落到不可解类，A* 会搜完整个可达分量后返回失败。A、C、D 都没抓住"可解性/奇偶性"这一要害。
3把八数码 A* 归入第 6 章分支限界法框架，下列对应错误的是？
Aopen 优先队列 = 活结点表，按 f=g+h 排序
B每轮取出的 f 最小结点 = 扩展结点，属最佳优先（LC）
Cf=g+h 充当限界值，可采纳启发下目标首次出队即最优
D由于状态空间有限，A* 的时间与空间都是多项式级
解析：选 D（错误项）。虽然八数码状态空间有限（9!/2），但 A* 最坏仍需扩展指数级规模的结点、优先队列同时容纳指数级活结点——"有限"不等于"多项式"。正因如此，更大的 15 数码常改用 IDA* 以 O(深度) 空间迭代加深。A、B、C 都正确地把 A* 对应到 LC 分支限界的三要素。
