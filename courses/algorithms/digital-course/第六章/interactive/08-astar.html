学习目标

  1. 能够拆解评价函数 f(n) = g(n) + h(n) 的三个部分，说明 g、h、f 各自的含义。
  2. 能够把 A* 归位到分支限界法框架：它是以 f 为优先级的优先队列式（LC）最佳优先搜索。
  3. 能够陈述并运用启发函数的可采纳性（h ≤ 真实剩余代价）如何保证 A* 找到最优路径。
  4. 能够判断曼哈顿距离在四连通网格上可采纳、在允许对角移动时会高估，从而选对启发函数。
  5. 能够分析 h=0 时 A* 退化为 Dijkstra/BFS，理解"h 越接近真实、扩展结点越少"。

一、f = g + h 与分支限界的关系

A* 就是以 f 为限界的 LC 搜索
定义 1 · 评价函数

A* 为每个结点 n 计算评价函数 f(n) = g(n) + h(n)：g(n) 是从起点到 n 已经走过的实际最短代价；h(n) 是从 n 到目标的估计剩余代价（启发函数）；f(n) 则是"经过 n 的整条路径总代价"的一个估计。A* 每次优先扩展 f 最小的结点。

f(n) = g(n) + h(n) = 已走实际代价 g + 到目标的估计代价 h
性质 · A* = 优先队列式分支限界

把 f(n) 看作"经过 n 的最优解代价的一个下界"，A* 就完全落入第 6 章框架：活结点表 = 按 f 排序的优先队列（open 表）；扩展结点 = 每轮取出的 f 最小者；限界函数 = f 本身，当 f(n) ≥ 已知最优时该结点可剪。因此 A* 正是以 f 为限界值的优先队列式（LC）分支限界法，也叫最佳优先搜索。

只用 h 会怎样？若把优先级改成只看 h（贪心最佳优先，greedy best-first），会一头扎向目标方向，速度快但放弃了 g，不保证最优。A* 的精髓正是把"已花代价 g"与"未来估计 h"相加，兼顾"来路"与"去路"。

二、可采纳性与最优性

h 不高估 ⇒ A* 最优
定义 2 · 可采纳启发函数

若对每个结点 n 都有 h(n) ≤ h*(n)（h*(n) 为 n 到目标的真实最短剩余代价），即 h 从不高估，则称 h 可采纳（admissible）。可采纳性保证 A* 返回最优路径：因为 f=g+h 此时是经过 n 的真实最优代价的下界，A* 不会在找到最优解前错误地放弃它。

设目标最优代价为 C*，某条次优路径上的目标结点为 G2，f(G2)=g(G2)>C* 目标处 h=0，g 即真实长度 最优路径上任一未扩展结点 n 满足 f(n)=g(n)+h(n) ≤ g(n)+h*(n)=C* 可采纳：h ≤ h* 于是 f(n) ≤ C* < f(G2)，A* 必先扩展 n 而非弹出次优目标 G2 优先队列按 f 最小出队 ⇒ A* 不可能先返回次优解，弹出目标时即最优 这就是可采纳 ⇒ 最优
// ── A* 网格最短路（四连通，单位边权）───────────── // h = 曼哈顿距离，可采纳 ⇒ 结果最优 priority_queue<Node> open; // 活结点表：按 f 最小的小根堆 g[start] = 0; open.push({start, h(start)}); while (!open.empty()) { Node u = open.top(); open.pop(); // 取 f 最小者作扩展结点（LC） if (closed.count(u)) continue; // 已扩展过则跳过（惰性删除旧副本） closed.insert(u); if (u == goal) break; // 目标出队 ⇒ 已得最优路径 for (Node v : neighbors(u)) { // 分支：生成四邻 if (wall(v)) continue; // 约束：墙不可通行 int ng = g[u] + 1; if (ng < g[v]) { // 松弛：发现更短的到 v 的路径 g[v] = ng; prev[v] = u; open.push({v, ng + h(v)}); // 用新 f = g+h 入表 } } }
四连通下曼哈顿可采纳，八连通下不然：本页只允许上下左右移动（四连通、每步代价 1），此时曼哈顿距离 |Δ行|+|Δ列| 恰是"无墙时的最少步数"，绝不高估，可采纳。但若允许对角移动（八连通），一步可同时减少行差与列差，曼哈顿会高估，须改用切比雪夫/对角距离，否则 A* 可能返回非最优路径。

三、h 的强弱与复杂度

从 BFS 到理想启发
h(n)=0 ⇒ f=g，A* 退化为 Dijkstra；网格单位边权下 Dijkstra 即 BFS 丢掉方向信息，向四周均匀扩散 h 越接近真实 h*，f 的区分力越强，被扩展的结点越少 越"识路"，越少走冤枉路 h(n)=h*(n)（理想启发）⇒ A* 只沿最优路径前进，几乎不扩展多余结点 上界情形 仍可采纳但更紧的 h 总是不劣于更松的 h（在扩展结点数意义上） 这称为启发函数的"占优"dominance 最坏情况（h 很弱或图无结构）时间/空间仍可指数级 A* 不改变问题固有难度
方法优先级是否最优特点
BFS / Dijkstrag（h=0）是均匀扩散，扩展结点最多
贪心最佳优先h（丢 g）否冲向目标，快但可能绕远/非最优
A*f = g + h是（h 可采纳时）兼顾来路与去路，扩展结点最少
看动画理解：格子颜色越亮表示越早被扩展。可采纳的曼哈顿启发让高亮区域朝目标方向拉长（而非像 BFS 那样铺成圆形），这正是 h 提供的"方向感"在减少无谓扩展。
易错点
  • 混淆 g 与 h。g 是已走的实际代价（向后看），h 是到目标的估计代价（向前看）；f=g+h 缺一不可，只用其一都不是 A*。
  • 用了高估的启发函数还期望最优。h 一旦高估（不可采纳），A* 可能提前锁定次优路径，不再保证最优。
  • 在允许对角移动的网格仍用曼哈顿。八连通下曼哈顿会高估，应改用切比雪夫/对角距离；四连通下曼哈顿才可采纳。
  • 把 A* 当成"h 更大就更好"。启发函数应在可采纳前提下尽量大（更紧、占优）；单纯放大 h 越过 h* 就破坏最优性。
  • 认为 h=0 时算法出错。h=0 只是退化为 Dijkstra/BFS，仍返回最优，只是扩展的结点更多、更慢。
  • 忘记 A* 仍是指数级下的分支限界。它在困难问题（如八数码、TSP）上最坏仍需指数时间/空间，启发函数只压低实际搜索规模。
本节小结
  • f(n)=g(n)+h(n)：g 已走实际代价、h 到目标估计代价、f 经过 n 的路径代价估计；A* 每轮扩展 f 最小者。
  • A* = 优先队列式（LC）分支限界：open 表是按 f 排序的优先队列，f 充当限界值/下界，最佳优先搜索。
  • 可采纳性 h ≤ h* ⇒ A* 最优；曼哈顿距离在四连通网格可采纳，八连通会高估须换启发。
  • h=0 退化为 Dijkstra/BFS（仍最优、扩展更多）；h 越紧扩展结点越少，理想 h=h* 几乎直达。
  • A* 兼顾来路 g 与去路 h，优于只看 g 的 BFS 与只看 h 的贪心；最坏仍为指数级。
1A* 的评价函数 f(n)=g(n)+h(n) 中，g(n) 与 h(n) 分别是？
Ag 是从起点到 n 已走的实际代价，h 是从 n 到目标的估计代价
Bg 是从 n 到目标的估计代价，h 是从起点到 n 的实际代价
Cg 与 h 都是到目标的估计代价，只是用不同启发函数
Dg 是曼哈顿距离，h 是欧氏距离
解析：选 A。g(n) 向后看，是起点到 n 的已走实际代价；h(n) 向前看，是 n 到目标的估计剩余代价（启发函数）。B 把二者对调；C 错在 g 是实际值而非估计；D 张冠李戴，g/h 是"已走/待走"的语义划分，不是两种距离度量的名字。
2要保证 A* 一定找到最优路径，启发函数 h 需满足什么条件？在本页四连通网格上曼哈顿距离满足吗？
Ah 必须尽可能大，越大越准，曼哈顿满足
Bh 必须可采纳（h ≤ 真实剩余代价，从不高估）；四连通网格上曼哈顿满足
Ch 必须恒等于 0，曼哈顿不满足所以 A* 非最优
D只要 h 连续可导即可，与是否高估无关
解析：选 B。最优性的充分条件是启发函数可采纳：h(n) ≤ h*(n)，即从不高估真实剩余代价。四连通、单位边权网格上，曼哈顿距离 |Δ行|+|Δ列| 恰是无墙时的最少步数，墙只会让真实代价更大，故 h ≤ h*，可采纳。A 错在"越大越好"——超过 h* 就破坏最优；C 错在 h=0 只是退化为 Dijkstra 并非唯一最优条件；D 与可采纳性无关。
3若把 A* 的启发函数设为 h(n)≡0，算法会怎样？
A算法出错，无法找到路径
B退化为 Dijkstra（网格单位边权下即 BFS），仍返回最优解，但扩展的结点更多
C变成贪心最佳优先，速度最快但可能非最优
D路径长度会翻倍
解析：选 B。h≡0 时 f=g，A* 只按已走代价扩展，正是 Dijkstra；在单位边权网格上 Dijkstra 等价于 BFS。它仍然最优（h=0 是最松的可采纳启发），只是失去方向感、向四周均匀扩散、扩展结点更多、更慢。A、D 无稽；C 说反了——贪心最佳优先是"只用 h 丢掉 g"，而这里是"只用 g 丢掉 h"。
