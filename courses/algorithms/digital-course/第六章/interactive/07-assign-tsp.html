学习目标

  1. 能够把旅行商问题（TSP）建模为排列树上的最优化搜索，说明固定起点后叶子数为 (n−1)!。
  2. 能够区分本页演示的最近邻贪心（启发式上界）与正式分支限界所用的下界函数，不把二者混为一谈。
  3. 能够写出 TSP 的一个可采纳下界（松弛：每个待定城市取最小可用出边）并说明它为何不高估真实巡回长度。
  4. 能够用优先队列式分支限界（LC）描述 TSP 搜索：按 lb 最小取扩展结点，lb ≥ best 即剪支。
  5. 能够指出 TSP 分支限界的时间/空间都是指数级，理解"好的 best 初值 + 紧下界"是加速的两大杠杆。

一、TSP 建模与解空间

排列树 · 固定起点
定义 1 · 旅行商问题

给定 n 座城市与两两之间的距离 d[i][j]，求一条经过每座城市恰好一次并回到出发点的闭合回路（哈密顿回路），使总长度最短。由于回路可从任意城市出发、且正反方向等价，习惯固定城市 0 为起点，只对其余 n−1 座城市排序。于是解空间是一棵排列树，叶子数为 (n−1)!（对称距离下还可再除以 2）。

目标：minπ [ Σk=0n−2 d[πk][πk+1] + d[πn−1][π0] ]
演示的最近邻只是"上界直觉"：本页动画每步走向最近的未访城市，这是一种贪心启发式，能快速得到一条可行回路，其长度可作 best 的初值（一个上界）。但它不保证最优，也不是分支限界赖以剪支的下界函数。请勿把"最近邻"与"限界下界"混为一谈。
旅行商问题TSP 哈密顿回路Hamiltonian cycle 下界lower bound 最近邻nearest neighbor LC 分支限界least-cost B&B

二、优先队列式分支限界（LC）求 TSP

下界函数 + 小根堆
定义 2 · 下界函数（限界函数）

对一条从起点出发的部分路径 P，定义下界 lb = 已走边权之和 + 把剩余城市接成回路所需代价的一个下界。一个简单且可采纳的松弛：让"当前端点、每个未访城市、以及回到起点"这些尚未确定出边的顶点各取其最小可用出边并求和。因为真实回路中每个这样的顶点必连出一条边、其权不小于自身最小出边，逐点求和即得 lb ≤ 真实巡回长度，永不高估。

lb(P) = len(P) + Σv 出边未定 min{ d[v][w] : w 为 v 的可用后继 } ⇒ lb ≥ best 时剪支
// ── TSP · 优先队列式分支限界（LC，最小化）───────── struct Node { // 活结点 = 一条从起点出发的部分路径 vector<int> path; // 已确定的城市序列，path[0] = 起点 0 double cost; // 已走边权之和 double lb; // 该结点的下界（限界函数值） bool operator<(const Node& o) const { return lb > o.lb; } // 小根堆：lb 小者优先 }; double tsp(int n) { priority_queue<Node> pq; pq.push(makeRoot()); // 只含起点 0 的路径 double best = nearestNeighbor(); // 用最近邻求一个上界作 best 初值 while (!pq.empty()) { Node u = pq.top(); pq.pop(); // ← 取 lb 最小的活结点作扩展结点（LC） if (u.lb >= best) continue; // 限界剪支：连下界都不优于 best if ((int)u.path.size() == n) { // 叶子：闭合回路 best = min(best, u.cost + d[u.path.back()][0]); continue; } for (int v = 1; v < n; v++) // 分支：一次生成全部可行子结点 if (!inPath(u, v)) { Node w = extend(u, v); // 追加城市 v，更新 cost 与 lb if (w.lb < best) pq.push(w); // 存活者入活结点表 } } return best; }
性质 · LC 的"首个叶子即最优"

用可采纳下界时，优先队列每次取出的都是 lb 最小的活结点。当某个叶子（完整回路）被取出时，它的 lb 就是其真实长度，而队列中所有其它活结点的 lb 都不小于它，故不可能再产生更短回路——因此 LC 首次弹出叶结点即得最优解，可提前终止。这正是优先队列式相对队列式（FIFO）的核心优势。

三要素落点：活结点表 = 优先队列 pq；扩展结点 = 每轮 pq.top() 取出的那个部分路径；限界函数 = lb。把 pq 换成普通 queue 就退化为队列式（FIFO）分支限界——广度优先、不"按潜力插队"，通常需要搜完更多结点。

三、复杂度与两大加速杠杆

仍是指数级
解空间排列树叶子 (n−1)!，TSP 是 NP 难问题 固定起点后对 n−1 城市排列 最坏情况无有效剪支 ⇒ 时间指数级 O((n−1)! · 单结点开销) 分支限界不改变最坏阶 空间是致命短板：优先队列最坏同时容纳指数级活结点 回溯法只需 O(n) 栈，分支限界需显式存活结点表 杠杆一：好的 best 初值（如最近邻上界）让 lb ≥ best 更易成立、剪支更早 上界越紧、剪支门槛越高 杠杆二：更紧的下界 lb（如归约矩阵法）逼近真实最优、剪掉更多子树 下界越紧、区分力越强
与回溯法对照：同是排列树上的最优化，回溯法（第 5 章任务分配）用 DFS + 隐式栈，空间 O(n)；分支限界用优先队列 + 显式活结点表，空间可达指数级，但借"最佳优先"常更早逼近最优。空间换时间是分支限界的基本取舍，也是 IDA*、迭代加深等混合技术的动机。
易错点
  • 把最近邻当成分支限界的下界。最近邻是求可行解/上界的贪心启发式，正式 BnB 剪支靠的是下界 lb；二者角色相反，一个是 best 初值、一个是剪支依据。
  • 下界方向或判据写反。TSP 是最小化，用下界，lb ≥ best 才剪；写成上界或 lb ≤ best 会剪掉含最优解的分支。
  • 下界取得过"紧"以致高估。限界函数必须不高估（可采纳）；一旦某结点 lb 超过其子树真实最优，就可能误剪最优回路。用最小出边求和这类松弛下界才安全。
  • 忽视活结点表的指数级空间。优先队列可能同时容纳指数级活结点，内存往往先于时间耗尽，这是分支限界相对回溯法的最大代价。
  • 误以为"LC = 深度优先"。LC 是最佳优先，按 lb 在树中各分支间跳跃扩展，既非 DFS 也非 BFS。
  • 忘记固定起点。不固定起点会把同一回路的 n 个旋转、2 个方向重复搜索，平白放大常数倍工作量。
本节小结
  • TSP 建模：排列树上求最短哈密顿回路，固定起点后叶子 (n−1)!，是 NP 难问题。
  • 最近邻 = 上界（best 初值），下界函数 lb = 限界依据，二者角色相反不可混淆。
  • 下界= 已走长度 + 各出边未定顶点的最小可用出边之和，是松弛的可采纳下界，永不高估；lb ≥ best 剪支。
  • LC（优先队列式）：小根堆按 lb 取扩展结点，可采纳下界下首个弹出的叶子即最优；换成普通队列即 FIFO 分支限界。
  • 时间与空间均为指数级；加速靠好的 best 初值与更紧的下界两大杠杆。
1本页动画用"最近邻"逐步连线。它在 TSP 的分支限界求解中扮演什么角色？
A它就是分支限界的限界函数，用来剪掉坏分支
B它是一种贪心启发式，快速给出可行回路作为 best 的上界初值
C它能保证得到最优回路，无需再做分支限界
D它是排列树的一种遍历方式，等价于广度优先
解析：选 B。最近邻每步走向最近未访城市，是贪心启发式，能快速得到一条可行回路，其长度可作 best 的上界初值——好的初值让后续限界剪支更早触发。它不保证最优（C 错），也不是下界函数（A 错，剪支靠的是不高估的 lb），更不是树的遍历方式（D 错）。
2用优先队列式分支限界（LC）求 TSP，每轮从活结点表中取出的扩展结点是？
A最早生成（入队最久）的结点
B下界 lb 最小的结点
C已走路径最长的结点
D随机选取一个活结点
解析：选 B。LC（Least Cost，最小耗费优先）用优先队列组织活结点表，每次取限界值最有希望者——最小化问题即 lb 最小的结点。A 描述的是队列式（FIFO）；C、D 都不是分支限界的取出规则。正因每次押注在下界最小的分支上，LC 往往更早逼近最优解。
3关于 TSP 分支限界的下界函数与复杂度，错误的是？
A下界必须不高估真实巡回长度，否则可能误剪最优解
B下界越紧，越容易触发 lb ≥ best，剪支越多
C加了下界函数后，TSP 的最坏时间复杂度降为多项式
D分支限界的活结点表可能占用指数级空间，是其相对回溯法的短板
解析：选 C（错误项）。TSP 是 NP 难问题，分支限界是精确算法但不改变最坏复杂度阶：总存在使下界始终小于 best、一次也剪不掉的实例，此时仍需搜遍 (n−1)! 量级的结点，最坏仍是指数级。A（可采纳性）、B（界越紧剪支越强）、D（活结点表指数级空间）均正确。
