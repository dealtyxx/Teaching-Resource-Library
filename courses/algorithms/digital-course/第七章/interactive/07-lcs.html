学习目标

Learning Objectives

本节学完后你应当

  1. 能准确写出 dp[i][j] 的状态定义：X 的前 i 个字符与 Y 的前 j 个字符的 LCS 长度，并说明为什么要用「前缀长度」这一对二维下标。
  2. 能分「末字符相等 / 不等」两种情形写出转移方程，并解释相等时为何一定走对角线、不等时为何取左上两格的较大值。
  3. 能写出边界 dp[i][0] = dp[0][j] = 0，并解释其含义（任一串为空则 LCS 为空）。
  4. 能用 Θ(nm) 的 C++ 填表实现，并从 dp 表右下角回溯出一条具体的 LCS 字符串。
  5. 能区分子序列（可跳选）与子串（必须连续），说明本题与「最长公共子串」的转移差异。

① 状态定义

State Definition
状态定义

dp[i][j] 表示字符串 X 的前 i 个字符 X[1..i] 与 Y 的前 j 个字符 Y[1..j] 的最长公共子序列（LCS）的长度（i = 0…n，j = 0…m）。
之所以用「两个前缀长度」作下标，是因为 LCS 天然是两个序列同时缩短的问题：每比较一对末字符，就把某一端（或两端）的前缀各缩短一位，子问题恰好落在更小的 dp[i′][j′] 上，形成二维重叠子问题。

最优子结构 · 无后效性

考察末字符 X[i] 与 Y[j]：
· 若 X[i] = Y[j]，则这对相同字符一定可以放进某条最优 LCS 的末尾（可以证明：存在一条最优解把它们配成一对不会更差），于是 dp[i][j] = dp[i−1][j−1] + 1。
· 若 X[i] ≠ Y[j]，则这两个字符不可能同时是 LCS 的末尾，至少要放弃其中一个：放弃 X[i] 得 dp[i−1][j]，放弃 Y[j] 得 dp[i][j−1]，取较大者。
每个子问题只依赖「更短前缀」的解，前缀一旦确定其 LCS 长度就固定，不受后续字符影响——无后效性成立。

② 转移方程 ③ 边界 ④ 计算顺序

Transition
dp[i][j] = dp[i−1][j−1] + 1　　　　　　当 X[i] = Y[j]
dp[i][j] = max( dp[i−1][j] , dp[i][j−1] )　当 X[i] ≠ Y[j]
边界条件

dp[i][0] = 0（Y 为空串，公共子序列只能是空）；dp[0][j] = 0（X 为空串，同理）。
实现时开 (n+1)×(m+1) 的表，把第 0 行、第 0 列全部置 0，真实字符从下标 1 开始对齐，可避免大量下标越界判断。

计算顺序 · 答案位置

dp[i][j] 依赖左上（i−1,j−1）、上（i−1,j）、左（i,j−1）三格，故按 i 从小到大、内层 j 从小到大逐行填表即可保证依赖已就绪。
答案就在右下角 dp[n][m]（因为它对应「整个 X 与整个 Y」）。这与「以 i 结尾」型状态不同——LCS 用的是「前缀」而非「结尾」，故答案是最后一格而非全表最大值。

⑤ C++ 代码 · 填表 + 回溯

Implementation
// dp[i][j] = X[1..i] 与 Y[1..j] 的 LCS 长度，Θ(nm) 时间 / Θ(nm) 空间 int lcs(const string& X, const string& Y, string& out) { int n = X.size(), m = Y.size(); vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0)); // 边界：dp[i][0]=dp[0][j]=0 for (int i = 1; i <= n; ++i) // ④ i 递增 for (int j = 1; j <= m; ++j) if (X[i-1] == Y[j-1]) dp[i][j] = dp[i-1][j-1] + 1; // 末字符相同，走对角线 else dp[i][j] = max(dp[i-1][j], dp[i][j-1]); // 否则丢弃一端 // 回溯：从右下角 (n,m) 反向走到边界，逆序收集字符 int i = n, j = m; out.clear(); while (i > 0 && j > 0) { if (X[i-1] == Y[j-1]) { out += X[i-1]; --i; --j; } // 对角线来的字符入选 else if (dp[i-1][j] >= dp[i][j-1]) --i; // 往 dp 值较大的一侧退 else --j; } reverse(out.begin(), out.end()); // 回溯得到的是逆序，需反转 return dp[n][m]; } // 调用 lcs("ABCBDAB","BDCABA",out) → 返回 4，out = "BCBA"
回溯要点：只靠 dp 表本身即可回溯，无需额外的 pre 数组——因为每一格的来源可由「X[i] 是否等于 Y[j]」以及左、上两格数值直接判定。这正是「dp 表自带方向信息」的一类问题。若担心比较字符耗时，也可另开 choice[][] 记录来向。

⑦ 易错点

Pitfalls
易错点
  • 把 LCS 当成最长公共子串。子序列可跳选，不等时取左/上的较大值；子串要求连续，不等时应归零，答案也变成全表最大值而非 dp[n][m]。
  • 下标偏移写错。dp 用 1-based（dp[i][j] 对应 X 的第 i 个字符），而字符串是 0-based，比较时必须是 X[i-1] == Y[j-1]，写成 X[i]==Y[j] 会越界并算错。
  • 忘记初始化第 0 行 / 第 0 列。dp[i][0] 与 dp[0][j] 必须为 0，否则整表数值被污染。
  • 相等时误写成 max(dp[i−1][j], dp[i][j−1]) + 1。相等时只能走对角线 dp[i−1][j−1]+1，取左上会重复计入同一个字符导致答案偏大。
  • 回溯时忘记 reverse。从右下角回溯得到的字符是逆序的，必须反转后才是正确的 LCS。
  • 误以为回溯路径唯一。不等且左上两格相等时，向上或向左都合法，会得到不同但等长的 LCS，这不是 bug。

本节小结

Summary
本节小结
  • 状态定义：dp[i][j] = X 前 i 个字符与 Y 前 j 个字符的 LCS 长度，用「两个前缀长度」作二维下标。
  • 转移方程：相等 dp[i][j] = dp[i−1][j−1] + 1，不等 dp[i][j] = max(dp[i−1][j], dp[i][j−1])；边界 dp[i][0] = dp[0][j] = 0。
  • 按行填表（i、j 均从小到大），答案在右下角 dp[n][m]，复杂度 Θ(nm)。
  • 从右下角回溯：相等取字符并走对角线，不等退向数值较大的一侧，最后 reverse 得到一条具体 LCS（通常不唯一）。
  • 与最长公共子串的关键差异：不等时归零、答案取全表最大值。

自测题

点击选项查看解析
1当 X[i] ≠ Y[j] 时，LCS 的转移方程是？
Adp[i][j] = dp[i−1][j−1]
Bdp[i][j] = max( dp[i−1][j], dp[i][j−1] )
Cdp[i][j] = dp[i−1][j−1] + 1
Ddp[i][j] = 0
解析：选 B。末字符不同则它们不可能同为 LCS 结尾，至少放弃一个：放弃 X[i] 得 dp[i−1][j]，放弃 Y[j] 得 dp[i][j−1]，取较大者。C 是相等时的转移；A 漏了取 max，等价于同时放弃两个字符，会漏解；D 是最长公共子串不等时的做法（断了归零），用在 LCS 上会把答案算小。
2关于 LCS 的答案位置，正确的说法是？
A答案在右下角 dp[n][m]
B答案是整张表的最大值 max{dp[i][j]}
C答案在 dp[n][0]
D答案是 dp 主对角线元素之和
解析：选 A。dp[n][m] 对应「整个 X 与整个 Y」的 LCS，正是所求。B 是最长公共子串的答案位置——那里状态是「以 X[i]、Y[j] 结尾」，故取全表最大值；LCS 用的是「前缀」，答案在最后一格。C 的 dp[n][0] 恒为 0（Y 空）；D 无任何意义。
3把 LCS 代码中不等时的转移由 max(dp[i−1][j], dp[i][j−1]) 改成常数 0，得到的是什么问题的解？
A仍然是 LCS，只是更慢
B最长公共子串（连续），但答案要改成取全表最大值
C编辑距离
D最短公共超序列
解析：选 B。不等时归零意味着「一旦断开，公共段长度清零重新计数」，这正是公共子串（要求连续）的定义；此时 dp[i][j] 表示「以 X[i]、Y[j] 结尾的最长公共子串长度」，答案在 max{dp[i][j]} 而非 dp[n][m]。A 错，改了递推就不是 LCS；C 编辑距离用的是 min 三项而非此式；D 最短公共超序列另有转移，与此无关。
