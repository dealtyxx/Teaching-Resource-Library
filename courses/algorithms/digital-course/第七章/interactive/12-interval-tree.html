① 区间 DP · 石子合并

Interval DP
状态定义

dp[l][r] 表示把第 l 堆到第 r 堆石子合并成一堆的最小总代价（每次只能合并相邻两堆，代价为两堆石子数之和）。这类「在一段区间上做决策、由更小的子区间拼成」的问题统称区间 DP。

最优子结构 · 枚举分割点

合并区间 [l,r] 的最后一步一定是把左右两个已合并好的子堆并起来，分界在某个 k（l ≤ k < r）：左子堆 [l,k]、右子堆 [k+1,r]。这最后一并的代价固定为整段之和 sum(l..r)（无论怎么并，[l,r] 的所有石子都要在最后被称一次）。于是枚举分割点 k 取最小：
dp[l][r] = mink( dp[l][k] + dp[k+1][r] + sum(l..r) )。子区间的最优解一旦定下不受外部影响——无后效性成立。

dp[l][r] = minl ≤ k < r( dp[l][k] + dp[k+1][r] ) + sum(l..r)
边界 · 计算顺序（区间 DP 的关键）

边界 dp[i][i] = 0（单堆无需合并）。
计算顺序必须按区间长度 len 从小到大：dp[l][r] 依赖更短的子区间 dp[l][k]、dp[k+1][r]，只有先把所有长度 < len 的区间算完，长度为 len 的才有据可依。所以三重循环是 外层 len、中层左端点 l（r = l+len−1）、内层分割点 k——绝不能简单地「l 从小到大」，那样会用到还没算好的长区间。

石子 [1, 3, 5, 2]，前缀和 sum：len=2 先算： dp[0][1] = 0+0 + (1+3) = 4 dp[1][2] = 0+0 + (3+5) = 8 dp[2][3] = 0+0 + (5+2) = 7 len=3：dp[0][2] = min(dp00+dp12, dp01+dp22) + 9 = min(0+8, 4+0) + 9 = 13 len=3：dp[1][3] = min(dp11+dp23, dp12+dp33) + 10 = min(0+7, 8+0) + 10 = 17 len=4：dp[0][3] = min(0+dp13, dp01+dp23, dp02+0) + 11 = min(17, 11, 13) + 11 = 22
答案：最小合并代价 = dp[0][3] = 22。分割点在 len=4 时取 k=1（dp[0][1]+dp[2][3]+11 = 4+7+11 = 22）最优——即先分别合并 [1,3] 与 [5,2]，再合并两大堆。

② 区间 DP · C++ 代码

Implementation
// 石子合并：dp[l][r] = 合并区间 [l,r] 的最小代价，O(n³) int stoneMerge(const vector<int>& a) { int n = a.size(); vector<int> s(n + 1, 0); for (int i = 0; i < n; ++i) s[i+1] = s[i] + a[i]; // 前缀和，O(1) 求区间和 vector<vector<int>> dp(n, vector<int>(n, 0)); // 边界：dp[i][i]=0 for (int len = 2; len <= n; ++len) // ① 先枚举区间长度 for (int l = 0; l + len - 1 < n; ++l) { // ② 再枚举左端点 int r = l + len - 1; dp[l][r] = INT_MAX; for (int k = l; k < r; ++k) // ③ 枚举分割点 dp[l][r] = min(dp[l][r], dp[l][k] + dp[k+1][r] + s[r+1] - s[l]); } return dp[0][n-1]; } // stoneMerge({1,3,5,2}) → 返回 22
为什么外层是 len 而非 l？区间 DP 的依赖方向是「短区间 → 长区间」。若外层写 l、内层写 r，当算 dp[l][r] 时其右侧子区间 dp[k+1][r] 可能对应更长的、尚未计算的区间。按长度递增能严格保证所有被依赖的短区间都已就绪，这是区间 DP 与线性 DP 最不同的一点。

③ 树形 DP · 树上最大独立集

Tree DP
状态定义（两个分量）

f[u][0] = 以 u 为根的子树中，不选 u 时的最大权；f[u][1] = 选 u 时的最大权。
「独立集」要求所选结点两两不相邻，因此选了 u 就不能选它的任何孩子。用「选 / 不选」两个分量正是为了把这个约束在父子间传递下去。

f[u][1] = val[u] + Σc ∈ 子(u) f[c][0]
f[u][0] = Σc ∈ 子(u) max( f[c][0], f[c][1] )
父子合并 · 先子后父

选 u（f[u][1]）：加上 u 自身权值，其每个孩子都只能不选，故累加 f[c][0]。
不选 u（f[u][0]）：孩子可选可不选，各取 max(f[c][0], f[c][1])。
父结点的两个分量都由全部孩子已算好的值合并而来，所以必须先算完所有子结点再算父结点——这正是后序遍历（DFS 递归返回时合并）的顺序。答案 = max(f[root][0], f[root][1])。

本页树：0 的孩子 {1,2,5}，2 的孩子 {3,4}；权 val = {0:3,1:2,2:4,3:1,4:2,5:2} 叶子：f[1]=(0,2) f[3]=(0,1) f[4]=(0,2) f[5]=(0,2) (不选, 选) 结点 2：f[2][1] = 4 + f[3][0] + f[4][0] = 4+0+0 = 4 结点 2：f[2][0] = max(0,1) + max(0,2) = 1+2 = 3 结点 0：f[0][1] = 3 + f[1][0]+f[2][0]+f[5][0] = 3+0+3+0 = 6 结点 0：f[0][0] = max(0,2)+max(3,4)+max(0,2) = 2+4+2 = 8
答案：最大独立集权 = max(f[0][0], f[0][1]) = max(8, 6) = 8。取得 8 的方案是不选根 0，选 {1, 2, 5}（权 2+4+2 = 8）——它们互不相邻、也都不与被跳过的根相邻，合法。

④ 树形 DP · C++ 代码

Implementation
// 树上最大权独立集：f[u][0/1] = 子树内 u 不选/选 的最大权，O(n) vector<vector<int>> g; // 邻接表 vector<int> val, f0, f1; void dfs(int u, int fa) { f1[u] = val[u]; // 选 u：先记自身权 f0[u] = 0; // 不选 u for (int c : g[u]) if (c != fa) { dfs(c, u); // 先递归算完子结点（后序） f1[u] += f0[c]; // 选 u ⇒ 孩子必不选 f0[u] += max(f0[c], f1[c]); // 不选 u ⇒ 孩子随意取大 } } // 调用 dfs(root, -1) 后，答案 = max(f0[root], f1[root])

⑤ 易错点

Pitfalls
易错点
  • 区间 DP 外层误写左端点 l。必须外层枚举长度 len，否则计算 dp[l][r] 时其子区间可能尚未算好，得到错误值。
  • 区间 DP 忘记初始化 dp[l][r] 为 +∞。取 min 前若不置为极大值，第一次比较就会被残留的 0 污染。
  • 区间和用循环现算。sum(l..r) 应借助前缀和 s[r+1]−s[l] 做到 O(1)，逐次累加会让复杂度多一个因子。
  • 树形 DP 顺序写反（先父后子）。父结点依赖全部孩子的 f 值，必须后序（DFS 递归返回时合并），先算父会读到未初始化的子值。
  • 树形 DP 递归不传父结点、导致往回走。无根树用邻接表时要用 if (c != fa) 跳过父亲，否则会在父子间来回递归死循环。
  • 选 u 时错误地对孩子取 max。选了 u 后孩子只能不选，累加的是 f[c][0]；若写成 max(f[c][0],f[c][1]) 就可能选中相邻结点，破坏独立集约束。

本节小结

Summary
本节小结
  • 区间 DP：dp[l][r] = 区间 [l,r] 的最优值，枚举分割点 k 合并；必须按区间长度从小到大计算。
  • 石子合并转移 dp[l][r] = mink(dp[l][k]+dp[k+1][r]) + sum(l..r)，用前缀和 O(1) 求区间和，复杂度 O(n³)。
  • 树形 DP：为每个结点设「选 / 不选」两个分量，把相邻约束在父子间传递。
  • 独立集转移：f[u][1] = val[u] + Σf[c][0]，f[u][0] = Σmax(f[c][0],f[c][1])；答案 max(f[root][0], f[root][1])。
  • 树形 DP 用后序遍历（先子后父）合并，复杂度 O(n)；答案在根结点取两分量最大。

自测题

点击选项查看解析
1区间 DP（石子合并）的三重循环，最外层应枚举什么？
A左端点 l
B区间长度 len（从小到大）
C分割点 k
D右端点 r（从大到小）
解析：选 B。dp[l][r] 依赖更短的子区间 dp[l][k] 与 dp[k+1][r]，只有按长度递增才能保证所有短区间先算好。A 若外层是 l，算长区间时其右侧子区间可能还没算，读到错误值；C 分割点必须在最内层；D 单看 r 递减也无法保证「短区间先于长区间」这个真正的依赖方向。
2树上最大独立集里，f[u][1]（选 u）的转移是？
Aval[u] + Σ max(f[c][0], f[c][1])
Bval[u] + Σ f[c][0]
CΣ f[c][1]
Dmax(f[u][0], val[u])
解析：选 B。选中 u 后，独立集约束要求它的每个孩子都不能被选，故累加各孩子的 f[c][0]，再加 u 自身权 val[u]。A 是 f[u][0]（不选 u）的式子——不选 u 时孩子才可自由取 max；C 漏了 u 自身权且让孩子全选，直接违反相邻约束；D 无意义。
3对石子 [1,3,5,2]，最小合并代价是？
A11，即所有石子之和
B22
C24（一律从最左开始顺次合并）
D13
解析：选 B。按区间 DP 填表 dp[0][3] = 22（分割点 k=1：先合并 [1,3] 得 4、合并 [5,2] 得 7，再合并两大堆 +11，共 22）。A 的 11 只是石子总数，合并需多次称重，代价必然大于它；C 是「从左到右顺次合并」这种贪心顺序的代价：4 +（4+5）+（9+2）= 4+9+11 = 24，比最优的 22 大——正说明贪心不最优、必须用 DP 枚举分割点；D 的 13 是子区间 dp[0][2] 的值，不是整段答案。
