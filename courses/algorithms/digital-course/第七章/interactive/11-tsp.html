状态压缩 DP · 旅行商

dp[S][i]：从 0 出发，走过集合 S，当前停在 i 的最短路。集合用二进制位表示。

学习目标

Learning Objectives

本节学完后你应当

  1. 能理解状态压缩的核心：用一个整数的二进制位表示「哪些城市已访问」这个集合。
  2. 能写出 dp[S][i] 的状态定义：从起点出发、已访问集合 S、当前停在城市 i 的最短路径长度。
  3. 能写出转移方程与边界 dp[{0}][0] = 0，并说明按 S 递增枚举保证子集先于超集算好。
  4. 能写出最终答案 min(dp[全集][i] + w(i,0))（回到起点），并从 par 数组回溯环游路径。
  5. 能推导复杂度 O(2ⁿ·n²)，理解为何 n 只能到约 20。

① 状态压缩的思想

Bitmask
用二进制位表示集合

旅行商问题（TSP）要求从起点出发遍历所有城市各一次后回到起点，使总路程最短。DP 的难点在于「当前已经访问过哪些城市」本身就是一个集合，无法用普通下标表示。
状态压缩的做法：给 n 个城市编号 0…n−1，用一个 n 位整数 S 的第 i 位是否为 1 表示城市 i 是否已访问。例如 n = 4 时 S = 0b1011 = 11 表示已访问 {0, 1, 3}。判断、加入、遍历子集都可用位运算高效完成。

S >> i & 1城市 i 是否在 S 中 S | (1<<j)把城市 j 加入 S 1<<n全部子集个数 2ⁿ (1<<n)−1全集

② 状态定义与转移

State & Transition
状态定义

dp[S][i] 表示从起点 0 出发，已经访问过集合 S 中的所有城市，且当前正停在城市 i（i ∈ S）时，走过的最短路径长度。
两维缺一不可：S 记录哪些城市已走过，i 记录现在人在哪——只有知道当前位置，才能算出走向下一城的距离，从而满足无后效性。

dp[S ∪ {j}][j] = mini ∈ S( dp[S][i] + w(i, j) )　　j ∉ S
边界条件

dp[{0}][0] = 0，即 dp[1][0] = 0（只访问了起点 0、人在 0，路程为 0）。其余全部初始化为 +∞（表示尚不可达）。

计算顺序 · 答案

转移总是从 S 走向它的超集 S∪{j}，而超集对应的整数更大，故只要按 S 从小到大枚举，被依赖的 dp[S][i] 一定已经算好。
最终答案要回到起点：ans = mini≠0( dp[全集][i] + w(i, 0) )，全集 = (1<<n)−1。

例题演算 · n = 4（本页演示的图）

Worked Example

4 个城市，距离矩阵对称：w(0,1)=5, w(0,2)=8, w(0,3)=6, w(1,2)=4, w(1,3)=7, w(2,3)=3。枚举 0 出发的 3! = 6 条环路：

0→1→2→3→0 : 5+4+3+6 = 18 ← 最短 0→1→3→2→0 : 5+7+3+8 = 23 0→2→1→3→0 : 8+4+7+6 = 25 0→2→3→1→0 : 8+3+7+5 = 23 0→3→1→2→0 : 6+7+4+8 = 25 0→3→2→1→0 : 6+3+4+5 = 18 ← 与第一条互为逆向，同为最短
答案：最短回路长度 = 18，路径 0 → 1 → 2 → 3 → 0（其逆向 0→3→2→1→0 等价）。状压 DP 通过 dp[S][i] 把这 6 条路里的公共前缀子问题合并计算，避免了朴素全排列的重复。

③ C++ 代码 · 填表 + 回溯路径

Implementation
// 状压 TSP：dp[S][i] = 从 0 出发、已访问集合 S、当前在 i 的最短路 // 时间 O(2ⁿ·n²)，空间 O(2ⁿ·n) int tsp(const vector<vector<int>>& w, vector<int>& tour) { int n = w.size(), FULL = (1 << n) - 1; const int INF = 1e9; vector<vector<int>> dp(1 << n, vector<int>(n, INF)); vector<vector<int>> par(1 << n, vector<int>(n, -1)); // 回溯父结点 dp[1][0] = 0; // 边界：只访问 {0}，停在 0 for (int S = 1; S <= FULL; ++S) // ④ S 递增：子集先算好 for (int i = 0; i < n; ++i) if ((S >> i & 1) && dp[S][i] < INF) // i 已在 S 中且可达 for (int j = 0; j < n; ++j) if (!(S >> j & 1)) { // j 尚未访问 int S2 = S | (1 << j), nd = dp[S][i] + w[i][j]; if (nd < dp[S2][j]) { dp[S2][j] = nd; par[S2][j] = i; } } int best = INF, last = -1; for (int i = 1; i < n; ++i) { // 回到起点 0 int c = dp[FULL][i] + w[i][0]; if (c < best) { best = c; last = i; } } // 回溯：沿 par 从 last 退回起点，再反转 tour.clear(); for (int S = FULL, cur = last; cur != -1; ) { tour.push_back(cur); int p = par[S][cur]; S ^= (1 << cur); cur = p; } reverse(tour.begin(), tour.end()); // 得到 0 → … → last return best; // 环路：再从 last 回到 0 } // 本页数据 → 返回 18，tour = {0,1,2,3}，环路 0→1→2→3→0

④ 复杂度分析

Complexity
O(2ⁿ·n²) 从何而来

状态数 = 集合数 × 当前位置数 = 2ⁿ × n；每个状态转移时要枚举下一个城市 j，是 O(n)。三者相乘得 O(2ⁿ · n²)。空间上要存整张 dp 表，为 O(2ⁿ · n)。
与朴素枚举全排列的 O(n!) 相比，状压 DP 把阶乘降到指数——n = 15 时 15! ≈ 1.3×10¹²，而 2¹⁵·15² ≈ 7.4×10⁶，差距巨大。但 2ⁿ 仍是指数，n 一般只能到 20 左右（2²⁰·20² ≈ 4×10⁸）。

⑤ 易错点

Pitfalls
易错点
  • 忘记初始化 dp[1][0] = 0。整表若全为 INF 则无从转移，起点状态必须单独置 0。
  • 枚举顺序写错。必须按 S 从小到大枚举，才能保证转移来源 dp[S][i]（更小的 S）已算好；打乱顺序会读到未完成的值。
  • 转移时未判断 j ∉ S。若 j 已在 S 中还去访问，会重复经过城市，违反 TSP「每城恰一次」。
  • 最后忘记加回起点的边 w(i,0)。dp[全集][i] 只是「走完所有城停在 i」，还要 + w(i,0) 才是闭合回路；漏掉会少算最后一段。
  • 位运算优先级坑。S >> i & 1 依赖 >> 高于 &，但 S & 1 << j 会因 << 高于 & 而出错，判断某位务必写成 (S >> j) & 1 或加括号。
  • 用 int 存路径和溢出 / INF 相加溢出。转移前应确认 dp[S][i] < INF 再累加，否则 INF + w 可能溢出或产生假的更优值。

本节小结

Summary
本节小结
  • 状态压缩用整数二进制位表示「已访问城市集合」，位运算完成判断、加入、遍历。
  • 状态定义：dp[S][i] = 从 0 出发、访问集合 S、当前在 i 的最短路；边界 dp[{0}][0] = 0，其余 +∞。
  • 转移 dp[S∪{j}][j] = min(dp[S][i] + w(i,j))（j ∉ S）；按 S 递增枚举保证依赖就绪。
  • 答案 min(dp[全集][i] + w(i,0))，别忘了加回起点那条边；用 par 数组可回溯环游路径。
  • 复杂度 O(2ⁿ·n²)，比全排列 O(n!) 快得多，但仍是指数，n 约到 20。

1状压 TSP 的时间复杂度是？
AO(n!)
BO(2ⁿ·n²)
CO(n²)
DO(2ⁿ)
解析：选 B。状态数为 2ⁿ（集合）× n（当前位置），每个状态转移枚举下一城 O(n)，共 O(2ⁿ·n²)。A 是朴素全排列的复杂度，状压 DP 正是把它从阶乘降到指数；C 漏掉了集合维；D 漏掉了 n² 的位置与转移因子。
2枚举时为什么要按集合 S 从小到大的顺序？
A为了让代码更短
B转移从 S 走向其超集 S∪{j}，超集的整数更大；S 递增能保证被依赖的子集状态已算好
C因为 S 从大到小会死循环
D顺序无所谓，随便枚举都对
解析：选 B。dp[S∪{j}][j] 依赖 dp[S][i]，而 S∪{j} 作为整数严格大于 S，因此按 S 递增枚举时，转移来源必定已经计算完毕——这就是「子集先于超集」的拓扑顺序。C 说法无依据；D 错，若先算了大的 S 就会读到尚未填好的小 S 的值，得到错误答案。
3填完 dp 表后，TSP 的最终答案应如何取？
Adp[全集][0]
Bmax over i 的 dp[全集][i]
Cmin over i≠0 的 ( dp[全集][i] + w(i,0) )
Ddp[全集][n−1]
解析：选 C。dp[全集][i] 表示「走完所有城市、当前停在 i」，还必须加回从 i 到起点 0 的边 w(i,0) 才构成闭合回路，并在所有可能的末城 i 上取最小。A 的 dp[全集][0] 通常是 INF（走完所有城市不可能又恰停在起点且是先离开的）；B 取 max 与「最短」相悖；D 只看某个固定末城，漏了取 min 和回起点的边。
