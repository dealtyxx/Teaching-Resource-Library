章节定位

本案例位于第 4 章「网络爬虫」4.3 节：在掌握 requests 发送请求、BeautifulSoup 解析页面的同时，把《个人信息保护法》的合规要求直接写进爬虫代码。技术上学会的是请求头设置、HTML 解析、数据脱敏与合规存储；思政上要回答的是另一个问题——「能爬」与「该爬」之间，隔着法律与伦理的双重边界。

背景导入：数据是新时代的石油，但谁有权开采

课堂从 Cambridge Analytica 丑闻纪录片片段开始。有人说数据是新时代的石油，可是石油埋在无主的地下，数据却连着一个个具体的人：他的电话、他的行踪、他的病历。过去十年，四起真实案件把「谁有权开采」这个问题反复推到公众面前。

📁脉脉非法获取LinkedIn用户数据案2016侵犯隐私权

职场社交应用脉脉爬取 LinkedIn 中国用户数据，未经用户授权为其建立职场社交关系。法院认定其行为侵犯用户隐私权。本案确立了一个重要导向：数据在网页上「看得见」，不等于「可以拿来用」。

⚖️ 结果：被判侵犯用户隐私权，赔偿并道歉

📁某房产中介爬取业主信息案2019刑事案件

中介人员爬取链家、贝壳等平台的业主电话，用于推销骚扰并造成隐私泄露。依据《刑法》第253条之一「侵犯公民个人信息罪」，情节严重的可处 3 年以下有期徒刑——爬虫写得再好，也救不了越过刑法红线的人。

⚖️ 结果：涉案人员被刑事拘留

📁某高考志愿填报App泄露学生信息案2021侵犯公民个人信息罪

该 App 爬取考试院网站的学生数据并出售给培训机构。受害者是刚刚走出考场的学生，泄露的是最敏感的教育与联系信息。

⚖️ 结果：构成侵犯公民个人信息罪

📁Facebook—Cambridge Analytica 数据丑闻2018数据滥用

Cambridge Analytica 获取 8700 万 Facebook 用户数据，用于政治广告精准投放，影响 2016 年美国总统大选。天价罚单说明：数据合规不是道德倡议，而是真金白银的法律责任。

⚖️ 结果：Facebook 被罚款 50 亿美元

⚖️法律红线

《个人信息保护法》（2021）：第13条，收集个人信息需明示同意；第26条，医疗、金融等敏感信息需单独同意；第66条，违法最高罚款 5000 万元或上一年度营业额 5%。《数据安全法》（2021）：数据采集须合法、正当、必要，重要数据出境需安全评估。《刑法》第253条之一：非法获取公民个人信息，情节严重处 3 年以下有期徒刑。

🪪什么是「个人信息」

姓名、身份证号、电话、住址；指纹、人脸等生物识别信息；行踪轨迹、网络浏览记录；健康信息、财产信息——凡是能单独或与其他信息结合识别出特定自然人的，都受法律保护。

技术讲解

合规爬虫与普通爬虫的差别，从第一行请求头就开始了：表明身份、留下联系方式，而不是伪装成浏览器潜入。下面是本案例的核心代码——一个把隐私保护内建到每个方法里的爬虫类。

import requests
from bs4 import BeautifulSoup
import hashlib

class PrivacyAwareCrawler:
    """隐私保护爬虫：只取公开数据，敏感字段一律脱敏"""

    def __init__(self):
        self.session = requests.Session()
        self.session.headers.update({
            'User-Agent': 'EthicalCrawler/1.0 (Educational; Contact: xxx@edu.cn)'
        })

    def anonymize_phone(self, phone):
        """电话号码脱敏：138****5678"""
        if len(phone) == 11:
            return phone[:3] + '****' + phone[7:]
        return '***'

    def anonymize_email(self, email):
        """邮箱脱敏：z******n@example.com"""
        parts = email.split('@')
        if len(parts) == 2 and len(parts[0]) > 2:
            u = parts[0]
            return u[0] + '*' * (len(u) - 2) + u[-1] + '@' + parts[1]
        return '***'

    def hash_identifier(self, identifier):
        """不可逆哈希：用于统计去重，不存储原文"""
        return hashlib.sha256(identifier.encode()).hexdigest()

    def fetch_public_data(self, url):
        """仅抓取公开展示的内容"""
        response = self.session.get(url, timeout=10)
        soup = BeautifulSoup(response.text, 'html.parser')
        articles = []
        for item in soup.find_all('article'):
            articles.append({
                'title': item.find('h2').get_text(),
                'publish_date': item.find('time').get_text(),
                # 不抓作者联系方式，不抓评论者 IP
            })
        return articles

    def respect_privacy_settings(self, user_data):
        """尊重用户隐私设置：非公开信息不碰"""
        if not user_data.get('is_public', False):
            return None
        return {
            'username': user_data.get('username'),
            'bio': user_data.get('bio'),
            # 不包含 email、phone 等私密字段
        }

采集只是前半场，数据落盘同样有讲究。合规存储要求数据必须与元信息绑在一起：从哪来、做什么用、留多久、采取了哪些隐私措施。用逐行模拟观察 ComplianceDataStorage 的完整流程。

思政引导

⚖️法治意识· 合规不是选择题

  • 《个人信息保护法》确立四项原则：知情同意、最小必要、公开透明、数据安全——每一项都能落成代码里的一个函数。
  • 法律责任是阶梯式的：脉脉案是民事赔偿，房产中介案是刑事拘留，Facebook 案是 50 亿美元罚款——违法成本只会越来越高。
  • 敏感信息（医疗、金融）依据第26条须单独同意；违法处理个人信息依据第66条最高可罚 5000 万元或上一年度营业额 5%。

🧭职业伦理· 数据采集三问

  • 每次按下运行键之前先问三句：我有权采集这些数据吗（合法性）？用户知情并同意了吗（知情权）？我只采集必要的数据吗（最小化）？
  • 技术伦理三不原则：不因技术可行就采集一切，不因数据公开就随意使用，不因缺乏监管就心存侥幸。
  • 工程师的职业尊严，体现在爬虫 User-Agent 里那行敢于署名的联系方式上。

🤝社会责任· 泄露的数据会伤人

  • 数据泄露的下游是具体的伤害：电信诈骗精准掌握受害人信息、身份盗用冒名贷款、行踪泄露危及人身安全。
  • 弱势群体需要额外保护：14 岁以下儿童信息须监护人同意，老年人信息易被诈骗利用，患者的医疗隐私特别敏感。
  • 你写的每一行采集代码，都在决定这些风险是扩大还是收敛。

🌱人文素养· 换位思考与技术向善

  • 换位想一想：如果你的电话被泄露，每天接到 10 个骚扰电话；如果健康信息被公开，求职时遭遇歧视；如果行踪被跟踪，人身安全受到威胁——数据背后是人。
  • 技术向善有真实的路径：爬虫可以服务疫情数据汇总、环境监测等公益事业，但前提永远是不侵犯隐私。
  • 合法使用公开数据是正当的——学会合规，不是放弃技术，而是让技术走得更远。
