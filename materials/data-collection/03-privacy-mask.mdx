## 场景导入

社团纳新，你写了个小程序收集报名表：姓名、手机号、身份证号……表是攒起来了，可这份 Excel 一旦转发出去、随手丢在群里，就是一次实打实的信息泄露。与其事后补救，不如在**写入的那一刻**就把它脱敏：手机号只留号段和尾号，身份证藏掉中间的出生信息。这一节，我们用几行切片代码，给个人信息上一道最便宜的保险。

## 动手实验

仪表是演示，真正干活的是函数。`mask_phone` 和 `mask_id` 的核心就一招——字符串切片加拼接：留下两头有用的部分，中间统统换成星号。运行看看前后对照：

<PyPlayground
  client:visible
  title="手机号 / 身份证脱敏函数"
  note="把 mask_phone 改成只保留后 3 位，或自己加一个 mask_email 试试——一边改一边想：留多少，才算既够用又够安全。"
  code={`# 两个最常用的脱敏函数：切片 + 拼接，只在两头各留一小段
def mask_phone(phone):
    # 手机号 11 位：留前 3（号段）与后 4（尾号），中间 4 位打码
    return phone[:3] + "****" + phone[7:]

def mask_id(idcard):
    # 身份证 18 位：留前 6（地区）与后 4（含校验位），中间 8 位打码
    return idcard[:6] + "*" * 8 + idcard[-4:]

records = [
    ("手机号", "13812345678", mask_phone),
    ("手机号", "13998887766", mask_phone),
    ("身份证", "110101200601011234", mask_id),
    ("身份证", "310110199905053210", mask_id),
]

print("原文  →  脱敏后")
print("-" * 30)
for label, raw, fn in records:
    print(f"{label}  {raw}  →  {fn(raw)}")`}
/>

<DimCard dim="法治意识" title="《个保法》给采集划的红线">
  <ul>
    <li>《个人信息保护法》第51条：处理个人信息应采取去标识化、加密等安全技术措施——脱敏不是「加分项」，是法定义务。</li>
    <li>第66条：违法处理个人信息，最高可处五千万元、或上一年度营业额百分之五的罚款。合规的成本，远低于违规的代价。</li>
    <li>手机号、身份证号是能识别到个人的信息，采集要有明确目的，存储要有安全措施，两者缺一不可。</li>
  </ul>
</DimCard>

<DimCard dim="职业伦理" title="顺手脱敏，是一种专业默认">
