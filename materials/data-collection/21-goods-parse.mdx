## 场景导入

毕业设计选了个比价小程序，第一步要把电商列表页的商品解析成结构化数据。你信心满满写好 XPath，一跑却报错——原来有的商品没标价格、有的缺销量，页面「缺胳膊少腿」才是常态。真实世界的解析，一半是提取，一半是容错。

## 动手实验

综合挑战的核心不是「抓到」，而是「抓全还不崩」。思路是：先定位每张商品卡，再逐卡提取字段，遇到缺失就用条件容错兜底——

```python
# 容错三件套：取列表 → 判空 → 给默认值
price_nodes = card.xpath("./span[@class='price']/text()")
price = float(price_nodes[0]) if price_nodes else 0.0
```

下面是完整的列表页解析器，第 3、4 张卡故意「缺斤少两」，看它如何稳稳兜住。

  note="把第 2 张卡的 price 节点也删掉，再运行——看容错计数会不会变成 2，字典里的价格是不是都兜成了 0.0。"

  code={`from lxml import etree

# 内联电商列表页：4 张商品卡；第 3 张缺价格、第 4 张缺销量——残缺是常态
html = """
<div class="goods-list">
  <div class="card"><h3>机械键盘</h3><span class="price">299</span><em class="sold">1200</em></div>
  <div class="card"><h3>无线鼠标</h3><span class="price">89</span><em class="sold">3400</em></div>
  <div class="card"><h3>USB 集线器</h3><em class="sold">560</em></div>
  <div class="card"><h3>显示器支架</h3><span class="price">159</span></div>
</div>
"""

tree = etree.HTML(html)
cards = tree.xpath("//div[@class='card']")   # 先定位所有商品卡

goods, fixed = [], 0
for c in cards:
    name = c.xpath("./h3/text()")[0]                 # 名称必有，直接取
    price_nodes = c.xpath("./span[@class='price']/text()")
    if price_nodes:                                  # 条件容错：有才取
        price = float(price_nodes[0])
    else:
        price = 0.0                                  # 缺价格补默认，并计一次
        fixed += 1
    sold_nodes = c.xpath("./em[@class='sold']/text()")
    sold = int(sold_nodes[0]) if sold_nodes else 0   # 三元容错：缺销量记 0
    goods.append({"name": name, "price": price, "sold": sold})

for g in goods:
    print(g)
print("容错补默认值：", fixed, "处")`}
/>
