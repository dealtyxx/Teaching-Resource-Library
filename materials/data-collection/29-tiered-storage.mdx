## 动手实验

架构的核心是一个「分级路由」函数：读入每条数据的密级标签，自动决定它该明文直存、受控存储，还是加密加脱敏。下面这段代码给三类数据分派不同策略，并打印一张分级台账：

<PyPlayground
  client:visible
  title="分级存储路由器"
  note="把「学生健康档案」的 level 改成「公开」，看它如何被降级成明文直存——想想现实中一次错误的密级标注，会闯多大的祸。"
  code={`import hashlib

# 一批待入库的数据条目，各自带「密级标签」
items = [
    {"name": "选课手册", "level": "公开", "payload": "2024春选课指南"},
    {"name": "师生通讯录", "level": "内部", "payload": "王老师 13800001111"},
    {"name": "学生健康档案", "level": "敏感", "payload": "张三 身份证3201xxxx"},
]

def mask(text):
    """脱敏：只留头尾，中间打码"""
    return text[:2] + "***" + text[-1:] if len(text) > 3 else "***"

def route(item):
    """分级路由：按密级决定存储策略"""
    lv = item["level"]
    if lv == "公开":
        return "开放库(明文)", item["payload"]
    if lv == "内部":
        return "受控库(限校内访问)", item["payload"]
    # 敏感数据：加密指纹 + 脱敏，且须境内存储
    digest = hashlib.sha256(item["payload"].encode()).hexdigest()[:12]
    return "加密库(境内/脱敏)", f"{mask(item['payload'])} #sha256:{digest}"

print("=== 分级存储台账 ===")
for it in items:
    store, saved = route(it)
    print(f"[{it['level']}] {it['name']}")
    print(f"    -> 存入 {store}")
    print(f"    -> 落库内容：{saved}")`}
/>

## 思政会客厅

<DimCard dim="数据主权" title="重要数据，境内存储">
  <ul>
    <li>数据不只是 0 和 1。人口、地理、健康、关键基础设施的数据事关国家安全——它存在哪个国家的服务器上，就可能受哪个国家的法律管辖。</li>
    <li>《数据安全法》确立数据分类分级保护制度：重要数据要评估、要备案，出境更要过安全审查。分级路由里那句「境内存储」，正是这一制度的代码投影。</li>
    <li>数据主权是国家主权在数字空间的延伸。守住重要数据，就是守住数字时代的国门。</li>
  </ul>
</DimCard>

<DimCard dim="社会责任" title="密级标错，代价是别人的安全">
  <ul>
    <li>把敏感数据当公开数据存，泄露的是一个个真实的人：他们的住址、健康、行踪。架构师的一次偷懒，可能变成千万人的风险。</li>
    <li>分级、加密、脱敏、备份，每一道工序都在替数据主体承担责任。技术能力越大，越要敬畏手里的数据。</li>
    <li>好的数据治理不是为了应付检查，而是让「把数据用好」和「把人保护好」这两件事同时成立。</li>
  </ul>
</DimCard>

<Callout icon="⚖️" tone="red" title="《数据安全法》第二十一条">
国家建立数据分类分级保护制度，根据数据在经济社会发展中的重要程度，以及一旦遭到篡改、破坏、泄露或者非法获取、非法利用，对国家安全、公共利益或者个人、组织合法权益造成的危害程度，对数据实行分类分级保护。对关系国家安全的重要数据实行更严格的管理——这正是「分级存储」的法律源头。
</Callout>
