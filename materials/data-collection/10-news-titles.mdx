## 动手实验

游戏里靠手点，工程里靠代码点。下面这段代码先用 `find()` 取回头条，再用 `find_all()` 一次性抓下所有 h2 标题，打印成编号清单——这就是「批量提取」的核心三步：建对象、定标签、取文本。

<PyPlayground
  client:visible
  title="新闻标题批量提取器"
  height={340}
  packages={['beautifulsoup4']}
  note="试着把 find_all('h2') 改成 find_all('h2', class_='title') 做精确匹配，或往 html 里再加一条标题后重新运行，看看编号清单怎么变。"
  code={`from bs4 import BeautifulSoup

# 内联的新闻列表 HTML —— 真实工程里，它来自 requests 抓回的网页源码
html = """
<div class="news-list">
  <h2 class="title">校运会开幕：三千学子同赛场</h2>
  <h2 class="title">图书馆本周起延长开放至午夜</h2>
  <h2 class="title">我校团队获全国数据竞赛金奖</h2>
  <h2 class="title">食堂上新：周六举办秋季美食节</h2>
</div>
"""

# 第一步：把 HTML 文本「煮」成一锅可查询的汤（BeautifulSoup 对象）
soup = BeautifulSoup(html, "html.parser")

# 第二步：find() 只取第一个匹配，先瞧瞧头条
first = soup.find("h2")
print("头条：", first.get_text(strip=True))

# 第三步：find_all() 一次取回所有 h2，批量提取标题
titles = soup.find_all("h2")
print(f"共抓到 {len(titles)} 条标题：")
for i, h2 in enumerate(titles, start=1):
    print(f"  {i}. {h2.get_text(strip=True)}")`}
/>
