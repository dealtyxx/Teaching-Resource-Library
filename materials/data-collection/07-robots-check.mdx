## 场景导入

爬虫拿到 URL 就冲？慢——先看门口的告示牌。几乎每个网站的根目录都放着一份 `robots.txt`（例如 `https://example.com/robots.txt`），用几行朴素文本宣告：哪些路径欢迎抓取、哪些谢绝来访、对哪个爬虫另有约法。它没有密码、没有防火墙，技术上拦不住任何人——但在法庭上，它是被反复引用的「行业规矩」。这一课，我们让代码替你读懂它、遵守它。

## 动手实验

裁判当熟了，就让标准库替你值班。`urllib.robotparser` 是 Python 自带的 robots 裁判，无需安装任何第三方包。真实环境里它自己上网读协议：

```python
# 真实环境：裁判自己去读站点的 robots.txt
from urllib.robotparser import RobotFileParser

rp = RobotFileParser()
rp.set_url("https://www.example.com/robots.txt")
rp.read()                                  # 发起真实请求读取协议
print(rp.can_fetch("study-bot", "https://www.example.com/news/1.html"))
```

在沙箱里我们用 `parse()` 直接喂入一份内联的 robots.txt 文本，判决逻辑完全一样——批量审查一份抓取计划：

<PyPlayground
  client:visible
  title="Robots 合规校验器"
  note="试着在通配组里加一行 Disallow: /search，再往 plans 里添一条 study-bot 访问 /search 页面的计划，看判决怎么变。"
  code={`# 标准库自带的 robots 裁判：urllib.robotparser
from urllib.robotparser import RobotFileParser

# 内联一份 robots.txt（相当于从 https://example-news.cn/robots.txt 读到的内容）
robots_txt = """User-agent: *
Disallow: /admin/
Disallow: /user/
Allow: /news/
Crawl-delay: 2

User-agent: bad-bot
Disallow: /
"""

rp = RobotFileParser()
rp.parse(robots_txt.splitlines())   # 喂入文本行，不发任何网络请求

# 待审查的抓取计划：(爬虫身份 User-Agent, 目标 URL)
plans = [
    ("study-bot", "https://example-news.cn/news/20260721.html"),
    ("study-bot", "https://example-news.cn/admin/login"),
    ("study-bot", "https://example-news.cn/user/10086/profile"),
    ("bad-bot",   "https://example-news.cn/news/20260721.html"),
]

print("=== Robots 合规判决书 ===")
for ua, url in plans:
    verdict = "可以抓取 ✅" if rp.can_fetch(ua, url) else "禁止抓取 ⛔"
    print(f"[{verdict}] UA={ua}  ->  {url}")

# 别漏了礼貌条款：两次请求至少间隔几秒？
print(f"\\n站点要求的 Crawl-delay：{rp.crawl_delay('study-bot')} 秒")`}
/>

把 `can_fetch()` 放在每个请求发出之前，返回 False 就一票否决——这一行 if，就是你的爬虫与麻烦之间的隔离带。

## 思政会客厅

<DimCard dim="法治意识" title="从君子协定到裁判文书">
  <ul>
    <li>Robots 协议 1994 年由工程师社区自发提出，是互联网最早的「君子协定」之一；我国司法实践普遍将其认定为内容行业公认的商业道德。</li>
    <li>违反 robots 不必然违法，但「无视告示牌 + 替代性使用他人内容」的组合，多次被法院依《反不正当竞争法》认定为不正当竞争。</li>
    <li>合规的正确姿势是写进代码：请求发出之前先 can_fetch，禁止就不抓——让程序替你守住底线，比事后解释可靠得多。</li>
  </ul>
</DimCard>
