## 场景导入

毕业季，你想做一个「数据岗位薪资地图」。招聘页上每张职位卡都是一个嵌套小宇宙：标题里套着链接，公司名旁边挂着融资阶段，薪资藏在 span 里，技能标签是一串 li。这一战要把本模块所学全部用上——`find_all` 拿卡片、Tag 属性取链接、`select` 精准掏薪资，最后输出规范的 JSON。这也是你与 BeautifulSoup 的「毕业答辩」。

## 动手实验

放大到「整页」：三张卡（其中一张缺薪资），全量解析 + 容错 + JSON 结构化输出：

<PyPlayground
  client:visible
  title="全量采集：嵌套解析 + 容错 + JSON 输出"
  packages={['beautifulsoup4']}
  height={340}
  note="试着再添一张缺 tags 的卡片，看容错逻辑是否稳住；或把输出改成只保留 15K 以上的岗位。"
  code={`from bs4 import BeautifulSoup
import json

html = """
<div class='job-card'>
  <h3><a href='/job/1'>数据采集工程师</a></h3>
  <span class='salary'>15-25K</span>
  <ul class='tags'><li>Python</li><li>爬虫</li></ul>
</div>
<div class='job-card'>
  <h3><a href='/job/2'>数据分析师</a></h3>
  <span class='salary'>12-20K</span>
  <ul class='tags'><li>SQL</li><li>可视化</li></ul>
</div>
<div class='job-card'>
  <h3><a href='/job/3'>实习生-数据标注</a></h3>
  <ul class='tags'><li>细心</li></ul>
</div>"""

soup = BeautifulSoup(html, 'html.parser')
jobs = []
miss = 0
for card in soup.find_all('div', class_='job-card'):
    s = card.select_one('.salary')          # 可能缺失
    if s is None:
        miss += 1
    jobs.append({
        "title": card.h3.a.get_text(),
        "link": card.h3.a['href'],
        "salary": s.get_text() if s else "面议",
        "tags": [li.get_text() for li in card.select('ul.tags li')],
    })

print(json.dumps(jobs, ensure_ascii=False, indent=2))
print(f"共 {len(jobs)} 岗，其中 {miss} 岗缺薪资已容错为「面议」")`}
/>
