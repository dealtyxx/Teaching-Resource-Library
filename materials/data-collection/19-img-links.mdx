## 场景导入

社团要办一面「校园活动海报墙」，你负责把各院系官网的活动海报图片「搬」过来。图片地址都藏在 `img` 标签的 `src` 属性里，几十张一张张复制太慢——XPath 的 `@` 属性提取正为此而生：一行 `//img/@src`，所有链接尽入囊中。但「抓得到」不等于「用得了」，这中间隔着两个字：版权。

## 动手实验

`//img/@src` 负责「全都抓到」，谓语 `[@license='cc']` 负责「挑出能用的」。下面这个提取器把图片分成「可复用」与「需授权」两栏——采集的同时，先把版权分好类。

<PyPlayground
  client:visible
  title="图片链接分流提取器"
  note="把某张 img 的 license 从 cc 改成 all-rights，或给没有 license 的图片补上 cc，再运行——看看两栏清单怎么变。"
  packages={['lxml']}
  height={360}
  code={`from lxml import etree

# 内联一个图库页面：每张图片带 src，部分标注了 license 授权协议
gallery = """
<gallery>
  <img src="sunset.jpg" license="cc"/>
  <img src="logo_brand.png" license="all-rights"/>
  <img src="flow_chart.svg" license="cc"/>
  <img src="poster_movie.jpg"/>
  <img src="icon_open.png" license="cc"/>
</gallery>
"""

# 内联 XML 用 etree.XML 解析
tree = etree.XML(gallery)

# @属性提取：//img/@src 一次抓到所有图片地址
all_src = tree.xpath("//img/@src")
print("共发现图片：", len(all_src), "张")
print()

# 谓语 [@license='cc'] 只留标注 CC 协议、可复用的图片
reusable = tree.xpath("//img[@license='cc']/@src")

print("【可复用 · CC 协议】")
for s in reusable:
    print("  可用   ", s)
print()

print("【需授权 · 勿直接商用】")
for s in all_src:
    if s not in reusable:
        print("  需授权 ", s)`}
/>

## 思政会客厅

<DimCard dim="法治意识" title="抓得到，不等于用得了">
  <ul>
    <li>图片是受《著作权法》保护的作品。爬虫技术上能批量下载，不代表法律上能随意商用——「技术可行」与「法律许可」是两码事。</li>
    <li>能不能用，要看授权：有没有标注可复用协议？是否要求署名？用于商业还是仅供学习？采集前先读「许可证」，是数据工程师的职业底线。</li>
  </ul>
</DimCard>

2019 年 4 月，人类首张黑洞照片发布当天，视觉中国将其纳入版权图库、标注「商用需授权」；随后国旗、国徽等图片也被指挂上版权标签，舆论哗然。事件把「图片版权到底归谁、维权的边界在哪」推成了公共议题——保护版权天经地义，滥用「维权」同样越界。
</CaseFileCard>

<DimCard dim="开源共享" title="CC 协议：开放世界的礼物">
  <ul>
    <li>知识共享（Creative Commons，简称 CC）协议，让创作者主动讲清「我的作品你可以怎么用」——署名 BY、相同方式共享 SA、非商业 NC 等条款自由组合。</li>
    <li>维基百科的配图、海量开源素材都采用 CC 协议。善用 license 标注去筛选可复用资源，既高效又体面：站在别人「开放」的肩膀上，也别忘了回馈开放。</li>
  </ul>
</DimCard>
