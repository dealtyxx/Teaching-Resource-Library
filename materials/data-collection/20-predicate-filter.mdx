## 场景导入

上个项目你学会了「把图片全抓下来」，但师姐提醒你一句：「别什么都抓，服务器会烦，你也用不完。」真正的高手采集像做外科手术——只取需要的那几个节点。XPath 的谓语（写在方括号里的条件）就是手术刀：价格高于 50 的、排在前两位的、既是中文又便宜的……想要哪些，说清楚，一次命中。

## 动手实验

同一个书店，三种诉求：「贵的」「靠前的」「又中文又便宜的」。看谓语怎么把「全都要」翻译成「只取所需」。

<PyPlayground
  client:visible
  title="三组谓语对比筛选"
  note="试着把第三组谓语改成 //book[@lang='en' or price>60]，把 and 换成 or，看命中结果多了哪几本。"
  packages={['lxml']}
  height={340}
  code={`from lxml import etree

# 内联书店 XML：每本书带 lang 属性、书名与价格
xml = """
<bookstore>
  <book lang="zh"><title>数据采集实战</title><price>45</price></book>
  <book lang="zh"><title>Python 之道</title><price>68</price></book>
  <book lang="en"><title>Web Scraping</title><price>52</price></book>
  <book lang="zh"><title>数据之美</title><price>39</price></book>
</bookstore>
"""

tree = etree.XML(xml)

def names(nodes):
    # 把命中的 book 节点转成书名列表，方便对比
    return [b.findtext("title") for b in nodes]

# 谓语一：价格高于 50（子节点值比较）
q1 = tree.xpath("//book[price>50]")
# 谓语二：position() 取前两本（位置筛选）
q2 = tree.xpath("//book[position()<=2]")
# 谓语三：多条件 and 组合（中文书且价格低于 60）
q3 = tree.xpath("//book[@lang='zh' and price<60]")

print("价格高于 50         →", names(q1))
print("排在前两位          →", names(q2))
print("中文书且价格低于 60 →", names(q3))`}
/>

## 思政会客厅

<DimCard dim="职业伦理" title="最小采集：不多拿一个节点">
  <ul>
    <li>谓语让采集从「全都要」变成「只取所需」。技术上你能用 //* 抓走整棵树，但职业伦理要求你只取与目的直接相关的那部分。</li>
    <li>「最小必要」不是能力不足，而是专业克制。多拿的每一个节点，都是多一分存储成本、多一分合规风险、多一分对他人系统的打扰。</li>
  </ul>
</DimCard>

<Callout icon="⚖️" tone="gold" title="最小必要原则">
《个人信息保护法》第六条要求：收集个人信息应限于「实现处理目的的最小范围」，不得过度收集。谓语表达式，正是这条法律原则在代码里的模样——先想清楚「要什么」，再动手「取什么」。
</Callout>
