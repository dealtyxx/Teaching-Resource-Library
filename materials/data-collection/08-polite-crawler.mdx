## 动手实验

真实环境里，礼貌三件套的标准写法如下（本机运行）：

```python
# 真实环境的礼貌三件套（先 pip install requests）
import time
import requests

urls = ["https://jwc.example.edu/notice/2026-001.html"]   # 待抓清单

session = requests.Session()                  # Session 复用 TCP 连接，本身就在给对方减负
session.headers.update({
    "User-Agent": "campus-bot/1.0 (contact: you@campus.edu)",   # 亮明身份，可被联系
})

for url in urls:
    resp = session.get(url, timeout=(3.05, 10))   # (连接超时, 读取超时)：不死等
    print(resp.status_code, url)
    time.sleep(3)                                 # 固定间隔——深夜也不例外
```

class PoliteCrawler:
    def __init__(self, name, contact, interval=3.0, timeout=5.0):
        # 请求头亮明身份：我是谁、有事怎么联系我
        self.headers = {
            "User-Agent": f"{name}/1.0 (contact: {contact})",
            "Accept": "text/html",
        }
        self.interval = interval    # 相邻两次请求的最小间隔（秒）
        self.timeout = timeout      # 单次请求最长等待（秒）

    def plan(self, urls):
        """输出访问计划（真实版把打印换成 requests.Session 的 get）"""
        print("== 职业装备检查 ==")
        print(f"身份头  {self.headers['User-Agent']}")
        print(f"超时    {self.timeout}s（拿不到响应就体面退出）")
        print(f"间隔    {self.interval}s（给服务器留出喘息）")
        print("-" * 46)
        clock = 0.0
        for i, url in enumerate(urls, 1):
            if i > 1:
                clock += self.interval      # 到点才发下一发
            print(f"t={clock:4.1f}s  第{i}次访问 -> {url}")
        print("-" * 46)
        print(f"共 {len(urls)} 页，全程约 {clock:.1f} 秒：慢一点，路更长。")

bot = PoliteCrawler("campus-bot", "you@campus.edu", interval=3.0, timeout=5.0)
bot.plan([
    "https://jwc.example.edu/notice/2026-001.html",
    "https://jwc.example.edu/notice/2026-002.html",
    "https://jwc.example.edu/notice/2026-003.html",
])`}

## 思政会客厅

<DimCard dim="职业伦理" title="三件装备，三种教养">
  <ul>
    <li>User-Agent 亮明身份是「敢署名」：匿名与伪装的心态本身就是风险信号；写上联系方式，站长有疑问能直接找到你。</li>
    <li>请求间隔是「不插队」：服务器算力是共享资源，你多占一分，正常用户就慢一分；robots 里的 Crawl-delay 优先于你自己的默认值。</li>
    <li>超时控制是「不纠缠」：拿不到响应就体面退出并记录，而不是挂着连接耗双方的资源，更不是立刻疯狂重发。</li>
  </ul>
</DimCard>

<DimCard dim="社会责任" title="你的对面是无数普通人">
  <ul>
    <li>教务网背后是全校的选课与成绩查询，公交接口背后是站台上等车的乘客——压垮服务器，伤害的从来不只是「网站」。</li>
    <li>单个爬虫全速跑似乎无伤大雅，规模化之后效果与拒绝服务攻击无异。工程师必须为代码的外部性负责。</li>
    <li>真正的高手先找官方渠道：开放 API、数据集下载、管理员授权——很多采集问题的最优解，根本不是「爬」。</li>
  </ul>
</DimCard>

<Callout icon="⚖️" tone="red" title="《网络安全法》第二十七条">
任何个人和组织不得从事非法侵入他人网络、干扰他人网络正常功能、窃取网络数据等危害网络安全的活动。高频轰炸把对方服务拖慢甚至拖垮，就可能落入「干扰他人网络正常功能」的范畴——限速不只是礼貌，更是法律底线。
</Callout>
