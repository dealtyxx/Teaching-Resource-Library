## 动手实验

一行手机号正则，拆开看其实很有条理：

```python
# 手机号正则拆解： r'1[3-9]\d{9}$'
#   1        第一位固定是 1
#   [3-9]    字符集：第二位只能是 3 到 9
#   \d       匹配一个数字（0-9）
#   {9}      数量词：让前面的 \d 再重复 9 次
#   $        结尾锚点：整串到此为止，多一位少一位都不行
```

`re.match` 从字符串开头匹配，再加上结尾锚点，就要求「整串」恰好是 11 位合法号码。下面这个校验器先用简单检查给出友好原因，最后交给正则做权威判定——改改 `numbers` 列表，看它判得准不准：

<PyPlayground
  client:visible
  title="手机号批量校验器"
  note="把正则里的 [3-9] 改成 [0-9]，再运行——原本被拒的 12345678901 就混了进来，这就是号段边界的意义。"
  code={`import re

# 手机号规则：第一位1，第二位3-9，其后9位数字，整串共11位
PATTERN = r'1[3-9]\\d{9}$'

def check(num):
    """校验单个号码，返回（是否通过, 原因）"""
    s = num.strip()
    if not s.isdigit():
        return False, "含非数字字符"
    if len(s) != 11:
        return False, f"长度{len(s)}位（应为11位）"
    if re.match(PATTERN, s):
        return True, "格式正确"
    return False, "首位或号段不符（须1开头、第二位3-9）"

numbers = ["13812345678", "15987654321", "12345678901",
           "1381234567", "008613812345678", "138-1234-5678"]

for n in numbers:
    ok, why = check(n)
    mark = "通过" if ok else "拒绝"
    print(f"[{mark}] {n.ljust(16)} {why}")`}
/>

## 思政会客厅

<DimCard dim="科研诚信" title="严谨是第一美德">
  <ul>
    <li>一条看似简单的手机号规则，却是数据入口的第一道闸门。写规则时多问一句「边界在哪」，胜过事后清洗一万条脏数据。</li>
    <li>校验不是刁难用户，而是对数据质量负责：错误号码会让验证码、回访、通知全部失效，源头把关就是诚信。</li>
    <li>别用「差不多能跑」交差。忘了结尾锚点，12 位、13 位的假号也可能被放过——魔鬼藏在你没测到的边界里。</li>
  </ul>
</DimCard>

<Callout icon="🎯" tone="gold" title="十环法则">
正则靶场里，「全中目标、零误伤」才算十环。工程里也一样：既不放过一个真号，也不错杀一个用户。所谓严谨，就是让规则刚好贴合真实。
</Callout>
