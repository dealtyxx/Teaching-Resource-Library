## 场景导入

运营同学甩给你一份 20 天的日销量表：大部分都在 100 件上下，唯独有一天写着 160、还有一天只有 40。是真的爆单和停摆，还是录入手抖多打了个零？在把这份数据交给老板做决策前，你得先把这些「扎眼的点」找出来——但找出来之后，是删，还是留？这一步的选择，藏着一个数据工程师的底色。

## 动手实验

这个过滤器先用 `statistics` 算出均值和标准差，画出「均值加减 3 倍标准差」的正常区间，再把落在区间外的可疑点搬进 `quarantine` 隔离列表——而不是从原始数据里删掉。最后打印清洗前后的统计对照与隔离清单：

<PyPlayground
  client:visible
  title="3σ 异常值过滤器：标记、隔离、不删除"
  height={340}
  note="把第 16 天的 40 改成 95，观察它如何从『隔离清单』里消失——是否异常，取决于一个点离群有多远，而不是我们喜不喜欢它。"
  code={`import statistics

# 20 天日销量（件）——第 10 天与第 16 天混入了可疑值
sales = [100, 102, 99, 101, 98, 103, 100, 97, 101, 160,
         99, 102, 100, 98, 101, 40, 100, 99, 102, 98]

def three_sigma(data):
    """用 3σ 原则算出正常区间边界"""
    mu = statistics.mean(data)
    sd = statistics.pstdev(data)          # 总体标准差
    return mu, sd, mu - 3 * sd, mu + 3 * sd

mu0, sd0, lo, hi = three_sigma(sales)
print(f"清洗前：均值={mu0:.1f}  标准差={sd0:.1f}")
print(f"3σ 正常区间：[{lo:.1f}, {hi:.1f}]")

kept, quarantine = [], []                 # 正常值 / 隔离区
for i, v in enumerate(sales):
    if v < lo or v > hi:
        quarantine.append((i + 1, v))     # 记下位置与原值，留待人工复核
    else:
        kept.append(v)

print("\\n隔离清单（第几天 → 原值，仅隔离不删除）：")
for day, v in quarantine:
    print(f"   第{day}天：{v} 件（超出 3σ，已隔离）")

mu1, sd1 = statistics.mean(kept), statistics.pstdev(kept)
print(f"\\n清洗后（仅统计正常值）：均值={mu1:.1f}  标准差={sd1:.1f}")
print(f"原始 {len(sales)} 条 = 正常 {len(kept)} 条 + 隔离 {len(quarantine)} 条，一条都没丢")`}
/>

## 思政会客厅

<DimCard dim="科研诚信" title="清洗是标记与隔离，不是删除与篡改">
  <ul>
    <li>异常值可能是错误，也可能是罕见的真相（比如一次真实的爆单）。一删了之，等于替数据「做了判决」——而你可能判错。</li>
    <li>正确姿势：把可疑值移进隔离区 quarantine，记录位置与原值，留待人工复核；原始 20 条一条不少。</li>
    <li>「删数据凑结论」和「标记隔离可复核」，代码上只差一个 append，诚信上却是南辕北辙的两条路。</li>
  </ul>
</DimCard>

<DimCard dim="法治意识" title="数据造假，规则零容忍">
  <ul>
    <li>《科研诚信案件调查处理规则》(2023) 对伪造、篡改数据等科研失信行为明确零容忍，一经查实即追责。</li>
    <li>合理清洗（有依据、可复核、原件保留）与数据造假（选择性删改、粉饰结论）的边界，就在于「过程是否透明、可追溯」。</li>
  </ul>
</DimCard>

<Callout icon="📉" tone="amber" title="撤稿背后的普遍教训">
国内外都有论文因数据经不起复核而被撤稿。教训惊人地一致：出问题的往往不是「算错了」，而是「为了一个好看的结论，把不听话的数据悄悄删掉了」。标记与隔离让每一步都可回溯，正是抵御这种诱惑的技术护栏。
</Callout>
