## 场景导入

实习第一周，导师发来一个「小活」：客服工单要交给外包团队做质检分析，但工单文本里散落着用户手机号、身份证号、邮箱。「把敏感信息全部脱敏，一条都不能漏。」手工找？一万条工单会看瞎眼。这正是正则模块的毕业设计——用**多模式规则引擎**让机器自动识别、自动打码，让「合规」变成一个可以被调用的函数。

## 动手实验

现在造出真正的规则引擎：模式列表驱动，逐条扫描、分类打码、输出审计统计——这就是企业脱敏中间件的雏形：

<PyPlayground
  client:visible
  title="多模式脱敏规则引擎"
  height={340}
  note="试着往 ticket 里再塞一个新手机号或邮箱，或给 RULES 增加一条「QQ号」规则（5-11位数字），看引擎能否自动接管。"
  code={`import re

# 规则引擎：名称 + 识别模式 + 脱敏函数，可持续扩展
RULES = [
    ("手机号", re.compile(r"1[3-9]\\d{9}"),
     lambda m: m.group()[:3] + "****" + m.group()[7:]),
    ("身份证", re.compile(r"\\d{17}[\\dXx]"),
     lambda m: m.group()[:6] + "********" + m.group()[14:]),
    ("邮箱", re.compile(r"[\\w.]+@[\\w.]+\\.[a-zA-Z]{2,}"),
     lambda m: m.group()[0] + "***@" + m.group().split("@")[1]),
]

ticket = """工单#8801 用户王女士来电 13812345678 反馈快递丢失，
登记身份证 110101199001011234 用于理赔，
回执发送至 wang.lady@example.com，请尽快处理。"""

masked = ticket
stats = {}
for name, pattern, fn in RULES:
    masked, n = pattern.subn(fn, masked)
    stats[name] = n

print("=== 脱敏后工单 ===")
print(masked)
print()
print("=== 审计统计 ===")
for name, n in stats.items():
    print(f"{name}: 命中并脱敏 {n} 处")
print("原文仅在授权系统内留存，外发版本零明文。")`}
/>
