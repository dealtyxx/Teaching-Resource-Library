## 场景导入

学校要做一份「毕业生就业质量报告」，就业办给了一张表（字段叫 `tel`、薪资单位是「千元/月」），校友会给了另一张（字段叫 `手机号`、薪资是「元/月」），两表还都带着身份证号。把它们合成一张标准表只是技术活的一半——另一半是判断：**做就业统计，根本用不到手机号和身份证**。集成的第一步，是决定哪些字段不该进来。

## 动手实验

完整版：两个部门各两行数据，含时效校验与「丢弃审计」——每个被裁掉的字段都要说明理由：

<PyPlayground
  client:visible
  title="多部门集成流水线：对齐 + 归一 + 最小化 + 审计"
  height={340}
  note="试着把 CUTOFF 改成 2026 看时效校验如何拦下旧数据；或往 KEEP 里加回 phone，体会「技术上一行代码，合规上一个决定」。"
  code={`FIELD_MAP = {"tel": "phone", "手机号": "phone", "薪资元": "salary",
             "salary_k": "salary", "行业": "industry", "城市": "city"}
KEEP = ["city", "industry", "salary", "year"]   # 最小化白名单
DROP_REASON = {"phone": "统计用不到联系方式", "id_card": "身份证与就业统计无关"}
CUTOFF = 2025                                    # 时效：只要近一年的

dept_a = [  # 就业办：千元薪资
    {"tel": "13812345678", "salary_k": 15, "城市": "杭州", "行业": "互联网", "year": 2025},
    {"tel": "15987654321", "salary_k": 9,  "城市": "成都", "行业": "制造业", "year": 2023},
]
dept_b = [  # 校友会：元薪资 + 身份证
    {"手机号": "13611112222", "薪资元": 12000, "城市": "西安",
     "行业": "教育", "year": 2025, "id_card": "610101200001011234"},
]

rows, dropped, expired = [], {}, 0
for raw in dept_a + dept_b:
    std = {FIELD_MAP.get(k, k): v for k, v in raw.items()}
    if "salary_k" in raw:                        # 单位归一化
        std["salary"] = raw["salary_k"] * 1000
    if std.get("year", 0) < CUTOFF:              # 时效校验
        expired += 1
        continue
    for k in list(std):                          # 最小化裁剪 + 审计
        if k not in KEEP:
            dropped[k] = DROP_REASON.get(k, "不在业务必需清单")
            del std[k]
    rows.append(std)

print("标准表：")
for r in rows:
    print(" ", r)
print(f"时效淘汰 {expired} 行（早于 {CUTOFF}）")
print("裁剪审计：")
for k, why in dropped.items():
    print(f"  丢弃字段 {k}：{why}")`}
/>

## 思政会客厅

<DimCard dim="职业伦理" title="集成的第一问：这个字段该不该进来">
  <ul>
    <li>白名单（KEEP）优于黑名单：默认不进，必需才进——把最小化原则做成数据结构。</li>
    <li>丢弃要留审计：每个被裁字段写明理由，未来复盘时「为什么没有手机号」有据可查。</li>
    <li>单位、字段名的混乱是常态，标准化的耐心正是数据工程师的基本功。</li>
  </ul>
</DimCard>

<DimCard dim="法治意识" title="最小化不是美德，是法定原则">
  <ul>
    <li>《个人信息保护法》第6条：收集个人信息应当限于实现处理目的的最小范围——就业统计拿身份证号即属超范围。</li>
    <li>部门间共享数据同样受法律约束：内部流转不等于随意流转。</li>
    <li>时效校验也有合规含义：超过保存期限的个人信息应当删除或匿名化。</li>
  </ul>
</DimCard>
