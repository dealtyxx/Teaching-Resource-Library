## 场景导入

实验室师姐把她整理的《校园食堂菜价数据集》发给你，开头一行写着：「来源: 2024 秋实地采集 ｜ 许可: CC-BY-4.0 ｜ 引用请注明」。这行不起眼的注释，正是开源数据的通行证。这一课你将用 csv 模块读写数据集，并养成一个共享时代的好习惯：**接收数据先看清许可，发布数据要写明出处**。

## 动手实验

下面用 io.StringIO 在内存里「造」一个带许可声明的 CSV 数据集，再用 csv.reader 原样读回。注意首行的 `#` 注释——它让每一份被转发的数据都能追溯到源头：

<PyPlayground
  client:visible
  title="带许可声明的 CSV 存取"
  note="把首行许可换成 CC-BY-NC（禁止商用）或 CC0（放弃权利），想想不同许可分别允许别人怎么使用你的数据。"
  code={`import csv, io

# 用内存缓冲区模拟一个 .csv 文件（Pyodide 不写真实磁盘）
buf = io.StringIO()
writer = csv.writer(buf)

# 首行：数据集「身份证」——来源与开源许可，随数据一起流转
writer.writerow(["# 来源: 2024秋校园食堂实地采集 | 许可: CC-BY-4.0 | 引用请注明"])
# 表头：清晰的列名是数据可用的前提
writer.writerow(["档口", "菜名", "价格", "份量克"])
# 数据行
rows = [
    ["一楼川湘", "糖醋排骨", "12.0", "260"],
    ["二楼面档", "牛肉拉面", "10.0", "400"],
    ["三楼粤式", "白切鸡", "15.0", "220"],
]
writer.writerows(rows)

# 拿到完整的 CSV 文本
text = buf.getvalue()
print("=== CSV 文件内容 ===")
print(text)

# 回读：把文本当文件解析
reader = csv.reader(io.StringIO(text))
license_line, header, *data = list(reader)

print("许可声明：", license_line[0])
print("表头字段：", header)
print(f"共读到 {len(data)} 条菜价记录：")
for r in data:
    print(f"  {r[0]} - {r[1]}：{r[2]} 元 / {r[3]}g")
print("\\n引用示例：数据来自《校园食堂菜价数据集》(CC-BY-4.0)，转载请署名。")`}
/>

## 思政会客厅

<DimCard dim="开源共享" title="用数据要引用，分享要标许可">
  <ul>
    <li>开源数据集不是「免费白拿」：CC-BY 要求署名，CC-BY-NC 禁止商用，CC0 才是真正放弃权利。用之前先读懂许可，是对贡献者的基本尊重。</li>
    <li>你发布数据时也一样——在首行写清来源、采集时间与许可，别人才敢放心引用、放心复现。一句注释，把「数据孤岛」连成「知识网络」。</li>
    <li>Linux、维基百科、无数公开数据集都建立在「我贡献、你署名、共同生长」的契约上。共享不是慷慨，而是让知识高效流动的制度。</li>
  </ul>
</DimCard>

<Callout icon="📜" tone="blue" title="CC 许可速记">
CC-BY：署名即可用 ｜ CC-BY-SA：署名且以相同许可分享 ｜ CC-BY-NC：署名且禁止商用 ｜ CC0：放弃权利、随便用。看懂这几个后缀，你就拿到了开源世界的通行证。
</Callout>
