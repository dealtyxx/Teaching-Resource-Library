## 场景导入：不知道要转几圈的循环

for 循环适合"转固定圈数"；但猜数字要转几圈？**没人知道**——可能 1 次猜中，也可能 10 次。
这种"重复到某个事件发生为止"的场景，属于 `while` 的领地。最经典的写法是：

```c
while (1) {        /* 条件恒真：靠 break 退出 */
    /* 猜一次、判一次 */
    if (猜中) break;   /* 唯一出口 */
}
```

`while(1) + break` 是嵌入式开发的"国民写法"——北斗接收机的主程序，本质就是一个永不停歇的 `while(1)`，靠事件驱动内部逻辑。
