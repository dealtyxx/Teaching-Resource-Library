## 场景导入：屏幕上的"中"字从哪里来

火车站的 LED 大屏、电梯楼层显示器、单片机上的 OLED——它们显示汉字的原理惊人一致：**点阵字模**。

一个 16×16 的汉字 = 256 个"亮/灭" = 256 个比特 = **32 字节**。C 语言的存法极其紧凑：

```c
const uint16_t font[16];   /* 16行,每行1个uint16管16盏灯 */
```

第 r 行第 c 列亮不亮？一个表达式解决：

```c
int on = (font[r] >> (15 - c)) & 1;
```

右移把目标位挪到最低位，`& 1` 把它"抠"出来——这叫**位映射**。本项目是模块四的收官：二维结构（16 行）、一维数组（font[16]）、嵌套循环（逐行逐列扫描）、位运算初体验，全部会师。

1. **手写基础版**：用给定的"中"字模数组，双层循环在控制台打出汉字（`█` 与空格）。先手算一行：0x7FFE 有几位是 1？

3. **信创加固定稿版**：把字模声明为 `const`（放 Flash 不占 RAM——嵌入式黄金习惯）；支持反显、放大 2 倍（每个比特画 2×2）；思考 8000 个汉字的 HZK16 字库占多少空间（8000×32=250KB），如何按 GB2312 区位码索引（第 12 章文件操作的伏笔）。

## 素养与思政

上世纪 70 年代，计算机处理不了汉字，有人断言"计算机是汉字的掘墓人"。王选院士团队用**字形压缩+高速还原**技术实现汉字激光照排，让"告别铅与火、迎来光与电"成为现实；GB2312 国标字库把 6763 个汉字编成整齐的区位矩阵。
你今天点亮的"中国"二字，走的正是这条路的第一步：**把方块字翻译成比特，再让比特替文明发光**。汉字信息化四十年，是"用自己的技术守护自己的文字"最生动的注脚。
