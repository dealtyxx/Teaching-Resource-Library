## 场景导入：40 个变量？不，一个数组

要统计 10 名同学的成绩，难道定义 `s1, s2, ..., s10` 十个变量？全校 4000 人呢？
**数组**一次解决：`int scores[10]` 在内存中申请**连续的** 10×4=40 字节，用**下标**访问每一格：

- `scores[0]` 是第一个元素——**下标从 0 开始**，最后一个是 `scores[9]`；
- `scores[i]` 的地址 = 首地址 + i×4——下标本质是"偏移量"，这就是它从 0 数起的原因；
- 数组 + 循环 = 批量处理：模块三的遍历统计三大件（计数、累加、擂台），从此有了真正的用武之地。

## 素养与思政

平均分抹平了差异，最低分却指向一个需要帮助的具体的人。教育部要求"精准资助"，就是拒绝只看平均数的懒惰——你的程序里那行找最低分的擂台代码，对应着现实中一双发现掉队者的眼睛。
**统计的意义不是数字本身，而是数字背后的人。** 写代码的人若心里有人，冷冰冰的数组也会有温度。
