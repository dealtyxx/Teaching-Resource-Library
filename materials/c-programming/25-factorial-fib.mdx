## 场景导入：给一段代码起个名字

前四个模块里，所有逻辑都挤在 main 里。计算 5! 要写一个循环，计算 8! 再抄一遍？
**函数**让你给一段逻辑起名字、定接口，然后随处调用：

```c
long long fact(int n) { ... }   /* 定义:返回类型 名字(参数表) */
long long f = fact(5);          /* 调用:传入5,接回120 */
```

调用的本质是**控制流的跳转**：程序跳进函数体执行，遇到 `return` 带着结果跳回调用点。参数是入口，返回值是出口——函数就是一台"值的加工机"。

## 素养与思政

斐波那契数列的每一项都是前两项之和——**没有凭空出现的数字，正如没有凭空出现的成果**。从"两弹一星"到北斗组网，每一代工程师都在前人的 F(n−1) 和 F(n−2) 之上写出自己的 F(n)。
函数思维也是如此：把可靠的逻辑封装好、命好名，后人调用即可，不必重新发明。**科学的积累性，就藏在"调用"这个动作里。**
