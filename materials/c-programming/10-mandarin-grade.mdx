## 场景导入：先验资格，再定等级

普通话水平测试分**三级六等**：一级甲等（≥97）、一级乙等（≥92）、二级甲等（≥87）、二级乙等（≥80）、三级甲等（≥70）、三级乙等（≥60）。

看起来是一条 `else if` 长链？没错——但工程上还差一层：**如果输入的分数是 -5 或 120 呢？** 直接进等级链会得出荒谬的"未达三级乙等"或"一级甲等"。正确的骨架是**嵌套分支**：

```
外层 if：分数在 0~100 内吗？
 ├─ 否 → 报错，拒绝鉴定
 └─ 是 → 内层 else-if 链：从高到低逐级比对
```

外层管"资格"，内层管"业务"——这是所有输入处理程序的通用模式。

int main(void) {
    float score = 101.0f;
    if (score < 0 || score > 100) {

        if (score >= 97)      printf("一级甲等\\n");
        else if (score >= 92) printf("一级乙等\\n");
        else                  printf("二级及以下\\n");
    }
    return 0;
}`}
  steps={[

    { line: 5, desc: '进入拒绝分支。注意：内层的整条 else-if 链（第 8~10 行）被整体跳过。', out: '输入无效' },
    { line: 12, desc: 'return 0。嵌套结构里，外层判假的部分，内层代码一行都不会碰。' },
  ]}
/>

> 注意 `||`（逻辑或）的短路方向与 `&&` 相反：**遇真即停**。`score < 0 || score > 100` 中若 score=-5，第一个条件为真，第二个不再求值。

## 素养与思政

全国普通话普及率已超过 80%，这是世界语言史上罕见的推广成就。统一的语言让新疆的棉农能和广东的客商直接谈生意，让凉山的孩子能通过直播看见更大的世界。
等级标准的意义不在"划分三六九等"，而在**给努力一个可丈量的阶梯**——就像你的代码：97 与 96.9 的边界必须清晰，进步的方向才清晰。
