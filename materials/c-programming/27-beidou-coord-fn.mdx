## 场景导入：同一段逻辑，你已经写过两遍了

第 3 章手写过 NMEA 坐标换算，第 6 章的实训又写了一遍——纬度一份、经度一份，逻辑完全相同。
这就是**封装**要消灭的"复制粘贴式复用"：

```c
double nmea_to_deg(double raw);   /* 封装一次 */
nmea_to_deg(lat);                 /* 调用 N 次 */
nmea_to_deg(lon);
```

封装的关键是**参数传递**的机制——C 语言是**值传递**（pass by value）：调用时把实参的**值拷贝**给形参，函数内部操作的是副本。两次调用传入不同的值，同一份代码就产出不同的结果——这就是复用的原理。

## VibeCoding 三段迭代提示

1. **手写基础版**：封装 `nmea_to_deg` 并用它换算一组北京坐标（纬度+经度各调用一次）。体会"逻辑只写一遍"。
2. **AI 优化进阶版**：让 AI 增加方向参数 `nmea_to_deg(double raw, char dir)`（S/W 为负）。审查参数顺序设计：值在前、修饰在后是否更顺手？它的非法 dir 处理返回什么？
3. **信创加固定稿版**：给函数写清"契约注释"（输入范围/输出范围/错误约定），做成可被同学直接调用的 `.h + .c` 工具对（第 8 章多文件的预演）；对比第 3 章信创版，思考哪些防护应该放进函数、哪些留给调用者。

## 素养与思政

北斗系统建成后向全球用户**免费开放**基本导航服务——定位精度、接口协议（ICD 文件）公开发布，全球任何厂商按接口即可接入。这是大国工程的胸怀，也是"封装与接口"的最高示范：**把复杂留给自己，把简单交给世界**。
你封装的每个工具函数也是一次微型的"开放服务"：接口清晰、文档完备、行为可靠，让同伴调用时不必了解内部实现——工程师的专业与善意，都写在函数签名里。
