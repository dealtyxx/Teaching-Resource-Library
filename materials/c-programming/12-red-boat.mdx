## 场景导入：让程序学会"重复"

模块二让程序学会了"选择"，这个模块让它学会"重复"。
打印一面 5 行的帆，难道要写 5 条 printf？如果帆高改成 50 行呢？**循环结构**用三要素解决一切重复：**初始化、条件、更新**：

```c
for (int i = 1; i <= 5; i++) { ... }
//   ①初始化    ②条件     ③更新
```

而画二维图案需要**嵌套循环**：外层循环走"行"，内层循环走"列"。我们的第一幅作品，是嘉兴南湖那条小船——1921 年，中国共产党第一次全国代表大会在船上完成最后议程。

> **关键直觉**：内层循环变量 `j` 在外层每一圈都会**重新初始化**。很多初学者的图案错乱，都源于误以为 j 会"接着上次数"。

## VibeCoding 三段迭代提示

1. **手写基础版**：先徒手写"直角三角形"（i 行打 i 颗星），再挑战"等腰三角形"（先打空格再打星）。规律：第 i 行 = (h−i) 个空格 + (2i−1) 颗星。
2. **AI 优化进阶版**：让 AI 把你的三角形改造成完整红船（帆+桅+船体+水波）。审查它的循环边界：第 0 行还是第 1 行开始？`<` 还是 `<=`？差一行，船就"漏水"。
3. **信创加固定稿版**：帆高、船宽全部宏定义；加入参数校验（帆高 1~20 之外拒绝）；思考若用户输入 10 万，程序会怎样——循环次数也需要设防。

## 素养与思政

1921 年夏天，十几名平均年龄 28 岁的青年，在南湖的小船上通过了党的第一个纲领。百年之后，"红船精神"被概括为：开天辟地、敢为人先的**首创精神**。
你今天写下的第一个嵌套循环，画的正是这条船。编程学习也是一次远航——从 3 行星号开始，终点是能够自主可控的万行工程。**每一段伟大的航程，都始于第一次起锚。**
