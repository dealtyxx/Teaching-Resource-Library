## 场景导入：销量榜是怎么排出来的

店铺后台有 8 件商品的销量，要按**从高到低**生成排行榜。这是你的第一个**算法**——冒泡排序：

- **两两比较**相邻元素，逆序就**交换**；
- 一趟下来，最小值必然"沉底"（升序则最大值"冒顶"，故名冒泡）；
- N 个元素最多 N−1 趟，每趟的比较范围缩短一格（沉底的不用再比）。

核心零件是**三步交换**——两个变量交换值必须借助第三者：

```c
int tmp = a[j];       /* ① 先把 a[j] 存起来 */
a[j] = a[j + 1];      /* ② a[j+1] 盖过来 */
a[j + 1] = tmp;       /* ③ 存的旧值放回去 */
```

写成 `a[j] = a[j+1]; a[j+1] = a[j];` 会怎样？第一步就把 a[j] 弄丢了——两句执行完，两格是同一个值。

## 素养与思政

电商排行榜、热搜榜、信用评分——排序算法每天都在替社会"排座次"。算法错一行，排行就失真：把 `s[j] < s[j+1]` 写反，冠军直接变末位。
2021 年施行的《关于加强互联网信息服务算法综合治理的指导意见》要求算法"公开透明、公平公正"。**榜单的公信力，是从每一次两两比较的正确性里长出来的**——这是排序教给我们的第一课：秩序无小事。
