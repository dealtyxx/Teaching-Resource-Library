## 场景导入：模块七毕业设计

校园歌手大赛：4 名选手、5 位评委。规则耳熟能详——**去掉一个最高分，去掉一个最低分，取平均**。
这是模块七的合龙工程，构件全部来自你的武器库：

- **结构体套数组**：`Singer` 里装 `float scores[5]`——一名选手绑定一组评分；
- **去高去低** = 项目 14 的擂台法（找 max/min）+ 项目 15 的异常剔除思想；
- **排名** = 项目 38 的结构体排序；
- 数学等价小抓手：不必真删除两个元素，`(sum - max - min) / (n - 2)` 一步到位。

float trimmed_mean(const float s[], int n) {

## 素养与思政

"去掉一个最高分，去掉一个最低分"家喻户晓，它的学名是**截尾均值**（trimmed mean）——统计学对抗异常值的经典手段。体操、跳水的国际裁判规则用它，评标采购用它，你的代码今天也用它。
**程序正义的意思是：公平不依赖每个评委都完美，而由规则结构性地保障。** 把规则写成代码，代码就成了公平的执行者——这是"用技术守护公正"最朴素的样本，也是你从语法学习者变成规则构建者的时刻。
