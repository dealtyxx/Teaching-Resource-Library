## 场景导入：程序死了，数据怎么活下来

第 1 章的内存布局表写着残酷事实：**RAM 断电即失**。你算出的每个结果、录入的每条记录，程序一退出全部灰飞烟灭。
**文件**是数据的"诺亚方舟"——存进磁盘/Flash，程序重启、设备断电都不怕。C 的文件操作是雷打不动的三部曲：

```c
FILE *fp = fopen("log.txt", "a");   /* ① 开:拿句柄 */
if (fp == NULL) return -1;          /*    必查失败! */
fprintf(fp, "系统启动\n");           /* ② 写:像printf多个fp */
fclose(fp);                          /* ③ 关:缓冲落盘 */
```

模式字符串是第一考点：`"r"` 读、`"w"` 写（**清空重写！**）、`"a"` 追加。日志永远用 `"a"`——用 `"w"` 写日志，是把史官的竹简烧了重刻。

## VibeCoding 三段迭代提示

1. **手写基础版**：写一个程序每次运行追加一行"第N次启动"，运行三次后用记事本打开 log.txt 验收。体会"程序会退出，文件在生长"。
2. **AI 优化进阶版**：让 AI 加上时间戳（`time.h` 的 time/localtime/strftime）。审查它 fopen 失败分支写了没——AI 常跳过这步。
3. **信创加固定稿版**：检查 fprintf 返回值（磁盘满时写入也会失败）；关键日志写完即 `fflush`；思考嵌入式 Flash 的写入寿命（约 10 万次擦写）——"每秒写一条"的日志一年写多少次？该攒批再写吗？

## 素养与思政

司马迁著《史记》"究天人之际，通古今之变"，靠的是史官世家数百年不断的记录。敦煌藏经洞的一卷卷文书，让千年前的日常今日可考。**文明的连续性建立在记录的连续性上。**
系统亦然：飞行有黑匣子，手术有病历，服务器有日志——出了问题，记录就是唯一的时光机。你今天写下的第一行 fprintf，是工程师版的"史官第一笔"：**如实、及时、不可篡改**。
