## 章节定位

本案例对应「1.1 Python 开发环境搭建与使用」。你要学会的技术动作很朴素：装好 Python、用 `venv` 建虚拟环境、用 `pip` 装库、按 PEP 8 写规范代码。但这套工具链背后站着一个更大的东西——**开源**。一行 `pip install requests`，你就免费站上了全球数百万开发者的肩膀。我们把「怎么装环境」和「为什么整个生态愿意免费共享」放在一起讲：前者是技能，后者是精神与责任。

## 背景导入：从 1989 圣诞节到 TIOBE 榜首

1989 年圣诞节，荷兰程序员 Guido van Rossum 在假期里动手写了一门新语言，目标只有六个字——**简洁、优雅、易读**。名字取自他喜欢的英国喜剧团体 Monty Python，和蟒蛇并无关系。谁也没想到，这个圣诞节的个人项目，三十多年后会成为 AI 时代最受欢迎的编程语言。

在很长一段时间里，Guido 被社区称为 **BDFL（Benevolent Dictator For Life，仁慈的终身独裁者）**：技术方向上他一锤定音，避免社区无休止内耗；但代码贡献对全世界开放，谁都能提交改进。集中决策保证方向不跑偏，开放贡献汇聚众人智慧——这种"集中 + 开放"的治理智慧，与中国"集中力量办大事、广纳贤才"的理念遥相呼应。

<CaseFileCard name="Guido 卸任 BDFL：一次制度化的权力交接" year={2018} tag="社区治理" verdict="Python 改由五人「指导委员会」选举治理，项目平稳过渡，未因创始人退出而分裂">
2018 年，围绕一项语法提案的激烈争论后，Guido 主动宣布卸任 BDFL，不再担任最终仲裁者。他没有指定接班人，而是推动社区投票，把个人权威转化为<strong>制度化的委员会治理</strong>。一个健康的开源项目，不应依赖某一个人永远在场——主动交权，本身就是对项目负责。
</CaseFileCard>

Python 的崛起，靠的从来不是某个公司，而是**开源生态**：Python 包索引 PyPI 上已有超过 40 万个开源库，NumPy、Pandas、Django、Flask、Scrapy 等明星项目让"造轮子"变成"取轮子"。中国是 Python 使用量第二大的国家，也早已从"使用者"变成"贡献者"——这正是下面两个实验要让你亲眼看到的。

## 技术讲解

先看一段规范的 Python 代码。它不做真实网络请求，只用来演示 PEP 8 的职业素养：类名用大驼峰、函数与变量用小写加下划线（snake_case）、常量全大写、每个公开函数都写文档字符串与类型注解。

```python
from typing import Optional

MAX_RETRIES = 3               # 常量：大写 + 下划线


class NetworkClient:          # 类名：大驼峰 CapWords
    """一个最小可读的网络客户端示例。"""

    def send_request(self, url: str, timeout: int = 10) -> Optional[dict]:
        """发送请求并返回解析后的数据。

        Args:
            url (str): 目标资源地址。
            timeout (int): 超时时间（秒），默认 10。

        Returns:
            Optional[dict]: 成功返回字典，失败返回 None。
        """
        ...
```

规范不是形式主义：`snake_case` 让人一眼看出这是变量还是类，文档字符串让队友不必读实现就能调用你的函数。**好的注释和命名，是对他人时间的尊重。**

最后，在下面的在线环境里真正跑一段 Python：先用一行 `import this` 请出《Python 之禅》，再动手写一个 PEP 8 命名检查器，用正则判断若干变量名是否符合 snake_case。改改 `names` 列表里的名字，看输出的 ✅ / ❌ 怎么变。

<PyPlayground
  client:visible
  title="《Python 之禅》与 PEP 8 命名检查器"

  code={`import this          # 请出《Python 之禅》(The Zen of Python)
import re

print("\\n—— PEP 8 命名检查器 (snake_case) ——")
# snake_case：小写字母/数字/下划线，且不以数字开头
pattern = re.compile(r"^[a-z_][a-z0-9_]*$")
names = ["send_request", "maxRetries", "user_id",
         "APIKey", "http_client", "2fa_token", "data"]

for name in names:
    ok = bool(pattern.match(name))
    mark = "✅" if ok else "❌"
    tip = "" if ok else "  → 建议改为 snake_case"
    print(f"{mark} {name}{tip}")`}

## 思政引导

<DimCard dim="创新思维" title="从个人项目到全球生态的治理智慧">
<ul>
<li>Guido 的起点只是一个圣诞假期的个人项目——<strong>伟大的创新常常始于一件"想把事情做得更优雅"的小事</strong>。</li>
<li>BDFL 模式是一种治理创新：集中决策避免内耗、保证技术方向，开放贡献汇聚全球智慧。</li>
<li>2018 年主动卸任、转为委员会治理，是更高级的创新——<strong>把个人权威制度化，让项目不依赖任何一个人</strong>。</li>
</ul>
</DimCard>

<DimCard dim="科学精神" title="透明、可审查、可复现">
<ul>
<li>开源意味着代码公开、接受全世界审查，漏洞与劣质实现无处藏身——<strong>透明是质量与安全的前提</strong>。</li>
<li>PEP 8 规范、文档字符串、类型注解，本质是让代码严谨、可读、可维护，这是工程上的科学态度。</li>
<li><code>requirements.txt</code> 冻结依赖，让实验环境可复现——<strong>可复现性是科学，也是工程的底线</strong>。</li>
</ul>
</DimCard>
