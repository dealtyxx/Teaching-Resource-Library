## 背景导入：谁控制着互联网？

1969 年，美国国防部的 ARPANET 项目孕育了 TCP/IP 协议——今天全球互联网的通用语言。技术无国界，但技术的**控制权**从一开始就有明确的归属：

- **DNS 根服务器**：IPv4 时代全球仅 13 台，其中 10 台在美国，瑞典、荷兰、日本各 1 台；
- **IPv4 地址分配**：美国占全球 50% 以上；
- **ICANN**（互联网名称与数字地址分配机构）：长期受美国政府监管；
- 2016 年，美国拒绝将「.中国」域名根服务器部署权交给中国——理论上，控制根服务器的一方可以在解析链路上切断任何一个国家的互联网。

面对挑战，中国的应对是体系化的：

- **IPv6 规模部署**：2023 年中国 IPv6 地址数量全球第一，摆脱 IPv4 地址不足的限制；
- **根服务器镜像**：在国内部署多台根镜像，提升解析速度、降低对外依赖；
- **国产网络设备**：华为、中兴等逐步替代思科；5G 标准制定中国占主导，华为主推的 Polar 码被采纳为 5G 控制信道编码；
- **雪人计划（2016 年）**：中国主导的 IPv6 根服务器工程，在全球部署 25 台根服务器，其中中国 1 台主根、3 台辅根——打破根服务器垄断。

<Callout icon="🔬" tone="blue" title="为什么偏偏是三次？">
两次握手不够——服务器无法确认自己发出的应答已被对方收到；四次建连又浪费——SYN 与 ACK 可以合并在同一个报文里。三次，是让「双方都确认彼此收发能力」的最小次数。挥手要四次，则是因为 TCP 全双工，两个方向的关闭必须分别确认。协议设计的每一处取舍，都是工程师精益求精的科学精神。
</Callout>

## 技术讲解

TCP/IP 协议栈分为四层，Python 的 socket 模块正是对它的封装：

- **应用层**：HTTP、FTP、SMTP、DNS——对应 requests、smtplib 等库；
- **传输层**：TCP（可靠）与 UDP（快速）——对应 `socket.SOCK_STREAM` 与 `socket.SOCK_DGRAM`；
- **网络层**：IP 地址与路由——对应 `socket.AF_INET`（IPv4）与 `socket.AF_INET6`（IPv6）；
- **链路层**：以太网、WiFi——由操作系统与网卡处理，Python 一般不直接操作。

本章核心代码：多线程 TCP Echo 服务器与客户端（真实 socket 程序，请在本机 Python 环境中运行）：

```python
import socket
import threading

def handle_client(client_socket, client_address):
    """处理单个客户端：循环回显消息"""
    try:
        print(f"🔗 客户端连接: {client_address}")
        while True:
            data = client_socket.recv(1024)
            if not data:                      # 对方关闭连接
                break
            message = data.decode('utf8')
            print(f"📨 [{client_address}] {message}")
            client_socket.sendall(f"Echo: {message}".encode('utf8'))
    finally:
        client_socket.close()
        print(f"🔌 [{client_address}] 断开连接")

def threaded_tcp_server(host='0.0.0.0', port=8888):
    """多线程 TCP 服务器：并发服务多个客户端"""
    server_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    server_socket.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    server_socket.bind((host, port))
    server_socket.listen(5)
    print(f"✅ 多线程TCP服务器启动，监听 {host}:{port}")
    try:
        while True:
            client_socket, client_address = server_socket.accept()
            t = threading.Thread(target=handle_client,
                                 args=(client_socket, client_address))
            t.daemon = True                   # 主线程退出时一并结束
            t.start()
    except KeyboardInterrupt:
        print("⏹️ 服务器关闭")
    finally:
        server_socket.close()

def tcp_client(host='127.0.0.1', port=8888, message="Hello, Server!"):
    """TCP 客户端"""
    client_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    try:
        client_socket.connect((host, port))   # 三次握手在这一行完成
        client_socket.sendall(message.encode('utf8'))
        response = client_socket.recv(1024).decode('utf8')
        print(f"📥 收到响应: {response}")
    finally:
        client_socket.close()                 # 从这里开始四次挥手
```
