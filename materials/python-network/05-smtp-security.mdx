## 章节定位

本案例服务于第 5 章「电子邮件客户端编程」5.2 节 SMTP 发送电子邮件实战。SMTP 协议诞生于网络上只有互信科研机构的年代,协议本身既无加密也无发件人认证;在 `smtplib` 里,明文与加密只差一行代码,却是隐私「裸奔」与受保护的分水岭。学习发邮件的同时,我们把 SSL/TLS 加密、SPF/DKIM/DMARC 认证与反垃圾邮件技术,同社会责任、科学精神的养成结合起来——会发邮件只是技能,负责任地发邮件才是职业素养。

## 技术讲解

`smtplib` 提供三种发送方式,安全性天差地别:

| 端口 | 连接方式 | 安全性 |
| --- | --- | --- |
| 25 | `SMTP` 明文连接 | ⚠️ 无加密,可被窃听、篡改 |
| 465 | `SMTP_SSL` 连接即加密 | ✅ 全程 TLS 保护(推荐) |
| 587 | `SMTP` 连接后 `starttls()` 升级 | ✅ 升级握手后受保护 |

核心代码对比如下——注意密码管理与批量发送的两处细节:

```python
import smtplib, ssl, os, time
from email.mime.text import MIMEText

sender = os.environ.get('EMAIL_SENDER')      # ⑴ 账号与密码来自环境变量
password = os.environ.get('EMAIL_PASSWORD')  #    绝不硬编码进源代码!

# ⑵ 明文发送(25端口)——⚠️ 不推荐:账号、密码、正文在链路上"裸奔"
def send_plain(msg):
    server = smtplib.SMTP('smtp.example.com', 25)   # 无任何加密
    server.login(sender, password)                  # 密码明文传输!
    server.sendmail(sender, msg['To'], msg.as_string())
    server.quit()

# ⑶ SSL加密(465端口)——✅ 推荐:连接建立即加密,全程受保护
def send_ssl(msg):
    context = ssl.create_default_context()
    with smtplib.SMTP_SSL('smtp.example.com', 465, context=context) as server:
        server.login(sender, password)
        server.send_message(msg)

# ⑷ STARTTLS(587端口)——先建普通连接,再升级为TLS加密
def send_starttls(msg):
    server = smtplib.SMTP('smtp.example.com', 587)
    server.starttls()                # 升级为加密通道
    server.login(sender, password)
    server.send_message(msg)
    server.quit()

# ⑸ 批量发送——限频 + 个性化,不做垃圾邮件制造者
def send_bulk(receivers):
    context = ssl.create_default_context()
    with smtplib.SMTP_SSL('smtp.example.com', 465, context=context) as server:
        server.login(sender, password)
        for receiver in receivers:
            msg = MIMEText(f'您好,{receiver.split("@")[0]}!', 'plain', 'utf-8')
            msg['From'], msg['To'] = sender, receiver
            msg['Subject'] = '重要通知(含退订方式)'
            server.send_message(msg)
            time.sleep(2)            # 每封间隔2秒,避免被判为垃圾邮件
```

## 思政引导

技术是中性的,`smtplib` 既能发会议通知,也能发百万封垃圾邮件——分界线在写代码的人心里。

<DimCard dim="社会责任" title="不做垃圾邮件的制造者">
  <ul>
    <li>垃圾邮件占全球邮件流量约 70%:浪费网络带宽资源、干扰正常工作生活、传播诈骗与不良信息。</li>
    <li>开发者责任三条:不开发垃圾邮件发送工具;为批量脚本添加发送频率限制(如每封间隔 2 秒);提供退订功能(Unsubscribe)。</li>
    <li>尊重收件人的注意力,就是尊重公共网络资源——你的一行 for 循环,可能是别人收件箱里的一场灾难。</li>
  </ul>
</DimCard>

<DimCard dim="科学精神" title="安全感来自可验证的密码学,而非口头承诺">
  <ul>
    <li>SSL/TLS 保护邮件传输隐私,SPF/DKIM 用密码学签名防伪造,DMARC 给出综合认证策略——每一层防线都建立在可证明的数学之上。</li>
    <li>安全意识三件套:不在代码中硬编码密码;使用环境变量或密钥管理服务;定期更换密码。</li>
    <li>演示明文风险不是制造恐慌:威胁可以被技术手段有效防范,严谨求证、以技术对抗风险,正是科学态度。</li>
  </ul>
</DimCard>
