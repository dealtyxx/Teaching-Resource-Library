## 背景导入：数据是新时代的石油，但谁有权开采

课堂从 Cambridge Analytica 丑闻纪录片片段开始。有人说数据是新时代的石油，可是石油埋在无主的地下，数据却连着一个个具体的人：他的电话、他的行踪、他的病历。过去十年，四起真实案件把「谁有权开采」这个问题反复推到公众面前。

## 技术讲解

合规爬虫与普通爬虫的差别，从第一行请求头就开始了：表明身份、留下联系方式，而不是伪装成浏览器潜入。下面是本案例的核心代码——一个把隐私保护内建到每个方法里的爬虫类。

```python
import requests
from bs4 import BeautifulSoup
import hashlib

class PrivacyAwareCrawler:
    """隐私保护爬虫：只取公开数据，敏感字段一律脱敏"""

    def __init__(self):
        self.session = requests.Session()
        self.session.headers.update({
            'User-Agent': 'EthicalCrawler/1.0 (Educational; Contact: xxx@edu.cn)'
        })

    def anonymize_phone(self, phone):
        """电话号码脱敏：138****5678"""
        if len(phone) == 11:
            return phone[:3] + '****' + phone[7:]
        return '***'

    def anonymize_email(self, email):
        """邮箱脱敏：z******n@example.com"""
        parts = email.split('@')
        if len(parts) == 2 and len(parts[0]) > 2:
            u = parts[0]
            return u[0] + '*' * (len(u) - 2) + u[-1] + '@' + parts[1]
        return '***'

    def hash_identifier(self, identifier):
        """不可逆哈希：用于统计去重，不存储原文"""
        return hashlib.sha256(identifier.encode()).hexdigest()

    def fetch_public_data(self, url):
        """仅抓取公开展示的内容"""
        response = self.session.get(url, timeout=10)
        soup = BeautifulSoup(response.text, 'html.parser')
        articles = []
        for item in soup.find_all('article'):
            articles.append({
                'title': item.find('h2').get_text(),
                'publish_date': item.find('time').get_text(),
                # 不抓作者联系方式，不抓评论者 IP
            })
        return articles

    def respect_privacy_settings(self, user_data):
        """尊重用户隐私设置：非公开信息不碰"""
        if not user_data.get('is_public', False):
            return None
        return {
            'username': user_data.get('username'),
            'bio': user_data.get('bio'),
            # 不包含 email、phone 等私密字段
        }
```

## 思政引导

<DimCard dim="法治意识" title="合规不是选择题">
  <ul>
    <li>《个人信息保护法》确立四项原则：知情同意、最小必要、公开透明、数据安全——每一项都能落成代码里的一个函数。</li>
    <li>法律责任是阶梯式的：脉脉案是民事赔偿，房产中介案是刑事拘留，Facebook 案是 50 亿美元罚款——违法成本只会越来越高。</li>
    <li>敏感信息（医疗、金融）依据第26条须单独同意；违法处理个人信息依据第66条最高可罚 5000 万元或上一年度营业额 5%。</li>
  </ul>
</DimCard>

<DimCard dim="职业伦理" title="数据采集三问">
  <ul>
    <li>每次按下运行键之前先问三句：我有权采集这些数据吗（合法性）？用户知情并同意了吗（知情权）？我只采集必要的数据吗（最小化）？</li>
    <li>技术伦理三不原则：不因技术可行就采集一切，不因数据公开就随意使用，不因缺乏监管就心存侥幸。</li>
    <li>工程师的职业尊严，体现在爬虫 User-Agent 里那行敢于署名的联系方式上。</li>
  </ul>
</DimCard>

<DimCard dim="社会责任" title="泄露的数据会伤人">
  <ul>
    <li>数据泄露的下游是具体的伤害：电信诈骗精准掌握受害人信息、身份盗用冒名贷款、行踪泄露危及人身安全。</li>
    <li>弱势群体需要额外保护：14 岁以下儿童信息须监护人同意，老年人信息易被诈骗利用，患者的医疗隐私特别敏感。</li>
    <li>你写的每一行采集代码，都在决定这些风险是扩大还是收敛。</li>
  </ul>
</DimCard>

<DimCard dim="人文素养" title="换位思考与技术向善">
  <ul>
    <li>换位想一想：如果你的电话被泄露，每天接到 10 个骚扰电话；如果健康信息被公开，求职时遭遇歧视；如果行踪被跟踪，人身安全受到威胁——数据背后是人。</li>
    <li>技术向善有真实的路径：爬虫可以服务疫情数据汇总、环境监测等公益事业，但前提永远是不侵犯隐私。</li>
    <li>合法使用公开数据是正当的——学会合规，不是放弃技术，而是让技术走得更远。</li>
  </ul>
</DimCard>
