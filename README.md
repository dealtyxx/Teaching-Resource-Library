# 离散数学课程资源库 · 课程思政

> 湖南信息学院 · 计算机科学与工程 — 将离散数学的严谨数理训练与家国情怀、科学精神、创新意识相融合的交互式教学资源库。

## 项目简介

以红金玻璃化交互页面串联 **11 章知识体系**，把计数、集合、关系、逻辑、图论与代数系统转化为可操作、可推理、可迁移的学习案例。每个知识单元按 **三阶层次** 组织：

| 层次 | 定位 | 适用场景 |
|------|------|----------|
| **基础层** | 建立概念直觉，完成对象抽取、符号化与第一步建模 | 课前预习、课堂导入 |
| **进阶层** | 围绕核心算法、推理链与可视化反馈展开互动演示 | 课堂讲解、动手探索 |
| **拓展层** | 迁移到工程系统、文化数字化、智能应用与综合案例 | 项目实践、思政延展 |

**规模**：11 章 · 122 个知识单元 · 367 个三阶案例页 · 6 大课程思政核心理念。

> 计数口径：121 个知识单元各有 基础 / 进阶 / 拓展 三页（其中 9.6 同态与同构 目录下含「层次体系」「映射体系」两个单元）；3.4 二元关系的运算 按 整体综合 / 逆运算 / 复合运算 / 幂运算 4 个子页组织。合计 121 × 3 + 4 = 367 页。

## 主要特性

- **三阶递进教学**：每个知识单元配 `X-basic.html`（基础层）/ `X.html`（进阶层）/ `X-extend.html`（拓展层）三个页面，难度与思政深度逐级递进；页面内 `window.SECTION_META.layers` 描述三阶结构。
- **主页直达三阶**：主页每个知识单元条目右侧有 基础 ●○○ / 进阶 ●●○ / 拓展 ●●● 三枚层级入口；11 个章节模块均有 `#chapter1`…`#chapter11` 锚点，章节页的「返回」链接可直接定位到所属章节；搜索结果同样保留层级入口。
- **交互可视化**：图论最短路、欧拉/哈密顿图、群与同构、纠错码等以 SVG/Canvas 实时演示。
- **课程思政融入**：两弹一星、北斗导航、湖湘织锦、非遗数字化等本土案例贯穿数理推理。
- **数学公式渲染**：MathJax 按需懒加载（使用站内本地副本，不依赖外部 CDN），无公式页面零开销；纯文本上下标自动归一化。
- **加载性能**：Google Fonts 采用非阻塞加载，字体未到达时先以系统字体显示，不阻塞首屏；根目录 `.nojekyll` 关闭 Jekyll 处理，GitHub Pages 原样发布全部文件。
- **AI 学习助手**：内置悬浮坞式助手（BYO-key，密钥仅存浏览器 localStorage，直连大模型，不经任何第三方服务器）。
- **响应式自适配**：内容感知的整页缩放，兼顾不同分辨率首屏观感；移动端独立响应式。
- **社交分享就绪**：全站 Open Graph / Twitter Card 元数据 + 品牌分享封面，微信/社交分享显示标题与缩略图。

```
Teaching-Resource-Library/
├─ .nojekyll                  # 关闭 GitHub Pages 的 Jekyll 处理
├─ README.md                  # 本说明
├─ index.html                 # 仓库根入口，跳转到 Discrete_Mathematics/
└─ Discrete_Mathematics/
   ├─ index.html              # 课程资源库主页（章节导航 / 三阶层级入口 / 搜索 / 思政理念）
   ├─ README.md               # 课程资源库说明（与仓库根 README 同步）
   ├─ 1计数基础与数论基础/ … 11环、域、格和布尔代数/
   │                          # 11 章；每个知识单元一个目录，内含 X-basic.html / X.html / X-extend.html
   ├─ shared/                 # 全站共享资源
   │  ├─ STYLE-GUIDE.md       # 全站统一规范（命名、外壳、配色、三阶结构等）
   │  ├─ README.md            # 共享框架（学习助手 / 分层进阶 / 能力雷达）说明
   │  ├─ discrete-ui.css      # 统一视觉与组件样式
   │  ├─ ai-tutor.js          # 学习助手（BYO-key）
   │  ├─ mathjax-auto.js      # MathJax 按需加载 + 整页自适配缩放
   │  ├─ auto-superscript.js  # 纯文本上/下标自动渲染
   │  ├─ favicon.svg          # 站点图标（图节点 motif）
   │  └─ og-cover.png         # 社交分享封面（1200×630）
   │                          # （另含 MathJax 本地副本，供公式离线渲染）
   └─ tools/                  # 维护脚本（Python 3）
      ├─ dm_normalize.py      # 批量规范化章节页外壳（返回链接、页脚、标题、字体加载等）
      └─ dm_check.py          # 全站一致性检查（链接、SECTION_META、三阶文件完整性等）
```

## 技术栈

纯静态站点：HTML5 + 原生 CSS/JavaScript，无构建步骤、无重型依赖。公式渲染用 MathJax 3（站内本地副本、按需加载），字体用 Google Fonts（非阻塞加载），访问统计用不蒜子。可直接部署到 GitHub Pages 或任意静态服务器。
